# 이동에 따라 코너 시작 거리 후보 갱신 · 2026-11-11

Imola 새 영상 1,200묶음을 합쳐 Magione, Laguna Seca, Zandvoort, Mugello, Imola의 저장 영상 6,087묶음을 개발 비교에 사용했다. 기존 T4/T5의 화면 사분면 활동과 두 시점 차분을 읽고, 원본·반전 입력에서 공통 성분과 좌우 차이 성분을 만들었다. 판독기는 각 방향별로 접근 아님과 4–8·8–12·12–16·16–20m의 다섯 상태를 읽었다. 학습과 채점에만 트랙 정답을 사용했다. [재생 코드](../runs/vision-corner-distance-belief-20261111-01/replay.py)

연속 입력에서는 이전 거리 후보를 몸 상대 이동만큼 가까운 쪽으로 옮겼다. 겹치는 구간은 비례해 나누고, 4m 아래로 이동한 확률은 버렸다. 새 영상은 이전 영상이 지지한 거리 구간에 더 큰 가중치를 받는다. 프레임이나 세션 세대가 끊기거나 상대 이동이 없을 때 이전 거리 후보를 사용하지 않았다. 좌우 확률은 각 방향 안에서만 이동한다. 정지, 2m 및 4m 이동, 접근 구간 이탈과 확률 보존을 확인했다.

## 서킷 제외 판독

한 서킷을 평가에서 빼고, 나머지 네 서킷의 내부 제외 비교에서 오경보 한도와 기존 우·결합 적중을 지키는 문턱을 고른 뒤 제외 서킷을 채점했다. 한 프레임만 사용하는 조건, 이전 거리 후보를 이동시키는 조건, 같은 방향으로 이미 울린 경보의 거리까지 갱신하는 조건을 각각 비교했다. 다섯 서킷 모두 새 출력이 없는 문턱 1.0이 선택됐다.

이미 본 결과에 여러 문턱을 대입한 진단에서는 Mugello가 0.99에서 좌 4→5, 우 1→2, 결합 2개 유지, 직선·범위 밖 5→12개였다. 같은 문턱에서 Laguna Seca는 오경보 12→34, Imola는 45→53개였다. Imola 문턱을 0.95로 낮추면 좌 14→15, 우 5→6, 결합 15→16개였고 오경보는 45→66개였다. 공통 판독기로 채택하지 않았다. [서킷별 문턱과 채점](../runs/vision-corner-distance-belief-20261111-01/result.json)

## 기존 경보에서 거리만 갱신

연속 프레임에서 같은 방향으로 이미 경보가 나왔을 때, 직전 거리에 차량 이동을 반영해 현재 거리의 변화량을 제한했다. 거리가 늘어날 때만 적용하는 조건과 항상 적용하는 조건을 비교했다. 기존 우·결합 적중과 안정 예고 수를 학습용 서킷에서 유지하도록 제한량을 골랐다.

Magione를 제외하고 고른 1m 제한을 Magione에서 평가하니 공통 62쌍의 거리 변화 오차는 0.293→0.241m, 실제로 접근 중 예고 거리가 증가한 경우는 16→14쌍이었다. 방향·거리 ±5m 동시 적중은 71→67개였다. 나머지 네 서킷을 각각 제외하면 제한량 0m가 선택됐다. 경보 방향과 직선·범위 밖 오경보는 모든 거리만 갱신한 비교에서 같았다.
