# GitHub 코드 관리 인계 — 2026-11-03

사용자 요청에 따라 개인 저장소 `HeIIowrld/fly-driver`의 `main`을 소스·학습 도구·설정·검사의 공유 기준으로 사용한다. 커밋 작성자는 로컬에 등록된 사용자 Git 신원이다. 팀 저장소 `YCC-GitHub/fly-driver`는 이번 직접 반영 대상이 아니다.

## 이번 공유 범위

`src/`, `scripts/`, `tests/`, `configs/`, `docs/`, `integrations/`, `runtime-scripts/`와 패키지/설치/협업 문서, Git 제외 규칙 및 오프라인 CI를 공유한다. 로컬 작업 파일의 스냅샷을 만들며 과거 로컬 Git 이력 전체를 외부에 올리지 않는다. 로컬의 기존 브랜치·index·작업 파일은 초기화하지 않는다.

`_related_research/`의 약5.4GB 산출물, `runs/`의 실행 결과, 외부 자료/가중치·NPZ, 게임 바이너리/트랙, 자격 증명은 이번 Git 공유에 포함하지 않는다. 자료는 삭제하지 않고 기존 저장소/참조표를 유지한다. 문서의 과거 실행 경로는 원본 증거 위치를 뜻하며 GitHub에 원본이 포함됐다는 의미는 아니다. `configs/`에는 과거 실험 설정/증거 참조도 있으므로 모든 항목이 새 clone에서 즉시 실행 가능한 기본 설정은 아니다.

## 검증

- 별도 Python 3.12 환경에서 그래프·레이싱 목표·카메라 정합 검사 15개와 단일 비행 회로의 합성 검사 19개: 총34개 통과.
- 선택한 Python 소스 전체 AST 구문 검사. 단일 파일 최대 약1.2MB, 공유 파일 합계 약29MB.
- 선택 파일에서 고신뢰 비밀키/토큰 패턴과 문자열 자격 증명 할당 후보 검사: 후보0. 이 패턴 검사만으로 모든 비밀정보 부재를 수학적으로 보장하지 않는다.
- 전체 테스트·실제 학습 재현·AC 주행은 이번 변경에서 실행하지 않았다. CI는 위34개 오프라인 검사를 실행하며 새 주행 성과로 해석하지 않는다.

학습 진입점/미포함 준비물은 [CONTRIBUTING.md](../CONTRIBUTING.md)를 따른다. Git revision과 데이터/설정/전처리/checkpoint SHA를 함께 기록해야 한다. 최종 연구 완료 판단은 [대전제](PROJECT_CHARTER.md)와 [로드맵](ROADMAP.md)의 기전·운전 두 축을 따른다.

## 로컬 작업 폴더의 후속 Git 사용

현재 폴더에는 기존 연구 변경이 많이 남아 있어 사용자 작업을 보존하려고 원래 브랜치/index를 유지했다. 원격 `main`과 기존 로컬 브랜치의 이력이 다를 수 있으므로 무조건 pull/reset하거나 전체 add를 하지 않는다. 이번 공유 스냅샷·원격 commit·파일별 SHA·기존 index 보존 증거는 로컬 `runs/github-source-20261103/`에 기록한다. 팀원은 GitHub `main`에서 별도 clone으로 시작한다. 현재 NAS 폴더에서 개발할 때는 이 제약을 확인하고 변경 파일만 검토해 후속 커밋한다.
