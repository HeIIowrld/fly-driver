# 도로 쪽 경계와 혼동되는 표면 전환 · 2026-11-12

Silverstone 우회전 접근 13장의 원본 전방 영상에서 도로 쪽에 보이는 표면 전환을 다시 표시했다. 잔디·아스팔트 전환 3장과 어두운 띠가 있는 4장은 각각 6점으로 기록했다. 어두운 띠의 도로 쪽과 반대쪽을 구분했다. 나머지 6장은 포장 갓길의 끝을 확정할 수 없어서 보이는 물체나 포장 이음매만 표시했다. 위치의 불확실성은 약 1픽셀이며 한 번의 검토에 기반한다. 이 주석으로 실제 트랙 한계를 확정하거나 모델을 학습하지 않았다. ## 어느 선을 따라갔나

어두운 띠가 보이는 4장의 공통 영상 영역에서 기존 절댓값 대비 추적은 도로 쪽 전환 근처 34점, 양쪽 전환에서 벗어난 28점을 남겼다. 반대쪽 전환을 따라갔다고 분류된 점은 없었다. 원본과 겹쳐 보면 벗어난 경로는 아스팔트 안쪽으로 들어갔다. 이번에는 도로에서 바깥으로 밝기가 낮아질 때 점수가 커지도록 밝기 차의 부호를 살렸다. 색차, 시작점 조건과 추적 규칙은 같았다. 어두운 띠 4장에서는 도로 쪽 근처 40점을 남겼고, 주석한 24점 중 2px 이내로 따라간 점은 14→18개였다. 잔디 3장의 같은 지표는 8→13/18개였다. ## 영상에서 더 잘 보인 선을 거리로 바꾸면

어두운 띠 4장 중 두 추적과 두 투영 행이 모두 주석 범위에 들어온 19단면에서 수평 오차를 세 항으로 분해했다. 고정 평면이 고른 행에서 추적과 주석의 차이는 절댓값 중앙값 12.65→1.34px였다. 같은 주석 선 위에서 고정 평면의 행과 지도 투영의 행 사이 이동은 31.35px였고, 지도 투영 행에서 보이는 띠와 지도 경계 위치 사이에는 19.71px가 남았다. 후자는 주석된 표면 전환과 지도 경계의 위치 차이며, 둘이 같은 경계라는 보장이 없다. 기존 추적이 아스팔트 안쪽으로 벗어난 오차는 이 표본에서 다른 두 오차의 일부를 상쇄했다. 그래서 지도 경계의 가로 위치와 비교한 총오차는 3.19→11.40px로 늘었다. 각 단면에서 세 항의 합이 총오차와 일치하는지 검사했다. 지도와 렌더 위치는 이 진단에서만 사용했다. ## 전체 판독과 T4/T5

두 서킷의 기존 영상 2,400묶음에서 확인 문턱을 유지했고, 절댓값 대조군과 비교했다. 아래는 16–34m의 경계를 추적 결과로 교체한 경우다. 동시 적중은 방향과 시작 거리 ±5m를 모두 맞힌 프레임이며 오경보는 직선·범위 밖 경보다.

## 오른쪽 경계만 바꾼 대조

오른쪽에만 밝기 부호를 적용한 재생도 완료했다. Silverstone 우회전 13장의 오른쪽 추적 좌표가 양쪽 변경과 일치하고 왼쪽 추적 좌표가 절댓값 대조군과 일치함을 검사했다. Silverstone 결합 우 적중 3/13, 동시 적중 10건을 유지했고 오경보는 148→144건이었다. Spa에서는 절댓값 대조군의 우 13/49·동시 적중 13건·오경보 147건이 오른쪽만 바꾸면 14/49·15건·138건이었다. 양쪽을 바꾼 경우 오경보는 133건이었다. 이 재생에서는 Silverstone의 추가 우회전 적중이 없고 고정 34m 대조군보다 오경보가 많아 고정 판독기에 채택하지 않았다.
