# 차체 기울기를 반영한 도로 경계 투영 진단 · 2026-11-12

Silverstone 1967과 Spa의 저장 영상을 같은 타임라인으로 다시 읽었다. 차량 바닥과 평행한 평면에 단면을 투영하는 기존 방식과, 기록된 차체 피치·롤로 중력 기준 수평면을 투영하는 방식을 비교했다. 차량의 오른쪽 축을 검출기의 왼쪽 축으로 바꿔 롤 부호를 적용했다. 도로의 경사와 뱅킹은 따로 추정하지 않았다. 프레임마다 가장 늦게 끝난 카메라의 물리 상태 기록을 사용했다.

CSP 기록은 피치·롤 후보를 물리 변환에서 읽지만, 해당 필드는 녹화 소스에서 제어 입력으로 검증되지 않았다고 표시돼 있다. 이번 실험은 투영을 바꿔 보는 오프라인 진단이다. 지도 경계와 절대 위치는 횡오차를 계산하는 평가에만 썼다. [재생 코드](../runs/vision-corner-attitude-projection-20261112-01/attitude_replay.py)

두 투영에 동일한 경계 패치 체크포인트, 국소 곡률 문턱, T4/T5 확인 모델, 한 프레임 거리 갱신을 적용했다. 확인 모델의 경계 입력도 해당 투영의 경계로 구성했고 T4/T5 원본 특징은 같았다. Vallelunga 독립 평가에서 고정한 모델과 비교 기준은 그대로 두었다. [독립 평가 설정](corner-vallelunga-frozen-20261112.md)

## 실제 지도 경계의 높이와 비교

각 프레임에서 두 투영이 가정한 도로 평면과 지도 경계점의 차이를 차량의 위쪽 축으로 쟀다. 이전 T4/T5 결합 조건에서 추가로 오경보가 난 직선 표본과 전체 4–20m 접근 표본을 구분했다. 지점별 절대 오차의 중앙값은 아래와 같다. | --- | ---: | ---: | ---: |
| Silverstone 접근 | 24 | 0.255m | 0.222m |

Silverstone 대표 우회전 620~623번에서는 네 프레임 모두 높이 오차 중앙값이 줄었다. 원래 0.34~0.37m였고 수평면을 적용하면 0.21~0.23m였다. 서킷 전체에서 중력에 수직인 평면을 도로면으로 간주하면 경사나 뱅킹에 따라 오차가 커질 수 있다.

기존 경계 특징을 사용한 대조군은 두 서킷의 종전 채점을 재현했다. Silverstone에서는 차체 평면으로 재추출한 특징도 기존 특징과 같았다. Spa에서는 564프레임의 경계 배열에 차이가 있었고, 재추출 조건의 오경보는 기존 55건에서 52건이었다. 표의 투영 비교에는 동일한 재추출 절차를 썼다. [전체 결과와 대조군](../runs/vision-corner-attitude-projection-20261112-01/result.json)

Silverstone 우회전 접근에서 수평면을 적용하면 오른쪽 경계를 얻은 단면이 88→107개로 늘었다. 각 방식이 검출한 지점의 지도 경계 대비 평균 횡오차는 1.83→2.60m였다. 대표 우회전 621·622번에는 좌우 경계 쌍이 각각 8→9개와 9→10개로 늘었으나 우회전 경보는 모두 빠졌다. Spa 우회전 접근에서는 오른쪽 경계를 얻은 단면도 396→268개로 줄었다. 차체 기울기로 수평면을 가정하는 조건은 채택하지 않았다. [Silverstone 프레임별 결과](../runs/vision-corner-attitude-projection-20261112-01/ks_silverstone1967-frames.jsonl) · [Spa 프레임별 결과](../runs/vision-corner-attitude-projection-20261112-01/spa-frames.jsonl)
