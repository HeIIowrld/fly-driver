# 제동 뉴런과 전체 에피소드 gradient 누적

기록일: 2026-10-28 KST. 게임은 진단·학습 중 API 일시정지 상태다. 이 문서의 결과는 전체 서킷 완주를 증명하지 않는다.

## 관측한 제동 실패

t325는 t317 모델을 t324의 실제 AC 자료 738개에 재생했다. 정답 제동 >0.05인 표본은 t310에서 나온 회복 에피소드의 18개뿐이다. 위치·절대 방향은 교사 정답 작성에만 사용했고 actor에는 들어가지 않는다.

제동 출력 그룹의 body ID는 14113, 14973, 16542, 17510이다. 네 뉴런은 해당 18개 표본에서 활동이 모두 0이었다. 마지막 표본의 흥분 메시지는 약 3.35/4.21/7.18/3.84 ×10⁻⁶, 억제 메시지는 -6.39/-9.40/-9.62/-8.81 ×10⁻⁶였다. 직접 감각→출력 주입은 없다. 현재 rectified-tanh 동역학에서 합산 입력이 음수이므로 출력이 침묵한다. 이는 측정 연결 일부를 사용하는 공학적 rate 모델의 관측이며 실제 파리 제동 생리를 확인했다는 뜻이 아니다.

원래 에피소드 수치 상태를 유지하고 원래 chunk 경계에서 gradient만 끊어 제동 MSE를 역전파했다. 제동이 있는 두 chunk의 시작 인덱스는 112와 128이며 재생 예측 오차는 모두 0이었다. haltere_L 연결부 gradient norm은 0.282/0.501, haltere_R은 0.199/0.353, 시각 연결부는 0.0399/0.0199였다. 즉 학습 경로가 완전히 단절된 상태는 아니다. 이 gradient는 선언한 leaky surrogate이며 실제 forward 함수의 정확한 미분이라고 주장하지 않는다. 진단 중 optimizer update와 게임 명령은 0회이며 모델 파라미터는 그대로다.

## 회복 구간만 학습한 실험

t326은 t317에서 출발해 원본 회복 에피소드 t313의 140개 표본만 학습했다. 기관 연결부만, 학습률 0.001, 8 epoch, 72 update, 제동 정답 >0.05의 손실 가중치 20을 사용했다. 뇌 연결과 시각·출력부는 고정했다. 학습 가능성 확인용이며 주행 후보로 승격하지 않았다.

t327에서 제동 필요 18개 모두 예측 제동 >0.05를 보였다. 평균 정답 0.4097, 평균 예측 0.3830, 해당 구간 제동 RMSE 0.09116이었다. 전체 140개 RMSE는 조향/가속/제동 0.14095/0.04609/0.04409다. 이 구조와 입력으로 해당 회복 구간의 제동 반응을 맞출 수 있다는 증거다.

그러나 t328의 별도 개발 자료 75개에서는 제동 RMSE가 0.26860으로 악화했다. 제동 필요 8개의 평균 예측은 0.3489로 정답 평균 0.09666보다 컸다. 회복 구간을 외운 반응이 다른 상황에서도 적절하다는 근거는 없다.

## 전체 자료의 gradient를 모으는 방식

기존 chunk 모드는 각 16개 의사결정마다 Adam을 갱신한다. 길이 140인 회복 에피소드를 학습한 뒤 길이 198·400인 정상 주행을 처리하므로 마지막 정상 구간의 갱신이 회복 반응과 경쟁할 가능성이 있다. t325/t326만으로 이것이 유일한 원인이라고 단정하지 않는다.

`optimizer_update_scope: epoch`를 선택하면 모든 원본 에피소드의 정규화된 손실 gradient를 모은 뒤 한 번만 clipping·Adam 갱신을 한다. 각 chunk 뒤에는 gradient 연결만 끊고 수치 상태는 유지한다. 원본 에피소드 경계에서만 상태를 초기화한다. 한 epoch 안에서는 파라미터도 고정되어 일관된 동역학으로 모든 에피소드를 처리한다. 기존 기본값 `chunk`는 유지한다.

체크포인트에는 실제 update 횟수·선택 epoch의 update 횟수·선택한 scope를 남긴다. 합성 그래프 통합 테스트로 두 scope의 갱신 횟수, constructor 보존, 고정 회로 보존을 검증한다. 합성 테스트는 실제 AC 성능이나 해부학적 타당성 증거로 사용하지 않는다.

t329는 t326에서 출발해 t324의 원본 3개 에피소드 738개를 모두 학습했다. 기관 연결부만, 6 epoch, 실제 optimizer update 6회, 학습률 0.001, 제동 가중치 20, epoch 갱신이다. 개발 자료로 checkpoint를 선택하지 않았다. 선택 epoch는 6, 체크포인트 SHA256은 `8ebd757c1dd76199c80c23df6515da0b6bc0102d4315c6d9e3ceb6131ad07c37`이다.

최종 일반 학습 RMSE는 0.11967/0.10535/0.12732였다. t330의 별도 개발 RMSE는 0.10233/0.17195/0.25562였다. 제동 필요 8개에서 평균 예측은 0.2793으로 정답 평균 0.09666보다 컸다. 모델은 승격하지 않았으며 실제 게임 주행에 사용하지 않았다. 학습 방식 변경만으로 일반적인 제동 판단을 해결하지 못했다.

다음 단계는 다른 트랙 구간의 시각·몸 감각·감속 상황을 추가하고, 기관 연결부만 조정하는 제한이 상황 구분을 막는지도 확인하는 것이다. 실제 뇌 연결은 고정하면서 시각·기관 감각 변환부를 함께 학습하는 실험은 가능하지만 아직 수행하지 않았다.
