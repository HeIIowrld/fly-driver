# 네 시점의 겹눈형 입력을 공유 회로로 연결한 결과

2026-10-27 KST. 전면·좌후방·우후방·후방의 **시점별 국소 입력을 같은6,557뉴런 회로에
연결하는 경로를 구현하고 MuJoCo 렌더 영상으로 실행**했다. 시점 사이 결합은 공유 순환
연결 이후에 일어난다. 다중 시점 운전 학습, 일반 모델 대비 융합 효율, 실제 AC 영상 취득과
무개입 완주는 아직 검증하지 않았다.

## 구현한 경로

`VisualViewSample`은 source ID, 출처별 exposure ID, RGB 소안 응답·유효성, simulation
exposure 시각과 host 수신 시각, 교정 해시와 provenance를 보존한다. 기존 양안 표본과 혼합한
관측은 거부한다. native 캡처의 acquisition ID나 host 시각만으로 이 표본을 만들지 않는다.

`ViewMap`은 시점별 원점·camera-to-body 회전·FOV와 광학축·수용각을 고정한다.
현재 projector는 직접 perspective 영상만 지원한다. 실제 거울의 반사·곡면·UV 교정을
구현한 것은 아니다. 해시를 서로 바꿔 끼운 시점이나 미등록 시점은 거부한다.

`MultiViewPacker`는 각 소스의 RGB·시간차 RGB·age·유효성을 독립적으로 만든다.
시간차 RGB는 정규화한 밝기 변화율이며 방향과 속도를 가진 optical flow가 아니다.
다른 주기의 프레임을 같은 시각으로 바꾸지 않는다. 최초 노출·누락/지연 뒤 복귀에서
변화율을 만들어내지 않고, 같은 노출을 재사용하면 이전 변화율을 유지한다.
누락 뒤에도 exposure ID 역행과 같은 ID의 값 변경을 검출한다.

`MultiViewLocalLinear`의 각 시각 포트는 **선언한 한 시점의12개 이웃 소안만** 읽는다.
RGB·시간차 RGB와 각각의 유효성을 읽고 그 시점의 age로만 입력을 감쇠한다.
어댑터가 다른 시점의 픽셀이나 완성된 조작 벡터를 받아 합성하지 않는다.
이후 측정 구조의 고정 시냅스 행렬·지속 상태를 거쳐 선언한 출력 포트에서 조향·가속·제동
요청을 만든다. 전체 시각 회로나 T4/T5를 재현한 것은 아니며 수용장/포트 배치는 공학적 가설이다.

공통 활성과 비가산성은 **공유 내부 상태에서 신호가 상호작용한다는 기계적 증거**다.
유용한 장면 이해나 운전 판단을 학습했다는 뜻은 아니며, 일반 신경망보다 효율적이라는
결론도 낼 수 없다. 같은 다중 시점의 일반 순환 모델·재배선 회로·시점 제거 비교가 남아 있다.

고정된 진단 조작 `[-0.25, 0.1]`을 MuJoCo legacy adapter에 적용했고, 새 모델의3개
조작 요청은 기록만 했다. 모델이 실제 차량을 운전한24결정으로 부르지 않는다.
관절·회전 등 기존 MuJoCo 몸 감각을 받았으며 온도·하중은 환경에 센서가 없어 invalid로
남았다. raw 영상·시각 계약·처리 지연도 실제 AC 계약으로 승격하지 않는다.

실험 중 `mirror_right`를 결정8–14에서 누락했다. 해당 시점의 유효성은0이 되고, 복귀
직후에는 시간차 이력을 새로 시작한다. 다른 시각 입력과 회로 상태는 유지된다.
이름에 mirror가 있어도 이번 영상은 별도 **직접 가상 카메라**이며 반사된 실제 거울이 아니다.

## 영상 확인에서 찾은 문제와 수정

처음 네 카메라를 모두 앞쪽 원점에 놓은 `t25b`에서는 뒤·옆 영상 대부분을 차체가 가렸다.
원본 PNG를 직접 확인한 뒤 `t25c`에서 전방 `[.95,0,.2]`, 좌우 `[.6,±.65,.2]`,
후방 `[-.95,0,.2]`m의 가상 장착점으로 바꿨다. 원점은 차량 좌표이며 측정 장착점이 아니다.
수정 뒤 영상을 다시 확인해 주된 차체 가림이 줄고 도로·후측방이 보임을 확인했다.
일부 휠 가림은 실제 렌더 결과로 남겼다. 시점별 원점을 유지하고 근거리 parallax를 무시한
파노라마를 만들지 않았다. 후방 축59개와 시점별 포트 균등 배치의 적합성도 후속 검토 대상이다.

첫 `t25`는 영상 기록 뒤 선택 PNG 라이브러리 미설치로 실패했다. PNG 저장을 표준 라이브러리의
무손실 원본 RGB writer로 바꾸고 재실행했다. 실패224파일도 보존·해시 대조했다.
