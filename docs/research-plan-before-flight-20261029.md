### 구현·학습 순서와 통과 조건

1. **물리 기준 시험:** 직선 가감속과 좌우 원선회에서 하중 부호·힘/모멘트·휠 슬립을
   확인한다. combined slip·하중 의존성·열/냉각·압력/마모를 포함한 타이어 surrogate의
   가정과 유효 범위를 정한다. 기존 contact 마찰과 타이어 힘의 중복 적용을 방지한다.
   surrogate를 AC의 타이어 재현으로 취급하지 않고 이후 AC 기록으로 교정한다.
2. **속도·제동 출력:** 기존 조향 출력에 전진/감속의 검토된 출력 경로와 공통 조작 변환을
   추가한다. AC에 없는 독립 좌우 구동 권한으로 성능을 얻지 않도록 같은 조작 권한을 사용한다.
3. **오프라인 사전학습:** 교사 시퀀스에 조작과 상태 supervision을 분리 기록한다.
   먼저 단일 물리 조건의 제동/선회/탈출을 배우고 냉간·과열·셋업 변화를 단계적으로 늘린다.
   반복 replay와 source DAgger를 사용하고 AC 장시간 온라인 RL은 초기0을 유지한다.
4. **미사용 조건 평가:** 타이어 초기 상태·셋업·차량 반응 조합을 episode 단위로 나눈다.
   완주뿐 아니라 정지거리·미끄러짐·조작 진동·그립 추정 오차/불확실성·적응 시간도 기록한다.
   타이어/적응 상태 제거 대조로 기능 기여를 검사하고 모든 조합을 무작정 전수 학습하지 않는다.
5. **AC 적응:** 센서·조작·camera/clock을 교정한 뒤 짧은 실제 기록으로 보정한다.
   셋업 감지는 현재 셋업에 맞춰 운전하는 기능이며 자동 garage 셋업 최적화는 별도 과제다.

준비했고 캡처 ID·수집 구간·해시를 남긴다. Windows 선택35검사·WSL 선택33검사를 통과했다.
실제 AC 창은0개였고 픽셀은 읽지 않았다. 수집 시각을 렌더링/시뮬레이션 시각으로 간주하지
않으며 실제 PC/설치 경로에서 첫 센서·영상 기록과 동기 교정을 진행해야 한다.

[AC 연결부·읽기 전용 기록](ac-bridge-20261027.md): UDP 원본 프로토콜·이미지 ABI를
고정 버전에서 조사하고 별도 TCP 센서 앱과 기록기를 준비했다. Windows TCP 합성20표본은
기록됐지만 UDP는 시간 초과다. 실제 게임은 미연결이다. 다음 작업은 **실제 AC100표본 →
단위/축/clock 교정 → 노출 ID가 있는 영상 동기화 → 조작 적용 확인 → 저속 구간 학습** 순서다.
겹눈·회로·몸 되먹임이 최종 주행을 담당하고, 게임 정답 경로는 actor에 넣지 않는다.

아래는 단계별 당시 결과다. 각 문단의 ‘다음’은 당시 판단이며 현재 우선순위는 위 사전학습 경로다.

[기관별 되먹임·큰 곡선 시험](local-organ-feedback-20261027.md): 같은 V+body checkpoint가 기본4조건과 진폭4m·6m의8조건을 완료했다. 기관 제거도 모두 완료해 필수성은 입증되지 않았고 평균 오차 감소는 작다. 이제 AC bridge의 영상·계측·조작 계약과 기록 재생을 우선한다. 실제 게임 경로가 확인돼야 런타임 검증과 A5 이후를 진행할 수 있다.

[연속 학습·원본 입력량 정규화](local-temporal-20261027.md) 후 국소 겹눈→MeTu 회로가 개발4조건을 완료했다. 영상 제거·첫 영상 고정은0/4이고 몸 가중치는 아직0이다. 다음은 기관별 위치·회전 되먹임과 제거 대조, 더 큰 커브·새 시작 조건이다. 최종 EPG 억제도4/4여서 compass 기능·생리학적 이득은 입증되지 않았다. AC 관문은 미완료다.

[국소 겹눈→MeTu 구현](local-retinal-circuit-20261027.md)은 정지 자세 시험 RMSE0.161이지만 실제 연속 주행0/4로 승격하지 않았다. 상태를 계속 유지하면64틱 이후 출력이 크게 변한다. 다음 우선순위는 새 교사 연속 관측10,700결정을 이용한 시간축 학습과 긴 반응의 안정성 검증이다. 이를 통과한 뒤 분리된 기관 피드백·목표 형성과 AC로 이어간다.

[시각/CX 구조 조사](visual-cx-audit-20261027.md)에서2,626뉴런·92,740연결 후보와 공식 전달물질 자료를 확보했다. FC2 입력은1.84%만 남으므로, 다음 구현은 retinal 공간·시간 특징과 영상 기반 목표 형성을 분리하고 누락 경계를 검토한다. 구조 도달성을 생리학적 계산이나 주행 성공으로 취급하지 않는다.

[재구성 겹눈 통합](anatomical-eye-driving-20261027.md): 실제 관측에 연결하고 새 readout·checkpoint로 개발4조건을 완료했다. 영상 제거·회로 절단은 각각0/4다. 새 모델의 반복성·기관 제거 대조와 AC 랩은 아직 검증하지 않았다. 다음은 시각/CX 계산을 연결해 현재 조향 의도 어댑터를 대체하는 작업이며 아래 관문의 완료 조건은 유지한다.

## 완료 목표와 중간 성과

최종 목표 에이전트는 `겹눈 → 시각 회로 → 방향·기억/CX → 하행·국소 운동 회로 → 차량 조작 → 기관별 몸 감각 → 회로`의 폐루프를 가진다. 목표 모드는 **V+body**다. 주행 가능한 방향은 영상에서 얻고, 몸 감각은 자기 움직임·조작 응답을 알려 준다.

| 산출물 | 완료로 인정할 조건 |
|---|---|
| 일반 신경망 기준선 | GRU 등의 센서 기반 저속 주행. 학습·환경의 중간 검증 |
| 겹눈·기관 기능 모델 | 방향/수용각/시간 반응과 기관별 부호화가 자극 시험을 통과. 실제 해부학 재현 여부를 별도 표기 |
| 초파리 회로 운전 모델 | 검토된 실제 기능 그래프와 입출력·몸 감각 경로를 사용. 측정 연결과 학습 어댑터 구분 |
| 첫 최종 시연 | 위 모델이 AC 한 서킷을 영상+몸 감각만으로 무개입1랩 완주. 모델·차량·코스·assist·최저 진행 조건 고정 |
| 반복성 검증 | 새 학습 시드와 선언한 시작 조건에서 성공을 반복. 한 번의 좋은 실행과 구분 |
| 후속 연구 | 다른 서킷·더 높은 속도·생물학적 구조의 이득·실시간 비용과 탑재 최적화 |

이 목표에서는 GRU만의 완주나 FPGA 산술 일치가 최종 완료를 대신하지 않는다. 영상 소실 때의 반응, 기관 제거, 회로 재배선 대조로 무엇이 운전에 기여했는지 함께 확인한다.

## 현재 출발점

- 현재 주 모델은 재구성 겹눈의 국소 MeTu 입력과2,626뉴런·92,740연결 후보, 분리된 조향 위치·yaw 기관 되먹임이다. MuJoCo 기본4조건과 큰 곡선8조건을12/12 완료했고 몸 제거도12/12여서 기관 필수성은 입증되지 않았다. 평균 오차 개선은 작으며 고정 전진 의도만 사용한다. [현재 모델·대조](local-organ-feedback-20261027.md). AC는 읽기 전용 앱·합성 기록 시험까지이며 실제 게임은 미연결이다.
- 회로 없는 선형 시각 기준선도4/4, 영상 제거0/4다. 일반 GRU의 BC/DAgger 두 후보는0/4였고 정지 자세·조향 복사 진단으로 문제를 좁혔다. [시각 기준선](retinal-diagnostic-20261027.md), [기존 학습 실패](steering-input-audit-20261027.md). 과거 본학습·재시도의0/63과 별도 평가이며 성적을 합치지 않는다.
- 시각 경계는 아직 공학적 조향 대리 신호이고 기관 튜닝·신경 동역학·차량 출력 부호도 가설이다. 상위 시각/CX의 생물학적 대응, 반복 관문, AC adapter·동기 양안 캡처·1랩은 미완료다. [실제 경로·경계 손실](body-route-audit-20261027.md).
- 최신 critic 코드는 별도 작업 폴더의 `0cd8a5f`이며 기본 브랜치 `9b8b45f`와 구분한다. 새 실험은 변경 사항을 포함한 고정 소스 사본과 파일 해시를 남긴다. 기본 브랜치만으로 최신 실험을 재현할 수 있다고 표시하지 않는다.
- 같은 부분 회로 체크포인트를 재보정 없이 새 시작 조건30개에서 반복해30/30 완료했다. 이는 한 모델의 초기 조건 반복이며3학습 시드 관문이나 새 코스 검증은 아니다. actor p99는3.40ms, 전체 p99는18.57ms여서100Hz 마감 충족도 미입증이다. [반복·시간 기록](routed-repeat-eye-import-20261027.md).
- μCT 재구성 광학축1,709개를 가져와 검증했으나 현재 드라이버의 합성 격자와 별도다. 기존 readout을 재사용하지 않고 새 eye-map으로 데이터를 다시 수집해 비교해야 한다. 상위 시각/CX와 MaleCNS 광수용 뉴런의 등록은 미완료다.
- Windows MuJoCo DLL 정책은 변경하지 않았으며 별도 WSL CPU 환경의 최신 전체 테스트는163개 통과다. 코드 검증·합성 코스의 완료는 실제 회로의 AC 운전을 대신하지 않는다.

| A8 실행 비용·회로화 | 최종 감각·회로·수치 계약을 고정하고 최적화 | 전체 p50/p95/p99·상태 메모리·정밀도/과제성능·선택적 RTL | 목표 주기에서 지각→판단→출력 마감 충족, 최적화 전후 동일 평가 |

A1–A4의 사전학습은 A0나 게임 설치 완료를 기다리지 않는다. AC가 준비되면 A0의 짧은
계측을 병행해 감각 계약과 전이 차이를 일찍 확인한다. A5는 사전학습 모델과 A0의 관측·조작
계약을 갖춘 뒤 진행한다. 단순 게임 연결에 GRU를 썼다면 최종 회로 에이전트의 성공과 구분한다.

## 학습 전략

첫 조향 과제는 고정 저속의 BC-only와 BC+반복 DAgger로 나눈다. 학생이 실제로 방문한 상태의 교사 label을 모으고, 평가 시 교사 혼합률은0으로 한다. 단순한 nominal·복귀·커브 데이터의 비율, episode 순서, 이미지/행동 시각과 이전 명령 복사 의존성을 먼저 검사한다.

기준선이 성공한 뒤 실제 회로의 일부 어댑터·유형별 이득·readout부터 학습하고, 필요할 때 회로의 학습 자유도를 늘린다. 구조적 연결과 학습한 연결을 표시한다. RL은 BC+DAgger의 독립 주행 관문을 통과한 후보에만 적용하며, no-RL·초기·마지막·개발 선택 checkpoint를 따로 평가한다. 기존 실패 결과를 더 긴 PPO의 근거로 삼지 않는다.

MuJoCo는 부품 시험과 보조 사전학습 데이터 수집을 담당한다. 기존 AC 교사와 사용 가능한
공개 자료를 우선 재사용한다. 저장된 감각/교사 시퀀스로 대부분의 최적화를 수행하고,
AC에서는 부족한 센서 기록·짧은 보정 수집·실제 주행 평가를 한다. 기본 경로는
**기존 교사의 지식 → 파리 학생의 오프라인 학습 → 소량 AC 데이터로 미세조정**이다. AC에서
처음부터 다시 학습하는 실험이나 온라인 RL은 별도 제안과 예산 검토가 있어야 진행한다.

## 초기 예산과 중단 규칙

| 작업 묶음 | 초기 상한 제안 | 확대 조건 |
|---|---|---|
| A0 기록 | 10분 동기 기록 + 제한된 부호/응답 시험 | 연결·주기·시야 확인 |
| A1 자극 | 작은 결정적 자극 세트와 기록 재생 | 독립 수치/시간 계약 통과 |
| A2 한 후보·한 학습 시드 | BC 최대100,000 고유 결정, DAgger 최대3 round×20,000 결정; RL0 | 작은 진단으로 오류를 고친 뒤3시드 확인. 예산 상한을 채우는 것이 필수는 아님 |
| A3/A4 후보 | 기준선과 같은 데이터/interaction 상한·측정한 wall-time 한도 | 회로 상태·포트·센서 효과가 확인된 후보만 확대 |
| A5 첫 AC 후보 | 사전학습 후 교정·교사 수집·평가를 합쳐 초기 최대15,000 게임 결정 제안, 온라인 RL0 | 실제 처리율·오류 원인·오프라인 보정 효과를 확인한 뒤 확대 |
| 선택적 RL | 첫 제안50,000 interaction/후보·시드 | 성공한 BC+DAgger 대비 실패율 증가·거리 붕괴가 없을 때만 추가 제안 |

새 탐색 학습 시드 제안은101101–101103, 개발 조건은102101–102110, 최종 반복 평가 조건은103101–103110이다. 게임이 seed를 노출하지 않으면 날짜/숫자만 바꾼 것을 난수 시드라고 부르지 않는다. 차량·날씨·시작 상태·시각 조건의 시나리오 ID와 가능한 seed를 각각 기록한다. 새 평가 조건과 시드의 미사용 여부를 실행 직전 확인한다. 학습 데이터와 개발·최종 시험의 전체 episode/구간 그룹을 분리한다.

25 decision/s를 가정하면100,000 결정은 약1.11시간,1,000,000 결정은 약11.11시간이며 학습·수집·reset·평가 시간이 추가된다. 실제 속도 측정 전의 계산 예시다. 구현 결함·시간 불일치·기관 포트 부호 오류가 있으면 학습을 늘리기 전에 수정한다. 최종 시험 결과로 반복 튜닝하면 그 시험은 개발용으로 재분류하고 새 최종 조건을 만든다.

## 평가와 기록

첫 랩의 우선순위는 완주→개입/충돌/이탈→정지·후진·진행→횡오차·명령 진동→랩타임이다. 단순히 게임의 lap counter가 바뀌었다고 성공으로 세지 않는다. 평가기는 정답 위치를 사용해 구간 순서와 주행을 확인할 수 있지만 그 정보는 actor로 보내지 않는다. 첫 랩 이전에 declare한 유한 시간 상한과 최소 진행 조건으로 정지 정책을 탈락시킨다.

눈·몸 감각·뇌/국소 상태·요청/적용 조작·개입·종료 이유를 같은 시간축에 남긴다. 설명 산출물은 Markdown과 연결한 PNG/NPZ/JSON/영상으로 정리한다. 기존 설명용 HTML은 새로 생성·갱신·자동 실행하지 않는다. 기존 replay 코드를 새 결과 포맷에 맞추는 작업도 필요 목록에 포함한다.

각 run은 소스/설정/그래프/eye map/기관 매핑 hash, 모델과 어댑터의 구분, 게임·차량·서킷·assist·camera 설정, 학습/개발/시험 split과 지연을 기록한다. 초파리 구조의 우월성은 한 번의 완주와 다른 주장이다. 동일 감각의 C1-VB/C3-VB/C7-VB 비교와 시드별 결과 없이 확정하지 않는다.

## 바로 다음 구현 순서

사용자 제안에 따라 전면·좌우 사이드미러·룸미러 시각 구성을 채택한다. 몇 개의 원본 영상을
겹눈 광학축으로 샘플링하며 소안마다 별도 렌더 카메라를 만들지 않는다. 거울의 반사·원점·시각을
보존하고, **여러 시점의 정보를 파리 뇌 구조 안에서 합성하는 것을 주 학습 과제**로 둔다.
전방 단독 모델은 부품 시험·비교군이다. 같은 다중 시점을 받는 일반 순환 모델과 재배선
회로를 비교해 겹눈·측정 연결 구조의 이득을 검증한다. [구조·취득·교정 계획](compound-eye-camera-plan-20261027.md).

1. 공개 표본231상태에서 재현한 SAC 교사 추론을 실제 AC에서 검증한다. 온도/하중 인코더는 추가했고 실제 회로 포트·속도·제동 출력 경로를 확장한다. [수치 재현과 제한](ac-teacher-reconstruction-20261027.md).
2. 공개 dataset의 센서 구성을 감사하고, 부족한 동기 영상/계측만 추가 기록한다. episode를 분리해 파리 학생의 오프라인 증류를 진행한다.
3. 미사용 코스·속도·시각 조건과 기관/영상 제거 대조로 사전학습 모델을 검증한다.
4. 게임 화면 조작을 사용자가 재개하면 AC의 짧은 계측을 병행하고, 검증된 사전학습 모델을 AC 데이터로 보정한 뒤 구간→1랩을 평가한다.

아래 P01–P06은 기존 작업 묶음의 식별자다. 위 순서가 현재 우선순위이며 P02가 모든 학습의 선행 조건은 아니다.

1. **P01:** 새 관측·의도·시간 schema와 actor/TrainingOnly 분리. 현재 코드와 호환 경계를 정의한다.
2. **P02:** AC bridge의 영상·조작·telemetry capability probe와10분 기록. 넓은 시야를 얻는 방법을 이때 결정한다.
3. **P03:** 기록을 이용한 겹눈 방향/수용각·기관 위치/방향 인코더와 golden stimulus.
4. **P04:** 고정 속도 조향의 작은 BC/DAgger 기준선과 시각 의존성 평가.
5. **P05:** 실제 시각/CX/DN·상행 포트 조사, 기능 부분 그래프와 C7 대조군 봉인.
6. **P06:** C3-V→C3-VB 통합과 AC 구간 주행. 이후 A6/A7로 진행.

AC 설치·실행 파일·Monza와BMW Z4 GT3 자산·런처 창은 확인했다. 실제 연습 세션과 양안 캡처 가능성은 미검증이다. 재구성 eye map과 실제 회로 후보 ID는 위 자료 등록부에 기록했다. 드라이버 변경·AC 자율 주행은 수행하지 않았다.
