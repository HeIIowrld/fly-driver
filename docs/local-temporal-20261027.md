# 연속 상태 학습과 원본 입력량 정규화 비교

기록: **2026-10-27, Asia/Seoul**. [직전 정지 자세 모델](local-retinal-circuit-20261027.md)의 시간축 실패를 이어서 조사했다. 원본 입력량을 유지한 모델은 국소 겹눈→MeTu→측정 연결 구조→출력 경로로 개발4조건을 완료했다. 몸 피드백 가중치는 이번 모델에서 고정0이며 AC/V+body 최종 관문은 남아 있다.

## 바꾼 부분과 비교 조건

2,626뉴런·92,740연결과1,009개 MeTu 입력을 유지했다. MeTu마다 한쪽 눈의 이웃12광선×RGB를 받는다. 이 시야 배정은 seed730101의 공학적 가설이며 개별 뉴런의 해부학적 시야 대응은 아니다. 외부 조향 의도를 먼저 계산해 PFL에 넣는 경로는 없다.

기존 회로는 선택 부분망 안의 incoming 합계로 가중치를 나눴다. 잘린 입력이 많은 뉴런에서도 남은 입력 합계를1로 다시 키우는 방식이다. 새 비교 모델은 **회수한 원본 Traced 그래프 안의 전체 incoming 합계**로 나눈다. 따라서 선택 밖 입력의 비중은 남겨 두고 그 값은0으로 가정한다. untraced 뉴런이나 실제 미측정 입력까지 확보한 것은 아니다.

두 모델 모두 같은10,700개 훈련 관측의 출력 RMS를0.2로 맞춰 이득을 다시 정했다. 이 계산에 교사 label은 쓰지 않았다. 기존 정규화의 readout 이득은177.8028, 원본 입력량 정규화는967,331,520이다. 큰 이득은 작은 내부 출력 단위에 대한 공학적 변환이며 생리학적 전도도나 뉴런 발화율 단위가 아니다. **분모 변경과 같은 규칙의 이득 재보정을 함께 비교**했으므로 분모만 바꾼 고정 이득 인과 실험으로 표현하지 않는다.

두 초기 checkpoint의 국소 시각 가중치·특징 정규화·방향 지도·시간 상수는 정확히 같다.92,740개 연결을 모두 양성으로 보존했고 새 분모 계산과 실제 저장 행렬의 최대 차이는1.99e-8이다. 전달물질별 부호와 생리학적 동역학은 아직 적용하지 않았다.

## 연속 학습

훈련 전용 교사4 episode,10,700결정과 seed731101–731104를 사용했다. 새 학습 seed는740101이며 독립적인 여러 학습 시드를 시험한 것은 아니다.

- 각 episode 처음에서만 상태0으로 시작한다.512틱 BPTT 구간 경계에서는 gradient만 끊고 **수치 상태를 유지**한다.
- 종료된 episode의 padding은 해당 상태를 갱신하거나 초기화하지 않는다.
- 긴 episode와 짧은 복귀 episode에 같은 평균 손실 비중을 준다. 전체 epoch 동안 가중치를 고정하고 구간별 gradient를 누적한 뒤 한 번 갱신한다.
- Adam 학습률0.001, 고정8 epoch의 마지막 checkpoint를 평가한다. 최고 평가 결과를 고른 checkpoint가 아니다. 기관 가중치는 고정0이며 국소 retinal 가중치36,324개만 학습한다.

원본 입력량 모델의 전체 훈련 재생 조향 RMSE는 학습 전0.228061에서 학습 후0.629703으로 커졌다. 기존 정규화 모델도0.248849→0.502574로 커졌다. 이 지표만으로 주행 성능을 판정하지 않고 별도 실제 주행을 수행했다.

## 개발 조건 주행

고정1.5m/s·평탄한 동일 개발 도로, 동일4조건이다. 매 제어 틱에 회로를1회 갱신하고 시작 시 인위적인 예열을 하지 않는다. actor에는 영상과 허용된 몸 감각 필드만 전달하며 교사·경로 정답은 평가와 label에 분리했다.

마지막 모델의 nominal/midcourse/좌우 복귀 횡오차 RMS는0.556351/0.626233/0.564332/0.525990m다. 훈련 label 재생 오차와 주행 결과가 다르게 움직였다. 이 개발 조건에서 시간축 학습 후 주행 오차가 줄었다는 결과를 보관하며, 모방 오차의 일반적 개선으로 확대하지 않는다.

이 모델은 기존927뉴런·몸 피드백 모델의 개발4조건 평균0.136934m보다 오차가 크다. 입력 경계·몸 피드백·학습이 달라 같은 조건의 참고 비교이며 새 회로의 성능 우월성으로 주장하지 않는다. 속도·제동·거친 지형·AC 주행은 시험하지 않았다.

## 제거·영상 고정 대조

| 원본 입력량 모델 | 완료 | 조건별 횡오차 RMS 평균(m) |
|---|---:|---:|
| 추가학습 전, EPG 억제 | 2/4 | 1.203364 |
|8 epoch 후, 정상 | 4/4 | 0.568227 |
|8 epoch 후, 영상 제거 | **0/4** | 1.352575 |

첫 영상 고정은 센서 계약을 검증해 packing한 뒤 RGB·유효 마스크만 첫 프레임으로 유지한 명시적 대조다. 몸 감각과 실제 시간은 계속 갱신한다. 원본 영상의 시각·노출 기록을 고쳐 정상 측정이라고 표현하지 않는다. 영상 고정 시 평균 진행거리는6.546255m이며 모두 이탈했다. 따라서 이 조건의 완료에는 갱신되는 시각 입력이 기여했다.

최종 EPG 억제 모델은 완료율을 유지하면서 오차가 더 작다. **최종 모델에서 EPG의 필수성·이득 또는 생리학적 compass 계산을 입증하지 못했다.** EPG를 제거한 버전을 주 모델로 바꾸지 않았으며 전체 회로를 유지한 모델과 대조군을 분리 보관한다. 구조 경로가 있다는 사실과 해당 경로가 과제에 필요한 계산을 한다는 사실을 구분한다.

## 수치 조사와 한계

기존 양성 행렬의 power iteration은20,000회 후에도 잔차1.58e-6으로 지정 문턱에 수렴하지 않았다. 고유값 추정은1에 가깝지만 정확한 감쇠 시간을 주장하지 않는다. 원본 입력량 방식은 추정 고유값0.813944, 잔차2.41e-13이었다. 저장된 float32 가중치의 최대 절대 행 합은0.979006이다.

같은 입력을 받는 두 수치 상태 사이에서, 실수 연산으로 해석한 코어의 infinity-norm Lipschitz 상계는 약0.997580이다. 이는 고정된 입력에 대한 코어 상태 반응의 수치적 성질이며 차량을 포함한 폐루프 안정성이나 생리학적 기억 회로의 재현 증거가 아니다. 양성 회귀 연결과 잘린 입력0 가정 자체가 여전히 공학적 모델이다.

마지막 checkpoint의150개 정지 자세64틱 응답을 float64로 다시 계산했다. float32와의 출력 최대 차이는1.85e-5, RMSE3.68e-6이다. 이는 이 고정 시험의 수치 비교이며 새로운 장면·장시간 전체의 오차 보장은 아니다.
