# Monza 분리 검증과 차량 이동량 확인 · 2026-11-11

Magione에서 고른 겹눈·도로 경계 결합 설정을 바꾸지 않고 Monza에 적용했다. Monza의 기존 학습에서 제외한 물리 코너 묶음 6·9의 100개 프레임을 두 회차에서 채점했다. 해당 접근은 좌 6개와 우 8개이며, 실제 물리 코너는 방향별 하나다. 경계 이력용 원본을 포함해 140개 캡처의 네 시야와 몸 감각을 재생했다. Monza 기준 거리는 기존 순서형 판독을 썼다. 분리된 개발 검증이며 새 서킷 독립 평가에 해당하지 않는다.

기존 혼합 판독과 결합 판독 모두 좌 2/6, 우 7/8, 결합 5개, 직선·범위 밖 오경보 2개였다. 기존 판독이 놓친 5개 접근 중 2개는 경계의 시간 누적에서 현재 굽음 후보가 있었지만, 전체 경계 굽음 최솟값을 쓰는 조건에서는 5개 모두 후보가 없었다. 겹눈 점수로 확인하기 전에 걸러졌다. 안정 예고는 두 방식 모두 14m 한 건이었고, 공통 연속 5쌍의 거리 변화 오차는 5.74m였다. ## 같은 시작 위치를 차량 이동량으로 확인

세 캡처 고정 조건을, 연속 경계 관측이 같은 시작 위치를 가리키는 동안 누적 이동이 0.75m 이상인 조건으로 바꿨다. 직전 위치를 로컬 속도·요율로 현재 좌표에 옮기고 위치 차이 1m까지 인정했다. 영상·몸 감각이 끊기거나 굽음 방향이 달라지면 누적을 초기화했다. 이전에 고른 겹눈 유무 점수와 순서형 거리 가중치를 사용했다.

Imola의 추가 오경보는 세 프레임 확인에서 한 건이었고, 이동 기준에서는 같은 위치로 인정된 누적 이동이 기준에 미달했다. Magione의 새 결합 적중은 여전히 물리 좌회전 한 곳의 두 회차에 집중됐다.

## 거리 보정과 고정 설정

연속해서 같은 방향을 예고한 프레임에서 직전 거리에서 로컬 이동을 뺀 값이 현재 읽은 거리보다 가까우면, 현재 읽은 거리를 최대 0.05m 줄였다. 이 설정은 방향·오경보를 그대로 유지하고, Magione 결합 56개와 Monza 결합 5개를 보존했다. 공통 인접 거리 오차는 Magione 67쌍에서 0.392→0.383m, Monza 5쌍에서 5.743→5.723m였다. 실제 접근 중 역행 횟수는 각각 22회와 3회로 같았다. Magione 두 좌회전 회차의 최초 안정 예고는 기존 5.06·5.48m에서 6.54·6.47m였다. Monza의 14m는 유지됐다.

이 설정을 이후 새 서킷에서 재생할 개발 후보로 기록했다. Laguna Seca 영상은 이번 비교와 후보 선택에 사용하지 않았다. 새 서킷 통합 재생 및 기존 독립 기준의 합격은 아직 확인하지 않았다.
