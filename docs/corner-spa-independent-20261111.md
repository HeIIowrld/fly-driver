## 원본 재채점

사전 고정 뒤 주행선 표시를 끄고 수집한 Spa 원본 1,200묶음을 재사용했다. 입고 행 해시와 사전 고정 후보 해시가 기존 평가와 일치했다. 현재 Python 환경에 FlyVis가 없어 영상 특징 추출 단계는 기존 입고 행과 해시가 일치하는 저장본을 사용했다. 고정 후보의 방향·보류·오경보·합격 판정은 기존 평가와 모두 일치했다. 거리 예측 두 행에서 최대 3.6×10⁻¹⁵m의 부동소수점 차이가 있었다. [재검증 기록](../runs/vision-spa-independent-replay-20261111-01/verification.json)

기존 FlyVis 소스와 Windows ROCm 환경을 찾아 원본 픽셀부터 전체 평가를 다시 실행했다. 원본과 반전 입력의 특징 차이는 최대 1.8×10⁻⁷, 세 비교의 프레임별 거리 차이는 최대 0.0000016m였다. 세 비교의 전체 1,200프레임 판독 상태와 방향·거리 적중 판정, 사전 기준 결과는 각각 기존과 일치했다. [원본 픽셀부터의 재평가 검증](../runs/vision-spa-independent-replay-20261111-01-full-02/verification.json)
