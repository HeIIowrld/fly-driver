# 검증된 구간 확장과 NAS 보관 개선

기록일: 2026-10-28 KST. 교사 수집과 학생 성능을 구별하며 서킷 완주는 아직 검증하지 못했다.

## 기존 대기 작업의 종료와 자료 검증

t335의 기존 보관 프로세스가 정상 종료했다. 500개 요청·응답, 카메라 621개 묶음, 약 270MB의 원시 자료를 보관했다. t338의 API 일시정지도 완료했고, t336에서 원시 native prefix로 정차·가속 0·제동 유지와 vJoy 해제를 확인했다.

t337은 네 방향 영상에서 모든 입력을 다시 계산했다. RGB·contrast·두 유효성 마스크·영상 age·기관 값·기관 유효성의 최대 오차는 모두 0이며, 기하 교사 명령 재생 오차도 0이었다. 네 방향 유효 표본은 각각 500개, 서로 다른 카메라 묶음은 499개였다. 교사 최고 속도 27.673km/h, 최대 경로 오차 0.2584m다. 이는 학생 파리 모델의 성능이 아니다.

검증된 500개를 기존 738개와 합쳐 t341에 4개 원본 에피소드, 총 1,238개 표본을 저장했다. 실패했던 t332는 이 자료에 포함하지 않았다. t337의 manifest SHA256은 `c6c832f2a4d35fc50d2492967342549d9fb98df2b446f9c59b826f8ff8ec31ed`다.

## 카메라 묶음 형식

기존 파일 형식을 유지하면서 선택적으로 `camera.zip`(ZIP_STORED), `archive.json`, `bundle.json`의 세 파일로 저장한다. PNG를 다시 압축하거나 픽셀·시간·시점을 바꾸지 않는다. 각 파일의 SHA256·길이와 전체 묶음 해시를 기록한다. 복사 후 묶음 전체를 NAS에서 다시 읽어 검증한다. 수집 프로세스는 자기 카메라 consumer가 종료된 뒤에만 보관할 수 있다.

재생할 때는 묶음을 로컬 임시 폴더로 옮겨 전체 해시를 확인하고, 파일을 추출하지 않은 채 member를 읽는다. 파일명 경로 이탈·중복·manifest 불일치·파일 바이트 손상을 거부한다. 기존 개별 파일도 읽을 수 있으며, 검증된 로컬 사본을 사용해 재생 중 NAS를 반복해서 읽지 않는다. 원본 자료는 삭제하지 않는다.

t340은 실제 t335 원본을 새 형식으로 다시 보관했다. 3,112개 member의 이름·해시·길이 목록이 기존 보관과 완전히 같았다. 자료 270,514,697 bytes를 생성·전송·해시 재검증하는 데 8.959초, 재생용 로컬 복사와 전체 member 검증에 4.001초, 합계 12.960초가 걸렸다. 시스템 I/O가 통제되지 않은 한 번의 실제 측정이며 일반적인 속도 향상 배수를 보장하지 않는다. 이 복제본을 새 학습 표본으로 중복 집계하지 않았다.

묶음 SHA256은 `6d134533794b6c33b7063da8b06b5467edd166ea9b2b4a5ea74d62cf040bc7be`다. 새 교사 수집은 `--camera-archive-format bundle`로 선택할 수 있다. 다른 기존 소비자의 보관 기본값은 그대로다.

## 로컬 실행 사본

t339는 원본 작업 폴더의 코드·설정 283개와 테스트 85개를 로컬의 고유 폴더에 복사하고, 모든 바이트 해시를 확인했다. 원본은 삭제하지 않았다. `source-provenance.json`에 원본 revision·dirty 상태·원본 파일 해시를 남긴다. 실행 시 이 검증된 사본을 import하고 실제 자료 경로는 원본 작업 폴더를 기준으로 유지한다. 이후 소스가 바뀌면 기존 사본을 수정하지 않고 새 사본을 만든다.

로컬 사본에서 파일 묶음·기존 형식·손상 거부·순환 참조 수거 상태 복구·위치 보존·학습 통합 등 21개 테스트가 5.50초에 통과했다. 실제 영상의 재검증은 별도로 t337에서 확인했다. 원본 provenance hashing은 같은 파일 집합과 순서를 유지하면서 최대 4개 worker로 읽으며, 누락·순서·바이트 일치 테스트를 통과했다.

## 준비 중 발견한 추가 문제

t342에서 위치를 보존한 준비는 완료했다. 그러나 t343은 운전 명령을 0회 보낸 상태에서 센서 주기 오류로 중단됐다. 의도적인 준비 단계 GC 수거를 cadence history 작성 뒤에 수행한 탓에 간격이 벌어졌다. 제한을 느슨하게 하지 않고, 수거를 센서 준비 표본 4개를 모으기 전으로 옮겼다. 수정한 코드는 새로운 로컬 사본에서 검증·실행한다. t343의 실패 기록과 묶음도 보존했다.

수정한 t344 실행 사본으로 t345가 다음 500회 교사 주행을 완료했다. 센서 주기 제한과 경로·속도 제한은 그대로다. t346에서 실제 정지/vJoy 해제를 확인했고, t347은 새 묶음 형식에서 RGB·contrast·age·유효성·기관 값과 교사 요청을 재현했다. 모든 최대 오차가 0이었다. 이로써 새 형식의 실제 수집→보관→재생 검증 경로도 통과했다.

새 구간의 교사 최고 속도는 27.139km/h, 최대 절대 gap은 0.3591m, 마지막 gap은 0.1204m다. 주행 중 generation 2 수거와 foreground 이벤트는 모두 0이었다. 요청 간격 p50/p95/p99는 40.045/41.876/42.621ms다. 교사 전용 arc는 5175.809–5305.159m로 앞선 구간에 이어졌다. t348에서 다시 API 일시정지를 확인했다.

t349에는 원본 에피소드 5개, 검증된 표본 1,738개가 있다. 복제한 t340 자료는 포함하지 않았다. t347 manifest SHA256은 `067215f1e72480e6d37f1a48aded0513f329b0dd21ea2c87257ca67e94da71c0`이다.

## 다음 모델의 학습·평가 분리

t350은 t317 모델에서 출발해 t341의 1,238개 표본만 학습한다. 시각·기관 감각 연결부를 함께 조정하되, 회로·출력부·photometry는 고정한다. 8 epoch, 학습률 0.0003, epoch gradient 누적, 원본 에피소드 padding batch를 선언했다. 수치 상태는 원본 에피소드 경계에서만 리셋하고 chunk에서는 gradient만 끊는다.

최근 t347의 다음 트랙 구간 500개는 gradient 업데이트에서 제외했다. 새 장면에서의 출력·제동 오차와 시각/몸 감각/회전 입력 제거 검사를 수행할 평가 자료로 남긴다. 별도의 오래된 개발 자료 t303과도 비교한다. 서킷 전체 또는 새로운 차량·셋업의 최종 독립 시험으로 부르지 않는다. 학습 결과와 실제 학생 주행은 검증 전까지 성공으로 판정하지 않는다.
