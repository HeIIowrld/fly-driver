# 공개 교사 완주 재현과 감각 수집 지연 해결

기준: 2026-11-02, Asia/Seoul. 실제 실행 원본은 `runs/teacher-recovery-20261102/`에 있다.
이 보고서는 공개 교사의 재현 결과이며 초파리 학생의 자율 주행 결과가 아니다.

초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다. 변속·셋업 적응과 검증된 상대풍 감각도 포함한다. 지도·world pose·정답 라인은 교사/평가용이며 학생 actor 입력으로 사용하지 않는다.

## 이탈을 만든 조건 차이와 교사 비교

이전 저온 시험 원본은 [과거 보고서](teacher-speed-comparison-20261102.md)와 `runs/teacher-speed-curriculum-20261102/`에 보존했다. 당시 실패를 이번 성공으로 덮어쓰지 않는다.

- 공개 동일 학습 원본 234상태는 타이어 core 약 80°C·native 압력 24.64였지만, 이전 시험 시작은 약 26°C·압력 16대였다. 원 제작자의 동작 버전 설치 안내는 tyre blankets 켜짐, 안정화·TC·ABS·타이어 마모 꺼짐을 지정한다. 타이어 setup 수치는 유지하고 예열/assist 조건을 맞췄다. 새 엔진에서 실제 80°C·24.64를 확인했다.
- 원본 LastFF는 비영(중앙 약 0.0624)이지만 이전 controls의 FF_GAIN=0에서는 0이었다. FF_GAIN=1로 바꾸고 live-02에서 비영 피드백을 확인했다. 이는 교사가 읽는 감각 분포를 복원한 것으로, 물리적인 핸들을 움직였다는 뜻이 아니다.
- 기존 자동 변속 보조 경로는 중립 중 여섯 결정에서 조향을 고정하고 타력으로 갔다. 재현 경로는 확인된 자동변속 중립을 최대 300ms 허용하되 SAC의 원래 추론을 계속한다. 역기어·장기 중립·자동변속 꺼짐은 거부한다.
- 제어 요청을 단순 상대 주기로 지연시키지 않고 40ms 절대 deadline으로 예약했다. 원 SDK 주기는 약 20.7ms이므로 기존 최소 30ms 선택은 매번 두 프레임 약 41.4ms를 기다려 지연이 누적됐다. 원 관측 계약인 20~80ms를 유지한다.
- 원 공개 기록에서 조향 요청→SDK 응답 기울기가 약 270.0085였다. 현재 장치 raw gain 450의 실측과 일치하는 0.6 배율을 유지했다. 잘못된 조향 배율로 단정해 바꾸지 않았다. native track length 5758.66m와 reference 약 5760m도 대체로 일치했다.

여러 환경 차이를 함께 고쳤으므로 어느 하나만으로 이탈 원인을 완전히 설명했다고 주장하지 않는다. 수정 INI의 540만 모델 `live-02`는 최고 265.805km/h 후 시케인 구간에서 83.676km/h·3바퀴 이탈로 종료했으나, 원본 첫 core 온도는 약 **30.9°C**였다. 후속 재시작한 700만 live-03/04/05/06은 실제 80°C였다. 따라서 live-02와 live-03을 동등한 예열 상태의 모델 성능 비교로 쓰지 않는다. 이 차이를 발견한 뒤 실제 출발 온도를 맞춰 아래 live-08 재시험을 수행했다. 400만의 새 조건 완주와 다회 무작위 반복 성능 차이도 아직 측정하지 않았다.

## 다른 공개 교사와 차종 일반화

차종이 다르다는 이유로 교사 후보에서 제외하지 않는다. [원 SAC](https://github.com/dasGringuen/assetto_corsa_gym#benchmarks)는 540만 예제의 예상 랩을 약 112.1초로 안내하지만, 이는 제작자 수치이며 이번 700만 로컬 랩과 분리한다. 400만/540만/700만 가중치와 입출력 차이·과거 live 비교는 이전 보고서에 있다.

[Vector-Q Transformer SAC](https://github.com/chandankeelara/transformer-based-autonomous-racing-agent)는 Miata/Monza 완주율 80%를 보고한다. 공개 가중치·샘플·trajectory를 revision `45d33fa3b33252031d91384b0f47fc449a276672`에서 Git blob·크기·SHA로 검증해 `assets/external/vectorq-miata-teacher-20261102/`에 보존했다. `vectorq-offline-01`은 strict weights-only 로드, 216개 75×50 관측의 유한 출력, batch/single 동일 출력을 확인했다. CPU 단일 관측 중앙 54.33ms·최대 62.13ms는 현재 40ms 결정 예산보다 길다. GPU 성능과 Miata의 실제 운전은 아직 측정하지 않았으며 저장 trajectory에는 timestamp가 없어 랩타임으로 해석하지 않는다.

[progressive DisCor/F1](https://github.com/tanmaiy18/assetto_corsa_gym-main)은 F1 Monza 평균 92.95초를 보고하지만 차가 다르므로 BMW의 112초보다 교사 정책이 좋다는 순위가 아니다. [AssettoCorsaRL](https://github.com/AssettoCorsaRL/AssettoCorsaRL)과 [SamuelOrtizV framework](https://github.com/SamuelOrtizV/Assetto-Corsa-RL)는 공개 후보로 남긴다. upstream의 창 활성화 요구/desktop reset을 그대로 실행하지 않고 이 프로젝트의 background CSP 계약을 유지한다.

다른 차종 교사의 단위·조향/기어·타이어·관성·차체 좌표·감각 결측·제어 지연을 먼저 검증하고 학습한 어댑터와 공통 감각운동 표현으로 연결한다. 차종 밖 평가를 별도로 수행해야 범용성의 증거가 된다. 한 차의 교사 완주는 그 증거가 아니다.

## 검증 범위와 다음 작업

카메라는 이 교사 검증 내내 꺼져 있다. **모든 기록은 training_admissible=false, 학생 optimizer 업데이트 0**이다. TCP/host 시간이 안정된 것과 영상 노출·몸 감각의 물리 시간 정합은 별개다. 카메라를 켠 동시 수집의 지속 신선도·물리 정합을 확인한 뒤에만 학습용 시연을 승인한다.

이후 적격 시연을 에피소드 단위로 분리해 초파리 겹눈/운동 시각과 비행 유래 균형·운동·감각 되먹임 회로의 반응과 인과 기여, 실제 폐루프 조향·가감속·변속·셋업 적응 및 유효 완주/레이싱 라인·랩타임을 검증한다. 단순 교사 증류나 일반 신경망의 좋은 운전으로 생물학적 구조 목표를 대체하지 않는다.
