# 공간 시각 후보의 실제 냉간·고온 움직임 추론 — 2026-11-04

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.** 비행 기준·변속·타이어/셋업/차종·검증된 상대풍 적응을 유지한다. 측정 연결·생리 근거·기능 근사·학습한 차량 경계를 구별한다. 지도/world pose/절대 heading/교사 명령은 actor 입력에 넣지 않는다.

## 같은 몸에서 영상이 조향을 바꾸는가, 코너를 외운 것인가

같은 시작 회로 상태와 이후 몸/native 감각·감각 이력을 고정하고 영상 특징만 교체하면 코너 진입 전 조향은 바뀐다. 그러나 새 시각 후보도 기대 방향 반응은 **6/15구간**으로 불안정하다. 공간 시각 경계를 중립으로 만들면 기록별 진입 전 오차가 **4.44–12.23% 증가**한다. 영상이 조향에 기여하지만 올바른 선행 방향 판단이 안정됐다는 증거는 아니다. donor의 도로 상대 자세·위치가 완전히 일치하지 않고 독립 반사실 조작 정답도 없는 특징 경계 실험이다. 원본은 [시각 개입 보고서](native-visual-anticipation-20261104.md)에 연결한다.

현재 학생 성적은 주로 교사 조작을 기록에서 예측한 성적이다. 학생이 코너들을 자율 주행했다는 전제부터 아직 성립하지 않는다. 반복 Monza 자료에서는 현재 몸만 쓰는 TRAIN-only 선형 대조군도 개발 전체 조향 RMSE .059306(상수 .123026)을 얻었다. 회전·가속도·속도 등 현재 몸 반응에 조작 단서가 있고 누적 회로 상태로 익숙한 구간을 구분할 가능성도 있다. 이 대조군의 진입 전 0.2초 미래 예측은 .072535로 상수 .067974보다 나빴다. 몸으로 현재 조작을 추정하는 것과 앞 코너를 영상으로 판단하는 것은 다르다. 전부 암기했다고 확정하지 않으며 새 코너 일반화도 입증되지 않았다. [몸 단서 대조군·원본](anticipatory-steering-and-body-shortcut-20261104.md).

공간 시각 projection의 앞선 1,650업데이트는 소비된 Monza 개발 전체 조향 RMSE .071564375→.070204230(**1.90% 감소**), 진입 전 .062979949→.062626708(**.56% 감소**)다. 동시 2% 기준 미달이며 선행 보조 목표의 추가 이득은 없었다. 이번 통합/실제 시험에서는 optimizer 업데이트 **0**이다. 이 작은 기록 예측 개선을 폐루프 운전 개선으로 보고하지 않는다.

## 이번 구현

- `audited_native_visual_candidate`는 원래 native 후보의 감사 경로를 유지하고 완료된 시각 fit·수식 감사·전체 신경 궤적 개입·독립 개입 감사와 해시를 바인딩한다. readout/DN/body 상태와 시각 정규화의 dtype·shape·값을 보존하고 유한한 projection의 변화 상한을 검사한 뒤 optical 상태만 연결한다. 미래 보조 head는 actor 출력에 연결하지 않는다.
- moving launcher·교사 motion 독립 감사가 같은 후보 계획을 읽게 했다. 실제 설치 Lua SHA를 명시적으로 전달하며 기본값을 다른 소스로 바꾸지 않았다. 후보 선택은 future200의 고정 timing 실험이며 개발 성적을 보고 승격한 것이 아니다.
- 기존 초기 온도 설정 영수증에 묶인 기어 준비를 구현했다. 고온에서는 모든 host reader/검사를 paused 상태에서 준비한 뒤 한 번의 CSP resume로 실제 새 정지 packet을 확보한다. 추가 온도 설정 없이 기어 전용 준비를 마치고 다시 pause한다. 학습 전용 새 epoch와 이미 초기 온도를 설정한 동일 epoch는 명시적 별도 조건으로 검증한다.
- 몸 50ms·시각 150ms·source-render 25ms 경계를 유지한다. 회로 상태는 에피소드 안에서 연속 유지한다. CPU 소유자 스레드의 명시적 denormal flush는 수치 근사이며 종료 시 복원한다. NAS 큰 파일 저장은 추론 종료 후 수행한다.

## 남은 문제와 다음 검증

**actor_qualified=false·미승격·전체 목표 active.** 현재 두 짧은 교사 시험은 시각 후보를 실제 움직이는 감각 루프에 연결해 기한과 종료를 지킨 증거다. 학생의 실제 조향 개선·냉간/고온 적응·새 코너 판단·유효 완주·빠른 라인/랩타임·생리/R2 검증은 남아 있다.

우선 영상 교환의 도로 상대 자세/차로 위치 차이를 통제한 진입 전 자료를 확보하고 같은 몸·시작 상태의 지속 영상 개입에서 올바른 방향 반응을 늘려야 한다. 이어 고정된 별도 새 코너/트랙에서 조향·가감속을 평가한다. 이번 실제 입력은 모든 출력이 온도 학습 지원 범위 밖이므로 온도/하중/슬립의 변화에 적절히 반응하는 인과 검증과 학습 범위 확장도 필요하다. 독립 정지·입력 신선도·단위/부호 계약을 유지한 제한된 학생 폐루프, 타이어/자세/가속도·변속/셋업/차종/상대풍 적응, 유효 완주와 레이싱 라인/랩타임 개선으로 이어간다. 같은 Monza의 head 미세 조정만 반복해 위 목표를 대체하지 않는다.
