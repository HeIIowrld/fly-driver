# 교정 경계를 함께 학습한 코너 확인기 · 2026-11-12

Silverstone에서 물리 경계를 넣어 맞는 후보를 고른 장이 늘었어도 확인 점수에서 탈락한 사례를 겨냥했다. Imola·Laguna Seca·Zandvoort·Mugello에서 영상 관측 경계로 후보를 만들고, 노면 전환이 확인되어 카메라에 투영된 물리 경계로 후보를 다시 생성했다. 물리 좌표는 학습용 후보 생성과 별도 진단에 사용했다. 시험 영상에서는 원래 영상 관측, 차량 국소 움직임, 허용된 T4/T5 특징으로 고정 후보를 골랐다. [후보와 학습 입력](../runs/vision-corner-corrected-geometry-gate-20261112-01/gate_inputs.py) · [이전 병목 진단](corner-side-three-tracks-confirmation-20261112.md)

확인기 학습에서는 관측 후보만 쓰는 대조군과, 같은 개발 서킷의 교정 후보를 더한 세 조건을 비교했다. 교정 조건은 확인된 경계 모두 교체, 누락된 점만 채움, 이미 관측한 점의 좌표는 영상과 물리값의 중간으로 이동하고 누락 점은 채움이었다. 전체 교체 조건의 관측 후보는 8,582개 중 방향·거리 동시 적중 173개였다. 교정본에서는 6,956개 중 213개였다. 개발 서킷을 하나씩 제외한 실제 영상에서 문턱을 정했고, 직선·범위 밖 77건과 내부 67건의 공통 상한을 사용했다. 평가의 경계와 T4/T5 확인기는 각 프레임에서 같은 선택 후보를 받았다. | 이전 고정 설정 | 2/13 · 10 | 5/38 · 5 | 0/24 · 4/42 · 25 |
| 관측 후보로 재학습 | 2/13 · 5 | 4/38 · 4 | 0/24 · 4/42 · 15 |

적중은 4–20m에서 방향과 시작 거리 ±5m를 함께 맞힌 경우다. 범위 밖 경보에는 직선 경보가 포함된다. Monza는 기존 라벨 989장으로 채점했으며 내부 경보는 비교 대상에서 제외된다. 관측 후보 재학습은 Silverstone과 Monza의 기존 우 적중 프레임을 모두 유지했다. Vallelunga에서는 우 적중 1126번을 잃었고 내부 경보는 10건으로 같았다. 중간값 교정의 Monza 좌 적중은 실제 좌회전 접근의 1219번에 좌 10m를 낸 경우다. [전체 교체 및 대조군 재생](../runs/vision-corner-corrected-geometry-gate-20261112-01/result.json) · [부분 교정 재생](../runs/vision-corner-partial-geometry-gate-20261112-01/result.json)

관측 후보 재학습의 같은 후보에서 T4/T5를 추가하면 Silverstone은 우 적중 2건을 유지하며 직선·범위 밖 경보가 9→5건, 내부 경보가 4→6건이었다. Vallelunga는 우 적중 2→4건, 범위 밖 경보 4건 유지, 내부 경보 7→10건이었다. Monza는 우 적중 3→4건, 범위 밖 경보 9→15건이었다. 중간값 교정의 같은 후보에서 Monza 우 적중은 2→4건이었다. 좌 적중 수는 1건으로 같았고 맞힌 프레임은 달랐다. 범위 밖 경보는 8→16건이었다. [같은 후보와 프레임 검증](../runs/vision-corner-corrected-geometry-gate-20261112-01/verification.json) · [부분 교정의 차이](../runs/vision-corner-partial-geometry-gate-20261112-01/verification.json)

Silverstone 물리 경계 진단에서 오른쪽을 교체했을 때 기존 T4/T5가 맞힌 우 접근 3장은 전체 교체를 함께 학습한 확인기에서도 3장이었다. 양쪽을 교체한 진단에서는 우 적중이 1→0장이었다. 새 확인기를 고정 판독기에 적용하지 않았다. 평가 녹화는 이전에도 사용했다.
