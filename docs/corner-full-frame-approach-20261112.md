# 후보 미출력 프레임을 포함한 코너 접근 학습 · 2026-11-12

Imola·Laguna Seca·Zandvoort·Mugello의 유효 프레임 3,752장에서 코너 접근, 코너 내부, 직선·거리 범위 밖을 학습했다. 실제 접근은 292장이었고 이 중 87장에 기존 회전 경보가 없는 복구 후보가 있었다. 직전 접근 확인기는 후보가 생긴 프레임에서 접근 점수를 학습했다. 새 확인기는 후보와 독립적으로 현재 관측 경계, 몸의 국소 속도·요율·이력, 좌우 각각의 근거리와 원거리 굽음을 사용했다. 한쪽 관측이 끊긴 경우에도 해당 쪽 점 개수와 결측을 보존했다. [학습 코드](../runs/vision-corner-full-frame-approach-20261112-01/full_frame.py)

새 접근 점수, 기존 전체 프레임 접근 점수, 복구 후보에서만 학습한 접근 점수를 비교했다. 방향과 거리 확인은 같은 후보에 같은 모델을 사용했다. 두 판독은 접근 점수를 공유하며 T4/T5 조건에는 기존의 같은 후보에 대한 운동 시각 확인 점수가 더 들어간다. 새 접근 모델은 개발 서킷을 하나씩 빼고 확인했고 방향·거리 모델과 경계 선택기도 해당 서킷을 제외했다. 기존 전체 프레임 모델은 네 개발 서킷에서 학습했던 동결본이다. 기존 점수와 새 모델의 개발 수치에 이 차이가 있다. [동결 설정](../runs/vision-corner-full-frame-approach-20261112-01/training.json)

입력의 효과를 별도로 확인하기 위해 학습기와 서킷 제외 방식을 동일하게 두고, 기존 경계·몸 입력과 새로 추가한 개별 경계의 원근 굽음을 비교했다. 평균 정밀도는 Imola 0.154→0.152, Laguna Seca 0.164→0.167, Zandvoort 0.135→0.132, Mugello 0.321→0.344였다. 최대 점수 상태를 접근으로 판독한 횟수는 네 서킷 합계에서 적중 89→77장, 오판 401→372장이었다. 따라서 개별 경계의 굽음 입력만으로 서킷 전반의 접근 판독이 개선되지는 않았다. 개발 오경보·거리 오차 상한 내에서 새 접근 모델은 추가 적중을 얻지 못했다. 기존 전체 프레임 접근 모델은 개발 T4/T5에서 적중 한 건과 거리 오차 한 건을 추가했고, Silverstone에서는 범위 밖 오경보 한 건을 추가했다. 새 접근 모델은 추가 경보 없이 기존 판독을 재현했다. Silverstone 우회전 적중은 경계와 T4/T5 모두 2/13, 직선·범위 밖 경보는 14→10건, 내부 경보는 5→7건이었다. 시험 입력의 복구 경계에는 오른쪽 누락 1점이 횡오차 0.97m로 복원된 상태가 포함됐다.
