# 차량 이동으로 정렬한 노면 특징 추적 · 2026-11-12

Silverstone 1967과 Spa의 저장 영상 2,400묶음에서 이전 전방 영상을 차량 이동량에 맞춰 먼저 변환하고, 현재 영상과 남은 위치 차이를 추적했다. 변환은 고정 카메라 설정과 로컬 속도·요율, 초기 차체 평면을 사용했다. 추적한 좌표를 원래 이전 영상으로 되돌린 뒤 삼각측량하고, 기존 강건 평면 적합과 관측 범위 기준을 적용했다. 지도나 절대 자세는 판독 입력에 사용하지 않았다. 같은 경계 후보를 경계 확인 모델과 T4/T5 결합 모델에 각각 넣었다. ## 전방과 측면 카메라의 관측 범위

고정 카메라 설정에서 전방 1–40m, 좌우 ±16m, 높이 ±1m를 격자로 검사했다. 영상 끝까지 허용하면 전방과 각 측면에 함께 보이는 격자점은 차체 중심에서 최소 6.5m 떨어져 있었다. 양쪽 영상의 사방 4%를 피하면, 공통 가시 영역의 횡거리는 최소 9.5m였고 중앙 좌우 8m 이내의 격자점은 없었다. 이 수치는 영상에서 동일한 표면임을 확인하기 전의 카메라 기하 검사다. 현재 배치에서 도로 중앙의 평면을 동시 영상으로 맞추기에는 공통 영역이 부족하다.
