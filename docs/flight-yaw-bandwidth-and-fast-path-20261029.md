### 원래 이력의 분해

[t1249 분해](../runs/flight-physical-yaw-decomposition-continued-20261029-t1249/result.json)는
3블록의 양방향 full6회를 모두 사용했다. 유리한 조건을 골라 쓰지 않았다.
원래 영상·몸 감각·시각·전체 이력은 유지했고, flight 회로에만5개의 독립 상태를 두었다.

1. 원래 조건 복제.
2. yaw 값만0, 유효성 그대로.
3. yaw 부호 반전, 유효성 그대로.
4. 기존 `scene_command` 제거: 정규화된 시각 명령 증거0, 학습 bias 유지.
5. yaw0와 시각 명령 제거의 조합.

모든 원래 시각의 이전 입력 유지·10ms 적분·소수 잔여 간격을 보존했다.
원래 조건 복제는6회 전체에서 기존 출력과 **최대 차이0**이었다.
몸 피드백이 바꾼 조향의 최대 변화는 외부 교란0.05의 **1.569~1.786%**였다.
사전에 나열한9개 지연의 탐색적 상관 최대값은 실제 중앙 시차 **80.8~121.3ms**에서 나타났다.
이는 정확한 신경 전달 지연을 재는 실험이 아니다. 과거의 실제 표본만 선택했고 보간하지 않았다.

시각 명령의 동적 영향도 조건마다 달랐다. 예를 들어 block1/+ 조건의 시각 명령 효과RMS는
0.0006492로 몸 효과0.0005088보다 컸다. 이것만으로 실제 실패를 시각 원인 하나로 귀속하지 않는다.
시각 명령 제거는 망막이나 생물학적 시각 경로 제거와 동일하지 않다.

[분해 표·그래프](../runs/flight-physical-yaw-decomposition-report-20261029-t1252/summary.md).
그래프에서 파랑/초록은 의도 단위, 주황은 실제 yaw(rad/s)로 다른 축이다.

[t1253](../runs/flight-yaw-frequency-probe-20261029-t1253/result.json)은 원래 체크포인트·고정 그래프·

실제 AC 관측으로 기록하지 않는다. body baseline은 원래 full trial00의 마지막 baseline 표본이고,
yaw만 합성 사인 자극으로 바꿨다. 장면은 학습 정규화 평균에 고정했다.

진폭0.005/0.02rad/s × 감각 갱신10/40ms × 주파수0.5/1/2/4/8/12Hz =24조건이다.

학습 파라미터/영속 버퍼 불변, CSR 캐시와 원래 희소 행렬의 값 일치를 확인했다.

## 생물학적 근거와 현재 축약의 차이

초파리의 haltere afferent와 B1 운동뉴런 사이의 전기적 연결은 실제 실험 근거가 있다.
야생형과 shaking-B 변이를 비교한 연구는 빠른 근육 반응과 전기적 연결의 기여를 보고했다.
이 근육 EMG 지연을 모델 뉴런의 시간 상수와 동일시하지 않는다.
[Trimarchi & Murphey, 1997](https://pmc.ncbi.nlm.nih.gov/articles/PMC6573327/).

2026년 FANC 비행 제어 지도는 감각 하위형별 운동뉴런 연결을 제시하며,
화학 연결과 함께 전기적 연결 가능성을 별도로 다룬다. 전기 시냅스의 직접 검출 한계를 설명하고,
표면 겹침을 대리 지표로 사용한다. 이 대리 지표를 실측 전기 전도도/연결 수로 바꾸어 쓰면 안 된다.
[Dhawan et al., 2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC12872070/).

현재 `SignedRateCircuit`는 전기 시냅스·스파이크·날갯짓 위상 없는 공통50ms 발화율 축약이다.
따라서 실측 화학 연결망을 사용한다는 사실만으로 빠른 비행 균형 기전까지 구현됐다고 할 수 없다.
반대로 현재 느린 모델의 실패가 원래 초파리 비행 회로의 실패를 뜻하지도 않는다.
