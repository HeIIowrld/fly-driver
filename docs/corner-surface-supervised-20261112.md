# 충돌 메시 라벨로 학습한 영상 경계 · 2026-11-12

Magione·Spa의 저장 영상 2,408장으로 전방 경계 모델을 학습했다. 각 녹화의 마지막 20%인 619장은 검증에 사용했고, 경계에 인접한 앞 12장은 학습에서 제외했다. 두 서킷의 주행 자료에서 고른 체크포인트는 14회 중 11회차였다. Silverstone은 학습과 체크포인트 선택에서 제외했다. Silverstone 영상은 앞선 개발 진단에서 이미 사용한 녹화다. [학습 분할과 체크포인트 해시](../runs/vision-corner-surface-supervised-20261112-01/training.json)

전방 영상 320×180의 72–151행을 160×40으로 줄였다. 모델은 각 10–34m 단면의 좌우 횡좌표, 경계가 나타날 영상 행, 추론에 쓸 수 있는 표본 여부를 출력한다. 인접 비유효 노면이 확인되고 화면 안에 투영된 경계를 지도 라벨로 사용했다. 같은 좌표로 만든 2D 경계 점수도 함께 학습했다. 투영만으로 가림 여부를 확정할 수 없다. 기준 노면 메시와 카메라 렌더 좌표는 학습 라벨과 사후 채점에 사용했다. 추론에는 영상과 고정 카메라 배치를 넣었고, 기존 네 방향 영상의 가까운 경계와 확인기의 몸 감각을 재사용했다. 첫 GPU 시도는 BatchNorm에서 MIOpen 컴파일 오류가 났고 GroupNorm으로 바꿔 학습을 완료했다. ## Silverstone 경계 복구

우회전 접근 13장의 16–34m 중 전방 화면에 투영되고 인접 표면이 확인된 오른쪽 경계는 125점, 왼쪽은 128점이었다. 아래는 기존 영상 경계와 같은 프레임에서 비교한 결과다. 횡오차는 두 방식이 모두 추정한 오른쪽 113점에 대한 평균이다.

| --- | ---: | ---: | ---: |
| 기존 34m 영상 경계 | 113/125 | 102 | 1.56m |

## 코너 후보와 최종 판독

같은 1,200프레임에서 34m 대조군의 경보와 후보를 프레임별로 재현했다. 학습 경계를 넣어도 최종 우회전 적중은 네 조건 모두 경계 **1/13**, T4/T5 결합 **3/13**이었다. 방향과 시작 거리 ±5m를 모두 맞힌 결합 판독은 기존 34m와 직접 좌표 사용 조건에서 10장, 2D 점수로 교체한 두 조건에서 9장이었다. 결합 조건의 직선·범위 밖 오경보는 117건에서 직접 좌표로 빈 곳을 채우면 122건, 예측 행에서 2D 점수로 교체하면 129건이었다. [동일 프레임 검증](../runs/vision-corner-surface-supervised-20261112-01/verification.json)

489번에서 모델은 좌회전 후보를 우회전 10m로 바꿨다. 실제 거리는 11.75m였고 확인 점수는 경계 −0.336, T4/T5 결합 0.176으로 둘 다 고정 문턱 0.25 미만이었다. 490번에서 후보가 없던 34m 경계에 모델이 우 6m를 제안했다. 실제는 5.54m다. 예측 행을 쓰면 우 8m에 확인 점수 0.279를 얻었으나, 기존 우 14m 경보 우선 규칙 때문에 최종 경보는 그대로였다.

사후 대조에서 직접 횡좌표와 예측 행을 읽은 두 제안이 같은 방향에서 3m 이내로 일치하고 그중 하나가 확인 문턱을 넘을 때만 기존 거리 교체를 허용했다. 490번은 14→8m로 개선됐지만 세 건의 기존 동시 적중을 잃어 전체 동시 적중은 10→8건이었다. 경보 유무와 방향은 그대로였고, 이 교체 규칙은 채택하지 않았다. [거리 교체 대조](../runs/vision-corner-surface-supervised-20261112-01/distance-replacement.json)

새 후보가 있었고 두 모델에 기존 경보가 없던 프레임에서 직접 횡좌표 교체 조건의 T4/T5 전용 동시 적중은 1장으로 좌회전이었다. 그 조건의 T4/T5 전용 직선·범위 밖 오경보는 32건, 경계 전용 오경보는 21건이었다. 학습 모델은 경계 누락을 줄였으나 Silverstone 우회전 예고 성능을 높이지 못해 고정 판독기에는 채택하지 않았다. 다음 비교에서는 개별 횡좌표뿐 아니라 연속 단면의 방향과 굽음 시작을 물리 경계로 지도하고, 그 후보의 확인 점수를 서킷을 빼고 검증한다.
