# 겹눈과 도로 경계를 함께 쓴 코너 예고 · 2026-11-11

앞선 비교에서는 경계 굽음의 방향과 위치를 세 캡처 연속으로 확인해도 Magione에서 직선·범위 밖 오경보가 99개 추가됐다. 이번에는 그 후보를 겹눈의 코너 유무 점수로 확인했다. 3시점·4시야의 T4/T5 특징을 읽는 여섯 가중치는 Monza 기존 학습 구간에서만 적합한 것이다. 이번에는 새 가중치를 학습하지 않았다. [겹눈 판독층 학습](corner-factorized-readout-20261111.md) · [경계 확인 실험](corner-boundary-uncertainty-20261111.md)

Magione 1,887개와 Imola 616개 캡처 전체를 채점했다. Imola에는 4–20m 접근 양성이 없다. 기존 경보는 보존하고 새 경보에만 겹눈 점수 기준을 적용했다. 현재 점수와 연속 2·3캡처의 평균·최솟값, 좌·우 일치 여부, 거리 일치 조건을 비교했다. 새 경보 거리에는 경계 시작 거리, 순서형 겹눈 거리, 두 거리의 평균을 각각 썼다. 겹눈 특징이 없는 프레임에서는 이 결합 조건으로 새 경보를 만들지 않았다. 지도와 절대 위치는 채점에만 썼으며 Laguna Seca 자료는 이번 실험에 쓰지 않았다.

## 전체 비교

2,160개 설정에서 관측 점수가 바뀌는 임계값 65,703개를 검사했다. Magione 좌회전 적중을 늘리면서 두 서킷의 직선·범위 밖 오경보를 동시에 유지한 설정은 없었다.

좌회전과 방향·거리 결합 적중을 함께 늘린 설정 중 오경보 증가가 가장 작았던 것은 세 캡처의 경계 굽음 후보에 현재 겹눈 유무 점수를 적용하고, 거리는 기존 순서형 겹눈 판독으로 발행한 경우다. 아래 표는 이 설정을 개발 영상에서 고른 결과다.

| 지표 | 기존 혼합 후보 | 경계와 겹눈 결합 |
| --- | ---: | ---: |
| Magione 좌회전 | 9/64 | 14/64 |
| Magione 우회전 | 62/79 | 62/79 |
| Magione 방향·거리 ±5m | 51 | 56 |
| Magione 직선·범위 밖 오경보 | 28 | 28 |
| Imola 직선·범위 밖 오경보 | 2 | 3 |

추가 적중 5개는 한 물리 좌회전의 두 회차에 집중됐다. 이 두 회차에서 최초 안정 예고는 5.06→6.54m와 5.48→6.47m였고 나머지 두 회차는 같았다. 공통 인접 67쌍의 거리 변화 오차 0.392m와 실제 접근 중 역행 22회는 그대로였다. 추가된 5쌍을 포함한 전체 72쌍에서는 변화 오차가 0.420m, 역행은 24회였다.

추가된 Imola 오경보는 실제 코너 시작이 약 106m 남은 영상에서 4.86m를 예고했다. Magione에서는 직선·범위 밖 오경보가 늘지 않았지만 코너 내부에 새 경보 두 개도 생겼다. 이들은 공통 채점에서 별도 분류한다. 새 독립 평가 후보로 채택하지 않았다.
