# 비행 회로 출력 → 실제 AC 정차 조향 응답

기록: 2026-10-29, Asia/Seoul. [프로젝트 대전제](PROJECT_CHARTER.md)는 그대로다.
**실제 영상과 몸 감각을 받는 비행 후보의 조향 의도를 게임 축에 전달하고,
좌·우 응답을 독립 native 기록으로 확인했다.** 정차 부품 시험이며 경로 추종·주행 중
균형·학습한 가감속·완주·레이싱 최적화를 검증한 결과는 아니다. 후보 t1121은 미승격이다.

## 구성과 실제 입력

- 입력/회로: 기존 t1132 전체 재생을 통과한 `FlightStream`과 batched 설정을 그대로 사용했다.
  독립 네 시점 → 고정 저자 시각 회로 → 공간 시각/몸 v1 → 선택 비행 회로 → 두 운동 의도다.
- 새 변환: `src/flybrain_drive/flight_actuator.py`. 좌회전 의도 양수에 AC 조향 음수를 대응하고
  조향에 0.6을 곱한 뒤 ±0.1로 제한한다. 원래 의도·제한 전후·페달 변환을 모두 기록한다.
- **차량 페달은 전 구간 throttle=0/brake=1로 덮어썼다.** 회로의 전진/정지 출력을
  학습된 가감속 제어로 적용한 것이 아니다. 기어 버튼도 보내지 않았다.
- 명령은 시각 기준 0 → 좌 과제 +0.5 → 우 과제 −0.5 → 시각 기준 0의 고정 네 단계,
  단계당 25관측이다. 과제 명령을 회로 입력에 넣으며 출력축을 직접 좌우로 강제하지 않는다.
  이는 사전 지정한 부품 자극이다. 영상에서 커브를 발견해 회전했다는 시험으로 해석하지 않는다.
- 전 구간 원래 에피소드/관측 시각·회로 상태·이전 입력 유지. 단계 전환 때 상태를 초기화하지 않았다.
  반환 단계의 시각 기준도 조향 중립을 뜻하지 않는다. 최종 중립은 명시적 정리 입력이다.

표는 각 단계 마지막10관측의 응답 요약이다. **재생은 처음부터100관측 전부를 사용했다.**
독립 native 표본은 요약 구간 시작60ms 뒤부터 마지막 요청 직전까지 사용했다.
기존 t933 실제 보정 원자료에서 native gain=1.40624990/정규화 조향을 다시 계산했다.
차량/프로필/DLL/축 binding을 맞췄고, 단위는 `native_game_units`다. rad/deg로 재명명하지 않는다.
감사 허용오차0.005는 수집 후 적용한 공학적 대조 기준이며 사전 등록한 독립 생리 시험이 아니다.

## 실패와 세션 준비

첫 읽기 전용 사전 검사 t1143은 native AI 플래그 때문에 입력0개로 중단했다.
t1144의 API 재개 후10개 새 물리 패킷에서도 native AI=true였지만 CSP는 false를 보고했다.
따라서 단순히 일시정지의 오래된 패킷 때문이라고 단정할 수 없다. 원인 자체는 미해결이다.
가드를 완화하지 않고 t1145에서 명시적으로 API restart/start한 새 에피소드를 시작했고,
새10패킷의 native AI=false와 정차/브레이크를 확인한 뒤 다시 pause했다.
이후 t1146 사전 검사와 t1147 계측을 진행했다. 창 활성화·클릭·키 입력은0회다.

감사 t1148은 Python tuple과 JSON list의 표현 차이 검사 때문에,
t1149는 과거 보정 로그의 open 이벤트를 표본으로 취급한 오류 때문에 실패했다.
감사기를 수정한 뒤 같은 t1147 원본 전체로 t1150을 통과했다. 실패 결과도 보존했다.
실제 게임 시험을 다시 실행하거나 원자료를 편집해 통과시키지 않았다.

## 재사용과 다음 작업

`scripts/probe_flight_stationary_steering.py`는 `--execute` 없으면 읽기 전용 사전 검사다.
고정 계획은 `configs/flight-stationary-steering-v1-20261029.json`이고, 실제 실행은
성공한 전체 추론 소스/설정 인증과 일치해야 한다. 로컬 원본 로그와 NAS 복사 해시를 대조한다.
추론 전 actor 입력을 보존하고, 정리 입력에 실패해도 소유한 vJoy를 해제하도록 했다.
관련 codec 검사7개와 새 파일 Ruff가 통과했다.

다음은 **이동하는 차량의 실제 회전·기울기·하중 반응과 지연을 확인하고,
몸 피드백 경로의 교란 억제와 제거 대조를 수행하는 것**이다. 좌우 커브·양성 제동 자료,
경로 판단의 중립 편향·전이 실패·T4d 불일치·나머지 감각축 등록은 여전히 남는다.
최종 성공 조건인 학생 단독 유효 완주·반복·타이어/셋업 변화 대응·랩타임 최적화는 유지한다.
