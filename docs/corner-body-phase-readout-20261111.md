# 차량 회전과 코너 진입 전후의 판독 · 2026-11-11

같은 일곱 상태 판독기에 전방 운동 시각만, 차량 상대 운동만, 둘을 함께 넣는 조건을 비교했다. 차량 입력은 현재 속도와 요율, 직전 대비 변화, 요율을 속도로 나눈 곡률 근사다. 절대 위치와 방향은 학습 라벨과 채점에만 사용했다. 몸 값이 없으면 결측을 표시하고 프레임이 끊기면 직전 값을 쓰지 않았다. 차량 입력만 사용한 상태 판독도 최종 예고 거리는 기존 영상 거리 추정을 사용했다. 원본 몸 상태가 카메라와 동일한 물리 시각인지에 대한 검증은 남아 있다. Spa에서 절대 요율 중앙값은 직선 0.017rad/s, 4–20m 접근 0.179rad/s, 코너 내부 0.385rad/s였다. 차량 운동을 더했을 때 실제 좌 접근 22개의 좌우 방향 적중은 10→16개, 코너 내부로 분류한 수는 14→11개였다. 우 접근 49개의 방향 적중은 44→48개였다. 실제 코너 내부 464개에서 내부 점수가 가장 높은 프레임은 372→381개였다. 방향 적중은 정답으로 접근 프레임을 고른 뒤 좌우 점수를 비교했다. 공통 연속 거리 변화 오차는 5.01m로 유지됐다. 전체 7,287개 캡처에서 평가 서킷과 Spa를 새 학습 및 문턱 선택에서 제외했다. 문턱 선택에 사용하는 개발 서킷의 점수 역시 각 서킷을 제외해 학습한 모델로 냈다. 18개 비교 중 두 개에서 문턱이 선택됐지만 좌 적중 개선은 없었다. 몸 운동이 방향에 도움이 됐으며, 시작점이 실제로 4–20m 앞이라는 판정에는 추가 검증이 필요하다.
