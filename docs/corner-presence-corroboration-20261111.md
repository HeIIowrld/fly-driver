# 코너 유무 문턱을 놓친 프레임의 영상 근거 · 2026-11-11

운동 시각 판독의 코너 유무 점수가 기존 문턱 아래인 프레임에서, 좌우 점수 차와 영상 경계를 함께 쓰는 보완 판독을 비교했다. 방향이 일치하고 두 시작 거리의 차가 6m 이내일 때만 제안했다. 제안이 방향과 ±5m 거리 조건을 함께 맞힐지 로지스틱 회귀로 학습했다. 지도는 학습 정답과 채점에 사용했다. 평가할 서킷을 가중치 학습과 문턱 선택에서 제외했고 Spa는 모든 학습과 문턱 선택에서 제외했다.
