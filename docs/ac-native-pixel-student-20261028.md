## 입력을 어떻게 연결했는가

`configs/ac-native-pixel-retina.json`과 `ac_pixel_retina.py`는 1284×784 원본 창에서
전면 영역을 픽셀 좌표로 지정하고, 1709개의 엇갈린 수용장을 배치한다. 수용 폭은 픽셀 단위의
공학적 설정이다. 실제 파리 광학축·AC 카메라 FOV·신체 좌표계 광선으로 보정했다고 하지 않는다.
뇌 입력의 이웃 관계는 단위 좌표 임베딩으로 정의하며, 기존 신경 노드와 연결은 유지한다.

기록 영상을 직접 확인했을 때 미러는 잘리거나 내용이 불분명했다. 세 미러 입력은 값0·유효도0으로
남겼다. 전면 외 시점이 구현됐다고 표시하지 않는다. 미러를 직접 투영 카메라처럼 위장해 기존
ViewMap에 넣지 않았다. 기존 데이터 로더의 기본 요구는 전체 시점 유지이며, 이 실험의 보정에만
`required_views=[front]`를 명시했다.

타이어 온도·휠 하중·서스펜션 이동량은 기존 기관 모사132특징의 해당 구간으로 연결했다.
온도 C→K 등의 변환과 인코딩 범위는 선언한 공학 모델이며 독립적인 물리 단위 검증은 남아 있다.
도로 바퀴 조향각과 신체 축 각속도는 보정이 없어 누락 마스크로 유지했다. 최초 변화율은 무효,
실제 새 표본 이후에만 변화율이 유효해지며, 오래된 입력 뒤 복귀도 새 이력으로 시작한다.

시간은 호스트 수신 시각을 사용한다. 이를 simulation/exposure 시각이라고 이름만 바꾸지 않았다.
같은 캡처 ID를 다시 쓰면 이전 시간 대비를 유지하고, 새 영상으로 세지 않는다. 원본 기록의
`training_admissible=false`를 변경하지 않았으며 별도의 **실험적 host-paired 적합 데이터**를 만들었다.
이 결과는 정밀 보정 데이터나 배포 준비 완료를 뜻하지 않는다.
