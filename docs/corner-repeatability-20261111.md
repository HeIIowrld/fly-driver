# 같은 물리 코너에서 반복된 판독 누락 · 2026-11-11

저장 영상 여섯 서킷의 7,287프레임에서 공통 채점기가 나눈 4–20m 접근을 물리 코너별로 모았다. 같은 코너를 두 번 지났을 때 각 주행의 방향 적중과 안정 예고를 비교했다. 두 방문에서 남은 거리 차가 2m 이내인 프레임은 거리 차가 작은 순서로 중복 없이 짝지었다. 물리 코너 ID와 거리는 결과 비교에 사용했다. Magione 좌 ID 2는 두 방문 모두 안정 예고가 나왔지만, 비슷한 거리의 32쌍 중 25쌍은 양쪽 프레임에서 모두 방향을 놓쳤다. 그 50프레임 전부에서 원시 좌회전 점수가 우회전과 배경보다 높았고, 기존 코너 유무 문턱을 넘은 프레임은 0개였다. 오른쪽 ID 0의 양쪽 누락 4쌍도 원시 우회전 점수는 8/8에서 최고였고 유무 문턱 통과는 0/8이었다.

Imola 좌 ID 32의 양쪽 누락 3쌍은 좌회전 점수가 우회전보다 높은 프레임이 6/6, 배경보다 높은 프레임은 1/6이었다. 유무 문턱 통과는 0/6이었다. 나머지 반복 누락 6곳에서는 두 방문 모두 방향 적중이 없었으나 거리 차 2m 이내에 해당하는 짝이 없었다. 일치한 프레임은 같은 코너에 속하므로 표본 수를 독립 코너 수로 해석하지 않는다.
