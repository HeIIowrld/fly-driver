저자 μCT 광학축1,709개를 관측 경로에 연결하고 별도 시각 readout·회로 checkpoint를 만들었다. 개발4조건에서 회로+몸 피드백 **4/4**, 영상 제거 **0/4**, 회로 절단 **0/4**다. 좌460/857·우446/852축만 현재 카메라로 관측되고 나머지는 무효다. 새 모델의 평균 횡오차 RMS는0.136934m로 이전 합성 격자 회로0.094716m보다 크다. 생물학적 충실도나 성능 개선을 확정하지 않는다. 전체 테스트137개 통과·69파일 수집 해시 대조 완료. [구현·평가·한계](anatomical-eye-driving-20261027.md).

아래 단계별 기록은 당시의 상태다. 새 모델은 이전 합성 모델30/30 반복과 별도이며 상류 시각/CX 계산, 기관 생리학, 속도·제동 및 AC 연결 관문은 미완료다.

### 후속 구현: 감각 계약·기관 커널·AC 설치 점검

같은 날 목표 작업을 이어서 다음 코드를 추가했다. 추가·기존 선택 테스트49개와 전체 소스 정적 검사는 통과했으며, 전체 물리 테스트 재현을 뜻하지 않는다. [새 감각 검증](../tests/test_sensor_organs.py), [설치 점검 검증](../tests/test_ac_probe.py).

- `sensor_contract.py`: 명시적인 SI 단위/좌표·simulation/host 시계, actor용 눈/몸/적용 조작과 별도 TrainingOnly. 미래·미수신 입력, 허용하지 않은 몸 채널·정답 provenance, 잘못된 validity와 shape를 거절한다. 수신 시각과 simulation 시각을 서로 빼지 않는다.
- `body_organs.py`: 위치 선호 집단, 위치 변화의 증가/감소 채널, 회전의 양/음 채널. 새로운 센서 표본에서만 갱신하고 재사용 표본은 유지한다. 누락/오래된 표본은 무효화하고 episode 경계에서 상태를 초기화한다. **기능적 기관 근사이며 측정 뉴런·학습 정책과 아직 연결되지 않았다.**
- `ac-probe`: Steam의 등록/기본 라이브러리와 지정 경로를 읽는 점검 명령. 실제 점검은 [설치 점검 결과](../runs/ac-install-probe-20261027/capabilities.json)에 남겼다. 확인한 라이브러리에서는 게임 엔진을 찾지 못했다. 다른 경로의 설치 여부를 부정하는 결과는 아니다. 영상·동기 양안·telemetry·조작 응답은 모두 `not_probed`다.

A0/A1과 P01/P02/P03의 일부가 진행된 상태다. AC bridge, 감각→정책 연결, 실제 기능 그래프, AC 구간/전체 랩은 미완료다.

### 후속 통합: 실제 영상·물리에서 감각→정책 연결

그다음 겹눈의 방향/수용각 적분, 관측 packing, 기존 MuJoCo V→기관 변환, GRU/합성 회로의 지속 추론 경로를 연결했다. WSL CPU의 전체 테스트는 **110개 통과**했고 두 모델의 실제 영상·물리100단계 진단과 저장 모델 행동 재생도 완료했다. [자세한 구현·실행 증거](sensory-integration-20261027.md).

이 단계에서는 추론·역전파까지 검증했다. 아래 후속 작업으로 BC/DAgger 수집·훈련까지 연결했다. 실제 초파리 기능 회로와 AC는 여전히 미연결이다.

### 후속 학습·실제 구조 후보 검토

새 감각 입력으로 고정 저속 조향 BC/DAgger를 실행했다. 개발 평가4조건에서 무학습·BC·DAgger 모두 완료0/4이며 평균 진행거리는 각각6.13/27.42/23.30m다. 영상 누락 최종 모델은14.16m다. 단일 시드의 개발 실험이며 A2는 통과하지 않았다. `sensory_imitation.py`는 교사 label·실제 조작·actor 입력을 분리하며 평가 시 교사 조향은 없다.

## 다음 작업

P01 관측·시간·의도 계약과 P02 AC capability probe를 먼저 수행한다. AC는 최종 운전 대상이고 MuJoCo는 감각·회로·학습의 빠른 시험장이다. 전체 차량 보정·다른 backend 도입을 끝낼 때까지 AC 연결 확인을 미루지 않는다. T0의 축·물리 검증은 기존 MuJoCo 시험에 계속 적용한다.

그다음 P03 겹눈/기관 자극, P04 저속 고정 속도 조향, P05 실제 그래프·포트를 준비하고 P06 몸 피드백 및 AC 구간을 연결한다. BC+반복 DAgger가 독립 주행을 통과한 뒤에만 선택적 RL을 검토한다. 첫 서킷은 설치·동기 시야가 확인된 구성으로 고르며 Spa/Nordschleife는 후속 확장이다. 기능을 실행한 것, 합성 GRU가 주행한 것, 실제 기능 회로가 완주한 것을 각각 기록한다.
