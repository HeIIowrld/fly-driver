# 현재 카메라로 복구 경계 후보 재확인 · 2026-11-12

복구 후보를 고정 마운트 기하로 현재 전방 카메라와 해당 측면 카메라에 투영했다. 후보 횡좌표 앞뒤가 아니라 도로 안쪽·바깥쪽을 가로지르는 ±0.8m 띠를 사용했다. 띠 전체가 같은 카메라에 들어오고 두 픽셀 이상 차이가 날 때 Lab 명도·색차와 중앙·최대 기울기를 기록했다. 보이지 않는 방향은 결측으로 남겼다. 오른쪽 경계에는 전방·우측, 왼쪽에는 전방·좌측을 사용했다. 이 재확인에 후방은 쓰지 않았으며 기존 T4/T5 계산과 코너 판독 설정은 그대로였다. 카메라 투영은 고정 마운트의 평면을 쓰며 가림 여부를 판단하지 않는다. [코드](../runs/vision-corner-pixel-checked-boundary-20261112-01/pixel_checked.py)

네 개발 서킷을 하나씩 제외하고 학습했다. 경계 좌표 자체는 이전과 같은 후보를 썼고, 횡오차 1.25m 이내 비율 70% 이상에서 정확한 채택이 가장 많은 문턱을 선택했다. 기존 폭·이력 모델은 875점 중 631점이 정확했고, 영상 입력을 추가한 모델은 문턱 0.70에서 789점 중 555점이 정확했다. 시험 녹화 전에 문턱과 모델을 동결했다. [학습과 동결 설정](../runs/vision-corner-pixel-checked-boundary-20261112-01/training.json)

Silverstone 620번과 1049번의 전방 10m 오른쪽 경계는 폭으로 구한 좌표가 물리 라벨에서 각각 0.43m와 0.34m 떨어져 있었다. 두 후보의 띠 전체는 전방 화면에 들어오지 않았고 우측 화면에서만 측정됐다. 우측 화면의 바깥쪽 명도 중앙값은 안쪽보다 각각 87·31 낮았다. 색차는 각각 4.12·4.47이었다. 강한 명도 차는 있었지만 새 확인 점수는 0.525·0.463으로 문턱 아래였다. 우회전 접근에서 누락된 오른쪽 10점은 둘 다 보류했다. Silverstone 전체에서 정확히 복구한 오른쪽 점은 167→146점이었다. 적중은 방향과 시작 거리 ±5m를 함께 맞힌 프레임이다. Silverstone에서 T4/T5는 직선 경보와 범위 밖 경보를 한 건씩 없앴고, 코너 내부 경보는 한 건을 없애고 세 건을 추가했다. Monza는 코너 내부 라벨이 없는 기존 989장을 비교했다. 원래 관측의 좌표 보존, 두 방법의 같은 후보, 이전 폭·이력 결과의 재현, 합성 영상에서 화면 밖 띠 제외를 확인했다. 새 모델은 고정 판독기에 적용하지 않았다.
