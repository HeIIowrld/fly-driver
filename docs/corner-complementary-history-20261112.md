# 좌우 경계를 따로 누적한 코너 판독 · 2026-11-12

Silverstone 1967, Spa와 다섯 개발 서킷의 저장 영상 8,487묶음을 재생했다. 이전 시간 누적 실험은 주로 한 프레임에서 좌우 경계가 함께 잡힌 단면을 모았다. 이번에는 한쪽만 관측돼도 해당 측면의 점을 차량 좌표에 저장했다. 0.24초 안의 점을 로컬 속도·요율로 현재 좌표에 옮겨, 현재 비어 있는 측면만 채웠다. 보간은 관측 사이에서만 했고, 여러 과거 프레임의 횡좌표가 0.8m보다 크게 다르면 채우지 않았다. 추정값을 다시 이력으로 넣지 않았으며, 프레임이 끊기거나 이동량을 읽을 수 없으면 이력을 비웠다. 두 기존 모델이 모두 경보를 내지 않던 프레임에서 과거 두 장 조건의 같은 후보를 비교했다. Silverstone 898번의 좌회전은 T4/T5 결합만 확인했다. 예고 8m, 실제 8.56m였다. 직선·범위 밖에서는 T4/T5만 채택한 경보 44건과 경계만 채택한 경보 17건이 있었다. 다섯 개발 서킷의 우회전 접근에서 과거 두 장 조건은 좌우 경계 쌍을 2,251→2,311개로 늘렸지만, 결합 방향 적중과 동시 적중은 줄었다.

이 누적 방식은 고정 판독기에 채택하지 않았다. Silverstone 620번에서 경계 누락을 줄였지만 시작점은 9.77m 가까이 당겨졌다. 다음 개선은 화면에서 본 경계의 연속 위치와 가시성을 지도하고, 화면에서 확인한 굽음과 실제 코너 시작 위치의 거리 오차를 함께 채점하는 것이다.
