# 시각 학습과 주행선 입력 감사

기록일: 2026-10-29, Asia/Seoul. 목적의 기준은 [프로젝트 대전제](PROJECT_CHARTER.md)다.
이 문서는 실행 결과를 보존하며, 생리 기능이나 자율주행 성공을 선언하지 않는다.

이 문서의 학습 결론은 t1086 당시 결과다. 이후의 통제된 업데이트·개발 평가·소비자 입력 검사는
[최신 학습 안정성 진단](flight-visual-optimizer-diagnosis-20261029.md)을 따른다.

## 결론

**v6 시각 어댑터는 학습했으나 유용한 시각 주행을 입증하지 못했다. 운전 모델로 승격하지 않는다.**
v5의 몸 피드백 보호 기준은 유지한다. 주행선 표시가 켜져 있던 사실도 발견했으므로,
기존 영상의 입력 적격성을 확인하기 전에는 주행선 없는 시각 학습 자료라고 단정하지 않는다.

## 학습 결과와 한계

- 구현: `src/flybrain_drive/flight_navigation.py`. 공간 시각 576특징을 DNa04/05 명령으로
  변환하는 학습 경계다. 누락된 상위 시각 기능의 공학적 근사이며 실측 시각→DN 연결이 아니다.
- `t1085`는 과거 상태에서 분리된 표적의 backward에서 실패했다. 실패 기록은 보존했다.
  `flight_learning.py`는 이런 표적의 평가를 유지하되 연결된 기울기가 없으면 optimizer를 실행하지 않는다.
- `t1086`은 원래 에피소드 시각·상태를 유지해 6epoch/216회 업데이트를 완료했다.
  분리 경계 표적 평가 6회는 optimizer를 건너뛰었다. 조향만 지도했으며 종방향 제어 학습은 아니다.
- 상속한 v5 파라미터·buffer는 전부 고정했다. 모형 내 회전 억제 부호는 16조건에서 유지됐다.
  실제 차량 안정화나 초파리 생리 검증을 뜻하지 않는다.
- 개발 기록의 조향 RMSE는 30km/h에서 0.062837, 15km/h에서 0.786995였다.
  시각 정보를 제거한 쪽이 더 좋아 유용한 시각 기여를 통과하지 못했다.
  개발 자료는 독립적인 최종 시험 자료가 아니다.
- `t1088`은 strict reload, 학습 관측 3028개의 정규화 재구성, v5 상속 상태 불변을 확인했다.
  카메라 순서 교란과 시각 정보 제거도 기록했다. 차량 시험과 actor 적격 판정은 false다.

## 정답 주행선의 영상 유입 방지

실제 AC 설정에서 `IDEAL_LINE=1`, 엔진에서도 표시 ON을 확인했다.
내부 CSP API로 정차·브레이크 유지 상태에서 OFF로 바꾼 뒤 다시 일시정지했다.
`t1097`은 일시정지 목표 상태 도달과 전후 창 비전면을 기록했다. 바탕화면 자동 조작은 없었다.

카메라는 정상 수집 시작과 매 프레임에 `idealLineShown == false`를 요구한다.
ON/OFF를 알 수 없는 경우도 정상 자료 수집을 허용하지 않는다. 최대 8프레임의 명시적 진단은
학습 자료와 구분한다. 영구 설정도 `IDEAL_LINE=0`으로 변경했고 원본을 보관했다.

한 위치의 ON/OFF 비교에는 작은 차체 위치 변화가 있어, 픽셀 차이만으로 주행선의 렌더 포함
여부를 판정할 수 없다. **과거 기록 전체의 주행선 부재는 미확인**이다. 현재 OFF라는 사실로
과거 자료를 소급 승인하지 않는다. HUD·정답 라인·지도·world pose를 actor에 우회 제공하지 않는
대전제를 유지한다.

## 이어서 할 일

1. 보조 주행선 없는 새 영상의 입력 적격성을 확인하고 기존 기록의 사용 가능 범위를 정한다.
2. v6의 시각 표현·학습 실패를 학습 자료에서 진단한다. 개발 결과에 맞춘 반복 조정을 최종 검증으로 부르지 않는다.
3. 보호된 몸 경계와 원래 시간 이력을 유지하며 시각 제거·교란 및 몸 피드백의 인과적 기여를 검증한다.
4. 제동·다양한 좌우 커브·미등록 몸 축·타이어/접지/셋업 변화와 실제 차량 안정화를 검증한다.
5. 검증된 구조로 AC 유효 완주·반복 안정성과 레이싱 라인/랩타임 개선을 평가한다. 목표는 미완료다.
