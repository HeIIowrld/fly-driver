# 코너 시작 판독과 진입·통과·탈출 라인 재생 · 2026-11-13

## 좌우와 시작 거리

기존 판독이 회전을 확정하지 않은 프레임에서 좌우 각각의 4–20m 시작 후보를 2m 간격으로 점수화했다. 후보 앞뒤의 좌우 경계에 구간별 곡률을 적합하고, 차량 국소 속도·요율과 경계 이력 특징을 사용했다. 경계 기반의 같은 후보에 T4/T5 운동 특징을 추가한 판독도 비교했다. 개발은 Imola·Laguna Seca·Zandvoort·Mugello에서 한 서킷씩 제외했다. 추가 직선·범위 밖 8건, 코너 내부 5건, 반대 방향 2건, 거리 오차 2건을 이번 비교의 상한으로 정했다. 두 방식 모두 그 상한 안에서 개발 적중을 추가하지 못해 기존 경보를 유지했다. 경계 방식의 첫 추가 적중을 내는 문턱에는 범위 밖 9건과 거리 오차 3건이 포함됐고, T4/T5 조건에는 코너 내부 8건과 거리 오차 3건이 포함됐다. ## 곡률로 연결한 국소 라인

차량 앞 관측 또는 인과적으로 복원된 양쪽 경계에서 경로를 생성했다. 단면 사이 공백은 최대 4.01m까지만 연결했다. 기존의 차량 원점에 접하는 삼차곡선과, 경계 안에서 연속 단면의 위치를 함께 최적화한 스플라인을 비교했다. 스플라인은 굽음이 매끄럽고 직전 경로와 이어지도록 선택했다. 직전 경로는 차량 국소 속도와 요율로 현재 좌표에 옮겼으며 세션이나 프레임 연속성이 끊기면 버렸다. 스플라인에는 경계 여유 1.1m와 곡률 한계 0.15m⁻¹를 적용하고 구간 내부의 극값을 확인했다. 스플라인의 지지 범위는 첫 관측 단면부터이며 차량 중심에서 해당 단면까지의 연결은 검증 범위에 포함하지 않았다. [라인 생성 코드](../runs/vision-corner-onset-through-line-20261113-01/rolling_lines.py)

Monza의 기존 비교와 같은 22개 코너 구간을 지도와 렌더 자세로 채점했다. 지도와 렌더 자세는 라인 생성기에 들어가지 않는다. 지도 경계에서 1.1m 이상 떨어진 출력만 인정하고, 연속 프레임이 공유하는 1m 간격 횡단면이 5개 이상이며 최대 횡방향 차이가 1m 이하일 때 이어진 것으로 셌다. 연속 구간에 진입·초반·중반·후반·탈출이 모두 포함되면 코너 전체를 통과한 라인으로 집계했다.

곡률 기반 라인의 전체 연결은 좌 2/8, 우 6/14였다. 예고 사용 여부에 따라 선택된 라인이 달라진 프레임은 세 영상에서 없었다. Monza 평가 구간에서 161프레임은 지도 여유에서 탈락했고 54프레임은 라인이 없었다. 앞서 보존된 Monza 비교도 전체 연결이 0/22였지만 경계 여유 조건이 달랐다. 표의 직접 비교는 동일 경계와 동일 여유 조건을 사용했다. 이 실험은 저장 영상의 국소 라인 연결을 검증했다. 차량 추종과 랩타임은 검증하지 않았다.
