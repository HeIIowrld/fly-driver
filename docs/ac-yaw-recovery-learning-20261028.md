# 실패 상태를 포함한 회복·제동 학습

기록일: 2026-10-28 KST. 전체 파리 자율 서킷 주행 목표는 미완료다.

## 자료

t310의 실제 학생 주행 140회는 t311에서 원시 영상·몸 감각을 재구성했을 때 조향·가속·제동 출력 오차가 모두 0이었다. t313은 같은 상태에 현재 30km/h 최대 목표의 기하 교사를 질의했다. actor 배열·유효성 마스크·시각은 그대로 유지했고 교사 전용 위치·방향을 actor에 추가하지 않았다. 교사 정답은 실행되지 않은 반사실 제어값이다.

교사는 140개 중 18개에서 제동 >0.05, 14개에서 제동 >0.3을 요청했다. 마지막 상태의 학생 요청은 조향 0.1183, 가속 0.4254, 제동 0이었다. 교사는 조향 0.2718, 가속 0, 제동 0.5를 요청했다. 그때 교사의 상황별 속도 목표는 21.13km/h였다. 실제 마지막 feedback은 33.647km/h, reference gap -0.979m, 측면 여유폭 0.992m였다. 즉 이전 시험의 중단은 3m gap보다 1m 측면 여유폭 제한에 해당한다.

t314는 정상 교사 주행 t301의 400개와 회복 질의 t313의 140개를 합친 2개 에피소드, 540개 표본이다. 에피소드를 임의로 잘라 리셋하거나, 실패 상황을 정상 교사 실행으로 표시하지 않는다.

## 일반 기관 연결부 재학습

t315는 t305에서 시작해 기관 연결부만 4 epoch, 136 update, 학습률 0.0003으로 조정했다. 초기/최종 학습 RMSE는 다음과 같다.

| 출력 | 초기 | 최종 |
|---|---:|---:|
| 조향 | 0.17019 | 0.14673 |
| 가속 | 0.10889 | 0.08730 |
| 제동 | 0.08839 | 0.07932 |

제동 출력 RMS는 0으로 붕괴했다. 평균 제동 오차 감소를 제동 학습 성공으로 해석하지 않는다. t316의 별도 개발 표본 75개에서 RMSE는 0.10706/0.08865/0.03453이었다. 제동 정답 >0.05인 8개에서 예측 제동은 전부 0, 해당 부분집합 RMSE는 0.10202였다. 이 모델은 채택하지 않았다. 원본 대비 바뀐 텐서는 기관 연결부 21개뿐이며 시각·회로·출력부는 그대로다.

## 드문 제동 표본의 가중치

학습 설정에 선택적인 `brake_positive_weight`, `brake_label_threshold`를 추가했다. 정답 제동이 문턱보다 큰 유효 표본의 제동 손실에만 가중치를 준다. 가중치는 actor 입력에 전달하지 않으며, 결측 라벨이나 에피소드 padding을 유효하게 만들지 않는다. 기존 기본값 1은 기존 손실을 유지한다.

일반 RMSE를 그대로 보고하면서, 별도의 가중 RMSE를 기록하고 가중치를 선언한 학습에서는 이 값으로 training checkpoint를 선택한다. 개발 자료를 checkpoint 선택에 사용하지 않는다. 기본 손실·마스크·padding·희귀 제동 gradient·checkpoint 선택에 관한 테스트를 통과했다.

t317은 t315에서 시작해 같은 540개 표본, 기관 연결부만, 학습률 0.0003, 6 epoch, 204 update로 학습했다. 제동 정답 >0.05에 가중치 20을 선언했다. 이 값은 공학적 실험 설정이며 파리의 생리 계수는 아니다.

학습 최종 일반 RMSE는 0.13075/0.08376/0.08012, 가중 RMSE는 0.13075/0.08376/0.27771이었다. 가중 제동 오차는 초기보다 개선하지 못했다. 전체 선택 점수는 조향·가속 개선으로 감소해 6 epoch가 선택되었다. 따라서 가중 선택만으로 제동 실패를 차단하지는 못하며 제동 부분집합 검증을 별도로 유지해야 한다.

t318의 별도 개발 RMSE는 0.09326/0.08902/0.04150이었다. 제동 필요 8개에서 평균 예측 제동은 0.000346, 제동 >0.05인 예측은 0개다. 제동 학습 성공으로 판정하지 않는다. 체크포인트 SHA256은 `00c7f519da0ee7f6113285f9a56f7885635fd0d7a98a6187f8850ced04404b5b`이다.

## 실제 제한 구간 시험

t319에서 화면 조작 없이 API로 에피소드 재준비와 정차 보정을 마쳤다. t320은 같은 `tracking_30kmh` 제한으로 실행했다. 모델 제어 198회 후 30.075m 목표 구간을 마쳤고, 정지 후 vJoy를 해제했다. 최고 속도는 17.469km/h, 마지막 feedback 속도는 17.365km/h였다. 제동 요청은 전부 0이었다. 느려진 결과와 경로 개선의 효과를 분리한 비교는 아니다.

주행 feedback 기준 마지막 reference gap은 -0.879m, 최대 절대 gap은 2.594m(출발 오프셋 포함), 최소 측면 여유폭은 1.026m였다. 여유폭이 제한 1m에 가깝다. 반복 성공이나 충분한 강건성을 검증하지 못했다. 실제 요청 간격 p50/p95/p99는 40.314/46.356/54.457ms로 40ms 마감 보장도 아니다.

t321은 원시 데이터에서 198개 모델 요청을 다시 계산해 세 출력 모두 최대 오차 0을 확인했다. 정지 후 이동까지 포함한 최대 기록 변위는 31.218m로, 제어 종료 시의 목표 이동량과 구별한다. foreground 이벤트 0회, actor의 위치 입력·교사 제어 사용 0회다. SDK 응답 시점 허용 오차는 통과하지 못했으므로 액추에이터 적용 지연의 정확한 교정은 여전히 미완료다. 세부 수치는 `runs/ac-yaw-brake-recovery-trial-audit-20261028-t321/trajectory-summary.json`에 원시 이벤트 해시와 함께 저장했다.

t322에서 API 일시정지를 확인했다. live 입력 선언은 기본 설정으로 복구했고 후보는 승격하지 않았다. t323은 새 주행 상태 198개에도 실행되지 않은 교사 정답을 붙였으며, t324에 정상/실패/새 주행 3개 에피소드, 총 738개 표본을 합쳤다. t324로 추가 학습한 모델은 아직 없다.

## 다음 검증

제동 필요 상태에서 halt 출력 뉴런 활성과 입력 연결부 gradient를 먼저 조사한다. 가중치만 더 키우며 평균 오차를 낮추는 접근으로 제동 실패를 해결했다고 보지 않는다. 이후 감속·회복 자료를 확장하고 반복 경로 유지, 30km/h 조절, 더 긴 구간과 서킷 완주 순서로 실제 성능을 확인한다. 이번 결과는 단일 30m 구간 완료이며 전체 목표 달성을 뜻하지 않는다.
