# 비행 후보의 실제 기록 초기 학습 — 2026-10-29

[대전제](PROJECT_CHARTER.md)에 따른 새 비행 후보를 실제 영상/몸 기록으로 처음 학습했다.
학습과 상태 재생은 실행됐지만 **조향 예측이 평균 부근에 머무르는 약한 후보**다.
실제 운전에 승격하지 않았고 커브 추종·제동·균형·전체 서킷을 검증한 결과가 아니다.

## 사용 자료와 출력 계약

`t1037`은 t1029의4시점 공간 시각576특징,t1028의 몸16채널/유효성,t1005의 교사 표적을
원래1,543관측·시각·단계에 맞췄다. 학생805+인계대기2는 표적이 없고,교사736관측 중722개만 유효하다.
577표적을 학습하고 뒤145개를 개발 구간으로 뒀다. 같은 에피소드의 연속 부분으로 독립 시험이 아니다.
앞선 학생/대기 이력도 신경 상태 계산에서 전부 유지했다.

기존 자기 운동 보정의 정지 기준은 이 기록에서 준비되지 않았다.6운동좌표는mask=false로 두고,
실제 망막별 밝기/T4/T5의 공간 특징을 주 시각 입력으로 사용했다.
입력에는 영상·허용된 몸 감각·고정 과제 명령[회전0,전진0.2]만 있고,지도/정답라인/world pose/교사 조작은 없다.

실제 native 조향과 yaw를 속도8km/h초과736표본에서 대조해 correlation=-0.9668을 확인했다.
따라서 새 좌회전 의도 정답은 -기존 normalized steering이며,전진 의도 정답은throttle-brake다.
이 초기 codec은 steering=-left,throttle=max(forward,0),brake=max(-forward,0)로 변환한다.
동시 가속/제동을 표현하지 못하므로 이 형태의 향후 표적은 거부한다. 원래3채널 정답은 보존했다.
현재722표적은 전부 우회전 쪽이고 제동 양성0개다. 조향범위0.0087–0.1244,스로틀0.0093–0.0330으로 좁다.

## 첫 실패와 수치 안정화

`t1038`은6epoch/60업데이트를 완료했으나 조향이+1에 포화돼 실패했다.
두 운동 뉴런 차동의 상쇄 때문에 활동 스케일이7.98e-7로 잡혀 출력 이득이 지나치게 커졌다.
이 실패를 보존했다. 이후 수정은 학습 구간의 포화와 기울기 문제에서 출발했다.
개발 구간도 이미 살펴본 상태이므로 재시험을 새로운 blind test로 부르지 않는다.

`t1039`는 모형의 중립 motor 활동을 스케일 하한으로 사용하고,
출력은tanh로 유지하되 손실은포화 전 값과atanh(정답)의 차이로 계산했다.
정답을 자르지 않으며±1끝점은 해당 손실에서 거부한다. 내부 뉴런 전파 규칙을 바꾸는 gradient surrogate는 아니다.
입력 경계lr0.0002/출력lr0.005,gradient norm1,6epoch를 실행 전에 고정했다.
검증 오차로 최적 epoch를 고르지 않고 마지막6epoch를 저장했다.

중립/활동 스케일은 첫 입력의 별도 모형 neutral실험과학습 prefix입력만 사용했다.
이 모형 실험을 원래 에피소드 앞에 붙이지 않았다. 실제 시간 재생은원래 시작에서 다시 시작했다.
손실 정규화는학습 표적의std를 사용하고,평가/상수 기준은선언한 표적을 사용한다.
과거 calibration.json의 labels_used=false/validation_inputs_used=false는중립/활동 스케일 산정의 범위다.
그 파일의target_scale/오차표가 정답 없이 계산됐다는 뜻은 아니며,후속 생성 코드의 필드명을 명확히 했다.
