# 실제 게임 영상의 시각·비행 회로 연속 추론

기록일: 2026-10-29, Asia/Seoul. [프로젝트 대전제](PROJECT_CHARTER.md)는 유지한다.
초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.

**실제 네 시점 영상→고정 시각 회로→몸 감각/선택 비행 회로→운동 의도의 온라인 경로를 연결했다.
3초79관측·30초742관측을 모두 추론하고 원본 재생으로 확인했다. 차량은 교사 AI가 운전했고,
학생의 조향·페달 의도는 기록만 했다. 자율주행 성공이나 후보 승격은 아니다.**

## 연결한 경로와 정보 경계

구현: `src/flybrain_drive/flight_stream.py`,
설정: `configs/flight-stream-batched-v1-20261029.json`.

`실제 front/left/right/rear RGB → 카메라별721망막 입력 → 독립된 고정 저자 시각 상태4개 →
망막별 밝기·T4/T5 공간 특징 → 몸 v1/과제 목표 → 선택 실측 비행 회로 → 좌회전·전진 의도`

- 시각망은 카메라별45,669뉴런/1,513,231연결이다. 네 시각 상태와 비행 상태를 원래 시간 순서로 유지한다.
- 비행 모델은9,728뉴런/1,311,145선택 원본 연결의 단순화된 발화율 회로다.
  상위 시각 경계는 학습된 공학적 근사이며 실측 시각→DN 시냅스라고 주장하지 않는다.
- 고정 후보는 t1121/checkpoint.pt, SHA256
  `fa7563407040e56d41a68f635529a9422bd1a6e0b5a4ecaa0c3b0bea0946c8da`다.
  학습·정규화 변경은 없고 모든 원래 신경 파라미터를 고정했다.
- 몸 입력은 등록된 pitch/roll 자세·yaw, 하중비율4·native온도4다.
  나머지 각속도2축·선형가속도3과 미준비된6운동 좌표는 마스크를 유지한다.
- 모델은 정답 조향·레이싱 라인·world pose·진행률을 읽지 않는다.
  원본 native prefix와 카메라 파일/해시는 진단용으로 보관하지만 actor에는 허용 필드만 투입한다.
- 출력은 두 운동 의도다. 이 모듈에는 vJoy/페달/조향 액추에이터 전송 경로가 없다.
  기존 기록기의 `--flight-shadow-config`는 이 읽기 전용 경로를 선택하는 옵션이다.

## 시간·상태 계약

각 관측 사이에는 **이전에 알고 있던** 망막 입력과 비행 drive를 유지해 적분한다.
새 프레임을 과거 구간에 넣지 않으며, 원본 fractional tick도 유지한다.
같은 capture ID를 재사용하면 원래 수신/노출 시각과 RGB bytes가 같아야 한다.
카메라 세대 변경·시간 역행·80ms 초과 관측 간격·누락/미확인 주행선 상태는 실패 처리한다.
실패한 인스턴스는 자동 reset/재개하지 않는다. 기록기는 실패한 관측도 보관한 뒤 소유 lease를 중단한다.

GPU 커널/캐시는 관측 시작 전 임시 회색 버퍼·별도 scratch 상태로 준비한다.
그 계산은 실제 관측 prefix나 신경 이력으로 삽입하지 않는다.
실제 시각 상태는 원래와 같은1초 회색 steady state, 비행 상태는 원래0으로 별도 초기화한다.
외부 시각 라이브러리의 torch 기본 장치 변경도 원래 값으로 복원한다.

5ms짜리 동일 입력 내부 tick을 한 `simulate` 호출로 묶어 호출 비용을 줄였다.
각 tick의 dt·개수·이전 입력은 같다. 이것은 추가 카메라 프레임이나 생물학적 센서 대역폭이 아니다.
신경 상태를 건너뛰거나 재시각화하지 않았는지 전체 원본과 대조했다.

## 재사용 경로

`scripts/verify_flight_stream_replay.py`는 기존 raw/body/vision/후보 평가를 사용해 새 구현을 대조한다.
기록기의 다음 옵션은 성공한 **동일 설정/추론 소스 bytes** 대조를 요구한다.
설정·핵심 소스가 바뀌면 오래된 검증으로 실행하지 않고 새 전체 대조를 요구한다.

```text
scripts/record_ac_engine_ai_probe.py
  --config configs/ac-csp-yaw-retina.json
  --image-format bmp --shared-transport --ai-steer-multiplier .9
  --duration-seconds 30 --speed-hint-kmh 30 --local-event-spool
  --flight-shadow-config configs/flight-stream-batched-v1-20261029.json
  --flight-shadow-verification runs/flight-stream-batched-replay-20261029-t1132
  --output <새 고유 run 디렉터리>
```

위는 인자 목록이며 GPU용 flyvis 환경과 프로젝트 PYTHONPATH에서 실행한다.
기존 run 디렉터리를 덮어쓰지 않는다. 성공한 새 수집도 raw/의도 재생 감사를 마치기 전에는 검증 결과로 쓰지 않는다.

## 남은 일과 현재 실행 상태

- [균형 학습의 전이 한계](flight-steering-capacity-and-balanced-learning-20261029.md)는 그대로다.
  알려진 OFF 기록의 좌9/41·우39/68, 직진 편향, 합동 개발 검증 실패를 해결한 실험이 아니다.
- 두 수집은 그림자를 계산한 계측이며 양성 제동/타이어·접지·셋업 판단이나 학생 운전을 검증하지 않았다.
  전체 뇌·실측 광학축·생리 수용기·wingbeat/전기 시냅스 재현도 아니다. T4d 불일치와 몸 미등록 축도 남는다.
- 다음은 비행 readout→차량 axis codec의 단위·부호·중립/정차 응답을 별도 부품 계측으로 확인하고,
  몸 교란 피드백과 실제 plant 응답을 대조하는 단계다. 이를 완주나 운전 후보 승격과 구분한다.
- 지속적인 좌우 코너·제동과 실제 정차 prefix 자료, 시각/몸/선택 회로의 인과적 기여를 검증하고,
  최종적으로 학생 단독 유효 완주·반복 안정성·레이싱 라인/랩타임 개선을 검증해야 한다.

관련30검사와 수정 Python Ruff가 통과했다. 모든 이번 소유 replay/수집/감사 프로세스는 종료됐다.
마지막 t1141은 paused/AIoff/cameraoff/gas0/brake1/주행선 OFF·창 비전면을 확인했다.
실행 상태는 다음 작업에서 다시 읽는다. 전체 목표는 미완료다.
