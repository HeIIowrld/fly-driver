# 60m 파리 학생 주행과 제동 자료 확장

기록일: 2026-10-28 KST. 이전 목표 턴은 GPU 학습 경로 최적화·실제 학습·개발 평가를 완료한 진전이었다. 이번 단계는 최종 목표인 다중 시각/몸 감각 기반 AC 전체 서킷 자율 주행을 향한 실측 확장이다. 전체 랩과 타이어·셋업 최적화는 아직 검증하지 않았다.

## 실제 60m 구간

t389에서 엔진과 같은 generation의 최신 API 상태를 확인한 뒤, t391에서 승인된 CSP API로 에피소드를 재시작하고 정차 계측을 완료했다. 30m 성공 기록 t378이 있는 t373 모델로 t392의 60m 시험을 진행했다. 입력은 실제 CSP 네 방향 픽셀·몸 감각이며 추론은 CPU cached CSR, teacher action은 사용하지 않았다. GUI 조작은 0회다.

265개 제어 결정으로 시작점 대비 60.061m 변위 목표에 도달했다. 최고 속도 27.881km/h, 최대 기준선 이탈 2.594m, 최소 측면 여유 2.487m이며 종료 후 brake hold와 vJoy 해제를 확인했다. 이는 경로 arc length나 전체 랩 측정이 아니다. t393에서 원본 픽셀·몸 감각으로 모든 요청을 정확히 재생했다(최대 차이 0). 카메라·원시 바이트 해시도 검증했다. 광학적 동시 노출이나 물리적 겹눈 구현을 증명한 것은 아니다.

## 일시정지 API 오류

t394의 pause 요청은 accepted 이후 완료 영수증 저장에 실패했다. Lua 오류는 `Cannot commit camera metadata`였다. 같은 명령은 재시도하지 않았다. 최신 동일 generation/epoch 16 heartbeat에서 paused=true, gas=0, brake=1, camera_active=false를 확인했다. API 반환값은 영수증이 없어 확정하지 않는다. t394 실패 기록을 그대로 보존하고 t400에 읽기 전용 상태 검사 결과를 추가했다.

읽기 전용 status 조회가 생산자 오류를 그대로 보여주도록 클라이언트를 보완했다. 최신성·엔진 식별 검사는 유지하며 오류가 남은 상태에서는 변경 명령을 계속 거부한다. 이 동작에 대한 3개 테스트와 Ruff 검사를 통과했다. 오류 원인과 영수증 저장 복구는 다음 실제 주행 전 해결해야 한다.

## 새 전문가 질의

t395는 t393의 265개 실제 감각 입력에 기존 30km/h 상한의 고정 geometric teacher를 다시 질의했다. 감각 배열·마스크·시간·수치 상태 경계는 보존하고, 학습 정답만 교체했다. 정답은 실행되지 않은 counterfactual이며 위치·경로·heading은 teacher/진단 전용이다. 실제 브레이크 응답의 증명이 아니다.

새 기록에서 brake >0.05인 정답이 121개, >0.3이 103개 나왔다. 기존 1542개와 합친 t397은 7개 원본 에피소드/1807개 결정이며 양성 제동 사례는 18→139개다. t347의 500개 평가 구간과 이전 개발 구간 t303은 계속 gradient에서 제외한다.

`t398`은 기존 제동 가중치 20을 유지한 비교 조건이다. 양성 139개 ×20=2780으로 비제동 1668개보다 큰 가중 질량을 갖는다. 이를 확인해 동일 초기값·시드·자료·8 epochs에서 가중치만 3으로 낮춘 조건도 비교한다. 비교 평가는 개발 평가이며 독립 최종 시험이 아니다.

## GPU 재학습과 개발 평가 결과

두 조건 모두 t373을 초기값으로, 동일 seed 862919와 7개 원본 에피소드/1807개 결정으로 8 epochs를 학습했다. ROCm `cuda:0`, FP32 sparse COO, 64개 결정 청크 검사를 사용하며 실제 주행용 CPU constructor의 tick 검사는 유지했다. 변한 tensor는 선언된 시각/기관 adapter weight뿐이며 회로와 readout은 고정했다.

| 모델 | 다음 구간 RMSE 조향/가속/제동 | 이전 개발 구간 RMSE 조향/가속/제동 |
|---|---|---|
| 이전 t373 | 0.094800 / 0.066144 / 0.000011 | 0.125341 / 0.084319 / 0.320763 |
| t398, 제동 가중치 20 | 0.083867 / 0.065073 / 0.235818 | 0.139041 / 0.086958 / 0.394675 |
| t401, 제동 가중치 3 | 0.072510 / 0.060939 / 0.087815 | 0.137581 / 0.087754 / 0.328130 |

가중치 3은 새 자료를 학습한 조건 중 과도한 제동을 줄이고 다음 구간의 조향·가속 오차를 개선했다. 하지만 제동 정답이 모두 0인 다음 구간에서 평균 0.07787의 제동을 출력했고 이전 구간도 개선되지 않았다. 따라서 두 체크포인트 모두 실제 주행용으로 승격하지 않았다. 새 자료의 '제동 필요'는 geometric teacher의 판단이며 실제 노면 한계나 최적 랩타임의 증거가 아니다.

다음 단계는 API 영수증 저장 오류를 복구하고, 제동/비제동 상황에서 halt 출력의 구별 가능성과 고정 출력 gain(현재 약 245,347)의 영향을 진단하는 것이다. 학습 표본만 추가하면 제동이 다른 구간으로 번지는 문제가 남는다. 시각/몸 감각은 회로를 계속 통과시키고 위치·진행률·지도는 actor에 추가하지 않는다. 원래 목표인 전체 서킷 주행과 하중·온도·셋업 적응은 미완료 상태다.
