# 감각 기반 조향 학습과 실제 회로 후보 검토

기록: 2026-10-27, Asia/Seoul. **고정 저속의 조향 학습은 실행됐지만 완주 관문은 통과하지 못했다.** 실제 회로는 구조 후보 추출까지 진행했으며 주행 정책에 연결하지 않았다. AC 실험 결과가 아니다.

## 실행한 범위

`sensory_runtime.py`와 `sensory_imitation.py`에서 MuJoCo 원영상 → 합성 겹눈 수용각 적분 → 기관별 몸 감각 → 지속 GRU의 수집·BC·DAgger·독립 평가를 연결했다. 정답 경로 정보는 교사 label과 평가에만 사용한다. 저장 데이터의 actor 입력, 교사 행동, 실제 실행 행동을 분리하고 데이터·정책·소스 해시를 남긴다. 평가에는 교사 조향을 섞지 않는다.

이번 실험은 속도 의도를 1.5 m/s로 고정하고 조향만 학습한다. 속도 head는 감독 대상에서 제외하고 실행 때 고정값을 적용한다. 따라서 가속·제동 자율주행의 증거로 사용할 수 없다. 100 m 합성 평지 코스, 새 영상 25 Hz, 판단 100 Hz, 눈당 8×12 방향, CPU GRU 한 학습 시드다. 실제 초파리 광학축 지도나 실제 기능 그래프를 쓴 실험이 아니다.

교사 표본 4,800개로 BC 24 epoch, 학생 주행의 교사 label 2,400개를 추가해 총 7,200개로 DAgger 12 epoch를 실행했다. DAgger 수집의 교사 실행 혼합률은 0이다. 개발 조건 4개는 시작점·중간 시작점·좌우 자세 오차이며 독립 최종 시험 세트가 아니다.

| 평가 모델/조건 | 완료 | 이탈 | 평균 전진 거리 |
|---|---:|---:|---:|
| 무학습 | 0/4 | 4/4 | 6.13 m |
| BC | 0/4 | 4/4 | 27.42 m |
| BC + DAgger 1회 | 0/4 | 4/4 | 23.30 m |
| 위 최종 모델의 영상 누락 | 0/4 | 4/4 | 14.16 m |

BC의 훈련 MSE는 약 0.0744에서 0.00783으로 줄었으나 폐루프 운전은 실패했다. DAgger는 평균 거리를 악화시켰다. 영상 누락 때 성능이 낮아진 것은 이 네 조건에서의 관찰이며, 일반적인 시각 기여나 생물학적 이득이 검증됐다는 뜻은 아니다. 단일 시드의 실패를 숨기거나 성공한 구간만 골라 완주로 표시하지 않는다.

원자료는 [summary.json](../runs/sensory-bc-pilot-20261027/runs/steering-pilot-101101/summary.json), [수집 해시 영수증](../runs/sensory-bc-pilot-20261027/collection-receipt.json), [실행 소스 목록](../runs/sensory-bc-pilot-20261027/source-provenance.json)에 있다. 정상 종료를 확인한 뒤 66개 파일의 SHA-256을 대조해 수집했다. 실행 소스는 당시 변경 사항을 포함한 고정 사본이며 현재 파일과 자동으로 동일하다고 가정하지 않는다.

## 실제 MaleCNS 조향 구조 후보

[Westeinde 등의 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10881397/)에서 다룬 PFL2/PFL3·하행 뉴런 경로를 출발점으로, 확보한 MaleCNS 주석의 정확한 유형 이름과 `Traced` 상태로 후보를 골랐다. 논문의 기능 해석과 이번 MaleCNS 구조 추출은 서로 다른 근거다. 논문의 시냅스 수나 측정 동역학을 이번 모델에 이식한 것이 아니다.

`connectome_selection.py`는 원본의 incoming CSR 방향을 확인하고 선택된 뉴런 사이의 모든 연결을 유지한다. 유형·실제 ID·경계 손실·입출력 도달성·원자료 해시를 기록한다. 결과는 PFL2 12개, PFL3 24개, DNa03 2개, DNa02 2개로 **40개 뉴런·523개 유향 연결**이다. [등록부](../configs/malecns-steering-core-candidate.json), [경계 감사](../assets/external/malecns-steering-core-candidate-20261027/audit.json).

그러나 DNa02의 전체 입력 중 이 작은 망 안에 남는 시냅스는 양쪽 각각 약 **2.82%와 2.55%**다. 상위 시각·CX 입력, VNC와 기관 피드백 경로가 빠져 있다. PFL2/PFL3는 이 후보의 절단 입력 경계다. 세포체 좌우를 차량 회전 부호로 바로 사용하지 않으며, 연결 수를 흥분/억제·수용체·시간 상수로 간주하지 않는다. 이 후보만 연결해 전체 파리 회로를 구현했다고 주장할 수 없다.

## 검증과 다음 결정

새 학습 경로의 수집→훈련→DAgger→평가→모델 복원 시험과 회로 추출 시험을 추가했다. 겹눈 방향별 공간 배치를 유지하는 선택적 격자 인코더도 구현했다. 이는 일반 학습 모델의 대안이며 생물학적 시각 회로가 아니다. 해당 후보를 포함한 WSL 전체 테스트는 **118개 통과, 23.03초**다. [로그](../runs/sensory-bc-pilot-20261027/grid-pytest-validation.log), [검증 소스 해시](../runs/sensory-bc-pilot-20261027/grid-source-provenance.json). 이후 테스트 함수의 줄바꿈만 정리했으며 현재 소스 정적 검사도 통과했다. 격자 후보의 실제 주행 학습은 실행하지 않았다.

다음 우선순위는 다음과 같다.

1. **A0:** AC 설치·영상·telemetry·조작 응답을 확인한다. 현재 점검한 Steam 경로에서는 엔진을 찾지 못했고 실제 게임 연동은 미검증이다.
2. **A2:** 교사 자체의 같은 조건 완주, label 시각 정렬, 조향 포화와 실패 직전 영상·몸 반응을 진단한다. 공간 정보를 유지하는 격자 후보는 별도 고정 실험으로 비교한다. 손실 감소만으로 장기 PPO를 시작하지 않는다.
3. **A3:** 작은 조향 후보의 경계를 확장하기 전에 시각/CX 입력·좌우 출력 부호·누락 경로를 검토한다. 기관 입력을 임의의 뉴런에 넣고 생물학적 대응이라고 부르지 않는다.
4. **A4–A6:** 기관의 국소/상행 경로와 속도·제동을 통합한 뒤 AC 구간 주행, 마지막에 연속 1랩을 시험한다. 일반 GRU 완주와 실제 회로 모델 완주를 별도로 판정한다.

현재 판단은 **연구 방향은 실행 가능한 단계로 나눌 수 있으나, 안정적 기준선과 실제 감각운동 회로 모두 아직 확보되지 않았다**는 것이다. 실제 구조가 운전에 유리한지는 같은 감각·예산의 일반 모델, 기관 제거, 연결 재배선 대조로 확인해야 한다.
