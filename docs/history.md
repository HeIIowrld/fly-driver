# 이전 파일럿과 새 저장소의 출발점

2026-09-27 MECar-Simulation의 `experiments/fly_connectome/REPORT.md`와 코드를 읽고 정리한 기록이다. 이전 저장소의 코드·데이터·가중치를 이 저장소에 복제하거나 실행 중 가져오지 않았다. 원자료와 이전 실험은 원래 위치에 남아 있다.

파일럿은 MaleCNS v1.0에서 추출한 뉴런 165,122개와 집계 연결 25,563,197개를 썼다. 56차원 관측을 6,365개 VNC sensory 뉴런에 난수로 배정하고, 708개 VNC motor 뉴런에서 출력을 읽었다. 매 10 ms 판단마다 상태를 0으로 되돌려 네 차례 그래프 계산을 했다. 양의 연결 이득을 사용했으며 전달물질·수용체 모델은 없었다. 조향을 제외한 가속·요모멘트는 LimitDriver가 담당했다.

모방학습 표본은 학습 2,760개, 검증 727개였다. 여덟 주행을 여섯/두 주행으로 나누고 한 시드로 2,400회 학습했다. 카메라와 강화학습은 사용하지 않았다. Slurm job 245505/245506, RTX 6000 Ada, Torch 2.5.1 + CUDA 12.1 실행 기록이다.

| 후보 | 명목/무작위 30 m 평가 | 해석 |
|---|---|---|
| LimitDriver | 둘 다 완주 | 정답 상태·경로를 쓰는 교사 |
| MLP | 둘 다 완주 | 기존 관측의 작은 기준선 |
| 실제 연결 모델 | 약 6.64 / 6.60 m에서 이탈 | 이 입력·출력·상태 계약의 한 시드 결과 |
| 재배선 모델 | 약 9.11 / 9.33 m에서 이탈 | 실제 연결의 우월성을 보이지 않음 |

연결 모델의 학습 파라미터는 25,730,443개, MLP는 24,195개였다. 그래프 SHA-256은 `50abd7c9c5f501735811de4dba7f8bcb637295b0b61a62a6d16afc168413fa32`다. 이전 FlyHard 참조 commit은 `328906f4a0e62c8f9fc18805cf6edae6989b82a5`였다. 그 vendor 코드를 새 저장소로 옮기지 않았다.

이 결과는 커넥톰 전체의 성능 한계가 아니라, 무작위 입력·매 틱 상태 초기화·광범위한 운동 출력 선택을 먼저 바꿔야 할 근거다. 이전 presynaptic 열 순열은 뉴런별 입·출력 차수를 동시에 보존하는 방식이 아니었다. 새 `graph.rewire`는 방향 있는 edge swap으로 뉴런별 입·출력 차수를 보존한다. 경로 길이·도달성까지 같다는 보장은 없다.

기존 차량 모델을 점검했을 때 track의 Z는 저장됐지만 주행거리·투영은 XY에서 계산했다. Tensor 모델에 롤·피치·서스펜션과 네 바퀴 높이 입력이 있었지만 world Z와 완전한 3D 접촉은 없었다. NumPy 14DOF 모델의 수직 응답 토대 역시 전 서킷 경사 중력·뱅킹·접지 검증과 구분해야 했다. 그래서 새 저장소는 3D 노면과 접촉을 갖춘 backend에서 시작한다.

여기서 재사용한 것은 연구 질문과 확인된 증거다. 이전 결과를 새 GRU/희소 회로의 학습 결과로 표시하지 않는다.
