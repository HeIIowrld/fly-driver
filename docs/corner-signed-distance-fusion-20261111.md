# 반사 방향 판독과 거리 부품 결합 · 2026-11-11

Magione·Laguna Seca·Zandvoort를 한 곳씩 통째로 제외하고, 나머지 서킷에서 4–20m 접근의 좌·우를 학습했다. 원본과 좌우 반사에서 얻은 네 카메라 T4/T5 특징의 차를 써서 입력이 반사되면 방향 점수의 부호도 바뀌게 했다. 기존에 경보가 울린 접근을 더 반영하는 조건, 기존 방향 교체와 새 경보 추가를 비교했다. 같은 조건을 Monza의 기존 학습 구간을 추가한 경우에도 평가했다. 모든 거리 보정값은 각 평가 서킷을 제외하고 적합한 가중치에서 가져왔다.

Monza 학습 구간을 추가하자 접근 프레임만 골라 방향을 읽는 진단에서 Magione의 최고 좌 적중이 26/64→64/64였다. 같은 방식의 Zandvoort 최고 좌 적중은 19/31→18/31이었다. 이 수치는 접근을 미리 알려준 방향 진단이다. 일반 영상에서 경보까지 합친 조건에서는 좌 적중을 늘리면서 다른 서킷의 우 적중·결합 적중·오경보를 유지한 공통 설정이 없었다. ## 경계 방향과 개선된 거리 부품의 결합

색도 상한을 제거한 경계 판독을 Laguna Seca에서도 전체 재생했다. 63개 접근에서 방향이 맞은 경계 후보 5개는 모두 이동 확인을 통과하지 못했다. Zandvoort에서 앞서 확인한 방향 교체 조건을 세 개발 서킷에 그대로 적용하고, 거리에는 기존 판독과 새 거리 부품을 절반씩 사용했다. 이미 경보가 울린 프레임에서 경계 방향이 다르고 겹눈 유무·거리 조건을 만족할 때만 방향을 바꿨다.
