# 같은 오경보 예산에서의 T4/T5 비교 · 2026-11-12

다섯 서킷의 학습 제외 재생 6,087프레임을 다시 채점했다. 동일 후보에서 경계 전용 모델과 경계+T4/T5 모델을 비교했다. 기존 확인 문턱 0.25부터 올리면서, 오경보 예산을 초과하지 않는 가장 낮은 문턱을 각 모델에서 구했다. 새 직접 경보와 그 다음 프레임의 유지 경보가 모두 새 문턱을 통과해야 두 번째 경보가 이어진다. 기존 경계 판독의 경보는 그대로 포함했다. 이 분석은 평가 영상의 오경보를 보고 문턱을 고른 사후 비교다. 동시 적중은 4–20m에서 방향을 맞히고 거리 오차가 ±5m 이내인 프레임이다. 오경보는 직선과 범위 밖의 공통 채점 기준이다. 기존 영상 경계만 쓴 기준선의 오경보 59건을 예산으로 두면 두 조건에서 기존 적중과 안정 예고만 남았다. 같은 총 오경보 245건에서 결합 모델의 문턱은 약 0.284였다.

각 서킷에서도 경계 전용 모델의 0.25 오경보 수를 넘지 않도록 **공통 문턱 하나**를 적용한 진단에서는 결합 모델의 문턱이 약 0.533이었다. 이 경우 동시 적중은 20→26건, 안정 예고는 2→6곳, 오경보는 245→130건이었다. Magione 동시 적중은 4→2건으로 줄었고, Laguna Seca·Mugello·Imola에서는 늘었다. 서킷별로 다른 문턱을 적용하지 않았다. [서킷별 오경보 상한과 적중](../runs/vision-corner-matched-false-alarms-20261112-01/result.json)
