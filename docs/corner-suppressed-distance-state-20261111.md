# 경보를 보류한 프레임의 거리 추적 · 2026-11-11

요율 비율로 새 경보를 걸러내는 조건에서, 경보 보류와 다음 프레임으로 이어갈 거리 추정을 구분했다. 대조 조건은 기존대로 요율 비율을 통과한 후보만 거리 보정의 해당 단계를 실행했다. 실험 조건은 비율이 낮은 후보도 같은 거리 보정을 하고, 일정 점수 이상이면 보정한 추정값을 다음 프레임의 상태에 보존할 수 있게 했다. 점수가 낮은 후보도 보존하는 조건과, 직전 후보와 방향 및 이동 거리까지 맞아야 보존하는 조건을 비교했다. 보류된 후보를 새 경보로 내보내는 기준은 그대로 뒀다.
