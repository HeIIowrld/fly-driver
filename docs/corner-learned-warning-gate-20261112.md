# 방향과 거리의 동시 적중을 학습한 경보 확인 · 2026-11-12

기존 확인 모델은 후보 시작점 주변의 굽음이 후보 방향과 일치하는지 점수로 냈다. 이번에는 공통 채점에서 방향과 거리 모두 맞은 후보를 양성으로 두고, 나머지 후보를 음성으로 둔 경보 확인 모델을 학습했다. 출력은 양성·음성의 학습 가중치를 맞춘 분류 점수다. 비교 문턱은 0.50·0.65·0.80이다. 기본 경계 판독과 후보의 원래 방향·거리는 그대로 사용했다. [학습과 평가 코드](../runs/vision-corner-learned-warning-gate-20261112-01/warning_gate.py)

학습에는 학습 가중치와 무관하게 영상 대비로 만든 경계 후보를 사용했다. 후보의 거리, 좌우 단면 수, 도로 폭 변동과 앞뒤 국소 곡률을 입력했다. 추가로 경계 전용 또는 경계와 T4/T5를 결합한 곡률 모델의 예측을 같은 방식으로 요약했다. 지도와 주행 좌표는 학습 표적과 평가에 사용했다. 차량 이동량으로 한 프레임 거리를 이어받을 때에도 같은 점수 문턱을 적용했다.

다섯 개발 서킷을 한 곳씩 평가에서 남겼다. 남은 네 곳에서 경보 모델을 학습했다. 각 학습 서킷의 곡률 특징은 그 서킷과 최종 평가 서킷을 모두 제외한 세 곳에서 적합한 모델로 생성했다. 최종 평가에는 네 곳으로 적합한 곡률 모델을 적용했다. 같은 영상 대비 후보와 학습 패치로 보완한 후보 두 가지로 평가했다. 최종 평가 서킷의 학습 패치는 이전에 해당 서킷을 제외하고 적합했다. [학습과 평가 분할](../runs/vision-corner-learned-warning-gate-20261112-01/result.json)

## 다섯 서킷 제외 평가

아래는 학습 패치로 보완한 동일 후보에서 경계 전용 모델과 경계+T4/T5 모델을 비교한 결과다. 안정 예고는 한 서킷에서 같은 코너를 여러 번 접근해도 한 곳으로 셌다.

| 확인 문턱 | 경계 → 경계+T4/T5 동시 적중 | 오경보 | 안정 예고 물리 코너 |
| --- | ---: | ---: | ---: |
| 0.50 | 29 → 38 | 629 → 482 | 4 → 7 |
| 0.65 | 6 → 28 | 101 → 146 | 1 → 5 |
| 0.80 | 5 → 8 | 61 → 76 | 1 → 2 |

기존 굽음 확인은 사후에 오경보를 150건으로 맞춘 조건에서 동시 적중 35건과 안정 예고 8곳을 얻었다. 새 확인 모델의 문턱 0.65에서는 오경보 146건, 동시 적중 28건, 안정 예고 5곳이었다. 새 모델은 비교한 문턱에서 기존 조건보다 나은 절충점을 보여주지 못했다. [이전 동일 오경보 비교](corner-matched-false-alarms-20261112.md)

새 모델을 기존 경보의 추가 확인으로 사용했다. 결합 모델의 추가 문턱을 0.65로 두면 동시 적중 23건, 오경보 125건, 안정 예고 5곳이었다. 기존 확인 점수만 사용해 같은 오경보 125건으로 맞춘 조건은 동시 적중 23건, 안정 예고 6곳이었다. [추가 확인 결과](../runs/vision-corner-learned-warning-gate-20261112-01/cascade.json)

## Silverstone과 Spa

두 서킷을 제외한 다섯 곳으로 경보 모델을 학습하고 기존 녹화에 적용했다. 결합 모델의 문턱 0.50에서 Silverstone 동시 적중 9건과 안정 예고 4곳이 유지됐고 오경보는 124건이었다. 문턱 0.65에서는 오경보 34건과 안정 예고 3곳을 얻었으나 대표 우회전의 연속 경보가 사라졌다. 621번 첫 경보의 점수는 0.511, 622번의 이어받은 경보는 0.878이었다. 621번이 탈락하면 622번의 경보도 이어지지 않는다. 같은 0.65에서 Spa는 동시 적중 8건, 오경보 26건, 안정 예고 1곳이었다.
