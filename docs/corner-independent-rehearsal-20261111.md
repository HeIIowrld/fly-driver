# 독립 코너 판독 실행기와 Laguna Seca 촬영 준비 · 2026-11-11

초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.

[독립 평가 실행기](../scripts/evaluate_independent_corner.py)는 촬영 메타데이터에서 좌·우 물리 코너 수와 직선·범위 밖 구간을 확인한다. 입고되면 같은 원본 특징으로 부모·후보를 추론하고, 전체 캡처의 판독과 공통 적중 쌍의 거리 변화를 채점한다. Magione 개발 원본 1,887개에서 픽셀부터 전체 경로를 실행했다. 기존 좌 적중 3→9개, 우 62개 유지, 방향·거리 결합 45→51개, 범위 밖 경보 27→28개를 재현했다. 개발 재생에는 양쪽 한 물리 코너만 있어 별도로 표시한 개발 프로토콜을 사용했다. 독립 평가 프로토콜은 좌·우 각 두 물리 코너를 요구한다. [개발 리허설](../runs/vision-corner-independent-runner-rehearsal-20261111-01/replay/result.json).

## 거리 변화

Magione의 네 네이티브 TCP 아카이브에서 6,203개 패킷의 해시와 복사 시각을 확인했다. 촬영의 가장 이른 렌더 경계보다 이전이고 프레임 수신 전에 도착한 신선한 속력을 1,681/1,887개 캡처에 연결했다. 속력으로 이동량을 추정한 진단은 소스 틱과 물리 노출의 동시성을 검증하지 못했다. 거리 갱신 0.05m 제한에서는 결합 적중 51개를 유지하고 역행이 22→21쌍으로 줄었다. [네이티브 거리 진단](../runs/vision-corner-native-distance-20261111-02/result.json).

부모와 혼합 후보는 공통 방향 적중 쌍에서 같은 거리 추정기를 썼다. 거리 변화 MAE를 비교하면 둘 다 0.39862m였다. 같은 방향의 연속 영상에서 최근 세 간격의 예측 감소량을 이용하고, 반대로 늘어난 값에 최대 0.05m만 보정하는 후보를 만들었다. 영상 예측, 캡처 순번·시계·세대만 사용한다. 0.05m는 개발 비교에서 결합 적중 51개를 유지한 가장 큰 시험값이었다. 전체 원본 재생에서 공통 62쌍의 변화 오차는 0.39862→0.39539m, 역행은 22→21쌍이었다. 범위 밖 경보 기준은 여전히 실패했다. [영상만 쓴 거리 비교](../runs/vision-corner-visual-distance-20261111-01/result.json), [보정 후 전체 개발 검증](../runs/vision-corner-independent-protocol-20261111-02/development-verification.json).

## 선택한 독립 서킷

사용자 게임에 Mugello가 표시되지 않아 Laguna Seca를 선택했다. 로컬 설치 경로에서 두 코스의 파일을 확인할 수 있었으며, Laguna Seca는 사용자 게임의 메뉴와 실제 CSP 상태에서 모두 확인했다. Laguna Seca 설치 spline의 곡률 구간은 좌 17·우 15다. 영상 검증 전 부모·후보·거리 보정·채점 설정을 고정했다. 빈 아카이브의 입고 거부를 확인했다. [Laguna Seca 고정 프로토콜](../runs/vision-corner-independent-track-options-20261111-01/ks_laguna_seca-protocol.json).

실제 세션 상태 영수증은 BMW Z4 GT3 오프라인, 주행선 OFF, 일시정지 해제, 브레이크 0이다. 설치된 CSP 생산자의 네 방향 촬영 시작 조건은 정차·일시정지·브레이크 0.98 초과다. 생산자의 소유 카메라 재개와 AI 촬영 명령은 Laguna Seca를 지원하지 않는다. 140초 수동 주행 촬영의 프레임 예산은 기존 CSP 한도 안에 있다. 촬영과 독립 평가는 아직 실행되지 않았다. [상태 영수증](../runs/vision-corner-laguna-session-20261111-01/result.json), [촬영 예산 확인](../runs/vision-corner-mugello-capture-preflight-20261111-01/result.json).
