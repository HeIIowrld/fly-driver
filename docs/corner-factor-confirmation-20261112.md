# 코너 접근·방향·시작 거리의 별도 확인 · 2026-11-12

복구 경계의 같은 후보에 대해 4–20m 접근 여부, 접근일 때 방향 일치 여부, 방향도 맞을 때 시작 거리 ±5m 일치 여부를 각각 학습했다. 세 점수의 곱으로 후보를 확인했다. 경계 조건은 기존 경계 확인 점수와 시작점 전후 양쪽 경계 형상을 썼다. T4/T5 조건은 동일 입력에 기존의 T4/T5 결합 확인 점수 한 값을 더했다. 원래 회전 경보를 보존했고, 복구 경계에서 나온 후보와 거리 자체는 바꾸지 않았다. [학습과 재생 코드](../runs/vision-corner-factor-confirmation-20261112-01/factor_confirm.py)

네 개발 서킷에서 바깥 검증 서킷을 제외한 모델로 확인 점수를 계산했다. 안쪽 학습 자료를 만드는 경계 선택기에서도 해당 서킷과 바깥 검증 서킷을 제외했다. 기존 코너 선택기는 네 개발 서킷에서 학습한 동결본이다. 추가 직선·범위 밖 경보는 경계 4건과 T4/T5 5건, 내부 경보는 각 3건, 반대 방향과 거리 오차는 각 1건을 상한으로 두었다. 새 확인기는 상한 안에서 추가 적중을 내지 못했다. 개발에서 첫 적중을 포함하는 T4/T5 문턱의 오류는 직선·범위 밖 3건, 내부 1건, 거리 오차 2건이었다. 경계 방식에서 첫 적중을 포함하는 문턱은 범위 밖 6건, 내부 1건, 거리 오차 2건이었다. ## 프레임 수와 연속 접근 구간 수

같은 영상에서 연속한 프레임이 같은 방향의 접근 라벨일 때 한 구간으로 셌다. 이는 녹화 안의 연속 접근 표본 단위이며 서킷 고유 코너 수와 다를 수 있다. 어느 프레임에서든 방향과 시작 거리를 함께 맞히면 해당 구간을 적중으로 셌다. 아래 수치는 새 확인기가 추가 경보를 내지 않는 동결 결과다. [구간별 근거](../runs/vision-corner-factor-confirmation-20261112-01/approach-groups.json)

Silverstone의 두 적중은 같은 우회전 접근의 807·808번이었다. 나머지 세 접근에서는 두 판독 모두 적중이 없었다. Monza는 내부 라벨을 제외한 기존 989프레임으로 비교했다. 고정 판독기에 새 확인기를 적용하지 않았다. 같은 후보와 거리, 기존 경보와 관측점의 보존, 영상 뒤쪽을 제거해도 같은 점수가 나오는지 확인했다.
