## 동일 조건과 재현

- 원래 TRAIN 6/개발 2 이력과 5·10·20m 표적을 그대로 사용했다. 관측·마스크·시각·역할은 유지했다.
- TRAIN 전체 관측의 평균/표준편차만으로 정규화했다. 표준편차 하한 1e-5, 정규화 입력 ±5,
  평균 제곱오차 + 계수 제곱합의 ridge 계수 1로 모든 표현을 비교했다.
  개발 결과로 계수나 정규화·표현을 선택하지 않았다. 표현마다 차원이 달라 통제된 단일 원인 실험은 아니다.
- 원래 겹눈 721개 위치의 등록을 이력마다 정확히 대조하고, 원래 신경 반응 파일 해시와
  관측 시각을 확인했다. 강도 1개 + 운동 시각 8개 채널에 원래 tanh와 Gaussian 공간 요약을 썼다.
- 원래 `FlightScenePool`의 GPU 계산으로 4×4 특징을 다시 만들었으며 **8개 이력 모두 최대 오차 0**이었다.
  8×8의 Gaussian 폭은 0.09, 4×4는 원래 0.18이다. 해부학적 수용장 측정값으로 부르지 않는다.
- 처음 t1446은 NumPy 재계산의 최대 차이 1.3709068e-6이 지정한 1e-6을 넘어서 fitting 전에 실패했다.
  기존 데이터를 변경하거나 허용 오차를 늘리지 않았다. 원래 GPU 경로를 사용한 t1447을 별도로 실행했다.
  실패한 실행 소스/설정/결과도 보존했다.

## 판단과 다음 작업

공간 요약 손실 하나로 현재 실패를 설명할 근거가 부족하다. 반대로 이 선형 비교만으로
겹눈/운동 회로에 도로 정보가 없다고 판정할 수도 없다. 기존 개발 구간은 방향 변화가 작아
코너 검증 범위도 부족하다는 한계를 그대로 유지한다.

다음은 TRAIN 이력만 사용한 **이력 단위 내부 검증**으로 비선형 공간 표현과 구간 간 일반화를
분리한다. 원래 개발 역할을 바꾸지 않고, 미래 표적을 사용한 행을 무작위로 섞어 검증하지 않는다.
새 자료 수집 계획에는 좌/우 코너·다른 속도·실제 제동과 수집 전에 고정한 역할을 포함한다.
같은 알려진 개발 자료에서 반복 선택한 결과를 독립 평가로 부르지 않는다.

도로 중간 표현이 검증된 뒤 비행 유래 명령/운동 회로의 조향·가감속 공동 학습으로 연결한다.
빠른 몸 감각 통합, 차체 기울기·하중 이동·타이어/셋업 적응, 학생 단독 완주와 빠른 라인/랩타임은
여전히 미완료이며 이 비교로 대체하지 않는다.
