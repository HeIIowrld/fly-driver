# FlyBrain 레이싱 라인 협업 안내

두 사람이 시각과 차량 제어를 하나씩 맡는다. 목표는 초파리의 겹눈·운동 시각에서 전방 레이싱 라인을 예측하고, 비행 유래 균형·운동 회로와 차량 몸 감각을 연결해 이탈 없이 빠르게 추종하는 것이다. AC를 가진 사람이 원본 기록과 통합 주행을 맡는다. 기술 담당은 두 사람이 정하며, 어느 쪽을 맡아도 다른 사람은 저장 자료로 개발할 수 있다.

## 속도와 레이싱 라인

같은 코너에서도 진입 속도와 차량의 자세·그립이 달라지면 가능한 제동 지점과 회전 반경이 바뀌고, 빠른 라인도 달라질 수 있다. 첫 버전은 현재 속도를 시각 쪽에도 주고, 제어기가 같은 시각의 차량 상태와 이후 몸 감각을 바탕으로 추종 속도와 조작을 계산한다. 속도별 라인 정답이 충분한지부터 확인한다. 한 가지 속도에서 얻은 기록만 있으면 그 기록을 따르는 기준 모델로 평가하고, 여러 진입 속도의 기록이나 동역학으로 계산한 정답을 확보한 뒤 속도 조건의 효과를 확인한다. 지도·절대 위치·기록 라인은 교사 라벨과 평가에 사용한다. [그립을 고려한 최소 시간 궤적 연구](https://doi.org/10.1080/00423114.2019.1704804)

## 시각 → 차량 제어 데이터 계약 v1

예시는 형식 확인용이다. 현재 브랜치의 두 실험은 이 인터페이스로 연결하기 전의 기준 결과다.

```json
{
  "schema": "flybrain.racing_line.v1",
  "episode_id": "monza-example-01",
  "clock_id": "capture-monotonic",
  "observation_time_s": 12.48,
  "ego_frame": "body_xy_forward_left",
  "origin": "vehicle_reference_point",
  "source_speed_mps": 23.0,
  "points": [
    {"s_m": 5.0, "x_m": 4.98, "y_m": -0.20, "valid": true},
    {"s_m": 10.0, "x_m": 9.86, "y_m": -0.90, "valid": true},
    {"s_m": 20.0, "x_m": null, "y_m": null, "valid": false}
  ]
}
```

- 원점은 관측 시각의 차체 기준점이다. 데이터셋마다 원점의 정의와 변환을 manifest에 고정한다. 차체 평면에서 x는 앞, y는 왼쪽이며 길이는 미터, 속도는 m/s, 시간은 초다.
- `s_m`은 차량 기준점에서 경로의 진행 방향으로 잰 호길이 오프셋이다. 첫 비교는 5·10·20m를 사용하고, 빠른 제동에 더 먼 범위가 필요하면 두 사람이 표본 위치를 함께 확장한다. `s_m`은 양수이고 엄격히 증가한다. 유효점은 앞에서부터 연속으로 배치한다. 유효점의 좌표는 유한한 수이고 무효점 좌표는 `null`이다. 유효 범위 밖으로 경로를 외삽하지 않는다.
- `episode_id`와 `clock_id`로 영상과 몸 감각의 출처를 맞춘다. `observation_time_s`는 영상 관측 시각이며 `source_speed_mps`는 같은 시각에 정렬한 전방 속도다. 제어기는 최신 몸 감각으로 그 이후 차의 움직임을 반영한다. 다른 시계끼리 값을 직접 빼지 않는다. 허용 지연과 최소 유효 범위는 통합 시험에서 측정해 정한다.

## AC 보유자와 데이터 전달

- AC 보유자는 저장 영상·관측 시각·속도·경로 라벨과 조향·가감속 요청·속도·요레이트 기록을 팀이 접근할 수 있는 위치에 올린다. 공유 가능한 자료를 사용하고, 원본 설치 파일이나 라이선스가 걸린 트랙 자산은 제외한다. 데이터 버전, SHA-256, 학습·평가 분할과 파일별 좌표·시간 계약을 manifest로 전달한다.
- 두 사람은 각 브랜치에 실행 명령, 데이터 버전, 기준 대비 수치와 실패를 기록한다. 통합 때 AC 보유자가 먼저 저장 자료로 같은 경로 입력을 재생하고, 이후 같은 시작 조건에서 기록 라인과 시각 예측 라인을 넣어 구간 통과를 비교한다. AC 수집과 통합은 승인된 백그라운드 인터페이스를 쓰고 학생 조작을 그대로 기록한다.
