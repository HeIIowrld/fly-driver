# 실측 비행 경로를 실행하는 후보 제어기 — 2026-10-29

[대전제](PROJECT_CHARTER.md)에 맞춰 시각·몸 감각이 날개 운동 뉴런까지 전달되는 후보를 구현했다.
**학습 전의 기술 시험**이다. 안정화 반사·위상 제어·실제 AC 주행이 검증됐다는 뜻은 아니다.

## 실제 연결한 구조

구현 `src/flybrain_drive/flight_circuit.py`, 계약 `configs/flight-circuit-prototype-20261029.json`.
검증된 실측 부분망9,728뉴런/1,311,145연결을 사용한다. 외부 입력 포트 선언으로 DNg02 역할을
확장했지만 원래 뉴런 ID·내부 연결·시냅스 수는 바꾸지 않았다.

haltere의 unknown_sensory4개는 입력을 임의 지정하지 않고 원래 그래프 안에 보존했다.

형태/출력 신경측의 추가 확인 없이 somaSide를 새로운 근육 좌우 검증으로 취급하지 않는다.

## 도로의 공간 정보를 남기는 시각 경로

처음 t1034는6개 시각 운동 좌표만 받는 기술 원형이었다. 해당 설정과 소스를 보존했다.
주행의 도로 모양을 판단할 수 있도록 t1035의 v2에는 **필수 공간 시각 경로**를 추가했다.

각 카메라에서721망막 위치의 밝기와T4/T5 8유형 반응을 받아, 원래 좌표의4×4 Gaussian 공간
요약으로4시점×9채널×16위치=576특징을 유지한다. 시점·채널·위치를 섞어 평균 하나로 만들지 않는다.
이 특징과 선택적인6운동 좌표를 HS/VS 경계로 연결한다. 공간 요약은 공학적 기저이며
실측 HS/VS 수용장이 아니다. 현재4×4공간 해상도의 도로 인식 능력도 아직 검증하지 않았다.

실제 영상은 필수이며, 정지 기준이 없어 아직 사용할 수 없는 운동 추정값은mask=false로 둘 수 있다.
따라서 검증되지 않은 자기 운동 추정값을 주행 입력에 강제로 넣을 필요가 없다.
카메라 누락을 운동 추정값이나 검정 화면으로 대체하는 것은 허용하지 않는다.

## 신경 동역학과 불확실성

원래 내부 연결의 가중치는 고정하고, 원본 전체 incoming synapse 수로 정규화한다.
선택되지 않은 바깥 입력을 지우고 남은 가중치를 재정규화하지 않는다.
시간 간격10ms/공통tau50ms,비음수 bounded rate의 공학적 축약이다.
입력 경계·출력 변환에26,816개 학습 가능 계수가 있으며 현재는 초기값이다.
신경 상태는 매 호출에서 전달하고 외부 episode 경계에서만 초기화한다.

consensus acetylcholine은+1,GABA는-1,기타/unclear/신경조절물질은0으로 둔다.
Glu는 수용기별 기능이 불명확하므로 **-1/0/+1을 같은 초기값으로 모두 시험**했다.
0부호는 효과를 억제하되 다른 연결의 질량을 늘리지 않는다.
구조 연결1,311,145개는 모두 저장되며,유효 비영 연결은Glu±1에서1,254,062개,
Glu0에서1,102,910개다. 이 부호 가정이 생리학적으로 확인됐다고 주장하지 않는다.
운동 뉴런에서 근육으로의 출력과 CNS 내부 Glu 연결의 부호는 구분한다.

## 실행·감사 결과

`t1035`는 실제 기록의 공간 시각 반응,제어 자극에서 나온 시각 운동 추정,
몸 yaw/기울기 및 상위 명령을 분리한14개 입력 개입을 GPU에서200tick씩 실행했다.
일부는 입력별 영향을 분리하기 위한 counterfactual 조합이며 실제 주행 에피소드가 아니다.

- 세 부호 가정에서 모두 유한한 motor 반응과 시각·회전·명령·문맥 projection까지의 학습 기울기를 확인했다.
- 공간 시각 부분과6운동 좌표 부분도 각각 비영 학습 기울기가 있었다.
- 모든 신경 연결을0으로 만든 대조에서는 운동 뉴런 반응과 입력별 의도 차이가0이었다.
  고정된 중립/감속 readout 상수는 남지만,감각의 직접 출력 우회 경로는 없다.
- 원본 내부 가중치는 학습하지 않았고 optimizer/실제 차량/UI 조작은0회다.

`t1036`은 실제 저장 checkpoint를 열어 원본 간선 인덱스·선언한 부호·전체 incoming 정규화를
**모든 연결에서 정확히 대조**했다. 세 가정의 입력/출력 변환기 초기값도 동일했다.
모형에서 pulse반응10%도달은 몸 yaw40ms,시각 yaw110ms였다. 이 값은 선택한rate dynamics와
입력 가설에서의 진단이며 실제 파리의 반응 지연을 측정/재현한 결과가 아니다.

공간 정보/출력 공통·차동 검사2개와 Ruff도 통과했다.
모든 연결 제거 대조는 우회 방지 검사이며,실측 그래프가 재배선 그래프보다 유리함을 입증한 비교는 아니다.

## 논문 근거를 적용한 범위

DNg02집단의 날개 진폭 제어와 시각 운동 반응은 원 연구의 근거다.
이것만으로 이 후보의 차량 조작이 검증되지는 않는다.
[원 논문](https://doi.org/10.1016/j.cub.2022.01.008).

b1/b2의I/P 관련 결과는 **피치 안정화에서의 실험**이다. 이를 yaw/자동차 조향의 검증된 회로로
확장하지 않았다. 현재 readout의 좌우 차동→차량 회전은 별도 대응 가설이며,
b1의 위상·b2의 phasic 기능이나 I/P 안정화가 구현됐다는 뜻이 아니다.
[발표 논문](https://doi.org/10.1126/sciadv.abo7461).

MANC연구는 haltere/w-cHIN/운동 연결과 일부 전기 시냅스 가능성을 논의한다.
현재 화학적 시냅스 수 그래프에 보이지 않는 전기 연결을 임의로 추가하지 않았다.
이 후보에는 전기 시냅스·날개 주기 위상·근육 역학이 아직 없다.
[MANC 원 연구](https://doi.org/10.7554/eLife.96084).
