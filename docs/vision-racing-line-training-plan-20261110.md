# 카메라로 레이싱 라인을 예측하는 학습 계획

2026-11-10 · 설계 단계

첫 학습은 **전·좌·우·후방 영상 이력으로 교사가 실제로 달린 전방 5·10·20m 경로점을 예측**한다. 같은 영상에 속도를 추가한 실험과 겹눈·운동 시각 특징을 추가한 실험을 비교한다. 두 번째 학습은 차량 제약을 반영해 만든 더 빠른 라인을 별도 교사로 사용한다. 첫 단계에서 교사 라인에 가까워지는지는 저장 영상으로, 두 번째 단계에서 실제로 빨라지는지는 같은 제어기로 달린 유효 랩타임으로 판정한다.

전체 목표는 초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결하는 것이다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다. 이 문서는 시각 담당 범위를 설계한다. 차량 제어 담당은 주어진 라인의 추종, 가감속·접지 적응, 비행 유래 되먹임의 별도 비교를 맡는다. [프로젝트 헌장](PROJECT_CHARTER.md) · [팀 인계 및 JSON 계약](racing-line-team-handoff.md)

## 1. 영상과 교사 경로를 하나의 학습 샘플로 만들기

- 개발 랩은 112.552초 Monza Z4. 교사 전달 ZIP의 5,468개 경로·상태 표본과 NAS에 있는 네 시점 카메라 원본을 함께 사용한다. 카메라는 교사 ZIP과 별도다. 카메라 묶음은 전체 수집 1,582 프레임 중 1,577개가 적격이었다. 랩 시간, 시각 이력, 경로 끝, 분할을 적용한 최종 학습 수는 새로 센다.
- 원본은 runs/braking-corner-learning-20261105/monza-user-started-teacher-01의 demonstration/camera/vision 및 qualification-03/pairings.json이고, 전 랩 궤적은 runs/monza-z4-teacher-handoff-20261109/reference_lap.json이다. 기존 CameraArchive와 적격 기록을 재사용한다. 카메라 렌더 시각의 검증된 호스트 구간과 교사 QPC 기준을 확인한 뒤 같은 시간축으로 변환한다. 행 번호나 AC 발행 시각으로 조인하지 않는다. 뷰별 지연·누락과 조인 잔차를 기록한다. 현재 속도 입력에는 관측 시점까지 사용 가능한 센서만 쓰고, 교사용 차체 원점·방향은 검증된 앞뒤 궤적 표본에서 시간 보간할 수 있다. 카메라 노출의 정확한 물리 시각은 원본에서 확인되지 않았으므로 구간 양끝에서 라벨 민감도를 확인한다.
- 앵커 시점의 차체 원점부터 실제 교사 궤적을 따라 5·10·20m를 보간한다. 교사 JSON의 AC Gym X/Y 평면과 planar_yaw_rad를 사용한다. 월드 변위 d와 차체 방향 yaw로 x = cos(yaw)·dx + sin(yaw)·dy, y = −sin(yaw)·dx + cos(yaw)·dy를 계산한다. 오른쪽은 y 음수다. 렌더러 좌표와 비교할 때 기존 검증 코드의 [2,0] 축 변환을 적용한다. 미래 표본이 부족하면 뒷거리부터 무효 처리한다. 랩 끝에서 다음 랩으로 이어 붙이지 않는다.
- 학습에는 기존 지도 호길이 기준 971m와 2173m의 각 ±90m를 제외한다. 입력 이력부터 20m 라벨까지 제외 구간을 건드리는 창도 빼고, 개발 랩의 나머지에서 연속 구간을 잘라 검증용으로 고정한다. 검증 경계를 걸치는 창은 제거한다. 평가용 112.602초 랩과 기존 두 코너의 ±32m는 최종 비교용으로 보존한다. 기존 곡률 실험은 그 두 코너에서 20/14표본만 썼으므로, 이 표본 수를 새 경로 실험에 그대로 쓰지 않는다. 새 유효점 수를 보고한다.
- 첫 산출물은 입력·라벨 ID와 시간·분할·누락 이유가 들어 있는 manifest, 정합 확인용 직선/좌회전/우회전 예시, 교사 경로 JSONL이다. 기존 11월 7일 실험은 지도 중심선 곡률 예측이었다. 이번 라벨은 실제 교사 궤적의 위치다. [기존 실험](vision-heldout-curvature-20261107.md)

## 2. 동일 표본으로 기준 모델과 초파리 운동 시각 비교

입력 이력은 기존 약 90ms 프레임 간격을 활용해 우선 0/−90/−180ms 근방의 실제 시각을 사용한다. 모든 비교는 동일한 유효 샘플, 동일한 경로 출력, 동일한 분할에서 한다. 시간이나 속도 통계의 정규화는 학습 구간에서만 계산한다.

| 실험 | 입력 및 모델 | 확인할 것 |
| --- | --- | --- |
| A | 직진 (s, 0), 거리별 학습 평균 경로, 속도만 받는 작은 판독 | 영상이 없을 때의 오차, 속도가 몬자 위치를 간접적으로 암기하는 정도 |
| B | 네 방향 현재 영상. 고정 이미지 특징과 작은 MLP | 정지 영상에서 얻는 이득 |
| C | B와 같은 영상 특징을 3시점에서 결합, 작은 MLP | 일반 영상 이력의 이득 |
| D | C + 현재 전방 속도 | 같은 영상에서 속도가 더해 주는 이득 |
| E | 기존 각도 기반 망막 입력 + 고정 FlyVis T4/T5, 방향·시점별 풀링 + 작은 MLP | 운동 시각으로 얻을 수 있는 예측 성능 |
| F | E + 현재 전방 속도 | 운동 시각 조건에서도 속도가 더해 주는 이득 |

첫 판독은 가려진 점을 제외한 x/y Huber 손실로 학습한다. 5·10·20m별 목표와 손실을 따로 보고하고 과적합 여부를 검증 구간에서 본다. FlyVis는 관측된 간격으로 상태를 이어 가고 회차·명시적 재시작 때만 초기화한다. 분할 구간 입구는 그 구간 내부에서 준비 시간을 확보한다. 각 카메라의 방향과 회로 상태를 유지한다. 정지 또는 시간 순서를 교란한 대조와 T4/T5 출력을 가린 대조로 운동 정보의 기여를 확인한다. 초기에는 회로 파라미터를 재학습하지 않는다. [기존 AC 카메라 연결](ac-flyvis-camera-replay-20261029.md) · [부품 반응 검증](flyvis-component-response-20261029.md)

예측은 팀 계약 flybrain.racing_line.v1의 JSONL로 저장한다. 평가 표에는 거리별 횡오차 MAE/P95, 전방 오차, 유효 비율, 도로 경계 위반율과 분모를 둔다. 경계가 확인된 구간에서 점 사이 경로도 검사하고, 차체 전체의 이탈은 폐루프에서 따로 판정한다. 직선 평균에 가려지지 않도록 코너별·진입 속도대별 수와 오차를 표시한다. 가중치 선택은 개발 검증 구간에서 끝내고, 소수 코너와 한 평가 랩의 결과는 같은 서킷의 초기 결과로 기록한다.

## 3. 교사 라인보다 빠른 후보를 시각 학습에 되돌리기

재훈이의 제어기가 교사 라인으로 기준 유효 랩을 만들면 제어기를 고정한다. 먼저 학습용 구간에서 진입·에이펙스·탈출 위치를 작은 폭으로 바꾸고 트랙 경계와 차량 폭 여유를 검사한다. AC 기록으로 보정한 MuJoCo에서 같은 진입 상태와 그립으로 후보를 반복 비교한다. 후보는 이탈 없이 구간이 빨라지고 탈출 속도가 떨어지지 않을 때 저장한다. 코너 사이 효과는 서킷 전체에서 확인한다. 트랙 경계와 Z4 동역학 보정이 갖춰지면 TUM 방식의 최소 시간 궤적도 별도 교사 후보로 비교한다.

빠른 후보를 원래 영상에 붙일 때는 당시 차 위치·자세·속도에서 그 라인으로 연결 가능한 구간만 라벨로 쓴다. 연결이 불가능하거나 같은 영상에서 진입 상태별 목표가 달라지는 구간은 무효 또는 조건별로 분리한다. 후보가 요구하는 그립 값은 원본 실험 조건에 기록한다. 시각 모델이 관측할 수 없는 조건 차이는 학습 입력으로 슬쩍 넣지 않고, 필요하면 해당 조건의 새 AC 기록이나 허용된 몸 감각을 추가한 별도 비교로 다룬다. 라벨에는 원래 교사 ID, 후보 생성 방법, 제어기 버전, 진입 속도·그립, 구간 시간, 탈출 속도, AC 확인 여부를 남긴다.

같은 출발 조건에서 제어기를 고정하고 기록 라인, 시각이 예측한 교사 라인, 개선 라벨로 학습한 예측 라인을 비교한다. 유효 완주와 이탈을 먼저 보고, 유효 랩타임과 구간 시간·탈출 속도를 기록한다. 반대로 라인을 고정한 실험에서는 비행 유래 몸 되먹임의 기여를 분리한다. Monza 밖 검증은 새 서킷을 통째로 제외한 분할에서 하고, 한계에 가까운 속도의 제동에는 20m보다 먼 경로가 필요한지 제어 담당과 검증해 출력 계약을 확장한다.

## 첫 실행 순서

1. 개발/평가 랩의 영상·속도·경로 정합 및 분할 manifest를 만든다.
2. 직진·평균·속도 기준과 영상/영상+속도 판독을 학습하고, 같은 출력 형식으로 한 랩을 재생한다.
3. 고정 FlyVis 판독을 동일 표본에 붙이고, 거리별 횡오차·경계 위반·유효율과 회로 개입 결과를 낸다.
4. 재훈이에게 교사 경로와 예측 경로 JSONL, 시계·유효점 규칙을 넘겨 동일 제어기로 비교한다. 그 결과로 개선 라벨 생성에 들어간다.

이 문서의 모델과 비교는 실행 계획이다. 기존 교사 랩과 곡률 실험, FlyVis 부품 및 카메라 재생 결과가 출발 증거다.
