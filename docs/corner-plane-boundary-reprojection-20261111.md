# 기존 경계 픽셀의 노면 재투영 · 2026-11-11

기존에 관측한 경계점을 고정 평면과 장착값으로 픽셀에 옮긴 뒤, 같은 시선이 추정 노면과 만나는 위치를 계산했다. 8m 이내에서는 영상 안쪽 여유가 가장 큰 카메라를 사용했고 그보다 멀면 전방 카메라를 사용했다. 저장 경계 배열은 카메라별 픽셀을 보존하지 않으므로, 가까운 단면에는 원래 경계를 검출한 카메라와 다른 시선이 선택될 수 있다. 이 비교에서 경계 픽셀을 다시 검출하지 않았다. 전체 평면 적용, 평면 보정량 절반, 수평 이동 2m 한도, 2m 한도와 평면 적합에 사용한 전후 범위를 각각 시험했다.
