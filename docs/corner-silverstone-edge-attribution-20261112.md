# Silverstone 우회전 거리 오차의 경계별 원인 · 2026-11-12

Silverstone 전방 영상에서 우측 표면 전환을 표시했던 13프레임을 다시 재생했다. 그중 대표 우회전 620–623번에는 좌측 잔디·아스팔트 전환도 표시했다. 화면에서 전환을 확인하고 여섯 가로 위치의 녹색 대비가 최대인 점을 사용했다. 오른쪽 표시선은 어두운 띠의 전환이며 주행 가능 영역의 공식 경계로 확정한 선은 아니다. 네 프레임의 과거 두 장 누적 조건에서 표시선에 대한 투영 오차 중앙값은 오른쪽 1.12–3.41px, 왼쪽 0.96–2.31px였다. 이 값은 표시선 범위 안에서 비교한 점의 오차다. ## 실제 관측 위치와 관측 범위의 영향

지도와 절대 위치는 아래 진단에서만 사용했다. 동일 프레임에서 검출한 경계의 횡좌표만 지도 기준으로 바꾸거나, 관측이 없던 단면까지 지도 경계로 채웠다. 각 경우에 같은 국소 곡률 판독기를 실행했다. 지도 경계의 결과는 이 알고리즘과 관측 배치로 얻을 수 있는 가상 비교다.

620번의 9m 우회전은 왼쪽이나 오른쪽 중 한쪽의 횡좌표만 지도 기준으로 바꿔도 사라졌다. 9m 창의 양쪽 공통 곡률은 영상 경계에서 −0.01590m⁻¹, 모든 지도 단면에서는 −0.00033m⁻¹였다. 두 값은 기존 문턱 0.002m⁻¹의 양쪽에 있다. 실제 시작 지점 부근은 지도 단면을 전부 제공해도 이 검출기에서 경보가 나오지 않았다.

622번은 오른쪽 좌표만 바꾸면 우회전 17m, 왼쪽만 바꾸면 9m였다. 623번은 관측 좌표만 정확하게 바꿔도 후보가 없었고, 비어 있던 단면까지 채웠을 때 우회전이 나왔다. 621–622번은 이미 얻은 경계의 위치가 중요한 사례였고, 623번은 관측 범위가 함께 제한된 사례였다. [모든 경계 대체 조건과 곡률](../runs/vision-corner-silverstone-edge-attribution-20261112-01/result.json)

## 같은 경보의 시작 거리 재적합

국소 곡률은 기준점 앞뒤의 점을 같이 사용한다. 평행한 두 경계가 일정 거리부터 함께 굽는 합성 사례 16개에서 기존 예측 오차는 −4m에서 +1m였다. 좌우에 각각 별도 위치와 기울기를 허용하고 공통 굽음 시작점을 적합하면 합성 사례의 실제 시작 거리 6·10·14·18m를 모두 복구했다.

같은 계산을 기존 경보의 방향을 고정한 채 7개 서킷 영상 8,487묶음에 적용했다. 경계 기준선 자체가 경보를 낸 경우는 그대로 두고, 두 확인 모델의 국소 경보에 총 1,936회 적합을 시도했다. 1,350회는 양쪽 경계의 점 수 또는 관측 간격 기준에 미달했다. 나머지도 시작점 전후 지지, 방향, 잔차 개선 조건을 모두 충족하지 못했다. 실제 영상에서는 재적합으로 갱신한 거리가 없었으며 고정 판독기에 채택하지 않았다.
