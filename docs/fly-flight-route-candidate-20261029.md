# 비행 제어 실측 경로 후보 — 2026-10-29

[프로젝트 대전제](PROJECT_CHARTER.md)에 따른 M2의 구조 추출 단계다.
기존 DNa02 운전 모델과 별개이며, 아직 새 후보망을 차량 제어에 사용하지 않았다.

## 저자 시각 실행 경로 대조

`t1022`는 수정하지 않은 저자 `Network.stimulus_response` 경로로 깜박임 4조건과
이동 경계 144조건을 다시 실행했다. 자극과 NaN 패딩 위치는 저장된 입력과 일치했다.
중앙 세포형의 전체 반응 이력은 사전 지정 허용오차(rtol=2e-5,atol=2e-6) 안에서 일치했다.
최대 절대 오차는 깜박임 9.54e-7, 이동 경계 1.43e-6이었다. 가중치 변경·학습·차량 조작은 0회다.
따라서 이전 T4d 대비 불일치를 이 래퍼 실행 경로의 차이로 설명할 근거는 없다.
이는 생리 기능 전체 통과가 아니다. [시각 반응 결과](flyvis-component-response-20261029.md)를 유지한다.

## 추출한 구조

설정: `configs/fly-flight-route-extraction-20261029.json`.
원자료: MaleCNS v1.0의 보유 incoming CSR와 공식 주석. 원본 두 파일의 등록 해시를 확인했다.
경로마다 4연결 이내의 모든 동률 최단 경로를 합쳤으며, 선언한 끝점은 모두 보존했다.
노드 제한 20,000을 넘으면 임의 축소 없이 실패하도록 했다.
선택 노드 사이의 **모든 원본 연결**을 보존했으므로 결과는 경로 간선만의 나무가 아니다.
이 규칙은 구조 후보를 고르는 공학적 절단이며 완전한 생체 회로의 경계가 아니다.

| 경로 | 원본에서 4연결 이내 도달한 쌍 | 범위 안에서 도달하지 못한 쌍 |
|---|---:|---:|
| HS/VS 42개 → DNg02 29개 | 1,218 | 0 |
| DNg02 29개 → 날개 운동 주석 후보 67개 | 1,943 | 0 |
| haltere 주석 후보 205개 → 날개 운동 후보 67개 | 13,668 | 67 |

결과는 **9,728뉴런·1,311,145연결**이다. 구조상 입력 247개(HS/VS+haltere), 출력 67개,
나머지 내부 9,414개이며 DNg02는 내부 집단이다. 이것은 입력 자극이나 운동 부호가 등록됐다는 뜻이 아니다.

마지막 경로의 67개 미도달 쌍은 모두 `bodyId=29495`에서 출발한다.
주석은 type 미지정, sensory_ascending/unknown_sensory/haltere, rootSide=L이다.
이 끝점을 지우지 않았다. 4단계에서 못 찾았다는 뜻이며 전체 CNS에 경로가 없다는 주장은 아니다.

## 독립 대조와 잘린 경계

`t1024`는 원본 CSR를 ID로 직접 슬라이스해 내보낸 그래프와 비교했다.
내부 간선의 추가·누락·중복·가중치 변경이 없고, 모든 뉴런의 전체/보존 입출력 시냅스 수가 일치했다.

- 운동 후보의 입력 시냅스 보존율: 최소88.76%, 중앙99.83%.
- 내부 뉴런의 입력 보존율: 최소0.706%, 중앙66.67%.
- HS/VS와 haltere 입력 후보를 합친 입력 보존율: 최소4.23%, 중앙100%.

일부 내부 뉴런의 바깥 입력이 크게 잘렸다. 입력 경계 어댑터·상태·동역학과 절단 민감도를
검증하기 전까지 이 후보가 완전한 균형 제어 회로라고 주장하지 않는다.
기존 bounded route/ID extraction 검사 11개와 새 스크립트 Ruff가 통과했다.
검사는 추출/증거 처리에 관한 것이며 생리나 주행 검증이 아니다.

## 좌우·신경전달물질·운동 출력의 경계

- DNg02 somaSide: L15/R14. 날개 운동 후보 somaSide: L33/R34.
- haltere somaSide는 전부 비어 있다. rootSide가 L104/R101이며 entryNerve는 DMetaN이다.
  수용기 좌우를 세포체 위치로 추정하지 않는다. receptorType은 비어 있으므로 pitch/roll/yaw
  감각 포트나 위상·주파수 선택성을 자동 할당하지 않았다.
- 운동 후보 67개는 wm 주석 전체다. DLM/DVM/TTM 등 여러 종류가 포함되며 모두를
  날개 조종 근육 또는 같은 부호의 조향 출력으로 취급하지 않는다. 표적 근육과 기능별 재검토가 필요하다.
- [공식 다운로드 안내](https://male-cns.janelia.org/download/)의 뉴런별 전달물질 예측 표를 확보했다.
  43,282,834 bytes, GCS MD5/길이 및 SHA256을 확인했다.
  선택된 9,728개 모두의 원본 예측·confidence·consensus·ground_truth 필드를 별도 보존했다.
  consensus는 acetylcholine5207/gaba2762/glutamate1465/unclear248/기타46이다.
  이 표는 전달물질 예측 자료다. 수용기/표적과 무관하게 모든 glutamate를 억제 부호로 바꾸거나,
  unclear 값을 임의로 채우지 않았다. 현재 회로 간선은 부호 없는 실측 시냅스 수다.
