# 좌측 코너 판독 후보와 독립 평가 준비 · 2026-11-11

초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.

이번 목표는 영상으로 직선·좌·우와 시작 거리를 판독하고, 처음 보는 서킷의 저장 영상으로 검증하는 것이다. 개발 자료에서 좌회전 누락과 범위 밖 경보를 줄인 후보를 고정했다. 독립 양성 영상과 거리 변화 개선은 미검증이다.

## 배경 점수와 T4/T5 판독층

고정 판독기의 원래 T4/T5 특징, presence 관문, 거리 추정기를 유지하며 방향 판독층만 대조했다. 배경 점수를 0.02 낮추면 Magione의 과거 교사 라벨에서 좌 2/67→4/67, 우 64/85 유지, 범위 밖 26개 유지였다. 더 큰 변화는 범위 밖 경보를 추가했다. 이 선택은 개발 비교이며 다른 서킷의 양성으로 검증되지 않았다. [배경 점수 비교](../runs/vision-corner-background-margin-20261111-01/result.json).

혼합 후보는 고정 T4/T5 특징에 ridge 선형 판독층을 학습하고, 기존과 새 판독층 점수를 각각 50% 사용한다. ridge 값은 100이다. 반전 영상은 좌·우 라벨을 교환했고 방향 점수는 기존 원본/반전 평균 방식을 사용한다. 판독층을 합친 가중치를 기존 로더로 재생했다. 이 변경은 학습한 판독 어댑터에 해당한다.

- Monza는 기존 학습 구간을 학습에 쓰고 기존 물리 코너 검증 구간을 개발 진단에 썼다.
- Magione는 parent-02와 recovered-01을 학습에, candidate-01과 alternative-parent-01을 진단에 썼다. 두 역할에 같은 물리 코너가 포함된다.
- Imola는 02 기록의 기존 범위 밖 경보 31개를 음성 학습에 사용했다. 03 기록의 33개는 인접 진단으로 사용했다. 이 자료는 서킷 독립 평가 자료에서 제외한다.
- Monza 반전 특징이 없는 행은 기존 원본 단독 분기로 채점했다. 초기 비교에서 빠진 50개 검증 행을 복구하고, 단일 결정 산술로 기존 100행 검증 기준을 재현했다. [혼합 비교 전체](../runs/vision-corner-cross-track-direction-20261111-03/result.json).

혼합 없이 새 판독층만 쓰면 Imola 인접 음성은 개선됐으나 Monza 좌 적중과 결합 적중이 떨어졌다. 선택한 혼합 후보는 기존 Monza 검증에서 좌 2/6 유지, 우 6/8→7/8, 결합 5개 유지, 범위 밖 3→2개였다. Magione 교사 라벨에서 좌 2/67→8/67, 우 64/85 유지, ordinal 결합 33→39개, 범위 밖 26→27개였다. [후보 가중치와 고정 설정](../runs/vision-corner-blended-candidate-20261111-02/pins.json).

## 거리 변화와 판독 계산

혼합 후보의 Magione 인접 방향 적중 67쌍 중 정답 거리가 줄고 예측 거리가 늘어난 쌍은 22개다. 별도 배경 후보 거리 진단에서 현재 관측 90%와 속력으로 옮긴 이전 예고 10%를 섞으면 변화 오차 MAE가 0.388→0.380m로 줄었고 결합 적중 47개와 역행 22/64쌍은 같았다. 현재 관측을 50%까지 줄이면 역행은 17쌍, 결합 적중은 46개였다. 진단에 사용한 렌더 증인의 속력은 actor 사용 자격이 검증되지 않았다. 거리 갱신은 고정 후보에 적용하지 않았다. [거리 진단과 입력 계약 정정](../runs/vision-corner-background-distance-motion-20261111-01/result.json).

Monza에서 배치 산술과 단일 결정 산술의 작은 차이가 presence 임계값 한 건을 바꿨다. 배치 판독도 기존 실시간과 같은 단일 결정 산술을 사용하도록 변경했다. 반전 분기와 배경 점수 검사를 포함해 집중 테스트 17개를 통과했다. 변경 뒤 두 후보의 Magione 예측에서 방향·보류·경보가 같고 기존 공동 거리 채점의 결합 적중이 그대로인지 확인했다. [판독 코드](../scripts/infer_frozen_next_corner.py), [회귀 검사](../tests/test_corner_background_offset.py).

## 독립 평가 준비

압축 번들 조사에 이어 압축되지 않은 stream 39개를 확인했다. 대표 메타데이터 검사에 통과한 기록 1개는 Monza였고 38개는 원본 또는 계약 확인에서 거절됐다. Imola의 입고 864개에는 이동 중 근거리 양성이 없다. 현재 확보된 개발 원본에서 독립 서킷 양성을 찾지 못했다. [압축되지 않은 원본 조사](../runs/vision-corner-legacy-source-inventory-20261111-01/result.json), [Imola 전체 입고](../runs/vision-imola-full-capture-admission-20261111-01/result.json).

개발에 사용한 Monza·Magione·Imola를 제외했다. 다음 원본 후보는 Mugello다. 설치 spline에서 좌 15·우 21개의 곡률 구간을 찾았다. 이 수치는 영상 캡처의 입고 결과가 아니다. 고정 부모·혼합 후보, 공동 거리 옵션, 전처리와 채점 코드 해시, 좌·우 각 두 물리 코너 이상의 입고 조건을 기록했다. 같은 캡처에서 좌 적중 증가, 우와 결합 적중 유지, 범위 밖 경보와 미출력 증가 없음, 물리 코너별 안정 예고, 공통 적중 쌍의 거리 변화 오차 감소를 비교한다. 최종 독립 영상에서 설정을 고르지 않는다. [고정 평가 절차](../runs/vision-corner-independent-protocol-20261111-01/protocol.json).

현재 확인한 AC 엔진은 없고 기존 검증된 초기 실행 경로는 Monza·Magione·Imola로 제한된다. Mugello 원본 입고 또는 해당 트랙에서 검증된 CSP 촬영 경로가 필요하다. 독립 수집과 평가를 실행하지 않았다. 이 단계가 끝난 뒤 저장 영상 라인 연속성, 동일 라인에서 비행 회로의 몸 감각 기여, 타이어·셋업 적응 및 유효 완주와 랩타임 검증을 이어간다.
