# 기존 경보를 보존한 경계 복구 후보 비교 · 2026-11-12

관측 경계와 복구 경계에서 각각 독립적으로 코너 후보와 확인 점수를 계산했다. 두 기존 판독 중 하나라도 회전을 경보한 프레임에서는 기존 후보와 두 출력을 보존했다. 그 외 프레임에서 복구 후보가 확인을 통과할 때, 두 기존 출력이 보류였는지 또는 기존 후보와 방향이 같고 거리 차가 4m 이내인지 확인했다. 경계 기반과 T4/T5에는 같은 복구 후보를 제시했다. 경보하지 않은 쪽의 직선·보류 판정도 유지했다. [재생과 선택 코드](../runs/vision-corner-supplemental-boundaries-20261112-01/supplement.py)

개발 영상 Imola·Laguna Seca·Zandvoort·Mugello에서 경계 후보 선택기 학습 시 해당 서킷을 제외했다. 코너 판독기는 기존 동결본을 썼으며 개발 서킷에 대한 판독기 자체의 독립 평가는 아니다. 복구 문턱 0.65·0.55와 0.45에 폭 조건을 추가한 세 방식에 각각 세 가지 채택 조건을 적용했다. 기존 경보에 비해 직선·범위 밖, 내부, 반대 방향, 거리 오차가 각각 10%를 넘게 증가하는 조건을 제외했다. 상한을 내림한 값과 1 중 큰 값을 사용했다. 남은 조건은 방향·거리 동시 적중을 우선하고 추가 오류가 적은 순서로 골랐다. 범위 밖은 직선 경보를 포함한다. 적중은 방향과 시작 거리 ±5m를 함께 맞힌 프레임이다. 문턱 0.65는 Zandvoort에서 T4/T5 우회전 한 건을 더 맞혔다. 경계와 T4/T5의 내부 경보 증가가 각각 +5·+6건으로 허용치 +3건을 넘었다. 시험 전에 기존 경계를 동결했다.

Silverstone의 사후 진단에서는 세 복구 조건 모두 488번을 좌 6.88m에서 우 14m로 바꿨고, 621번은 우 13m에서 우 14m로 바뀌었다. 두 후보 모두 방향·거리 기준은 통과했지만 경계와 T4/T5 확인기가 모두 보류했다. 폭 조건은 620번의 맞는 거리 후보를 놓치고 1049번에서 좌회전으로 바뀌었다. 세 복구 조건 모두 Silverstone 우회전 접근 13장에 추가 회전 경보를 내지 못했다. [복구 후보 진단](../runs/vision-corner-supplemental-boundaries-20261112-01/silverstone-diagnostic.json)

시험 영상의 기존 경계를 쓰는 같은 후보 비교에서 Silverstone 우 적중은 경계와 T4/T5 모두 2/13이었다. T4/T5는 직선·범위 밖 경보를 14→10건으로 줄였고 코너 내부 경보는 5→7건이었다. Vallelunga 우 적중은 3→5/38, Monza는 3→4/42였다. Monza 범위 밖 경보는 8→25건이었다. 전체 시험 영상에서 기존 경보와 입력 관측 보존, 좌우 후보 공유, 4–20m 거리 및 직선·보류에서 거리 미출력을 검증했다. 이 복구 방식은 고정 판독기에 적용하지 않았다. 문턱 0.65로 복구한 488번과 621번의 보류 원인을 확인했다. 두 프레임 모두 코너 내부 차단을 통과했다. 경계 확인 점수는 0.844·0.880으로 문턱 0.919보다 낮았고, T4/T5 점수는 0.844·0.857로 문턱 0.925보다 낮았다. 다음 비교에서는 전체 판독 문턱을 낮추기보다 복구 경계에서 새로 나온 후보의 확인 점수를 따로 학습하고, 같은 후보를 두 방식에 넣어 맞는 우회전과 오경보를 비교할 수 있다.
