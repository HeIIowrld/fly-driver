# 이동 변화로 학습한 코너 시작 거리 · 2026-11-11

Magione·Laguna Seca·Zandvoort에서 한 서킷씩 통째로 제외했다. 나머지 두 서킷의 4–20m 접근으로 거리 판독을 적합했다. 원본과 좌우 반사에서 얻은 전·후·좌·우 3시점 T4/T5 대비 특징을 평균했다. 기존 판독의 방향, 경보 여부, 보류는 그대로 두고 경보가 있을 때만 새 거리값을 섞었다.

거리의 절대 오차만 학습하는 조건과, 같은 코너의 연속 캡처에서 예고 거리 변화가 차량 로컬 전방 이동과 맞도록 학습하는 조건을 비교했다. 실제 거리 차를 변화 정답으로 쓰는 대조도 뒀다. 지도는 학습과 채점 정답에만 사용했다. 서킷별로 학습한 접근은 121–206개, 인접 쌍은 83–181개였다.

## 동일한 거리 설정으로 비교

아래는 기존 예고 거리와 새 거리 판독을 절반씩 섞은 결과다. 모든 자료에 동일한 대비 특징, ridge 계수 1,000, 로컬 이동 변화 오차 가중치 1을 썼다. Monza는 앞선 세 서킷에서 적합한 단일 가중치로 검사했고, 두 주행의 기존 물리 코너 분리 검증 100개를 사용했다. Monza 100개 중 반사 특징이 없는 50개는 원래 특징만 사용했다.

Magione의 기존 좌회전 두 접근의 최초 안정 예고는 그대로였고 우회전 두 접근에서는 13.23·12.72m에서 15.26·13.53m로 앞당겨졌다. Zandvoort 안정 예고는 10.48m 한 건에서 10.57·14.36m 두 건으로 늘었다. Monza는 14m 한 건에 9m 예고가 추가됐다. 방향 경보를 그대로 사용했으므로 좌회전 누락과 오경보 수는 유지됐다.

절대 거리만 학습한 대조도 공통 거리 변화 오차를 줄였다. 동일한 특징과 혼합 비율에서 로컬 이동 변화까지 학습한 조건은 Magione에서 0.374→0.364m, Zandvoort에서 4.100→4.018m, Monza에서 4.951→4.789m로 더 줄였다. 고속 자료의 공통 쌍은 4·5쌍이라 효과의 규모는 별도 새 서킷에서 확인해야 한다.

세 서킷에서 적합하고 Monza로 확인한 거리 가중치와 결합 방법을 개발 부품으로 저장했다. 좌·우 판독과 통합한 새 독립 후보는 아직 고정하지 않았다.
