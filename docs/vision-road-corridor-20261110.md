# 도로 경계로부터 경로를 만드는 몬자·Magione 비교

2026-11-10 · 오프라인 저장 영상 평가

네 방향 영상 세 시점에서 차량 전방 0·5·10·20·30m 단면의 좌우 경계를 먼저 추정한다. 기존 밝기·기울기 특징과 같은 개발 분할을 썼다. 회귀는 단면 중간점과 로그 폭을 출력하고, 굽이 방향은 가까운 구간과 먼 구간의 중간선 방향 차이에서 계산한다. 경로는 현재 차량 원점에서 예측 중간선으로 점차 붙도록 생성한 뒤 호길이 5·10·20m에서 샘플링한다. 지도와 렌더러 절대 자세는 정답 생성·평가에만 사용한다. 제어기나 속도 계획은 연결하지 않았다.

몬자 개발 랩의 학습 725건과 검증 161건을 사용했다. 모델 선택은 검증 경계 오차로 했다. 기존 직접 경로 예측은 저장 가중치를 그대로 불러와 비교했다. 112.602초 평가 랩의 경로 평가는 기존 1,246프레임을 그대로 썼다. 경계·굽이 지표는 모든 단면의 좌우 기준값을 정의할 수 있었던 1,224프레임에서 계산했다. 특히 지도 호길이 971m 시케인에서는 경로 비교 39건 중 22건에만 전체 단면 라벨이 있다. 코너별 경로 비교에서는 빠진 라벨 때문에 프레임을 제거하지 않았다.

경계 MAE는 전체 20m 단면 좌 1.25m, 우 1.32m다. 굽이 방향은 우·직진·좌 세 분류이며, 전체 라벨 표본에서 61.8%였다. 971m는 1/22, 2173m는 20/29였다. 예측 단면 안에 경로를 두는 규칙은 실제 지도 경계 안에 들어간다는 보장이 없으므로 경계 밖 예측점을 실제 지도에서 별도 집계했다. 이 수치는 차체 이탈이나 랩타임을 측정한 값이 아니다.

Magione은 몬자 가중치를 저장한 뒤 그대로 불러왔으며 평가 후 해시가 동일했다. 배경 카메라 저장 영상 네 회차의 이동 구간 1,453프레임에서 렌더러의 차체 자세와 별도로 검증한 비대칭 트랙 폭을 사용해 평가 라벨을 등록했다. 회차별 속도 평균은 약 24.7~25.4km/h이며 구간이 겹친다. 일부 코너의 저속 반복 평가로 해석한다. 20m 단면 경계 MAE는 좌 2.74m, 우 1.98m다. 굽이 방향은 369/1453(25.4%)이고, 전부 직진으로 분류한 기준은 1031/1453(71.0%)다. 실제 좌·우 굽이가 있는 경우는 242/422(57.3%)를 맞혔지만 직진 표본에서 굽이 오탐이 많았다.

Magione에서 같은 규칙으로 만든 지도 기반 복귀 경로와 비교하면 20m 횡오차는 경계 모델 2.21m, 기존 영상 모델 2.51m, 직진 2.38m였다. 몬자의 경로 지표는 실제 교사 궤적 기준이고, Magione은 지도 경계에서 만든 경로 기준이다. Magione 교사 랩 재현이나 완주 성능은 이 수치로 판정할 수 없다.

두 미사용 몬자 코너에서 경로 오차가 커졌고 Magione에서는 굽이 오탐이 많았다. 현재 경계 모델은 기존 주행 모델 승격 근거에 미달한다. 다음 검증은 보이는 가까운 경계를 우선 평가하고, 깊은 코너에서 단면이 사라질 때 거리별 유효성을 명시한 뒤 새 서킷의 다양한 진입 자세로 비교하는 것이다. 같은 분할의 FlyVis 대조, 비행 유래 몸 되먹임과의 폐루프 결합, 더 빠른 라인의 학습·검증은 남아 있다.

첫 실행의 몬자 경로 지표는 경계 라벨이 완비된 표본만 집계했다. 원본은 보존했고 두 번째 실행에서 경로 평가 표본을 기존 전체 평가로 맞췄다. 회전된 좌표계에서 직선·좌·우 경계 변환과 경로 방향을 검사했다.
