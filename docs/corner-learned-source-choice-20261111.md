# 운동 시각과 누적 경계의 선택 학습 · 2026-11-11

기존 판독이 직선으로 냈거나 코너 유무 근거가 부족해 보류한 프레임에서 두 후보를 만들었다. 운동 시각 후보는 좌우 점수가 더 큰 방향과 4–20m 거리 추정을 사용했다. 경계 후보는 최근 다섯 영상의 누적 도로 경계로 방향과 시작 거리를 추정했다. 배경·좌우 점수 차, 코너 유무 점수, 각 후보의 거리, 방향 일치, 앞 프레임의 예상 거리와 차이를 두 로지스틱 회귀에 넣었다. 학습 정답은 방향·거리 ±5m 동시 적중이다. 두 후보가 있으면 추정 적중 가능성이 큰 것을 택했다. 여섯 서킷의 전체 7,287개 캡처를 채점했다. 평가할 서킷과 Spa를 학습과 문턱 선택에서 제외했다. 문턱 선택용 예측에서도 각 서킷을 자기 모델 학습에서 제외했다. 개발 자료의 기존 후보와 비교해 좌·우·결합 적중과 안정 예고가 줄거나 직선·범위 밖 오경보, 미출력 또는 거리 변화 오차가 늘어난 문턱은 제외했다. 모델 하나만 쓰는 조건 두 개와 두 후보를 비교하는 조건을 시험했다. 18개 평가에서 추가 경보 문턱이 채택되지 않았다.
