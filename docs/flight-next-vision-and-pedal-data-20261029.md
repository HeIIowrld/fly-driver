## 확인한 부족분

기존 t1121 학습 자료는 좌40·우1,579·중립576개로 불균형했고,
학습 자료의 주행선 OFF 적격성도 미확인이었다. 균형 손실만 바꾼 결과의
다른 기록 실패는 [기존 진단](flight-steering-capacity-and-balanced-learning-20261029.md)에 남아 있다.

t1276은 별도의 주행선 OFF 확인 자료 t1114 전체742관측/737유효 표적을 해시 대조했다.
라벨·마스크·시각·원래 이력·분할을 바꾸거나 모델을 학습하지 않았다.

| 기준 | 유효 표본 |
|---|---|
| 좌 의도 >0.01 | 41 |
| 우 의도 <-0.01 | 68 |
| 중립 의도 절댓값 ≤0.01 | 628 |
| 가속 >0.05 | 737 |
| 제동 >0.05 | 0 |
| 제동 >0 | 0 |

좌/우 의도는 기존 계약의 `-applied_steering`이다. 단위가 검증된 바퀴 각도라는 뜻은 아니다.
자료의 제동 최소·최대는 모두0이다. 이 자료만으로 일반적인 제동을 배웠다고 주장할 수 없다.
기존에 이미 평가한 자료이므로 새 맹검 평가로 다시 부르지 않는다.

## 다음에 수행할 일

1. t1275 전체12회와 독립 감사를 끝까지 확인하고6쌍의 사전 기준을 평가한다.
   초기 성공 두 쌍만 보고 회로를 승격하거나 비교를 중단하지 않는다.
2. 시각 학습에는 주행선 OFF 원본의 좌·우 커브와 중립을 추가 확보한다.
   기존 API의30초 교사 수집은 연속 위치에서 별도 에피소드로 수행할 수 있는 후보 경로다.
   실제 호출 전 현재 정차/AIoff/장치 소유권/카메라 조건을 확인하며 창 조작을 사용하지 않는다.
   새 에피소드 경계는 명시하고 각 이력 안의 시각·몸·회로 상태를 임의로 재설정하지 않는다.
3. 실제 코너 접근·감속·제동 표본을 확보한다. 낮은 속도의 수집에서 제동이 계속0이면
   속도 과제/교사 수집 프로필을 별도로 설계·검증한다. API 종료의 강제 정차를 도로 상황의
   제동 정답으로 섞지 않는다. 속도 과제가 바뀌면 그 목표·단위·전환 시각을 명시한다.
4. 새 원본 전체 에피소드의 학습/개발/평가 역할을 적합 전에 고정한다.
   학습 전용 정규화·원래 관측 간격·순환 상태를 유지하고 검증된 빠른 몸 경로와 구분한
   시각→비행 명령 경로를 GPU에서 학습한다. 같은 GPU의 다른 사용자 작업을 임의 종료하지 않는다.
5. 시각/운동 시각 제거와 몸 피드백 제거를 비교하고, 학생이 조향·가속·제동을 함께 내는
   새 실제 시험으로 이어간다. 그 뒤 반복 유효 완주와 속도·타이어·하중·셋업에 따른
   레이싱 라인/랩타임을 최적화한다. 시험용6kmh 페달을 학습한 가감속으로 부르지 않는다.

빠른 yaw 반응 한 부품의 성공은 정적 차체 기울기·다른 회전축·타이어/접지 대응의
기능 검증을 대신하지 않는다. 실측 화학 연결과 가정한 전기 결합/시간 상수의 구분도 유지한다.
