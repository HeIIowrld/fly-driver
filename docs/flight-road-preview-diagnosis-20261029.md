## 구현과 정답의 의미

`teacher_path_preview.py`는 원래 CSP 카메라 촬영 시각과 교사 주행 위치 기록으로
5·10·20m 앞의 경로 방향을 만든다. 목표 거리는 수평면의 실제 누적 이동 거리이며,
카메라의 수평 전방/화면 오른쪽 축으로 표현한다. 오른쪽 방향을 양수로 한다.
두 번째 표적은 `2 × 횡방향 변위 / 수평 직선거리²`인 pure-pursuit 곡률 대용값이다.
실제 도로의 국소 곡률이나 최적 레이싱 라인을 뜻하지 않는다.

- 위치·카메라 방향·미래 궤적은 **표적 생성에만 사용**한다. probe 입력은 기존 시각 특징 576개뿐이다.
- 원래 8개 이력의 5,932개 관측과 역할·조작 정답·시각·마스크는 수정하지 않는다.
  새 표적만 별도 NPZ에 저장한다. 미래 끝점이 없는 행도 유지하며 새 표적의 마스크만 false다.
- camera frame 메타데이터는 원래 event의 SHA256과 대조하고, 네 카메라의 반환 투영/방향/위치를
  기존 엄격한 기하 검사로 검증했다. 원점 이동을 추측하거나 보정하지 않는다.
- telemetry는 같은 CSP script clock에서 보간한다. AI 주행·비정지·바퀴 이탈 0인 연속 구간만 쓴다.
  100ms 초과 공백, 60m/s를 넘는 위치 급변, 종료/복구 단계를 가로질러 미래를 연결하지 않는다.
- 현재 교사는 고정 30km/h AI다. 이 표적은 실제 교사의 미래 경로이며 기록 라인이 아니다.

직진 보간·회전 불변성·우회전 부호/곡률·기록 공백·위치 급변·종료 단계·바퀴 이탈·역순 시각에
대한 7개 검사가 통과했다. 실제 8개 이력의 카메라 기하 거부는 0이었다.
5/10/20m 유효 표적 수는 각각 5,790/5,677/5,448개다.

## 고정 비교 실험

기존 `scene_features`만 받는 선형 ridge probe를 사용했다. TRAIN 6개 이력의 평균/표준편차만으로
정규화하고 ±5 범위로 제한했다. 목적은 평균 제곱오차 + 계수 제곱합이며 규제 계수는 사전 고정 1이다.
거리마다 방향과 곡률 표적을 함께 풀되 출력 간 학습 결합은 없다. 개발 자료로 계수·규제·정규화를
맞추지 않았다. 생물학적 회로 구현이나 실제 actor를 대신하는 모델이 아니다.

방향 오차 RMSE, rad. 각 셀은 `시각 probe / TRAIN 표적 평균 / 0방향`이다.

| 개발 구간 | 5m | 10m | 20m |
|---|---|---|---|
| 02 | 0.02223 / 0.00623 / 0.00452 | 0.03497 / 0.00561 / 0.00685 | 0.05384 / 0.00813 / 0.01053 |
| 07 | 0.03196 / 0.01412 / 0.01221 | 0.04478 / 0.01712 / 0.01880 | 0.07666 / 0.02170 / 0.03218 |

**두 개발 구간의 세 거리 모두 평균·0방향보다 나쁘다.** 운동 채널을 TRAIN 평균으로 치환하면
모든 개발 거리에서 오히려 방향 오차가 줄었다. 이 치환은 정보 제거 대조이며 실제 뉴런 손상 실험이 아니다.
시작 3초 이후의 별도 감사에서도 시각 probe는 모든 개발 거리에서 TRAIN 평균보다 나빴다.
따라서 실패를 초기 과도만으로 설명할 수 없다.

## 자료 범위에서 새로 확인한 한계

두 개발 구간의 모든 유효 표적은 세 거리 모두 방향 절댓값이 5도 이내다.
20m 방향 표준편차도 약 0.381/0.867도다. 반면 TRAIN 05/06에는 20m 앞 방향이
5도를 넘는 관측이 각각 146/226개 있다. 이 개발 구성이 코너 일반화 검증을 충족한다고 볼 수 없다.
역할을 바꾸거나 실패한 개발 결과를 지워 이 문제를 해결하지 않는다.

이 결과는 **현재 시각 요약 + 고정 선형 probe + 현재 역할 분리에서 예측이 실패했다**는 증거다.
겹눈/운동 회로에 정보가 전혀 없다거나 비선형 모델도 불가능하다는 결론으로 확대하지 않는다.
