# 곡선 구간 실패와 주행 중 교사 자료 보강 — 2026-10-28

앞선 턴은 새 후보806의60m와240m 실제 주행 및 원본 재생을 검증했다. 이번 턴은480m 시험에서348.214109m의 경로 실패를 확인하고, 실패 직전 상황의 교사 자료를 보강하는 경로를 추가한다. 전체 서킷 주행 목표는 아직 달성하지 못했다.

## 480m 실패

API 준비 t820, 읽기 전용 사전검사 t821 후 t822를 실행했다. 학생 요청1837회, 최고18.301073km/h,348.214109m에서 바퀴1개 이탈로 중단했다. 속도20km/h·이탈0·유효 랩·도로 여유1m 기준을 유지했다. 최종 native 제동 정지 및 vJoy FREE1, 창 조작0회를 확인했다. t823은 원본 픽셀·몸 감각에서1837회 요청을 재생해 오차 `[0,0,0]`, SDK 경로 연속성, 실제 정지를 확인했다.

이번806은240m를1회 통과했지만480m를 통과하지 못했다. 과거682가444.711m까지 간 별도 기록보다 이번 실패가 앞선다. 두 실행은 통제된 동일 조건 비교가 아니며 광범위한 개선/반복 안정성을 주장하지 않는다. 기본 모델을806으로 교체하지 않는다.

## 별도 curve320 자료 수집

`--expert-handoff --handoff-context curve320 --handoff-seconds30 --handoff-native-receipts`는 CSP/background·receipt15_route480·학생2000결정 한도의 별도 모드다. 원래 SDK 경로320m 이상이고 실제 속도가 기존 전환 조건을 만족할 때 같은 프로세스가 소유한 vJoy를 AI에 인계한다. 학생의 속도·이탈·도로 guard를 먼저 검사한다. 320m는 수집 조정자의 조건이고 actor 입력에 들어가지 않는다. 모델 상태와 감각 history는 원래 시작점부터 계속 이어진다.

시작 실제 속도16..18.5km/h·AI hint15·조향0.9·실제 상한20·30초/180m·같은 camera generation/epoch 조건은 유지한다. 카메라 예산은3817그룹,119.51초,2GiB다.320m 이후 AI 이동은 학생의480m 성과로 세지 않는다.

독립 읽기 전용 native 수신기는 AI 소유권 관측과 vJoy 반환 뒤 시작한다. 목표 주기10ms,최대40초/4000표본이고 원래308byte prefix와 QPC 수신 시각을 보존한다. 샘플을 보간하거나 중복 packet의 시각을 바꾸지 않는다. 모델의 관측 주기·신경 계산·actuator 입력은 바꾸지 않는다. 별도 worker 오류와 예산 초과는 실패로 남기고, AI lease를 원래 종료 절차로 닫는다.

감사는 파일 해시·카운트·원래 시간·packet 단조 증가·동일 실행의 앞뒤 raw native packet 범위를 검증한다. 원래 제어값을100Hz로 수신하도록 요청한 것이며 실제100Hz를 측정했다고 아직 주장하지 않는다. label 생성은 동일하게 미래40ms/최대25ms lateness를 적용한다.

## 인계 직후 표적의 추가 제외

시계 교환 개선 후 t844의 초기 불확실성은11.063ms로 줄었지만,806개 요청 뒤 카메라 대기 만료로 중단됐다. t845는806개 학생 요청을 원본으로 재생해 차이0을 확인했다.
