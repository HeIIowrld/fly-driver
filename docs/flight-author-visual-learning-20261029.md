## 사용자 확정 대전제

## 다음 작업

1. 이미 본 개발에 반복 맞추지 않는다. 실제 시각망 적응 체크포인트와 실패 비교를 보존하고, 빠른 코너 선행 판단에 필요한 시각 정보·시간 경로와 자료의 진입/탈출 다양성을 점검한다. 단순 yaw/속도 근사보다 좋은 미래 판단이 필요하다. 더 많은 epoch만으로 해결됐다고 가정하지 않는다.
2. 실제 시각망 학습과 비행 운동 회로는 아직 별개다. 검증된 목표 회전과 몸 yaw 피드백을 다른 신경 경로로 연결하고, 기하/자세와 접지·타이어·하중의 역할을 유지한다. 기존 30km/h 목표의 단위를 바꿔 해석하지 않고 고속 목표 계약·기어/조향/페달 실제 단위와 부호를 검증한다.
3. native AI-off 소유권을 실제 새 엔진/패킷으로 확인한 뒤에만 학생 제어를 적용한다. 조향·가속·감속, 60→100km/h/변속, 하중·타이어·셋업 적응, 유효 완주와 레이싱 라인/랩타임 최적화는 계속 남아 있다.
