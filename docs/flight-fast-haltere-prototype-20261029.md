# 빠른 haltere–b1 경로 후보 구현과 원본 이력 검증

기록: 2026-10-29, Asia/Seoul. [프로젝트 대전제](PROJECT_CHARTER.md)는 유지한다.
초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.

## 구현한 범위

원래9728뉴런의 화학 연결망·t1121 체크포인트·몸 encoder·시각/명령 가중치는 보존했다.
그 안의47개 haltere 감각뉴런과 좌/우 b1 운동뉴런 `801310`/`804301`, 총49개 상태에만
빠른 동역학을 적용하는 별도 후보를 구현했다. 새 익명 뉴런이나 차량 조향 보정 경로는 추가하지 않았다.

원래51개 화학 접촉이 있는 위치에만 대칭 전기 결합을 가정한다. 접촉 수를 운동뉴런별로
정규화한 값이 상대 가중치이며, **전기 접합의 존재·전도도·5ms 시간 상수는 실측값이 아니다.**
신경 활동을 정규화한 탈분극 대리 상태로 쓰는 rate 축약이며 실제 전압/스파이크/날갯짓 위상 모델은 아니다.
여성 FANC의 ID를 현재 남성 연결망에 섞지 않았다.

빠른 b1 감각운동 연결의 생리 근거는 있지만, 이것이 현재 모든 화학 접촉의 전기적 결합을
증명하지는 않는다. [초파리 shaking-B 실험](https://pmc.ncbi.nlm.nih.gov/articles/PMC6573327/),
[비행 제어 연결 지도](https://pmc.ncbi.nlm.nih.gov/articles/PMC12872070/)의 근거 수준과 구분한다.
EMG 지연을 뉴런 tau에 대입하지 않았다.

구현은 [flight_fast_haltere.py](../src/flybrain_drive/flight_fast_haltere.py)다.
원래 화학 입력은 기존 명목/소수 신경 간격마다 계산해 유지하고,49개 국소 상태만 최대1ms로 적분한다.
대칭 Laplacian 전류 `-g L a`는 그 뉴런 상태 안에서 작용한다. 나머지 상태는 기존50ms 재귀를 따른다.
결합0·tau50ms 조건은 원래 소수 간격 계산을 그대로 보존하는 대조다.
고속 내부 적분은 새 카메라/native 관측을 만드는 것이 아니다.

## 현재 통과 범위와 다음 작업

통과한 것은 별도 신경 회로 부품의 구현, 원래 대조와의 일치, 수치 세분화, 알려진 원래 이력 재생이다.
이 부품은 새 실시간 스트림으로 연결·인증하거나 차량에 전송한 상태가 아니다.
시각·하행 가중치의 불변이 운동 회로의 응답까지 같다는 뜻은 아니므로 새 주행 검증이 필요하다.
기존 실제 안정화4/6 개선·사전 기준 미통과와 후보 미승격은 유지한다.

다음은 명시적인 후보/소스/기준 계약을 가진 별도 실시간 스트림을 구현하고, 원래 이력과의
끝까지 대조·상태 지속성·실시간 비용을 확인하는 것이다. 기존 스트림 인증으로 새 동역학을
몰래 허용하지 않는다. 이후 새 실제 반복 비교를 사전 선언해 원래50/80/150ms 가드 안에서 평가한다.
시각 기여·겹눈 좌표/T4d·비행 기전 개입과 공정한 대조, 학습한 조향/가감속·학생 유효 완주·
타이어/셋업·빠른 레이싱 라인/랩타임의 원래 목표는 그대로 미완료다.
