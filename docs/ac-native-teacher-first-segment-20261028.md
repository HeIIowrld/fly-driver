## 증거의 한계와 다음 단계

이것은 짧은 단일 구간이다. 공개 모델의 전체 랩 성능 재현이나 파리 모델로의 전이를 증명하지
않는다. 현재 교사는 세계 위치·지도 ray·미래 곡률을 사용하는 privileged SAC다. 해당 정보는
파리 actor 센서에 넣지 않았다. 실제 카메라 crop/FOV/미러 보정과 영상 노출-물리시각 동기는
미검증이며 `training_admissible=false`로 유지했다. 같은 영상을 여러 결정에 연결한 경우도
새 영상인 것처럼 늘려 세지 않았다.
