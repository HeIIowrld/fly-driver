# 실제 움직임 기록의 감각 개입과 연속 준비 — 2026-11-04

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.** 비행 기준·변속·타이어/셋업/차종·검증된 상대풍 적응을 유지한다. actor에는 지도/world pose/절대 heading/교사 명령을 추가하지 않는다. 측정 구조·생리 근거·기능 근사·학습한 차량 경계를 구별한다.

앞선 목표 턴은 **progress**다. 실제 시각 후보 연결, 냉간/고온 움직임 추론과 독립 전체 감사라는 새 증거를 남겼다. 이번에는 그 실제 출력의 재구성과 초기 출력 문제를 확인하고 준비 경계를 구현했다. 전체 한계 주행 목표는 active이며 완료하지 않았다.

## 원본을 실제로 다시 계산했는가

루트는 `runs/thermal-visual-motion-20261104/`다. 원래 교사 저속 주행 `cold40-motion-01`/`hot110-motion-01`의 원본 네 방향 RGB·촬영 순서·시각으로 FlyVis를 다시 계산했다. 각 reference/GC-enabled/GC-deferred 세 재생은 에피소드 시작에서만 새 author prior를 사용한다. 각133/134 영상 그룹의 RGB/촬영 시각·특징 일치를 별도 `*-pixel-audit-01`이 확인했다. 이 계산은 오프라인이며 live GPU 지연 재검증이 아니다.

`replay_moving_native_sensory`는 실제 사용한 optical/native/head 후보를 감사된 loader로 연결한다. 현재 몸의 원본 prefix/첫 receipt와 촬영 당시 몸 이력, decision clock, camera publication을 그대로 사용한다. 회로는 각 독립 비교 분기의 시작에서만 초기화하고 중간에는 연속 유지한다. 원래 몸50ms·영상150ms와 계산 후 몸50ms 조건을 완화하지 않았다.

## 같은 몸·영상에서 온도만 바꾸면 반응하는가

원래 native19의 **온도 네 값(index11:15)만** 각40/80/110℃로 변경했다. 몸21·자세·회전·속도·가속도/하중/slip/압력, 영상·시각과 시작 회로 상태를 유지한다. 합성 prefix identity를 부여해 변경된 값을 원본 native bytes로 속이지 않는다. 물리 시뮬레이터의 타이어 상태를 바꾼 실험이 아니므로 새 온도에서의 실제 마찰·거동 정답은 없다. OOD 표시를 유지했다.

기존 학습 경계가 온도 입력 변화에 인과적으로 반응함을 확인했다. 적절한 감속·슬립 회피·그립 적응인지, 무엇이 더 빠른 라인인지까지 입증하지 않았다. 원래 모든 출력의 온도는 기존 학습 지원 범위 밖이었다. 온도만 nominal80℃로 대체하면 이 특정 OOD 표시는 사라지지만 실제 데이터의 지원 범위가 확장된 것은 아니다.

공간 시각 projection만 중립으로 바꾼 분기의 최대 조향 변화는 냉간 .007841/고온 .007589다. 이 저속6초 구간에서도 해당 시각 경로가 출력에 연결되어 있다. 전체 시각 기여 비율이나 고속 코너 판단 능력으로 일반화하지 않는다. 기존 진입 전 영상 교환의 기대 방향6/15는 아직 개선되지 않았다.

## 입력 독립적인 첫 출력과 준비 경계

온도와 optical 경계를 다르게 해도 두 기록의 첫 출력은 모두 **조향−.936079·가속.996127·제동.117736**이다. 원래 통합 모델은 첫 결정에서 현재 감각 drive를 저장하고 이전 drive가 흐른 시간만 회로 상태에 적분한다. 첫 결정에는 그 시간이 없어 초기 신경 상태의 근육을 읽는다. 따라서 첫 출력을 현재 영상을 판단한 조작으로 취급하면 안 된다. 첫0.1초에도 큰 편향이 남았다. 이 문제는 위 근육/readout 재구성과 원래 held-drive 인과 순서에 부합한다.

`ReadOnlyFlightPreroll`은 시작된 runtime을 단독으로 이어 사용한다. 이번 명시적 공학 조건은 **감각 적분 시간≥.5초·서로 다른 촬영≥3개**다. 조건 전에는 원래 출력 전체를 진단용으로 기록하고 `continuation_candidate=None`을 반환한다. 조건을 채우면 같은 runtime의 현재 예측을 후보로 반환하며 신경 상태·시각 trace·held drive를 초기화하지 않는다. 외부 state reset/다른 호출자의 recurrence 진행/촬영 역행/센서 거절은 terminal 실패다. 어느 단계도 actuator를 갖지 않으며 actor_qualified=false다.

두 `*-preroll-01`은 prefix를 삭제/시간 재배열하지 않고 전체569/572사건을 다시 실행했다. 준비 뒤에도 전체 연속 재생과 같은 예측을 유지하며 두 별도 `*-preroll-audit-01`이 사건별 조건/후보/근육 수식을 확인했다. **0.5초/3촬영은 연구용 노출 조건이며 출력 안정·적절성·정지·안전 보장이 아니다.** 원본 냉간 준비 완료 시각은 교사 동작 시작을 약20ms 포함하므로 정지 상태에서만 준비했다고 해석하지 않는다. 실제 live 제어권 인계에 아직 연결하지 않았고 학생 운전 개선 성적도 없다.

## 다음 단계와 미검증

같은 입력의 적절한 조작 정답/물리 반응 없이 출력 변화의 방향을 성공으로 정하지 않는다. 다음은 원래 교사 조작과의 시간·조향 단위/부호 대응을 확인해 준비 이후 실제 저속 구간의 조작 오차를 산출하고, 기존 고속 기록을 보존하면서 필요한 저속/온도 조건 자료를 학습에 연결하는 것이다. live 제어권 인계에는 새 준비 단계와 독립 정지·신선도·단위/부호 계약을 실제로 통합해야 한다.
