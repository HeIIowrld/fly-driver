# 연속 경계 형상과 코너 시작을 함께 학습 · 2026-11-12

기존 점별 경계 모델에 연속한 두·세 단면의 횡좌표 차와 굽음 오차를 추가했다. 같은 영상에서 별도 출력으로 시작 후보 없음·좌·우와 4–20m의 시작 거리를 학습했다. 기본 지도 후보는 충돌 메시에서 인접 비유효 노면까지 확인된 물리 경계로 계산했다. 두 모델 모두 Magione·Spa의 동일 학습 2,408장과 검증 619장을 사용했다. ## 경계가 이어져도 새 코너가 아닐 때

기하학적으로 굽은 곳을 곧 새 코너로 가르치면 이미 돌고 있는 구간이 양성에 섞였다. 기존 분류와 대조했을 때 Magione의 코너 내부 247장, Spa의 코너 내부 260장에서 물리 경계가 추가 굽음 후보를 제안했다. 두 번째 모델에서는 코너 내부·직선·거리 범위 밖인 기록을 새 시작 없음으로 학습했다. 접근에서는 물리 후보의 방향이 기존 진입 라벨과 같고 시작 거리가 ±5m 이내일 때만 물리 후보를 사용했다. 방향이나 거리가 충돌하면 해당 출력의 손실을 가렸다. 이 규칙은 학습에만 적용했다. [기존 진입 상태와 물리 후보 대조](../runs/vision-corner-surface-shape-20261112-01/teacher-audit.json) · [진입 확인 규칙과 학습 기록](../runs/vision-corner-surface-shape-20261112-01/entry-supervised/training.json)

수정한 규칙을 통과한 학습 양성은 좌 57장, 우 57장이었다. 검증에서는 좌 1장과 우 17장에 그쳤다. 수정 모델의 선택 체크포인트는 이 좌회전 표본을 맞히지 못했다. Silverstone에서도 0.5 문턱을 넘은 직접 시작 후보가 없었다. 이 상태에서는 수정 라벨의 양성 수와 검증 범위가 적어 시작점 모델을 일반화됐다고 판정할 수 없다.

## T4/T5가 더한 확인

두 판독기에 같은 후보를 주고 기존 확인 문턱 0.25를 유지했다. 최종 우 방향 적중은 모든 조건에서 경계 **1/13**, T4/T5 결합 **3/13**이었다. 연속 형상 경계의 결합 동시 적중은 기존 34m 대조군 10장보다 한 장 적은 9장이었으며, 직선·범위 밖 오경보는 117→139장이었다. 진입 상태를 반영한 모델의 같은 조건은 동시 적중 9장과 오경보 131장이었다.

두 판독기 모두 기존 경보가 없던 곳에서 첫 모델의 연속 형상 후보를 넣으면 T4/T5만 확인한 후보 중 방향·거리 동시 적중은 없었고, 방향만 맞은 접근은 2장, 직선·범위 밖 오경보는 34장이었다. 경계만 확인한 직선·범위 밖 오경보는 14장이었다. 첫 모델의 영상 행에서 2D 경계를 선택한 별도 조건에서는 T4/T5만 확인한 동시 적중이 1장, 방향만 맞은 접근이 1장, 오경보가 36장이었다. 이 비교는 기존 경보를 먼저 보존하는 판독에서 새 후보가 어떤 오류를 추가하거나 줄이는지 나타낸다. 620번의 맞는 우 16m 후보에 붙은 점수는 경계 −0.198, T4/T5 결합 −0.050이었다. 두 값 모두 문턱 0.25보다 낮았다. 기존 경보를 보존하고 같은 후보의 점수 문턱만 사후에 훑어도, 직선·범위 밖 오경보를 기존 34m의 결합 판독 수준인 117건 이하로 두면 네 후보 방식 모두 결합 우 방향·거리 동시 적중의 최대가 2건이었다. 기존 결합 판독과 같다.
