# 같은 코너 경보에서 시작 거리 보정 · 2026-11-12

경보를 내는 프레임과 좌우 방향은 기존 판독과 동일하게 두고 시작 거리만 보정했다. 학습에 사용한 표적은 영상 대비로 만든 직접 경보 중 방향이 맞았던 후보의 거리 오차였다. 후보별 거리 보정량을 상수 중앙값, 국소 경계 특징, 경계 곡률 모델의 예측, 경계와 T4/T5를 함께 쓴 곡률 모델의 예측으로 각각 추정했다. 회귀 모델의 학습에서 서킷별 가중치는 같았다. 보정은 최대 5m이고 출력은 4–20m 안으로 제한했다. 한 프레임 이어받은 경보에는 앞 프레임에서 적용한 보정량을 사용했다. 기존 경계만으로 이미 판독 가능했던 경보는 보정하지 않았다. [실행 코드](../runs/vision-corner-distance-residual-20261112-01/distance_residual.py)

평가한 각 개발 서킷은 거리 보정과 곡률 모델의 학습에서 모두 뺐다. 학습 중에는 곡률 특징을 얻는 서킷도 추가로 제외했다. Silverstone과 Spa에는 다섯 개발 서킷으로 학습한 보정을 적용했다. 지도와 주행 좌표는 거리 표적과 평가에 사용했다. 두 기존 경보 방식 각각에서 보정 전의 공통 채점이 재현되는지 확인했다. [서킷 분할과 전체 채점](../runs/vision-corner-distance-residual-20261112-01/result.json)

## 다섯 서킷 제외 평가

기존 경계+T4/T5 확인 모델이 낸 동일 경보로 거리만 비교했다. 방향 적중은 각 조건에서 116건, 오경보는 277건이었다. 거리 변화 오차는 방향을 연속 적중한 동일한 52쌍에서 계산했다. 안정 예고는 서킷 안에서 물리 코너를 중복 없이 셌다.

| 거리 보정 입력 | 평균 절대 거리 오차 | 방향·거리 동시 적중 | 안정 예고 | 거리 변화 오차 |
| --- | ---: | ---: | ---: | ---: |
| 원래 거리 | 5.75m | 58 | 12 | 2.85m |
| 학습 표본의 오차 중앙값 | 6.67m | 41 | 10 | 2.70m |
| 국소 경계 특징 | 4.75m | 73 | 14 | 2.11m |
| 국소 경계와 경계 곡률 모델 | 4.78m | 67 | 12 | 1.97m |
| 국소 경계와 경계+T4/T5 곡률 모델 | 4.66m | 77 | 14 | 2.09m |

경계 곡률 모델과 결합 곡률 모델을 비교하면 T4/T5를 넣은 거리 보정에서 동시 적중이 67→77건이었다. Magione은 원래 17건에서 결합 보정 후 33건으로 늘었다. Zandvoort는 4→2건이었고 안정 예고 1곳을 잃었다. 기존 경계 전용 경보로 같은 비교를 했을 때에는 결합 곡률 모델 보정이 경계 곡률 모델 보정보다 평균 절대 오차가 5.60→5.95m로 커졌다. [조건별 프레임 거리](../runs/vision-corner-distance-residual-20261112-01/approaches.jsonl)

## Silverstone과 Spa

Silverstone의 대표 우회전 621·622번에서 실제 시작까지의 거리는 14.40m와 10.17m였다. 원래 경보는 18.00m와 13.59m였다. 경계 곡률만으로 보정하면 14.70m와 10.29m, T4/T5를 결합한 곡률로 보정하면 16.21m와 11.80m였다. 두 조건 모두 이 우회전의 연속 예고를 유지했다. 전체 Silverstone 안정 예고는 경계 곡률 보정 4곳, 결합 보정 3곳이었다. Spa의 동시 적중은 원래 13건, 경계 곡률 보정 11건, 결합 보정 10건이었다.

서킷 제외 개발 영상의 거리 평균은 좋아졌지만 Silverstone과 Spa까지 일관된 개선이 확인되지는 않았다. Vallelunga의 독립 평가는 촬영 전에 고정한 설정을 사용한다. [독립 평가 설정](corner-vallelunga-frozen-20261112.md)
