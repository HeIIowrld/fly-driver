# Silverstone 우회전 경계 누락과 복구 · 2026-11-12

Silverstone의 좌 11·우 13개 접근 프레임에서 2–24m 단면별 좌우 경계 검출과 지도 경계의 화면 투영 위치를 비교했다. 화면 안에 투영됐다는 판정은 카메라 범위만 나타낸다. 실제 영상에서 노면 대비가 충분했는지는 별도 문제다. 지도와 카메라의 세계 좌표는 이 진단에 사용했다. [접근 프레임별 검출과 투영](../runs/vision-corner-causal-edge-recovery-20261112-01/observation-diagnostic.json)

우회전의 10–24m 오른쪽 지도 경계점 104개 중 79개가 전방 화면에 들어왔고 25개는 전방 밖의 다른 화면에 들어왔다. 기존 추출기가 쓰는 전방 화면에 들어온 79개 중 34개는 오른쪽 경계값이 비어 있었다. 2–8m에서도 우회전 오른쪽 지도 경계점 52개 중 16개의 검출값이 비어 있었다. 같은 근거리의 좌회전 오른쪽 경계점에서는 화면 안 43개 중 3개의 검출값이 비어 있었다.

최근 0.45초 안의 경계를 차량 속도와 요율로 현재 좌표에 옮겼다. 현재 관측값이 비어 있을 때 과거 두 관측이 좌우 각각 1m 이내에서 일치하면 채우는 방식과, 현재 인접 단면이 뒷받침할 때 과거 한 관측으로도 채우는 방식을 비교했다. 7개 서킷의 8,487묶음에서 같은 양쪽 굽음 시작 적합 규칙으로 채점했다.
