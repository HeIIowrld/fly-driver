# 실제 AC 감각 입력의 시간 기준 측정

갱신: 2026-10-27, Asia/Seoul. 최종 목표는 비전·몸 감각을 사용하는 파리 회로의 실제 AC
서킷 완주다. 이번 작업은 몸 감각 변화율과 영상 age를 계산하기 위한 시간 기준의 계측이다.
게임 입력·축 전송·actor 생성은 하지 않았다.

## 확인한 문제

네이티브 physics 표본은 하중·타이어 온도·회전 등을 주지만, 현재 읽는 prefix에는
시뮬레이션 시각이 없다. `BodyOrganEncoder`는 위치/온도/하중 변화율을 simulation time으로
계산하므로 패킷 ID나 PC 수신 시각을 simulation time인 것처럼 채워 넣으면 안 된다.
기존 `SampleTime` 계약과 누락 처리를 그대로 유지했다.

## 구현과 원본

`ac_native_clock.py`는 기존 `Local\acpmf_graphics` 매핑을 읽기 전용으로 연다.
고정한 AC Gym `sim_info.py`의 Windows UTF-16·4바이트 packing을 검사해156바이트만 읽는다.
이 범위는 `sessionTimeLeft`에서 끝나며 이동 거리·세계 좌표를 읽지 않는다.
랩 횟수·시간·세션 상태는 계측 정보이며 actor 입력이 아니다. 문자열 시간과 순위가 prefix에
포함되지만 순위는 결과 객체로 내보내지 않는다. 같은 스냅샷을 다시 받아도 새 프레임으로
바꾸지 않으며, 두 번 일치하는 복사는 원자성 보장이 아니다.

원본은 `assets/external/ac-native-memory-20261027/source.json`과 고정 blob
`a0f4c7d66f621d0ebc604ae437deba39829fdaf2`다. 외부 Python 모듈은 실행하지 않았다.

## 실제 결과

`runs/ac-native-clock-20261027-t32/`에 graphics 전/후와 physics 표본30쌍을 보존했다.
90개 원시 prefix의 SHA-256과 호스트 수신 순서를 다시 검증했다.

| 항목 | 측정 |
|---|---:|
| 서로 다른 graphics / physics 패킷 | 30 / 30 |
| 현재 시간 원시값 | 4,192,728 → 4,195,671 |
| PC 경과 시간 | 2.953초 |
| 밀리초 가정의 게임 경과 시간 | 2.943초 |
| 숫자값과 표시 문자열의 밀리초 환산 일치 | 60 / 60 |
| graphics 상태 | 모두 live |

밀리초 환산은 수집한 원시 문자열 `분:초:밀리초`를 해석해 숫자값과 직접 대조한 것이다.
따라서 이 구간의 단위 가정을 뒷받침하지만 physics/영상 노출의 정확한 시각을 주지는 않는다.
연습 메뉴에서도 `live`이므로 상태 하나를 실제 운전 진입이나 제어 허용 조건으로 쓰지 않는다.
이전 WGC 끝점 이미지는 정차·연습 메뉴였으며 이번 측정 동안 화면 전환을 요청하지 않았다.

1. 일시정지·재개·랩 전환·세션 재시작의 시간 변화를 측정한다. 뒤로 가거나 건너뛴 시각은
   명시적인 세션 처리 대상으로 두고 신경 상태를 임의로 초기화하지 않는다.
