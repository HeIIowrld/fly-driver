# 측면 경계 후보와 T4/T5 경보 문턱 · 2026-11-12

## 측면 영상에서 바깥 경계 고르기

같은 쪽의 이웃 경계를 참조하는 기존 측면 대비 조건에서, 바깥쪽 거리 가점·바깥 띠 밝기·이웃 허용 폭을 조합한 28개 설정을 비교했다. 이전에 보존한 Magione·Spa 영상 경계에서 누락된 단면에 한해 물리 메시로 횡오차를 채점했다. 기존 방식의 복원 건수 이상인 설정에서 서킷별 평균 횡오차가 가장 크게 늘어나는 비율을 최소화했다. 설정은 Silverstone과 Vallelunga를 읽기 전에 동결했다. [개발 평가와 고정 설정](../runs/vision-corner-side-transition-20261112-01/training.json)

개발 영상에서 선택된 설정은 기존 이웃 허용 폭 2m와 기존 영상 대비 점수였다. 이웃 허용 폭 확대나 바깥쪽 가점은 이 기준을 개선하지 못했다. 기존 조건은 Magione의 평가 대상에서 3,830점에 평균 0.94m, Spa에서 974점에 평균 1.75m였다. 추정치는 Magione에서 평균 0.19m 바깥쪽, Spa에서 0.33m 안쪽이었다. 기존 측면 대비와 새 실험의 Silverstone·Vallelunga 재생은 프레임별로 일치했다. [동일 재생](../runs/vision-corner-side-transition-20261112-01/result.json)

Silverstone에서 이전에 빠졌던 오른쪽 경계 10점에는 **현재 2m 이웃 제약을 통과하고 실제 위치와 0.66m 이내인 영상 후보가 각각 있었다.** 지도 위치는 이 사후 진단에서 후보의 가능한 오차를 재는 데만 사용했다. 반면 선택된 10점 중 1.25m 이내는 2점이었다. 같은 영상 안에서 도로 안쪽 전환과 바깥 경계 후보의 순위를 직접 비교하도록 학습하는 것이 다음 개선 지점이다. [10점의 후보 위치 검증](../runs/vision-corner-side-transition-20261112-01/ceiling-audit.json)

## 같은 코너 후보의 확인 문턱

Imola·Laguna Seca·Zandvoort·Mugello를 하나씩 제외해, 같은 후보의 경계 확인 점수와 T4/T5 결합 확인 점수를 모았다. 코너 내부 상태 차단도 각 제외 분할에서 다시 계산했다. 두 기존 판독의 개발 오경보 중 작은 값인 직선·범위 밖 77건과 코너 내부 67건을 각 조건의 공통 상한으로 사용했다. 두 확인 점수를 0·25·50·75·100%의 결합 점수 비중으로 비교하고, 조건별 문턱은 개발 영상에서만 정했다. T4/T5 결합 확인 점수에는 원래의 경계 정보도 들어간다. [교차 평가와 고정 문턱](../runs/vision-corner-paired-risk-20261112-01/training.json)

개발 영상에서 고른 설정은 T4/T5 결합 확인 점수를 그대로 사용하고 문턱을 0.92496→0.93257로 올리는 것이었다. 개발 교차 평가에서 기존 T4/T5의 전체 동시 적중은 14→13건, 직선·범위 밖 경보는 77→67건, 내부 경보는 73→65건이었다. 세 평가 영상에서는 후보 방향과 거리를 공통으로 고정했다.
