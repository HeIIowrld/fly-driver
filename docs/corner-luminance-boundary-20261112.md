# 오른쪽 경계의 색·밝기 진단과 판독 변화 · 2026-11-12

Silverstone 우회전 접근의 10–24m 오른쪽 기준 경계 주변에서 ±0.25–0.75m 위치를 실제 전방 카메라에 투영했다. 양쪽 픽셀 띠가 모두 화면 안에 들어온 곳 중 기존 검출값이 비어 있던 곳은 31개였다. 그곳의 밝기 차이 절댓값 중앙값은 Lab L값 2, 색차 중앙값은 0이었다. 밝기 차 18 이상은 4곳, 기존 색 조건을 만족한 곳은 1곳이었다. 기존 검출값이 있던 44곳도 지도 기준점 주변의 밝기 차 중앙값은 2였다. 기준점 주위 픽셀의 대비가 약하다는 관측이며, 지도 경계가 영상에서 사람이 선택할 경계와 어긋나는 정도는 이 검사에서 확정하지 않았다. 지도 투영은 원인 진단에만 사용했다.
