# 겹눈 영상 진단: 첫 저속 시각 조향 완료와 기관 포트 분리

기록: 2026-10-27, Asia/Seoul. **합성 겹눈 입력의 선형 진단 모델이 MuJoCo 개발4조건을 모두 완료했다. 같은 모델에서 영상만 제거하면 완료0/4다.** 실제 파리 회로나 Assetto Corsa의 완료가 아니다. 본래 목표인 시각·몸 감각·실제 회로의 AC1랩은 미완료다.

## 관측 정보와 기존 학습을 분리해서 확인했다

앞선 GRU는 [새 도로 장면과9,900개 시범으로도 완료0/4](steering-input-audit-20261027.md)였다. 영상 자체에 필요한 정보가 없는지, 학습이 그 정보를 활용하지 못하는지 구분하기 위해 정지 자세300개를 수집했다. 눈당16×24 방향과 수용각 적분은 앞선 실험과 같다.

코스 위치6개×횡위치5개×방향5개인150자세를 선형 ridge 모델의 학습에 사용했다. 다른 코스 위치6개의150자세는 정지 자세 시험으로 남겼다. 정규화는 학습 데이터로만 계산하고 ridge 강도는0.1로 고정했다. 위치·방향·교사 조향은 감독 label이며 actor tensor에는 넣지 않았다. 이 시험은 같은 합성 코스의 정지 자세 진단이며 새로운 서킷 일반화나 독립 최종 평가가 아니다.

| 정지 자세 시험 | 횡위치 RMSE | 방향 RMSE | 교사 조향 의도 RMSE |
|---|---:|---:|---:|
| 학습 label 평균만 출력 | 0.707 m | 0.123 rad | 0.804 |
| 겹눈 RGB 방향별 값의 선형 모델 | 0.064 m | 0.020 rad | 0.053 |
| 몸 감각만의 선형 모델 | 0.748 m | 0.126 rad | 0.845 |
| 영상+몸 감각의 선형 모델 | 0.064 m | 0.020 rad | 0.053 |

기존 GRU를 자세마다 상태0에서 한 번 추론한 조향 RMSE는 정상 입력0.772, 영상 제거0.804, 몸 제거0.779였다. 영상 정보는 존재하지만 이 진단에서는 기존 정책이 이를 정확한 조향으로 변환하지 못했다. 한 프레임 진단을 연속 이력 전체의 해석으로 확대하지 않는다.

## 선형 시각 모델을 실제 주행에 적용했다

위150개 학습 자세만으로 맞춘 조향 readout을 고정했다. 실제 주행 중에는 겹눈 영상과 validity만 읽고, 교사·위치·방향 정답과 몸 감각을 조향 계산에 사용하지 않았다. 같은 고정 저속1.5m/s 의도와 기존4개 개발 조건에서 새 노출25Hz·판단100Hz로 연속 실행했다. 속도·제동을 자율 학습한 모델이 아니다.

| 조건 | 완료 | 판단 단계 | 횡오차 RMS |
|---|---|---:|---:|
| 기본 시작 | 예 | 6,703 | 0.018 m |
| 중간 시작 | 예 | 4,490 | 0.019 m |
| 왼쪽 자세 오차 | 예 | 6,714 | 0.102 m |
| 오른쪽 자세 오차 | 예 | 6,711 | 0.104 m |

같은 학습 행·계수·정규화를 유지하고 주행 중 영상 값만0으로 바꾼 대조에서는4조건 모두 이탈했다. 전진 거리는 각각10.19/12.38/7.44/13.08m였다. 따라서 이 진단 모델의 해당 조건에서는 영상 입력이 완료에 기여한다. GRU와는 모델·학습 자료가 달라 특정 구조 하나의 인과적 우월성으로 비교하지 않는다.

[정상 영상 주행](../runs/retinal-diagnostic-20261027/runs/retinal-ridge-t6/evaluation.json), [영상 제거 대조](../runs/retinal-diagnostic-20261027/runs/retinal-ridge-missing-t6/evaluation.json), [고정된 선형 모델](../runs/retinal-diagnostic-20261027/runs/retinal-ridge-t6/ridge-model.npz). float32 특성의 행렬 곱을 작은 readout으로 재결합할 때 정지 시험 예측과 최대 약1.45×10⁻⁵ 차이가 생겼으며, 허용오차10⁻⁴ 안임을 확인하고 실제 값을 manifest에 기록했다. 정상/영상 제거 모델의 배열도 별도로 대조한다.

이는 A2의 유용한 중간 증거다. 하나의 결정론적 시각 진단 모델·하나의 합성 코스·4개 개발 조건이며, 계획의3학습 시드×10조건 관문이나 실제 회로 운전 관문을 통과했다고 표시하지 않는다.

## 몸 감각을 복사하는 지름길도 수치로 확인했다

교사 시범9,900개에서 기관 위치 집단의 Gaussian 값을 역변환해 실제 측정 조향각을 복원하고 Ackermann 곡률을 계산했다. 학습·경로 정답 없이 측정 조향만 복사한 조향 의도의 RMSE는 전체0.096, 각 시퀀스의 첫50단계를 제외하면0.0097, 교사 행동 절댓값0.1 이하에서는0.0033이었다. 반면 첫50단계에서는0.450이었다.

이 결과는 많은 안정 주행 표본에서 몸 감각 복사만으로 손실을 작게 만들 수 있음을 보인다. 기존 GRU가 오직 이 복사만 한다는 증명은 아니다. 초기 복귀와 큰 교정 행동, 영상의 위치·방향 단서에 별도 감독과 평가가 필요하다. [복사 진단과 표본 수](../runs/retinal-diagnostic-20261027/runs/steering-copy-final-t6/summary.json).

## 실제 회로용 모달리티 포트를 분리했다

`ModalityPortAdapter`는 graph의 input ID를 중복 없이 모두 분담하도록 검사한다. 시각 특징은 시각/CX 절단 입력에만, 선언한 기관 feature는 해당 기관 집단에만 들어간다. 회전·위치 feature의 인덱스는 별도 계약이며 실제 수용체 튜닝을 측정한 것이 아니다. `SparseCircuit.step_with_drive`는 internal/output 뉴런으로의 외부 직접 주입을 거절한다. 수치 상태는 단계 사이 유지한다.

실제927뉴런·11,526연결 후보에서 각 인공 자극을100단계씩 실행했다.

| 인공 자극 | 직접 구동된 input 뉴런 | 출력에 처음 반응한 갱신 |
|---|---:|---:|
| 시각 특징만 | PFL 경계36개 | 2번째 |
| 회전 feature만 | haltere 주석201개 | 3번째 |
| 위치/운동 feature만 | chordotonal 주석425개 | 3번째 |
| 모두 invalid, 초기 상태0 | 0개 | 반응 없음 |

선택 feature에1을 넣고 공학적 adapter gain을 고정한 단위 자극이다. 실제 움직임·생리 반응·조향 방향의 검증이 아니다. 시각과 몸의 입력이 실제 경로를 거쳐 출력에 닿는다는 구조·코드 검증이며 아직 위 선형 주행기와 이 회로를 결합해 운전하지 않았다. 미관측 입력 때문에 기존 수치 상태를 매 단계0으로 지우지 않는다.

## 다음 구현

검증된 시각 readout을 공학적 절단 경계 어댑터로 고정한 뒤, 분리된 시각/기관 포트와 실제 회로의 출력으로만 조향하는 후보를 만든다. 시각 readout의 차량 조작 직접 연결은 회로 모델의 출력 경로로 사용하지 않는다. 실제 회로가 지나가는지, 기관을 제거하면 무엇이 달라지는지, 재배선 대조와 어떤 차이가 있는지 확인한다. 상위 시각/CX 회로·기관 튜닝·출력 부호·AC 연결과1랩은 계속 별도 관문으로 남는다.
