# 측면 경계 후보 순위와 네 카메라 기여 · 2026-11-12

## 실제 경계와 같은 단면의 오답 후보

기존 측면 카메라의 영상 대비와 이웃 경계 제약을 통과한 후보들을 같은 단면 안에서 비교했다. Magione과 Spa에서 경계가 빠진 단면만 골라 물리 메시에서 0.6m 이내인 후보들의 점수를 높였다. 대비 강도와 후보 띠의 폭·위치, 이웃 경계까지의 거리로 학습한 조건과, 바깥쪽과 안쪽의 Lab 밝기·색차를 여러 높이에서 추가한 조건을 비교했다. 후보 풀이 같았고 기존에 관측된 경계는 보존했다. 두 개발 서킷을 번갈아 제외해 어느 설정에서 서킷별 오차 악화가 가장 작았는지 비교했다. ## T4/T5 확인 점수에서 각 카메라가 한 일

운동 시각 추출기는 전후좌우 영상의 T4/T5 반응을 각각 유지한다. 반사 입력에서는 좌우 카메라의 자리가 바뀐다. 원본·반사 특징을 결합한 뒤 시간 변화, 공간 구역, 운동 방향의 성분이 함께 표준화되고 주성분을 거쳐 확인 점수에 들어간다. 모델에 카메라별 단일 가중치는 없으며, 후보의 방향과 실제 특징값에 따라 영향이 달라진다.

같은 코너 후보, 경계 특징과 문턱을 고정했다. 선택한 실제 카메라의 원본 특징과 그 카메라에서 유래한 반사 특징을 개발 서킷 평균으로 함께 대체했다. 네 카메라의 16개 조합에서 확인 점수의 로그 오즈 변화를 계산해 각 카메라의 Shapley 기여를 구했다. 모든 영상을 사용한 결과는 기존 판독과 일치했고, 네 기여의 합은 전체 영상과 전부 평균으로 대체한 경우의 로그 오즈 차이와 일치했다. 아래 값은 후보가 있고 운동 시각 특징을 사용할 수 있는 프레임의 **절댓값 평균**이다. 카메라 평균 대체는 기존 특징 위에서 수행한 진단이다. 실제 카메라가 끊겼을 때는 입력 가용성과 시간 이력이 달라진다. 평가에는 이전에 사용한 녹화를 썼다. 현재 결과를 바탕으로 카메라의 입력을 차단하거나 고정 판독기에 새 가중치를 적용하지 않았다.
