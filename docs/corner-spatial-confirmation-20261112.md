# 코너 후보 시작점 전후의 좌우 경계 비교 · 2026-11-12

복구 경계 후보의 시작 거리 앞 최대 10m와 뒤 12m를 양쪽 경계에서 각각 비교했다. 한쪽에 점 여섯 개 이상, 시작 전후 각각 두 개 이상이 있을 때 직선, 처음부터 이어진 이차 곡선, 후보 거리 이후 굽기 시작하는 곡선을 적합했다. 시작점을 4m씩 앞뒤로 옮긴 경우도 비교했다. 새로 복구한 점의 적합 가중치는 직접 관측의 0.35배로 두고, 큰 잔차의 영향을 제한했다. 양쪽 지지점 개수와 적합 오차 차이를 기존 확인기에 추가했다. 방향을 반사한 합성 코너에서 결과가 동일했고, 직선과 시작 전 관측 부족 조건도 확인했다. [학습과 재생 코드](../runs/vision-corner-spatial-confirmation-20261112-01/confirm_spatial.py)

Imola·Laguna Seca·Zandvoort·Mugello에서 평가 서킷을 뺀 새 확인기를 학습했다. 안쪽 학습 후보에 사용한 경계 선택기에서도 해당 서킷과 바깥 검증 서킷을 제외했다. 기존 코너 판독기는 네 개발 서킷에서 학습한 동결본이다. 동일 후보 1,091개와 동일 추가 오류 상한에서 이전 확인기는 경계 기반 2건과 T4/T5 1건을 추가로 맞혔다. 새 형상 확인기는 두 방식 모두 개발 상한 내 추가 적중이 없었다. 시험 녹화는 문턱을 고정한 뒤 평가했다. 이전 확인기의 프레임별 결과는 앞선 실행과 일치했다. [동결 설정](../runs/vision-corner-spatial-confirmation-20261112-01/training.json) · [재생 검증](../runs/vision-corner-spatial-confirmation-20261112-01/verification.json)

Silverstone 488번과 621번은 양쪽 경계에서 우회전 방향의 굽음이 나왔다. 안쪽 경계는 14m 시작 모형보다 계속 굽는 모형의 적합 손실이 각각 0.027·0.028만큼 낮았다. 바깥 경계에서는 14m 시작 모형이 계속 굽는 모형보다 0.008·0.003만큼 낮았다. 두 프레임의 방향 근거는 일치했지만 시작 위치 근거는 경계마다 달랐다. 새 형상 입력으로 T4/T5 점수는 488번 0.716→0.906, 621번 0.893→0.968이 됐다. 점수는 새로 학습한 모델의 출력이며 두 모델의 절대 신뢰도가 같은 척도라고 해석할 수 없다. 개발 상한을 만족한 설정에서는 두 프레임 모두 보류됐다. [두 프레임의 형상](../runs/vision-corner-spatial-confirmation-20261112-01/silverstone-profiles.json) · [프레임별 확인 점수](../runs/vision-corner-spatial-confirmation-20261112-01/ks_silverstone1967-candidates.jsonl)

새 확인기에서는 Silverstone 우회전 적중이 두 방식 모두 2/13이었고, T4/T5를 추가하면 직선·범위 밖 경보 14→10건, 내부 경보 5→7건이었다. Vallelunga와 Monza에서도 형상 확인기가 새 경보를 추가하지 않았다. 0.65 조건의 복구 경계에는 Silverstone 우회전 접근에서 오른쪽 점 하나가 오차 0.97m로 복구된 상태가 포함됐다. 기존 경보와 관측점을 보존했다. 이 형상 확인기는 고정 판독기에 적용하지 않았다.
