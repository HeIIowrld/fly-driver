# flyvis 운동 시각 부품 반응 — 2026-10-29

자동차를 초파리의 가상 몸으로 제어하는 연구의 M1 부품 검사다.
사용자 대전제는 [프로젝트 대전제](PROJECT_CHARTER.md)를 따른다.

## 실제 수행과 결론

저자 공개 모델 `flow/0000/000`을 결과 확인 전에 정한 그대로 유지했다.
가중치·연결·동역학을 바꾸지 않고 GPU에서 깜박임 4조건 및
이동 경계 12방향 × 6속도 × 2대비 = 144조건을 실행했다.
실제 자극 구간의 전체 노드 반응은 유한했다. 가중치 변경·최적화·차량 조작은 0회였다.
실행망은 45,669노드/1,513,231연결/721망막 입력이다.

저자 시간 좌표와 분석 함수를 직접 사용했다. 설치된 분석 파일과 고정 소스의 SHA256도 대조했다.
깜박임 지수는 독립 NumPy 계산과 오차 0, 선호 방향은 독립 복소 벡터 합과 대조했다.
저자 방향 마스크가 실제 유효 반응 구간 안에 있는지도 검사했다.

T4는 밝은 경계, T5는 어두운 경계 선호를 기대했다.
T4d는 깜박임뿐 아니라 여섯 속도의 이동 경계에서도 반대 대비를 선호했다.
T4d의 기대 대비 DSI도 낮으므로, 방향 각도만 가까운 것으로 통과시키지 않는다.
단일 공개 모델의 결과이며 모든 flyvis 모델이나 생체 전체의 성질로 일반화하지 않는다.
대비 지수는 각 대비 최대 반응의 차이/합인 공학적 요약이다.
DSI·선호 방향·깜박임 지수는 저자 함수의 정의다.
아직 생리 기능 검증 전체·차량 통합·주행·랩타임 목표는 미완료다.

## 실패를 포함한 기록

- `t1017`: 첫 예비 분석. `t1020`은 소스 해시·프로토콜 검사를 더한 예비 분석이다.
- `t1018`: 확장 시험이 두 번째 조건에서 비정상 값 검사로 중단됐다.
  저자 데이터셋이 속도별 길이를 맞추려고 붙인 후행 all-NaN 저장 패딩이 원인이었다.
  이것을 신경 동역학 발산의 증거로 해석하지 않는다.
- `t1019`: 원래 패딩과 시간축을 보존하고, 실제 자극 구간만 유한값 조건으로 검사했다.
  중간 결측이나 혼합 NaN 프레임은 거부한다. 원본 회로는 패딩까지 그대로 실행했다.
  전역 `finite_responses=false`, `finite_valid_responses=true`를 구분해 기록했다.
  144조건 실행 시간 합계 138.24초, GPU tensor 최대 2,333,507,072 bytes였다.
- `t1021`: 144조건의 속도별 분석과 그림. 원본 응답/설정/분석 소스 해시를 보존했다.
- 관련 검사 13개와 Ruff가 통과했다. 이 검사는 입력/증거 처리의 검증이며 생리 기능 검증이 아니다.

### 사전 등록 — FlyVis 중심 반응의 보류 속도 방향 판독 (2026-10-31)
기존 12방향×6속도×2대비 모델 결과 중 중심 T4a–d/T5a–d 8개만 사용한다. 자극 전 1초 평균 대비 자극 중 최대값을 각 세포의 특징으로 정하고, 대비별로 다른 다섯 속도에서 cos/sin을 ridge α=1로 학습하여 보류 속도의 12방향을 판독한다. 표준화는 훈련 fold만 사용하며 각 fold의 원형 오차와 ±15°·90° 이내 수를 모두 기록한다. 기존 데이터와 반응 결과를 이미 확인한 뒤 설계한 탐색 분석이며, 속도 외 다른 모델·대비·형태·공간 패턴에 대한 독립 검증이 아니다. 판독기는 공학적 진단이며 기존 비행 회로, 실제 운전 또는 생리 기여로 부르지 않는다. T4d 대비 실패를 유지한다.
