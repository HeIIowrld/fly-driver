# 조향·가감속 학습 경로 수정과24회 공동 학습

2026-10-29, Asia/Seoul. [대전제](PROJECT_CHARTER.md)는 유지한다.
이번에는 모델 경로를 실제로 추가해 GPU 공동 학습과 개발 비교까지 완료했다.
**개발 통과 조건은 false이며 게임에 배치하지 않는다.**

## 구조에서 확인한 누락

기존 v6는`scene_command`만 학습 가능하고, 그 출력은4개 DNa04/05 조향 포트에만 연결됐다.
DNg02 쪽 가감속 입력과 몸/운동 readout은 고정이었다. 조향의 간접적인 power 영향은 있지만
가감속 명령을 직접 개선하는 새 학습 경로는 없었다.
비행 모델의16개 몸 감각에는 명시적 차량 속도/바퀴 회전이 없고, 기능적 시각 자기운동6채널은 cache에서 zero/invalid다.
영상에 속도 단서가 전혀 없다는 뜻은 아니며, 검증된 명시적 속도 되먹임이 빠져 있었다는 뜻이다.

t1431은 고정 신경망의 명령 전달부터 검사했다. TRAIN 몸 중앙값/고정 장면 평균/30km/h 목표라는 한 조건에서
625개 조향 current 조합을2초 가했을 때 조향 출력은−0.750~+0.824로 변했다.
조향 current의 분석 기울기와 수치 차분은 최대0.000321 차이로 일치했다.
같은 조건의 forward 출력은0.073~0.125였고, common power 포트를 별도로 바꾼85조건에서는
−0.576~+0.9997로 넓어졌다. 이는 해당 유한 그리드의 관측 범위이며 전체 상태의 도달 가능성 상한이 아니다.
신경 그래프 자체의 기울기 단절을 원인으로 단정할 근거는 없었다.

## 새 v7 실험 모델

- 기존 시각·운동 가중치와9,728뉴런/1,311,145연결의 운동 그래프, 몸 경계·readout을 고정했다.
- 원래4시점×9채널×16공간 요약에 공유9→8 비선형 patch 변환을 적용하고,
  학습한 상위 명령으로4개 조향 포트와 common DNg02 power current를 조절한다.
  새 상위 시각 경계는 **미측정 상위 뇌를 줄여 표현한 공학적 근사**다. 실측 고위 뇌 연결로 부르지 않는다.
- 새 가상 몸 계약은 기존16개 값/마스크를 유지하고, native speedKmh/3.6과 바퀴 각속도4개를 추가한21개 입력이다.
  차량용 몸 감각 대용값이며 실제 파리 감각기관의 생리 튜닝을 뜻하지 않는다.
  unregistered 선형 가속·roll/pitch 각속도 마스크는 그대로 false다. 위치·절대 heading·교사 조작은 actor에 넣지 않았다.
- 새 turn 명령 경계는 영상/목표/속도 크기만 받는다. 현재 yaw나 바퀴 간 회전 차이로
  조향 정답을 곧바로 대용하지 못하게 했다. 기존 몸 반사 및 power 문맥에는 원래 몸 감각이 남는다.
  따라서 전체 모델에 몸 신호의 다른 조향 영향이 없다는 주장은 하지 않는다.
- 기존 current에 bounded log-odds 조절을 적용한다. 초기 delta0에서는 기존 drive가 정확히 같고,
  새 제어가 운동 뉴런을 건너뛰어 액추에이터로 가는 잔차 경로는 없다.

관련11검사와 t1435 실제 신경 그래프 검증을 통과했다. 실제 원본 한 행을 고정한 구성요소 시험에서
초기 drive 동일, 기존16개 float32 cache/마스크 동일, turn/power 최종층 기울기 모두 유한·비영이었다.
이 단일 고정 입력 검증을 실제 주행 또는 전체 이력 학습으로 확대하지 않는다.
prototype t1433은 turn 분기에 바퀴 정보도 있던 이전 구조라 최종 학습 초기값으로 사용하지 않았다.
t1432는 float64 몸 비율을 float32 cache와 직접 비교한 검사 오류로 실패했다.
원래 cache 변환을 명시한 후 exact 비교했으며 tolerance를 완화하거나 원자료를 바꾸지 않았다.

## 실제 공동 학습

t1434는 기존 v2 train6/개발2의 원래8이력5,932관측에 명시적 몸21만 추가했다.
기존 장면·정답·mask·목표·시각·16개 몸 값은 보존했다. 평가 역할 자료는 열지 않았다.
같은 자료로 비교해 구조 변경 효과와 단순 새 자료 추가 효과를 섞지 않았다.

t1437은 RX9070XT에서 **고정24epoch/24회 승인된 업데이트**를 완료했다.
loss는0.675491→0.665344였다. 조향은 좌/우/중립 동등 비용, forward는 원래 유효 표적별 비용을 반씩 합친
bounded logistic loss다. 모든 원래 시각과 이전 입력 hold를 사용하고64관측마다 미분만 detach했다.
운동 상태를 중간에 reset하거나 정답을 이동하지 않았다. checkpoint는 마지막24회로 고정했다.
개발 자료로 fitting/정규화/수락·중단 판단을 하지 않았다.
기존 파라미터는 매 update 불변 검사를 통과했다. source aid-absence 자격은 승격하지 않았다.
실제 제동 표적은0이므로 longitudinal 학습 범위는 throttle/coast이며 제동 학습을 주장할 수 없다.

## 개발 결과

기존에 여러 번 본 개발2구간이며 새 blind 평가가 아니다. 오차는 정규화된 의도 좌표의 RMSE다.

| 구간 | 조향 기존v6 | 조향 v7 | 조향 TRAIN평균 / 0 | forward 기존v6 | forward v7 | forward TRAIN평균 |
|---|---:|---:|---:|---:|---:|---:|
| 02 | 0.070537 | 0.068259 | 0.055131 / 0.052572 | 0.183794 | 0.133740 | 0.159943 |
| 07 | 0.102438 | 0.093337 | 0.096665 / 0.093186 | 0.190467 | 0.174545 | 0.162137 |

조향은 기존보다 줄었지만 **두 구간 모두0 조향 기준을 이기지 못했다.**
forward는 전체 오차가 개선됐지만 한 구간에서는 평균 기준보다 나빴다.
시각 전체/운동 정보 제거는 전체 조향 오차를 조금 키웠으나,
**3초 이후에는 운동 정보 제거가 두 구간 모두 오히려 좋아졌다.**
따라서 안정된 주행에서 운동 시각이 유용하게 쓰인다는 검증은 아직 없다.
입력 정보를 고정 TRAIN 평균으로 치환한 비교이며 실제 뉴런 제거 실험은 아니다.

정속 쪽 forward 회귀가 더 큰 문제다.3초 이후 RMSE는 기존0.011026/0.016736에서
새0.105075/0.102474로 나빠졌다.
t1440은 clipping 없이 원래 예측을 재검사했다. 개발07의 유효 forward 표적578개 중
253개에서−0.01 미만을 예측했고,3초 이후 유효517개 중223개가 이 경우다.
실제 제동 정답은0이다. 초기 unlabelled 행과 구분한 수치이며, 잘못된 제동 예측을 숨기지 않았다.
일부 개선만 골라 학습 성공·학생 운전 가능으로 승격하지 않는다.

## 다음 모델 작업

가감속 학습 경로/속도 관측 누락은 이번에 명시적으로 수정했다.
그러나 조향 일반화와 정속 제어는 여전히 미통과다. 학습 epoch나 자료량만 늘리는 것으로 해결됐다고 보지 않는다.

1. 영상에서 차량 기준 앞길 방향/곡률·preview를 읽는 중간 학습 목표를 분리한다.
   원시 camera pose/교사 미래 궤적은 **교사 표적 생성에만** 쓸 수 있고 actor 입력으로 넣지 않는다.
   기존4×4 요약의 정보 손실과 photometric 초기 과도도 함께 검사한다.
2. 실제 가속/정속/감속·제동과 서로 다른 속도 목표를 포함하는 자료로 power 경로를 검증한다.
   현재30km/h 단일 목표/제동0 조건으로 목표 속도 일반화나 제동을 판정하지 않는다.
3. steering/power의 운동 readout 결합과 명령 조정을 분리해 검사한다.
   coast 오차·잘못된 제동을 줄였는지 원래 전체/3초 이후 이력에서 확인한다.
4. 이후에만 새 시각/몸 통합·빠른 몸 경로·실제 학생 주행을 재검증한다.
   타이어/셋업 적응·유효 완주·빠른 레이싱 라인·랩타임은 계속 필요하다.

v5 교사 수집은8lease5,911관측 완료 뒤 index8 개발이70관측/wait9회에서 카메라 신선도로 실패했다.
read-only 감사는 완료 train/개발7구간만 처리하고 종료했다. 이번 모델 작업에서 수집을 재시작하지 않았다.
이 실패와 이전 성공/실패도 보존하며 새로운 모델 학습 성공으로 바꾸어 부르지 않는다.

실행 소스는 snapshot1436, 평가 소스는1438이다. 원본 checkpoint·예측·실패·새 몸 계약·검증은
[보존 영수증](../runs/flight-embodied-command-learning-20261029-t1441)에 묶는다.
현재 알려진 새 학습/평가/수집 작업은 모두 terminal이며 파리 actor 배치는0이다.
