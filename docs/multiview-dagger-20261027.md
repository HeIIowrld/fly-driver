# 학생이 벗어난 상태의 복귀 학습

갱신: 2026-10-27, Asia/Seoul. 최종 목표는 실제 AC의 비전 기반 서킷 주행이다.
이번 MuJoCo 단계는 [전체 모형 도로에서18.55m 이탈한 실패](ac-native-physics-20261027.md)를
개선하기 위한 수집·학습이며, AC 조향·페달 성공으로 표시하지 않는다.

## 수집과 입력 경계

수집 당시 학생 체크포인트는 `a9baddb6413c77948f292a2882ff5ad098fb3990aa606b36165b9259f3aa2262`다.
처음에는 학생만 조향해355결정 뒤 이탈한 상태까지 기록했다. 이후 x=3,15,27,39,51,63,75,87의
출발점에서 측방±0.4/0.6m·방향±4/6도 조건을 만들고, 교사/학생을 확률0.5로 골라 최대256결정씩
조향했다. 한 혼합 구간도154결정에 이탈했으며 이 실패를 제외하지 않고 보존했다.

모든 관측에서 정답은 교사가 따로 계산한다. 학생이 실제 실행한 조향도 교사 정답으로 바꾸어
라벨링하지만, 학생 추론 입력에는 정답·경로·진행률·세계 위치를 넣지 않는다. 실행 주체·실행값·
교사 정답은 서로 다른 배열로 저장한다. 교사가 실행할 때도 학생의 수치 신경 상태는 진행시켜
다음 결정의 이력을 유지한다. 영상은 네 독립 시점으로 기록하며, 기존 시각 정규화 통계와 몸 감각
계약은 유지한다.

새 기록2,269결정에 기존 교사512결정을 합쳐 **13에피소드·2,781결정**을 봉인했다.
병합 전에 감각 보정·행동 의미·결정 주기·brain tick 수·원시 파일 해시가 같은지 확인한다.
입력 파일을 변경하지 않고 새 사본을 만들며 에피소드 ID 충돌도 피한다.

## 재학습과 평가

- 학습률0.0001·6epoch,32결정 TBPTT, 시각 어댑터만 학습한다.
- 시각 평균/분산과 조향 이득은 기존 체크포인트 그대로 두고 다시 보정하지 않는다.
- 같은 길이의 완전한 에피소드들을 최대4개씩 묶는다. 시퀀스를 자르거나 가짜 새 에피소드로
  만들지 않으며, 각 에피소드에서 수치 신경 상태는 detach 뒤에도 이어진다.
- 전체 학습 재생 RMSE로 체크포인트를 선택한다. 주행 평가를 체크포인트 선택에 쓰지 않는다.
- 평가1은 이탈했던 기본100m 도로의 개발 재시험이다. 평가2는 학습에 없는 주기85·진폭2.5의
  새 곡선이다. 각 최대2,000결정이며 정상·시각 제거·교사 기준값을 기록한다.
- 행동은1.5m/s 고정 속도에서의 곡률 의도다. 가속·제동 정답은 없고 손실에서 제외한다.

설정은 `configs/multiview-dagger-pilot.json`과 `configs/multiview-dagger-fast-pilot.json`이다.
수집/학습/평가는 각각 유한 예산과 고유 실행 폴더를 사용한다. 실제 주행 결과가 나올 때까지
데이터가 늘었다는 이유로 완주나 복귀 성공을 주장하지 않는다.

## 같은 고정 연결을 빠르게 계산

고정 희소 행렬의 정방향 CSR과 전치 CSR을 한 번 준비해 상태 기울기에 사용하도록
`cached_csr_cpu` 선택 모드를 추가했다. 측정 연결·가중치·부호·시간상수·신경 상태 업데이트는
바꾸지 않는다. 기존 COO 방식은 기본값으로 유지했다. 캐시는 체크포인트에 저장하지 않으며,
행렬 교체·in-place 변경·체크포인트 재로딩 때 갱신한다. CPU 고정 연결에만 허용한다.

실제6557뉴런 행렬의32tick 작은 실험에서 상태 오차는최대7.45×10⁻⁹, 기울기 오차는
1.86×10⁻⁹였고 희소 연산은약14~19배 빨랐다. 병행 학습 중의 국소 실험으로, 전체 학습 시간이나
파리 구조의 우위를 뜻하지 않는다. 전체 학습 첫 epoch는 COO204.91초·CSR42.64초였고,
RMSE0.3319014914와0.3319014906이었다. 둘째 epoch의 RMSE 차이도약1.28×10⁻⁹였다.

COO 원래 실행을 유지한 채, 같은 봉인 데이터·시드·최적화 조건으로 CSR 실행을 별도 시작했다.
두 실행 결과를 보존하며 숫자와 주행 결과를 따로 비교한다. PyTorch CSR은 실험적 지원 경로라는
라이브러리 경고가 있으므로 CPU에서 명시적으로 선택하고 검사한다. 일반 재귀 모델도 받을 수
있는 구현 최적화이며 생물학적 회로의 계산 효율 우위라고 주장하지 않는다.

## 실제 게임 제어 준비

센서는 실제 AC에서 읽었지만 영상 동기·축/단위·조향/페달 적용은 아직 검증 전이다.
[vJoy 설치](ac-control-prerequisites-20261027.md)는 사용자 승인·설치 뒤 완료했다.
공식 SDK와 동일한 DLL 해시·실제 장치 Free 상태·축 범위를 조회했다. 장치 획득/축 전송은0건이다.
정규화 조향/페달과 HID 축/반전을 명시하고, 드라이버 수락과 실제 게임 적용값을 구분한다.
원자적인 전체 조이스틱 상태 요청을 보내는 인터페이스지만, 게임 적용의 원자성은 미검증이다.
실제 호출 전에는 설치·장치·게임 축 매핑을 확인해야 하며, 이 MuJoCo 곡률 정책을 그대로
실제 AC 조향각 정책으로 취급하지 않는다.

여전히 모형 도로 두 조건·조건당 한 시드다. 닫힌 서킷 랩·독립 다중 차량·실제 AC·자율
