# Laguna Seca 기존 원본의 고정 후보 재진단 · 2026-11-11

Zandvoort 세션은 열리지 않았고, CSP 상태는 Laguna Seca 일시정지였다. 이미 독립 평가에 사용한 Laguna Seca 원본 1,000개를 보존한 뒤 같은 FlyVis 특징과 채점 자료로 최신 고정 후보를 재생했다. 이번 실행은 이미 본 서킷의 실패 원인 진단이다. Zandvoort 프로토콜의 가중치·임계값·평가 기준은 유지했다.

| 지표 | 원래 판독 | 겹눈·경계·경보 종료 후보 |
| --- | ---: | ---: |
| 좌회전 | 4/38 | 1/38 |
| 우회전 | 0/25 | 0/25 |
| 방향·거리 ±5m | 4 | 1 |
| 직선·범위 밖 오경보 | 12 | 6 |
| 미출력 | 0 | 0 |
| 안정 예고가 나온 물리 코너 | 1 | 0 |

후보에는 보류 15개가 포함된다. 두 판독이 함께 맞힌 연속 프레임 쌍이 없어 공통 거리 변화 오차를 계산할 수 없었다. 근거리 경보 종료는 이 영상에서 적용된 프레임이 없었다. [전체 캡처 채점](../runs/vision-laguna-warning-end-diagnostic-20261111-01/warning-end/result.json)

## 실패 단계

4–20m 접근 63개 가운데 경계 관측이 부족한 프레임은 25개, 충분한 경계로 계산했지만 굽음 기준에 미달한 프레임은 33개였다. 방향이 맞는 경계 후보는 좌 3개, 우 2개였다. 5개 모두 같은 시작 위치가 로컬 이동량 0.75m 이상에 걸쳐 확인되지는 않았다. 따라서 겹눈 유무 점수와 거리 단계 전에 새 접근 경보가 모두 걸러졌다. [프레임별 단계](../runs/vision-laguna-warning-end-diagnostic-20261111-01/failure-stages.json)

Laguna의 같은 코너 접근에서 연속 캡처 사이 실제 시작 거리 감소 중앙값은 좌 4.25m·우 4.53m였다. 개발 자료인 Magione에서는 좌 0.51m·우 0.40m였다. 캡처 시각 차 중앙값은 각각 약 100ms와 65ms였고, Laguna의 접근 연속 구간 21개 중 5개는 단일 프레임이었다. 영상 사이 이동량 차이가 크므로 두 서킷에서 연속 확인이 같은 관측 밀도를 갖는다고 볼 수 없다. 이 분석만으로 샘플링, 주행 속도, 경계 외형 중 어느 요인이 실패를 일으켰는지는 확정할 수 없다.
