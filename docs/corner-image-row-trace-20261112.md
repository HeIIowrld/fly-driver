# 영상에서 이은 경계와 차량 좌표 변환 · 2026-11-12

Silverstone 1967과 Spa의 전후좌우 저장 영상 각각 1,200묶음을 재생했다. 기존 가까운 경계 단면을 전방 영상의 시작점으로 옮긴 뒤, 같은 영상에서 대비가 이어지는 픽셀 경로를 구했다. 위쪽 행을 따라갈 때 급격한 횡이동에는 비용을 주고, 연속 3행에서 대비가 약하면 더 먼 쪽을 보류했다. 지지가 없는 행을 건너뛰어 보간하지 않았다. 그 경로에서 고정 카메라의 차체 평면 투영으로 16–34m 단면의 좌우 위치를 읽었다. 기존 경계가 비었을 때만 채우는 조건과 추적이 지지한 곳을 교체하는 조건을 각각 실행했다. 이는 영상의 대비를 잇는 실험으로, 사람이 표시한 경계로 새 모델을 학습하는 실험은 다음 단계다. ## 영상 위치와 거리 변환

Silverstone 620번의 먼 경계를 기존 후보와 같은 단면에서 대조했다. 영상에 표시한 표면 전환까지의 픽셀 거리 중앙값은 오른쪽 0.73→0.63px, 왼쪽 1.45→0.39px였다. 가까워진 선을 차체 평면으로 옮겼을 때는 기존의 좌 17m 제안이 보류로 바뀌었다. 같은 추적 경로를 지도 투영의 세로 위치에서만 다시 읽은 진단은 우 7m를 제안했다. 실제 시작 18.77m와는 11.77m 차이다. 지도는 이 개입과 오차 산출에만 쓰였다.

622번에서 추적은 왼쪽 경계를 교체해 후보를 좌 16m에서 우 13m로 바꿨다. 실제는 우 10.17m였다. 경계 확인에서는 이 새 후보가 보류였고, T4/T5 결합에는 13.59m의 기존 유지 경보가 이미 있었다. 따라서 이 프레임의 최종 우회전 적중은 늘지 않았다. 오른쪽은 실제 접근 13장 중 2장에서만 16–34m의 경계를 추적했다. 추적 교체를 적용해도 좌우 쌍 단면 수는 106개로 같았다. 방향과 시작 거리 ±5m를 모두 맞힌 경우를 동시 적중으로 셌다. 오경보는 직선·범위 밖 경보다. 34m 대조 조건의 프레임별 후보와 최종 경보는 두 영상에서 이전 결과와 일치했다. 두 모델의 기존 경보가 없던 프레임에서 같은 추적 교체 후보를 제시하면, Spa의 T4/T5만 확인한 동시 적중은 3장, 직선·범위 밖 경보는 76장이었다. 경계 확인에만 나온 오경보는 19장과 방향 오판은 6장이었다. Silverstone에서 T4/T5만 확인한 동시 적중은 0장이었다. 확인은 같은 후보를 받아들이거나 보류하므로 잘못된 거리나 방향을 직접 바꾸지 못한다.


## 대각선 대비와 시작점 확인

기본 추적에서 Silverstone 807–809번은 14m 이내에 전방 화면에서 시작할 오른쪽 단면을 찾지 못했다. 시작점을 투영할 수 있던 다른 프레임에서도 바로 주변의 픽셀 대비가 약하거나 먼 쪽으로 이어지지 않는 경우가 있었다. 추가 조건에서는 시작 후보를 22m까지 확인하고, 전방 영상에서 실제 국소 대비가 있는 위치만 시작점으로 사용했다. 수평과 위쪽 대각선 대비를 함께 읽고 먼 쪽에 최소 네 행의 지지를 요구했다. 지도와 절대 위치는 추적과 확인에서 사용하지 않았다. Silverstone 우회전 접근 13장에서 직접 추적해 읽은 오른쪽 단면이 20→128개가 됐다. 기존 후보와 좌우를 결합한 쌍 단면은 106→115개였다. 두 방식과 지도 행 대조가 모두 위치를 낸 공통 오른쪽 116개 단면에서 지도 경계까지의 횡오차 중앙값은 기존 1.30m, 추적 후 1.33m, 같은 추적을 지도 행에서 읽은 진단 1.85m였다. 더 많은 지지점이 생겼고, 이 비교에서는 오른쪽의 위치 오차가 줄지 않았다. 왼쪽 공통 106개 단면은 1.22→0.72m였다.

교체 조건에서 Silverstone 621번은 좌 14m에서 우 14m, 622번은 좌 16m에서 우 13m로 바뀌었다. 두 프레임 모두 기존 T4/T5 결합에서 이미 맞히던 프레임이다. Silverstone 결합 우 적중 3/13과 동시 적중 10건은 34m 대조군과 같았고 오경보는 117→148건이었다. 빈 단면만 보완하면 결합 우 적중과 동시 적중을 유지했고 오경보는 117→115건이었다. Spa에서는 교체 조건의 결합 우 적중 13/49가 유지됐고 동시 적중은 15→13건, 오경보는 136→147건이었다. 두 조건 모두 실험으로 보존했다.
