# 색도 상한 제거 뒤 코너 경보가 막힌 단계 · 2026-11-11

색도 상한을 제거한 기존 개발 재생을 Zandvoort 1,000개와 Magione 1,887개에서 다시 실행했다. 원래의 상대 색도 판독과 전체 경보가 프레임별로 일치하는 것을 확인한 뒤, 이동 확인·겹눈 유무 점수·순서형 거리 조건을 분리했다. 이미 평가한 Zandvoort를 사용한 개발 진단이다. 이전 독립 평가의 가중치와 판정은 보존했다.

Zandvoort에서 방향이 맞는 경계 후보 9개는 좌 4개와 우 5개였다. 좌 4개는 모두 직전 프레임에 같은 방향 경계 후보가 없어 이동 확인에 실패했다. 그중 2개는 겹눈 유무 점수와 거리 조건을 모두 통과했지만 기존 판독기가 이미 반대인 우회전 경보를 내고 있었다. 우 5개 중 3개는 이동 확인에서 막혔고 1개는 유무 점수에서 막혔다. 나머지 1개는 경계·이동·유무·거리 조건을 모두 통과했으나 기존 좌회전 경보 때문에 교체되지 않았다. 순서형 거리 범위는 9개 모두 통과했다.
