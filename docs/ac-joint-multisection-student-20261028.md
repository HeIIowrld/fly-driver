# 시각·몸 감각 공동 학습과 실제 제한 주행

기록일: 2026-10-28 KST. 모델 t350은 CPU로 학습한 모델이다. GPU 전환은 별도 t368 실험에 기록한다.

## 학습과 새 구간 평가

t350은 t341의 1,238개 표본으로 시각·기관 감각 연결부만 8 epoch 학습했다. 원본 graph·dynamics·readout·photometry는 그대로다. t351의 tensor 비교로 선언한 adapter 외에는 바뀌지 않았음을 확인했다. 체크포인트 SHA256은 `db13fcc68b3ba8bcb50712e0ccf8e6dcea8fbc3e4cabf014e4d1ff06a672e93a`다.

학습 RMSE는 조향/가속/제동 0.13532/0.13587/0.05292에서 0.05701/0.06863/0.09891로 바뀌었다. 조향·가속은 줄었으나 일반 제동 오차는 늘었다.

최근 t347의 다음 구간 500개는 gradient 업데이트에서 제외했다. source recording·sensor identity·image hash의 중복이 없음을 확인했다. t351의 해당 구간 RMSE는 0.06073/0.08048/0.04829였다. 정답 제동은 모두 0인데 평균 제동 요청이 0.03905여서 불필요한 제동이 남았다. 이는 제동력의 물리적 3.9%라는 뜻이 아니다.

|---|---:|
| 네 방향+몸 감각 | 0.06073 |
| 시각 없음 | 0.24149 |

시각·몸 감각이 모두 출력에 기여하지만 좌측을 가렸을 때 조향 오차가 더 낮았다. 네 시점을 항상 최적으로 합성한다고 말할 근거는 없다. t352의 기존 개발 자료 75개에서도 RMSE 0.15800/0.11920/0.31890으로 제동 일반화가 나빴다. 모델을 승격하지 않았다.

## 영상 선택 중단과 제한된 기다림

t356은 123개 모델 요청 뒤 최고 15.46km/h, 최대 기록 변위 17.915m에서 영상 신선도 제한으로 중단됐다. 마지막 주행 feedback의 gap은 0.553m, 측면 여유폭은 2.568m였다. t357의 원시 영상·몸 감각 모델 재생 오차는 세 출력 모두 0이며 정지/vJoy 해제를 확인했다.

당시 generation 2 수거는 없었다. camera frame 124는 QPC 159020.1470456초에 수신됐고, 가장 오래된 render 하한은 159020.0970115초였다. 다음 frame 125는 159020.2178343초에 도착했다. 마지막 feedback 수신~장치 해제 사이에 기존 frame이 선택 제한 110ms를 약간 넘어섰다. 다음 frame은 수 ms 뒤 도착했지만 기존 코드는 즉시 중단했다.

새 `wait_for_candidate`는 최대 20ms 동안 새 영상을 기다린다. 선택 제한 110ms와 제어 직전 최종 나이 제한 150ms, 추론 80ms 제한은 그대로다. producer 오류·잘못된 시각·잘못된 budget은 기다리며 숨기지 않는다. timeout에는 낡은 frame을 재사용하지 않고, scheduler가 늦게 깨어나도 deadline 뒤의 새 frame을 허용하지 않는다. 기다림 중에는 신경 상태를 진행하거나 제어 명령을 보내지 않는다. 관련 신선도·대기·actuator guard 테스트 27개를 통과했다.

## 같은 모델의 다음 실제 시험

t362에서 API로 정차 상태 에피소드를 다시 준비했다. t363은 같은 t350 가중치로 181회 요청 후 목표 변위 30.040m에 도달했다. 최고 기록 속도는 정지 전후 포함 24.170km/h, 주행 feedback 기준 24.153km/h였다. 마지막 gap은 -0.735m, 최소 측면 여유폭은 1.181m로 여유가 크지 않다.

t364는 새 묶음 형식에서 모델 요청을 재계산해 최대 오차 0을 확인했다. 정지 후 이동까지 포함한 최대 변위는 32.421m다. foreground 이벤트 0회, 교사 제어·위치의 actor 사용 0회, 실제 정지와 vJoy 해제를 확인했다. t365에서 API 일시정지를 마쳤고 live 입력 선언은 기본 설정으로 복구했다.

이 성공 런에서는 camera wait가 1ms를 넘긴 사례가 0개였다. 따라서 30m 완료를 기다림 변경의 인과 효과라고 단정하지 않는다. 단일 구간 완료이며 반복 성공·30km/h 유지·전체 서킷 완주·제동 일반화는 여전히 미검증이다. SDK 응답 시각 오차 허용 기준도 통과하지 못했다. 다음 단계는 학생이 실제 겪은 상태의 교사 질의를 추가하고, 반복 주행과 더 긴 구간에서 검증하는 것이다.
