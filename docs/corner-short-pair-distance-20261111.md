# 연속 접근 쌍을 이용한 코너 시작 거리 학습 · 2026-11-11

전방 T4/T5 활동으로 시작 거리를 회귀한 조건, 속도·절대 요율 등 반전해도 유지되는 몸 감각을 추가한 조건, 같은 물리 코너에 연속 접근한 프레임 쌍의 거리 변화까지 학습한 조건을 비교했다. 물리 코너 ID와 지도 거리는 학습·채점에만 사용했다. 예고에서는 기존에 좌·우 경보를 낸 프레임의 거리만 보정했다. 평가 서킷과 Spa는 학습·보정 비율 선택에서 제외했고, 비율 선택에 쓰는 개발 예측에서도 해당 서킷을 학습에서 제외했다.
