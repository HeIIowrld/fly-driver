`final-state-01.json`은 완료 뒤 관련 Python 프로세스0·원본 checkpoint/요약/검사 log SHA를 기록한다. 25개 run entrypoint를 각 manifest의 프로그램 SHA와 일치하는 `executed-entrypoint.py`로 보존했고 `entrypoint-source-receipt.json`을 남겼다. 초기 audit의 옛 버전은 등록된 변경을 역적용한 뒤 원래 SHA와 정확히 일치할 때만 보존했다.

각 run의 manifest/config/source SHA·seed·termination reason을 따른다. 실행 중 소스가 이후 버전으로 바뀐 entrypoint는 `executed-sources/`의 SHA 검증 보존본을 사용한다. 봉인 계획은 소스 hash 불일치를 거부하므로 옛 계획에 최신 entrypoint를 무조건 끼워 넣지 않는다. 기존 `PROJECT_CHARTER`는 변경하지 않았다.
