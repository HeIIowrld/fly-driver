# 조향/추진 명령 분리와 몸 경계 보호 — 2026-10-29

[대전제](PROJECT_CHARTER.md)에 따라 초파리의 시각·비행 감각운동 구조를 자동차에 연결한다.
이번에는 조향과 추진의 명령 경계를 구현하고, 보정된 몸 감각 변환을 최적화에서 보호했다.
**새 후보는 오프라인 부품 시험 단계다. 시각 주행·실제 차량 안정화·완주/랩타임 검증은 남아 있다.**

## 구현한 v5 경계

구현은 `src/flybrain_drive/flight_commands.py`, 설정은
`configs/flight-circuit-separated-v5-20261029.json`이다.

| 과제 입력 | 직접 입력하는 원본 뉴런 | 대응 |
|---|---|---|
|turn_bias|DNa04:10924/11814,DNa05:11830/12801|기존 모델의 뉴런 자극 반응으로 정한 공학적 조향 방향|
|desired_speed_kmh/30|기존 DNg02 29개|추진 관련 과제 명령|
|몸 회전/기울기/하중/온도|기존 haltere201개와 별도 문맥 경계|보정된 입력 변환 유지|

조향 입력은 방향에 맞는 집단에 음수가 아닌 추가 전류를 준다. turn_bias=0이면 이 추가 전류는0이다.
속도 명령은 조향 포트를 직접 바꾸지 않고 조향 명령은 DNg02 포트를 직접 바꾸지 않는다.
원본 연결망 안의 조향/추진 상호 영향은 그대로 남는다.
뉴런9,728개/원본 연결1,311,145개의 ID·값·정규화는 바꾸지 않았다.
네 기존 뉴런에 외부 명령을 허용하는 input mask 역할만 추가했다.
모든 명령은 원본 연결을 거쳐 운동 readout으로 전달되며 직접 명령→차량 출력 경로는 없다.

몸 encoder는 weight/bias 전체를 optimizer parameter 대신 **buffer**로 저장했다.
따라서 optimizer momentum과 weight decay의 대상이 아니다. `assert_body_boundary_protected()`로
저장 기준과도 비교한다. motor readout은 이번 단계에서 고정했다.
효과적인 회전 반응의 부호는 학습 뒤 별도로 검사한다. 입력 계수 고정만으로 전체 안정성이 보장되지는 않는다.
보호 범위는 각속도/유효성6입력을 haltere201개 포트로 변환하는 빠른 encoder다.
기울기/하중/온도→DNg02의 별도 context는 계속 학습 가능하다. 따라서 기능 재검사를 유지한다.

v4→v5 전환은 `import_calibrated_v4()`로 명시적으로 수행한다.
원래 goal의 속도 열을 보존하고 lateral 열은 power 경계에서 제거한다.
새 goal 계약은 v2이며 turn/speed의 수치 의미는 유지한다.
기존 `FlightCircuit`으로 v5 설정을 읽으려 하면 오류로 중단해 이전 경로로 조용히 실행하지 않는다.

## 실제 연결망에서 전환과 최적화를 검사

`t1081`은 v4 보정 후보`t1076`을 명시적으로 전환하고, 원래5기록4,747관측을 모두 재생했다.
그 기록들의 turn_bias는 모두0이다. **이 조건에서 전환 전후 모든 예측의 최대 오차는0**이었다.
원래 시각과 학생/인계 prefix를 유지했으며, 기록 중간에 상태를 초기화하지 않았다.
이는 임의의 nonzero turn 입력에서도 v4와 동일하다는 주장이 아니다.

고정 장면/몸 감각의 별도 모형 시험에서 얻은 명령 반응은 다음과 같다.
이는 모형200tick 준비 후의 출력 의도이며 실제 차량 조작/속도 달성 시험이 아니다.

| turn_bias /목표 속도 | 추가 조향 집단 전류 | 좌회전 의도 | 전진 의도 |
|---|---|---:|---:|
|0 /15km/h|0|-0.04309|0.01019|

|-0.5 /15km/h|음의 방향 두ID에0.1|-0.15477|0.01475|

조향 과제 변화에 대한 DNg02 직접 입력 차이0, 속도 과제 변화에 대한 조향 직접 입력 차이0이다.
따라서 **경계에서** 두 명령이 분리됐다. recurrent 회로의 운동 출력은 약한 상호 영향을 보였다.

이후 명시적 학습 기록 episode-02의 원래 시작부터320관측을64개씩 이어서 사용해
실제 적용 제어 표적으로 AdamW5회를 실행했다. lr0.0001, weight_decay0.01,
목적함수는 기존 bounded-mean logistic 손실이며 교사 정보를 actor 입력으로 넣지 않았다.
신경 상태와 직전 인코딩 입력은 chunk 사이에 수치 그대로 유지하고 gradient만 detach했다.

- 학습 가능 계수25,380개 중 최대 변화0.00049946. 실제 gradient/optimizer 실행을 확인했다.
- 몸 weight/bias 최대 변화0, 고정 readout의 모든 계수/buffer 변화0.
- 원본 연결의 indices/값 변화0.
- 최적화 전후 모두 좌/우/추진 명령 반응3조건 통과.
- 보정 미사용 장면의 추가 yaw16조건은 최적화 전후 모두 억제 부호 통과.

5회 실행은 보호 기능 시험이며 새 주행 모델을 충분히 학습하거나 성능을 개선한 결과가 아니다.
후보: `runs/flight-separated-command-probe-20261029-t1081/checkpoint.pt`.

## 시각 경로에서 새로 확인한 활성화 문제

`t1082`는 네 실제 장면의 시각/몸/과제 입력을 고정해 모형의 국소 입력 민감도를 측정했다.
HS/VS 경계의 조향 미분 최대값은0.0234–0.0241/추가 전류 단위이며 중심차분도 비슷했다.
공간 시각576특징에 대한 조향 gradient norm은0.00988–0.01052였다.
이는 수치 전달이 있다는 뜻이며 도로 인식의 정확도·유용성을 검증한 결과가 아니다.

반면 DNa04/05의 국소 미분은 매우 작으면서±0.01 유한 자극에는 큰 반응을 보였다.
서로 다른 구간을 비교한 이 값의 비율로 시각/명령 경로의 강도를 결론 내리지 않았다.
`t1083`에서 두 장면에 사전 선언한 양의 추가 전류 수준을 모두 적용해 원인을 확인했다.

- 추가 명령이 없는 baseline에서 네 DN의 net은 약-0.000235~-0.000547이었다.
- rate 모형의 rectified-tanh 활성화에서 이 뉴런들이 억제된 상태에 놓였다.
- 선언한 표본 수준에서 추가 전류0.0003 또는0.001부터 rate/조향 변화가 검출됐다.

이는 **현재 rate 모델의 문턱**이다. 실제 뉴런의 발화 문턱이나 DNa04/05 생리를 측정하지 않았다.
작은 국소 gradient와 문턱을 넘긴 유한 자극의 반응을 혼동하면 학습 경로를 잘못 평가할 수 있다.
현재 공간 시각→HS/VS 경계가 유용한 도로 판단을 만들지 못한 문제는 그대로 남아 있다.
