# 학습한 도로 경계의 연속 굽음과 시작 거리 · 2026-11-11

여섯 서킷의 저장 영상 7,287묶음에서 학습 경계의 거리별 굽음, 도로 폭, 관측 구간을 읽었다. 현재 프레임만 쓰는 조건과 직전 프레임의 굽음을 상대 전진량만큼 옮겨 함께 쓰는 조건을 비교했다. 같은 서킷이 평가용 입력과 경계 모델 학습에 겹치지 않도록 했고, 코너 판독을 학습하는 서킷도 해당 경계를 만든 모델의 학습에서는 제외했다. ## 접근 중 거리 변화

경보 문턱을 적용하기 전에 두 프레임 모두 같은 실제 코너의 방향과 거리를 채점할 수 있었던 경우를 모았다. 정답 방향의 예측 거리만 뽑았으므로 이 결과는 전체 경보 채점과 별개다. Spa의 접근 연속 27쌍에서 거리 변화 오차는 현재 굽음 5.07m, 정렬 굽음 5.31m였다. 실제 가까워지는데 예측 거리가 늘어난 쌍은 각각 12건과 13건이었다. 직전 거리에서 몸 상대 전진량만 빼면 같은 쌍의 **거리 변화량** 오차는 0.08m였다. 이 값으로 최초 거리나 코너 방향을 알 수는 없다. 다른 다섯 서킷에서도 상대 전진량만큼 줄인 변화량이 두 시각 회귀보다 실제 변화에 가까웠다. ## 두 시각 판독이 방향에 동의할 때

이미 결과를 본 뒤, 가까운 코너의 방향은 정렬 굽음 모델로 확인하고 시작 거리는 학습 경계의 시작점 적합에서 가져왔다. 두 방식이 같은 방향을 낸 경우에만 경보를 추가했다. Spa는 좌·우·결합 2·15·10→3·15·11건, 직선·범위 밖 오경보 80→82건이었다. 974번은 6m로 읽었다. 오경보 두 건은 직선 한 건과 범위 밖 한 건이었고, 코너 내부에서도 한 건을 추가로 제안했다. Imola는 적중 증가 없이 오경보가 한 건 늘었으며 다른 네 개발 서킷은 경보가 추가되지 않았다. Spa의 안정 예고 3곳과 공통 6쌍의 거리 변화 오차 5.01m는 그대로여서 사전 기준은 통과하지 못했다.
