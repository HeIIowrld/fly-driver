# FlyBrain — 초파리의 감각·몸 제어 구조로 자동차 운전

**자동차를 초파리의 가상 몸으로 삼아, 초파리의 시각 인식과 비행 유래 감각·균형·운동 제어
구조를 도입하고, 그 구조로 조향·가속·감속·빠른 레이싱 라인과 랩타임을 학습한다.**
최종 검증 무대는 원본 Assetto Corsa 서킷의 학생 단독 주행이다.

일반 자율주행 모델의 성능이나 실측 연결망을 단순히 통과시킨 결과로 이 목표를 대체하지 않는다.
비행 회로의 기능을 차량이라는 몸에 대응시키는 연구이며, 전체 초파리 공력 시뮬레이터를
먼저 완성해야 한다는 뜻은 아니다. 측정 구조·기능 근사·차량 대응·학습한 변환을 구분한다.

## 몸과 감각의 연결

`게임 영상·차량 움직임 → 겹눈/운동 시각과 가상 몸 감각 → 비행 유래 균형·운동 회로 →
전진·회전·감속 의도 → 차량 조작 → 다시 감각으로 되먹임`

차체 기울기·회전은 몸 자세와 회전으로, 가감속·하중 이동·접지·타이어 상태는 몸 반응과
제어 여유로 대응시킨다. 레이싱 라인은 학습/보상/평가의 기준이며, 정답 좌표나 지도는
actor 입력에 넣지 않는다. actor는 영상과 허용된 몸 감각으로 경로와 속도를 판단해야 한다.

## 현재 상태 — 2026-10-29

**최신 판단(t1120~t1127):** 모형 조향 경로의 양방향 응답을 확인하고 좌40·우1579·중립576의
학습 비중을 보정했다. 학습 좌조향은0/40→39/40으로 개선됐지만, 알려진 OFF 기록에서는0/41→9/41에
그쳤고 우조향은68/68→39/68로 줄었다. 직진 편향·합동 개발 검증 실패가 남아 실제 운전에 승격하지 않았다.
[최신 회로 응답·균형 학습·한계·다음 작업](flight-steering-capacity-and-balanced-learning-20261029.md)을 먼저 읽는다.
아래 수치는 각 단계의 기록이며 현재 자율주행 성공을 뜻하지 않는다.

v5에서 조향/추진 명령 경계를 분리하고 몸 변환을 optimizer에서 보호했습니다. 전체4747관측 전환 오차0,
실제5회 업데이트 뒤 몸/readout 변화0과 회전 억제16조건 유지를 확인했습니다. 시각 주행·실제plant는 미검증입니다.
[현재 v5 구현·검사·시각 활성화 문제](flight-separated-commands-20261029.md)를 먼저 확인합니다.

몸 yaw 입력 열만 보정해, 보정에 쓰지 않은4장면×4pulse의 **모형 내 회전 억제 부호16/16**을 확인했습니다.
실제 차량 안정화·생리 검증은 아니며 시각/주행 성능 문제는 남아 있습니다.
[경로 분리·보정·한계](flight-yaw-boundary-calibration-20261029.md)를 현재 기준으로 읽습니다.

- 실제 AC의 네 시점 영상·native 몸 감각·vJoy 제어·백그라운드 계측을 검증했다.
- 현재 비교용 학생은 실측 부분망 6,557뉴런/644,512연결을 쓰는 단순화된 발화율 모델이다.
  겹눈 초기 운동 시각과 비행 몸 제어 전체를 구현한 모델은 아니다.
- 비교용 source949는 60.21m를 검증했고, 240m 시험은 161.96m에서 속도 제한을 넘어 실패했다.
  전체 서킷·반복 안정성·최적 랩타임은 미검증이다.
- flyvis 저자 소스·공개 가중치를 고정하고 GPU에서 깜박임/이동 경계의 원시 반응을 수집했다.
  144조건의 저자 지표 대조에서 T4d 극성 불일치가 남았다. 생리 검증 전체와 차량 통합은 미완료다. 비행 후보망9728뉴런/1311145연결을 추출하고 원본과 대조했으며 기능 검증은 남았다.
  다음 우선순위는 운전 증류 추가보다 이 기전의 도입이다.

별도 가상 몸 v1은 pitch·roll·yaw와 하중비율/native온도를 구현하고 원래1543관측 전체에 재생했습니다.
선형가속도·회전 두 축의 등록과 새 회로/actor 통합은 남아 있습니다.

실제 네 시점 영상1543관측을 새 flyvis 회로에 연속 재생해 망막별 T4/T5 반응을 확보했습니다.
카메라별 공간 변환은 공학적 설계이며 비행 운동망과의 결합·주행 검증은 남아 있습니다.

여러 시점의 T4/T5 반응에서 회전·상대 병진을 읽는 작은 기능 어댑터도 보정했습니다.
새 합성 시험에서 부호24/24·주된 축23/24이며, 실제 게임에서의 운동 추정과 비행 운동망 결합은 미검증입니다.

실측 비행 후보망에 공간 시각·몸 회전·상위 명령과 날개 운동 출력을 연결해 GPU 기술시험을 했습니다.
실제 단일 기록으로 초기 학습했지만 예측이 평균에 치우쳐 있습니다. 제동·좌우 커브 자료 확대와 균형/실제 주행 검증이 남았습니다.

모두 우조향이며 제동 표적은 없어, 좌우·제동 자료 확보와 목표 조건을 구분한 학습이 필요합니다.
