# 고정 모델30조건 반복·실행 시간·재구성 겹눈 자료 확보

기록: 2026-10-27, Asia/Seoul. **같은 부분 회로 체크포인트가 사전에 고정한 새 시작 조건30개를 모두 완료했다.** 서로 다른 모델을 세 번 학습한 검증이나 AC 운전 성공은 아니다. μCT에서 재구성한 겹눈 광학축도 별도로 확보·검증했으며, 이번 주행의 합성 격자와 혼동하지 않는다.

## 결과 전에 평가 조건을 고정했다

[이전 부분 회로 모델](routed-circuit-driving-20261027.md)의 체크포인트 SHA-256 `149686a70f42fb2506e8da08e283d0796d1e1141b3ac135be545ca96707b8d18`을 고정했다. 회로·어댑터·readout을 재보정하거나 학습하지 않았다. 기존 설정과 별도 평가 suite를 분리해, 저장 모델의 configuration은 바꾸지 않고 시작 조건과 평가 예산만 전달했다.

[사전 등록 프로토콜](../configs/routed-fixed-checkpoint-repeat.json)은 각 평가 manifest보다 먼저 작성됐다. 세 묶음마다10개, 시작 X는1.5–7m, 횡위치 오차는[-1,1]m 균등 표본, 방향 오차는[-8,8]도 균등 표본이다. 묶음별 난수 시드는720101/720201/720301이며 각 조건의 실제 값은 suite에 고정했다. 통과 기준은 **각 묶음10회 중9회 이상 완료**다. 횡위치·방향 범위는 앞선 정지 자세 학습 범위 안이며, 새로운 코스의 일반화 시험이 아니다.

## 현재 루프의 실행 시간

CPU 평가 프로세스3개를 동시에 실행했고 각 프로세스의 Torch/OMP/LP thread는1개였다. 아래는30조건의 판단 기록을 합친 벽시계 분위수다. AC 화면 캡처나 실제 입력 장치의 지연은 포함하지 않는다.

| 처리 구간 | p50 | p95 | p99 |
|---|---:|---:|---:|
| 감각 관측·겹눈/기관 변환 | 0.916 ms | 2.544 ms | 2.725 ms |
| 신경 판단 | 0.414 ms | 0.630 ms | 0.730 ms |

| 환경 step: 물리·필요한 영상 렌더링 등 | 0.763 ms | 15.876 ms | 17.254 ms |
| 전체 | 3.164 ms | 17.147 ms | 18.573 ms |

전체 처리의22.868%가10ms를 넘었다. actor 구간만은200,895개 중4개가10ms를 넘었다. 따라서 이 동기 루프가100Hz 마감을 만족한다고 주장할 수 없다. 감각·회로 계산보다 환경 step의 긴 구간이 더 크지만, 동시 프로세스와 OS 스케줄링이 있는 측정이라 전용 환경의 최악 지연이나 하드 실시간 보장도 아니다. AC에서는 실제 캡처·telemetry·조작 지연을 별도로 측정하고 capture와 판단의 비동기 경계를 검증해야 한다.

## 저자 자료에서 재구성 광학축을 가져왔다

[Eye structure shapes neuron function in Drosophila motion vision](https://www.nature.com/articles/s41586-025-09276-5)의 [저자 저장소](https://github.com/reiserlab/eyemap_T4/tree/99d2a43123db636cedb55af9ff31a59657e7d17e)를 commit `99d2a43123db636cedb55af9ff31a59657e7d17e`에 고정했다. `20240701.RData`의 처리된 `ucl_rot_sm`과 lens/cone 대응을 사용했다. 원본 자료·해석에 사용한 R 파일·README·GPL-3.0 LICENSE는 출처 파일로 보존했으며 저자의 R 코드는 실행하지 않았다.

변환 결과는 **왼눈857개·오른눈852개, 합계1,709개 광학축**이다. 렌즈와 cone의1기반 순열·좌우 대응, 축의 단위 길이, 정준 좌표의 오른손 기저를 검사했다. 최대 단위 길이 오차는약2.22×10⁻¹⁶, 기저 determinant는1이다. 저자 좌표는 X전방·Y좌측·Z위쪽이며 이미 정준화된 축에 회전을 다시 적용하지 않았다. facet ID는 처리된 lens 행 번호이며 MaleCNS의 body ID가 아니다.

[자료 등록부](../configs/eyemap-t4-source.json), [변환 manifest](../assets/external/eyemap-t4-20261027/eye-axes.json), [광학축 NPZ](../assets/external/eyemap-t4-20261027/eye-axes.npz). 원본 RData는 Git 버전과 바이너리로 대조했고, Windows checkout의 텍스트 CRLF는 LF로만 정규화해 비교했다. R 인덱스가 double로 저장된 경우 정수 값과 완전한 순열임을 확인한 뒤 변환했다. 수용각·광수용 시간 반응·개별 MaleCNS 광수용 뉴런의 등록은 확보한 것이 아니다.

## 현재 카메라로 보이는 범위도 따로 확인했다

`load_anatomical_eyes`는 가상 눈 위치·head-to-body 회전·가정한 수용각을 명시적으로 받아 `EyeGeometry`를 만든다. 이 검사에서는 회전I, 단일 가상 pupil/눈, sigma1도 가정을 썼다. 현재의120도 전방 카메라 설정에서 흰 입력을 투영하고, 관측 가능한 방향만1·나머지는0과 invalid가 되는지 확인했다.

| 눈 | 전체 축 | 관측 가능 | 비율 |
|---|---:|---:|---:|
| 왼눈 | 857 | 460 | 53.68% |
| 오른눈 | 852 | 446 | 52.35% |

즉, 이 카메라 설정을 재구성 자료에 적용하면 광학축 약 절반은 관측되지 않는다. 좁은 전방 영상을 복제해 나머지를 채우지 않았다. [시야 감사](../runs/anatomical-eye-import-20261027/runs/anatomical-eye-field-t8/audit.json).

**이번30조건 주행은 기존 합성16×24 격자 입력을 썼다.** 재구성 광학축은 아직 주행 backend에 자동 연결하지 않았다. 광학축 수·배열·관측 범위·eye-map hash가 달라 기존 readout을 그대로 재사용할 수 없으며, 실제 축으로 관측을 다시 수집하고 별도 모델을 맞춰 비교해야 한다. 시야 밖 방향, per-facet 위치, 수용각과 시간 반응의 남은 가정도 구분해서 관리한다.

새 suite 분리와 자료 변환·시야 검증을 포함한 최신 WSL 전체 테스트는 **136개 통과, 26.31초**다. [로그](../runs/anatomical-eye-import-20261027/pytest-validation.log). AC 실행 위치와 실제 게임 연결은 여전히 확인되지 않았고, 최종 목표는 미완료다.
