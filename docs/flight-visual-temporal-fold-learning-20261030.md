## 실제 저자망의 동일 optimizer 비교

`configs/flight-author-temporal-fold-learning-20261030.json`은 다음 조건을 고정했다. t1701 독립 사전 검토도 통과했다.

- 3개 전체 이력 fold마다 원래 저자 가중치에서 두 조건을 새로 시작한다. 각 fold의 보정·vision+body readout은 동결한다.

- 초기 회색 상태와 손실은 기록하되 초기 상태는 detached다. 이후 모든 원래 유효 표적이 기여한다. 이전 영상은 원래 관측 간격 동안 유지하며 detach는 수치 reset이 아니다. 학습 중 바뀌는 가중치와 이어지는 상태를 그대로 기록한다.
- 각 최종 가중치에서만 보류 이력739관측을 새 에피소드 상태로 재생한다. 보류 결과로 중간 checkpoint/epoch/학습률/모델을 고르지 않는다. 실제 원래 시각망의 가변 파라미터만 바꾸고 고정2,959개와 보조 readout은 불변이어야 한다.

시각 학생 제어·유효 랩은 아직0이다. [Native 운동 부품](flight-native-neural-actuator-20261030.md)은 실제 신경 요청과 작은 브레이크 응답을 확인했지만 시각망이 그 주행을 결정하지 않았다. 현재 motor branch에서 하중/타이어/바퀴 회전은 보존만 됐고 causal 적응 경로로 아직 연결되지 않았다. 실제 제동·속도·조향의 회로 내 학습,60→100/가변속·변속·몸 적응·유효 완주·레이싱 라인/랩타임 최적화 전체 목표를 유지한다.
