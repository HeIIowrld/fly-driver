# 코너 유무와 좌·우 판독 분리 실험 · 2026-11-11

Laguna Seca의 독립 평가에서 혼합 판독층은 4–20m 접근 63개 중 62개를 원시 방향 단계에서 배경으로 분류했다. 이 실패를 바탕으로 기존 개발 영상에서 가까운 코너의 유무와 좌·우 방향을 각각 학습하고 평가했다. Laguna 영상과 특징은 이번 학습·설정 비교에 사용하지 않았다. [독립 평가 기록](corner-laguna-independent-20261111.md)

## 입력과 비교 조건

- 기존 전·후·좌·우 카메라의 세 시점 T4/T5 활동을 썼다. 반사 분기가 있을 때 코너 유무 점수는 평균하고 좌·우 부호 점수는 부호를 뒤집어 평균했다. 반사 분기가 없으면 원래 영상의 점수를 썼다. 원래 대비 특징과 카메라별 RMS로 나눈 특징을 비교했다.
- 단일 서킷 학습은 Monza 기존 학습 889개를 썼다. 방향 판독층은 4–20m 양성만 사용했다. Monza 물리 코너 분리 검증 100개, Magione 전체 1,887개, Imola 전체 616개를 비교했다. Magione 8개와 Imola 426개의 특징 미가용 표본을 분모에 남겼다. Imola는 4–20m 양성이 없다.
- 혼합 학습은 코너 유무 판독층에만 Magione 물리 코너 0의 759개와 Imola 기록 01–03의 93개를 추가했다. 평가에는 Magione의 코너 2 및 코너 ID 없는 프레임, Imola의 나머지 기록, Monza 기존 분리 검증을 썼다. Magione 양성은 물리 코너 0·2에 집중돼 이 혼합 비교의 Magione 평가에는 좌 접근만 있다.
- 거리는 모든 비교에 기존 ordinal 판독을 썼다. 앞선 Laguna 프로토콜의 공동 거리 교체와 시간 보정은 적용하지 않았다. 따라서 여기의 결합 적중은 Laguna 프로토콜을 재생한 Magione 결과와 분리해서 읽는다.

## 관측

좌·우 선택만 점수화하면 원래 대비 특징의 정규화 계수 1,000 판독층은 Monza 좌 6/6·우 8/8, Magione 좌 64/64·우 79/79를 맞혔다. 이는 정답으로 접근 프레임을 골라 계산한 진단이다. 같은 판독층의 코너 유무 점수에 0.35를 적용하고 ordinal 거리 조건까지 통과시켰을 때는 Magione 좌 62/64·우 77/79, 직선·범위 밖 오경보 767개였다. 기존 혼합 후보의 오경보는 28개였다.

혼합 비교에서 Magione 좌는 9→32개로 늘었고 Imola 보류 기록의 오경보는 0개였다. 같은 설정에서 Monza 적중은 좌 2→0·우 7→5개, 오경보는 2→8개였다. 기존 후보가 이미 경보를 낸 프레임의 좌·우만 교체하는 대조에서는 적중 수가 그대로였다. 기존 유무 점수와 새 유무 점수가 함께 통과할 때 경보를 추가하는 대조도 Magione 적중을 늘리지 못했고, Imola 전체의 오경보는 최소 99개였다.

10개 판독층마다 관측 점수가 바뀌는 모든 임계값을 검사했다. 각 평가 묶음에서 기존 혼합 후보의 좌·우·결합 적중을 유지하고 오경보를 늘리지 않는 공통 임계값은 0개였다. 이번 실험에서 새 판독층은 독립 평가 후보로 채택하지 않았다. 접근 거리 변화와 최초 안정 예고는 기존 독립 평가 결과가 최신 검증 근거다.
