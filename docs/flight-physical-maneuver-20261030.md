# 물리 단위의 목표 회전·속도를 비행 운동 회로에 연결

갱신: 2026-10-30T00:13:23+09:00. 실험 t1662–t1665. 이전 [실제 파리 시각망 학습](flight-author-visual-learning-20261029.md)을 이어, 새 물리 입력 경로와 운동뉴런 출력의 연결을 검사했다.

## 사용자 확정 대전제

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.** 이번 결과는 그중 운동 회로 입력과 출력의 부품 검사이며 생리 기능·차량 폐루프·완주를 대신하지 않는다.

## 새로 구현한 연결

`src/flybrain_drive/flight_maneuver.py`의 새 계약 `flybrain.flight.physical_maneuver.v1`은 목표 좌회전율(rad/s)과 목표 속도(m/s)를 받는다. 기존 30km/h 목표를 고속 목표로 바꾸어 해석하지 않는다. 입력 시 새 물리 계약과 `racing_goal.v1` 계약을 함께 명시해야 하며, 옛 계약은 배열 모양이 같아도 거절한다. 외부 속도 상한은 목표 순항 속도가 아니며, 상한만 바꿔도 같은 물리 명령의 결과는 변하지 않아야 한다.

| 입력·경로 | 이번 구현과 근거 |
|---|---|
| 목표 회전율 | 공학적 비음수 전류 인코딩 → 기존 DNa04/05 네 ID → 원래 실측 화학 연결 → b1/b2 운동뉴런 |
| 실제 몸 회전 | 원래 단위·마스크의 각속도 → 보호된 haltere 경계 → 같은 실측 회로. 목표 경로 바깥에서 yaw를 먼저 빼지 않음 |
| 목표 속도와 실제 속도 | 한 번 계산한 속도 오차 → DNg02 전류 → 실측 연결 → DLM/DVM 운동뉴런 |
| 자동차 요청값 | 위 날개 운동뉴런 여섯 집단의 출력만 사용. 좌회전 intent의 음수가 AC 조향, signed forward가 가속/제동 요청 |
| 영상 예측 연결 | 실제 적응 시각망의 저장된 개발 예측 20m chord curvature와 몸 속도로 `desired_yaw_left=-v*kappa_right` 생성. 정확도가 미통과인 후보의 오프라인 연결 검사이며 운전용 승인이 아님 |

이 인코더와 차량 대응은 공학적 가설이다. DNa04/05 방향은 기존 모델 주입 반응으로 정한 방향이지 생체 neck projection의 확정 증거가 아니다. 목표 회전율의 단위를 받는다는 사실과 실제 차량이 그 회전율을 추종한다는 증거는 구분한다. 실제 차량 응답 보정은 아직 없다.

원본 v5 체크포인트에서 화학 그래프·보호된 몸 경계·운동 readout의 기존 gain/mix를 가져와 동결했다. 옛 vision/task 인코더는 호출하지 않는다. 조용한 가상 몸의 합성 중립 상태로 private 복사본의 운동 기준 offset만 명시적으로 재설정했으며, 원래 gain/mix는 값 그대로 복원·검사했다. 원본 체크포인트는 바꾸지 않았다. 6km/h fast-haltere/electrical 가설의 이전 인증을 이 새 경로에 적용하지 않는다.

차체 pitch/roll은 앞 단계 시각 정렬에서 사용된다. 여기의 haltere 경계에는 각속도만 들어가며 정적 기울기나 온도를 회전 수용기 입력으로 부르지 않는다. 원래 무효인 각속도 채널은 계속 무효다. 타이어·하중·셋업에 따른 접지/제동 여유와 주행 페이스 조절은 아직 이 새 운동 경로에 구현하지 않았다.

## 합성 주입 결과: 물리 차량 응답이 아닌 신경 intent

실제 몸 속도는 합성 60km/h로 고정하고 회전·목표 속도를 바꿨다. 각 조건은 선언된 별도 실험이며, 원래 연결의 동일 rate dynamics를 유지한다.

| 명령 | 좌회전 intent | signed forward intent |
|---|---:|---:|
| 목표 yaw0, 목표60km/h | .00000025 | .0000000 |
| 목표 좌회전 +.3rad/s | .0834692 | .0011419 |
| 목표 우회전 -.3rad/s | -.0625645 | .0025544 |
| 목표100km/h | -.0165638 | .7768207 |
| 목표20km/h | .0036047 | -.2433384 |
| 좌회전+.3 및 목표100km/h | .0651314 | .7772141 |

목표 좌회전+.3에서 실제 몸 yaw를 +.3으로 바꾸면 좌회전 intent가 .0834692→.0545147로 줄고, -.3으로 바꾸면 .1123858로 늘었다. 정해 둔 좌우·가속/감속 방향·양방향 yaw 피드백·외부 상한 불변성 일곱 검사는 통과했다.

목표 회전 입력/속도 오차/몸 yaw 피드백을 각각 제거한 대응 조건 쌍의 차는 모두0이었다. 세 외부 입력 뉴런 집단을 모두 차단한 실험에서는 운동뉴런 활동이0이었다. 입력이 운동 readout으로 직접 우회하는 경로는 없다.

**회로 간 결합은 남아 있다.** 가속 목표만 바꿔도 조향 intent가 -.01656 변하고, 같은 좌회전 명령의 출력도 가속 시 줄어든다. 이것은 보정 없이 실제 차를 안정적으로 운전할 수 있다는 증거가 아니다. 좌우 gain도 대칭이 아니며 실제 steering/yaw와 페달/속도의 응답 관계를 측정해야 한다.
