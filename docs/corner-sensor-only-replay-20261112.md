# 센서 기록만 사용하는 코너 판독 재생 · 2026-11-12

저장 영상에서 이미 추출한 좌우 경계, 코너 후보 특징, 차량의 국소 속도·요율, T4/T5 운동 시각 특징을 하나의 입력 파일로 받아 네 상태와 코너 시작 거리를 출력하는 명령을 추가했다. 모델 체크포인트와 설정 해시를 확인하고 판정 기준을 그대로 적용한다. 새 영상에서 이 명령의 입력을 만들려면 네 카메라의 원본 영상에서 기존 경계와 운동 시각 특징을 추출하는 단계가 필요하다. 이번에는 기존 Silverstone 1967과 Vallelunga Extended의 영상 관측을 사용했다. [재생 코드](../scripts/replay_corner_boundary_states.py)

입력에는 서킷 지도, 절대 위치, 정답 방향·거리, 이전 판독 결과를 포함할 수 없다. 과거 프레임을 옮길 때 사용하는 차량 움직임은 기록된 국소 속도·요율이다. 두 판독은 같은 경계를 복원하고 같은 코너 후보를 고른다. 경계 판독은 T4/T5 입력을 사용하지 않는다. 결합 판독은 해당 운동 시각 특징이 누락되면 보류한다. 국소 속도·요율이 없으면 양쪽이 보류하며 현재 관측 경계는 그대로 기록한다.

## 실행과 입출력

프로젝트 루트에서 실험에 사용한 Python 환경으로 다음과 같이 실행한다.

```powershell
python scripts/replay_corner_boundary_states.py --input runs/vision-corner-sensor-only-20261112-01/ks_silverstone1967-sensors.npz --output runs/vision-corner-sensor-only-20261112-01/replay
```

센서 NPZ의 필드는 다음과 같다.

| 필드 | 내용 |
| --- | --- |
| `run`, `frame`, `generation`, `received_s` | 녹화 식별자, 캡처 번호, 세션 세대 식별자, 수신 시각 |
| `stations`, `sections` | 2–34m의 2m 간격 표본과 프레임별 오른쪽·왼쪽 횡좌표 |
| `motion` | 센서 시각, 속도 m/s, 국소 요율 rad/s. 양수는 좌회전이다. |
| `heads` | 직선·좌·우 후보 점수 및 후보 거리 |
| `t4t5` | 좌·우 방향의 운동 시각 특징 각 768개 |

`boundaries.npz`에는 현재 관측, 복원한 경계 및 복원 여부가 들어 있다. `forecasts.jsonl`은 프레임별 공통 후보, 센서 가용 여부, 두 판독의 상태 및 거리다. 거리는 확정된 좌·우 상태에서만 기록한다. `result.json`에는 입력과 출력의 해시 및 사용한 체크포인트 해시를 기록한다.

## 검증과 남은 평가

두 서킷 각 1,200장에서 기존 실험의 경계와 최종 상태·거리를 동일하게 재현했다. 별도로 T4/T5 입력 전체를 제거해도 같은 프레임의 경계와 경계 판독이 유지되고 결합 판독이 보류되는지 검사했다. 국소 움직임을 제거한 경우에는 과거 경계를 복원하지 않고 양쪽이 보류했다. 해당 녹화의 앞부분만 입력했을 때도 전체 재생의 같은 구간과 일치했다. 기존 결과의 Silverstone 우 동시 적중 2/13과 Vallelunga의 같은 후보 기준 T4/T5 우 적중 3→5/38은 이 재생에서 유지됐다. [입력 분리와 재생 검증](../runs/vision-corner-sensor-only-20261112-01/verification.json)

이번에 별도 촬영을 시도하기 전에 읽기 전용 CSP 상태를 확인했으나 최신 세션 상태를 검증하지 못했다. 이 확인 과정에서 게임 UI·액추에이터·세션 제어 명령은 보내지 않았다. 기존 녹화로 재현성을 검증했으며 새 녹화의 일반화와 실시간 적용은 남아 있다. [CSP 확인 결과](../runs/vision-corner-sensor-only-20261112-01/session-status/result.json) · [앞선 코너와 직선 비교](corner-recovery-routing-20261112.md)
