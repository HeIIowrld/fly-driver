## 적용 제어값 라벨의 의미

Python native 제어값 수집과 관측을 명시적으로 같은 `time.perf_counter` QPC 시계로 기록했다. 관측 후40ms부터 최대25ms 늦게 수신된 **새 native 패킷**을 대응시킨다. AI 활성 구간을 시계 경계 안에서 확인할 수 없는 경우나 늦은 값은 제외한다. 반복 패킷을 새 시각으로 재사용하지 않는다.

조향은 같은 차량/장치에서 측정한 native 이득 약1.4062499와 기존 학생 장치 배율0.6으로 역변환한다. AI 조향 배율0.9의 실제 주행에서는 학생 범위를 넘는 값이 없었다. 범위 밖 값을 잘라 정답으로 만드는 처리는 하지 않았다. 가속·제동은 native 적용값0..1이다.

이 라벨은 **이후 시점에 수신한 적용 제어값의 공학적 대용 목표**다. AI 내부의 의도된 명령을 읽은 것이 아니며 실제 물리 명령 시각과 차량 제어 지연을 정확히 입증하지 않았다. `getCarInputControls()`의 사용자 입력을 AI 명령이라고 쓰지도 않았다. 이 한계를 계약에 기록한 탐색적 오프라인 학습 자료다.

자료: `runs/ac-engine-ai-registered-receipt-dataset-20261028-t647`, manifest SHA-256 `a4807f3358dab3638f8ac4b29ecef10bf4cc64f6abc31ff104230aab1ebbdb3c`.

원본 관측 1,473개, 조향/가속/제동 각각 유효 목표1,464개, 명시적 시퀀스3개다. 80ms를 넘는 공백과 별도 AI lease는 경계로 보존했다. 시퀀스 안의 수치 신경 상태를 chunk마다 초기화해서는 안 된다. 전체 코스 검증에서는 인위적인 중간 신경 초기화를 성공으로 인정하지 않는다.

새 설정 `configs/ac-engine-ai-registered-receipt-training.json`, suite t649, 학습 t650은 source499에서 시작하는 16 epoch GPU 실험이다. 정상 종료 코드0, 약117.63초에 완료됐다. 그래프는 고정하고 시각·기관 연결과 readout을 학습했다. 학습률은2e-5, readout gain 학습률은0.005다. 파라미터·입력·목표·기울기는 cuda:0, GPU 최대 텐서 할당량은986,851,840 bytes였다. 체크포인트 SHA-256은 `76214341d499d7dc9503fdf5fb1eb4657b64415df7c42ea8486b29e996886ffd`다. 그래프 불변·보정 일치·학습 자료 해시와 CPU 저장을 t649/checkpoint-integrity.json에서 확인했다.

t652에서 기존 source499의240m 성공 관측984개를 같은 입력으로 재생해 비교했다. 비교용 기하학 교사 라벨 기준 조향 RMSE는0.09115→0.08590, 가속은0.10183→0.12176, 제동은0.06559→0.05739였다. 제동 음성906개에서0.05초과 요청은203→0으로 감소했지만, 제동 양성78개에서 평균 제동 요청도0.01057→0.000726으로 줄었고 해당 구간 RMSE는0.19455→0.20104로 나빠졌다. 이는 서로 다른 목표를 쓰는 오프라인 회귀 진단이며 새 실제 주행 결과나 교사 라벨의 최적성 증명이 아니다.

이번 독립 실험에는 기존 성공 구간의 고정 정책 보존 손실이 없었다. 무제동 자료만으로 미세조정하면 제동 출력을 약화시킬 수 있다는 한계가 실제 진단에 드러났다. **새 모델은 배포하지 않는다.** 다음 학습에는 실제 코너 감속·제동이 포함된 전문가 자료와 제동/기존 정책 보존 조건이 필요하다. 임의의 API 강제 정차를 도로 상황에 따른 제동 정답으로 섞는 방식은 사용하지 않는다.
