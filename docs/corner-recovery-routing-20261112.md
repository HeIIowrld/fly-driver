# 복원 후보 선택과 직선·보류 판독 · 2026-11-12

기존 경계의 후보가 없을 때 복원 후보를 쓰는 방식과, 기존 후보가 있어도 복원 후보가 같은 방향에 3m 이내일 때 바꿀 수 있는 방식을 비교했다. 네 개발 서킷을 하나씩 빼는 교차 평가로 두 방식의 확인 문턱을 고정했다. 이전 문턱을 그대로 쓰는 대조도 남겼다. 모델 가중치와 코너 내부 차단은 이전 설정을 재사용했다. Silverstone 1967과 Vallelunga Extended는 이번 학습과 문턱 설정에서 제외했고, 두 서킷의 이전 실험과 같은 저장 영상 각 1,200장을 썼다. 같은 프레임에서 경계와 T4/T5 확인기가 동일한 후보를 받는지 확인했다. 표는 후보 확인 단계의 경보다. 동시 적중은 4–20m 접근에서 방향과 시작 거리 ±5m를 함께 맞힌 경우다. Silverstone의 복원 두 장은 같은 코너의 연속 프레임이다. 807번은 기존 후보가 없어 우 15m를 채택했다. 808번은 우 12.36m와 우 14m가 같은 방향이고 차이가 1.64m라 복원 후보를 허용했다. 실제는 각각 16.76m와 9.03m였다. 모든 후보를 경쟁시키면 488번에서 실제 18.04m에 우 6m도 확정됐지만, 방향·거리 일치 조건은 그 후보를 걸러냈다. 방향·거리 일치 조건에서 Silverstone의 두 우 적중은 경계와 T4/T5에 공통이었다. T4/T5는 직선 경보 3건과 범위 밖 경보 1건을 없애고, 코너 내부 경보 2건을 추가했다. Vallelunga에서 우 동시 적중은 3→5/38, 전체는 3→6건이었다. 우회전 적중 3건을 추가하고 기존 우 적중 1건을 잃었다. 좌회전 적중 1건을 추가했으며 반대 방향 경보 1건도 추가했다. 코너 내부 경보는 7→10건이었다. ## 직선 판독을 따로 학습한 결과

기존 상태 규칙은 관측된 경계 쌍이 충분하고 코너 후보가 없을 때만 직선을 냈다. 직선으로 판독할 수 있는 경우를 늘리기 위해 영상 경계의 근거리·원거리 곡률과 폭, 차량의 국소 속도·요율, 직전 프레임의 이력으로 직선을 학습했다. 차가 정지했거나 경계 쌍이 6개 미만이면 판독 보류를 유지했다. 확정된 좌우 경보와 시작 거리는 그대로 사용했다. 개발 네 서킷에서 실제 접근과 코너 내부를 직선이라고 오판한 수가 각각 기존 이하인 문턱을 골랐다. 범위 밖 코너는 학습에서 제외하고 결과에 따로 집계했다. 개발 교차 평가의 직선 적중은 101→441건, 접근 직선 오판은 31→31건, 내부 직선 오판은 106→45건이었다.
