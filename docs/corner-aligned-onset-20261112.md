# 이동을 반영한 도로 경계와 코너 시작 거리 · 2026-11-12

저장 영상에서 추출한 좌우 경계를 7개 서킷의 8,487묶음에서 다시 평가했다. 현재 프레임에서 기존 경계 적합이 불가능할 때, 최대 0.45초 앞서 관측한 경계점을 속도와 요율로 현재 차량 좌표에 옮겨 시작점 하나를 양쪽 경계에 함께 맞췄다. 일정 간격으로 경계점을 다시 보간하는 대신 이동 후 좌표에서 직접 적합했다. 현재 프레임에서 적어도 세 경계 쌍이 필요하고, 추정 시작점 앞뒤에도 현재 관측이 각각 하나 이상 있어야 한다. 단일 프레임 적합과 같은 최소 곡률 및 적합 개선 문턱을 사용했다. 지도와 절대 위치는 공통 채점의 정답에만 쓰였다. ## 경보가 연속으로 나왔을 때의 거리 갱신

직전 프레임과 같은 방향의 경보가 연속되면, 앞서 예고한 거리에서 몸 감각으로 얻은 이동량을 뺐다. 새 거리와 차이가 4m 이내이고 이동으로 갱신한 값이 4m 이상일 때만, 갱신값에 새 거리의 차이를 25% 반영했다. 프레임이 끊기거나 방향이 바뀌거나 몸 상태를 읽을 수 없으면 현재 영상 거리에서 다시 시작한다. 이 조건에서 Silverstone의 동일한 방향 적중 쌍 두 개는 거리 변화 평균 절대 오차가 2.02→0.51m였다. 다섯 개발 서킷의 동일한 여섯 쌍에서는 1.14→0.28m였다. 안정 예고 수는 그대로였다. ## T4/T5를 추가한 경보의 거리 갱신

기존 사후 비교의 동일한 영상 경계 후보와 0.25 확인 문턱을 재사용했다. 경계 모델과 경계+T4/T5 모델의 경보를 각각 재현하고, 같은 이동 갱신 규칙을 적용했다. 이 비교에서는 두 서킷 모두 경보 방향, 동시 적중, 오경보와 안정 예고 수가 갱신 전과 같았다.
