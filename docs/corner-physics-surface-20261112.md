# 충돌 메시로 대조한 실제 영상의 노면 경계 · 2026-11-12

Silverstone 1967의 설치 파일에서 로드되는 KN5 6개를 읽었다. 물리 표면으로 분류한 숫자 접두사 노드 236개는 모두 `4.kn5`에 있었다. 벽을 제외한 바닥 삼각형 382,430개에 설치된 기본 및 서킷 `surfaces.ini`의 `IS_VALID_TRACK` 설정을 적용했다. 메시의 좌표, 텍스처와 원본 파일은 저장하지 않았다. 각 녹화 프레임의 차량 수평 좌표에서 2–34m 단면을 만들고, 연속된 유효 노면의 양 끝과 바로 인접한 비유효 노면을 확인했다. 이 경계는 설치 파일의 표면 설정을 나타낸다. 실제 경기의 타이어 판정과 페널티는 별도로 검증해야 한다. ## 영상에 보이는 선의 정체

우회전 접근 13장에 대해 각 좌우 경계의 차량 횡좌표와 전방 영상 투영을 함께 기록했다. 16–34m 오른쪽 130단면 중 95개는 유효 아스팔트와 비유효 `OUT`의 전환, 30개는 아스팔트와 잔디의 전환이었다. 5개는 유효 노면의 끝을 얻었지만 인접 비유효 표면을 확인하지 못했다.

앞서 원본 영상에 표시한 7장의 공통 54점에서 표면 메시의 투영과 육안 주석 사이 거리 중앙값은 **0.29px**였다. 같은 단면의 AI 경로 폭에서 얻은 점은 **1.65px**였다. 어두운 띠가 있는 4장의 공통 30점에서 띠 반대편까지의 거리는 메시 3.43px, AI 경로 1.31px였다. 이 구간의 띠는 도로 쪽이 표면 설정 경계에 가까웠고, AI 폭은 반대편에 더 가까웠다. 설치 파일 해시와 녹화 프레임 해시를 각각 기록했다. 녹화 당시의 메시 해시가 보존된 것은 아니므로 같은 위치인지 원본 영상의 정합으로도 확인했다. [원본·표면 경계·AI 경로 투영](../runs/vision-corner-physics-surface-20261112-01/surface-vs-strip.png) · [공통 단면 검증](../runs/vision-corner-physics-surface-20261112-01/verification.json)

기존 절댓값 추적과 밝기 부호 추적을 새 기준으로 다시 비교했다. 13장의 오른쪽 공통 125단면에서 고정 평면 행으로 읽으면 횡오차 중앙값은 둘 다 **1.18m**였다. 충돌 메시가 투영되는 행에서만 두 경로를 다시 읽은 진단에서는 절댓값 **0.95m**, 부호 **0.32m**였다. 이미지 추적의 개선이 실제 거리로 연결되려면 행 배치도 맞아야 한다. 이 진단의 행은 추론에 사용하지 않았다. ## 코너 후보와 T4/T5 확인

Silverstone 1,200묶음에서 기존 34m 곡률 판독의 영상 경계 대신 충돌 메시 단면을 넣는 오프라인 대조를 했다. 같은 기존 코너 시작 라벨에서 확인 전 우 방향 적중은 영상 **1/13**, 메시 **11/13**이었다. 방향과 거리 ±5m를 함께 맞힌 우회전은 **0→9장**이었다. 기존 영상 경계의 좌회전 후보였던 488·489번은 메시 단면에서 우 18m·우 12m가 됐다. 620·807번은 메시에서도 후보가 없었고, 808·809번은 방향을 맞혔지만 거리 오차가 ±5m를 넘었다. [확인 전 후보](../runs/vision-corner-physics-surface-20261112-01/mesh-oracle.jsonl)

이 후보를 고정 확인 모델에 넣은 진단에서 경계만 쓰는 조건의 우 적중은 **1/13**에 머물렀고, T4/T5 결합은 기존 영상 후보의 **3/13에서 6/13**으로 늘었다. 두 모델에 기존 경보가 없던 프레임에 같은 메시 후보를 주었을 때 T4/T5만 확인한 동시 적중은 우 3장과 좌 1장이었다. 같은 조건의 T4/T5 전용 직선·범위 밖 오경보는 3장, 코너 내부 경보는 93장이었다. 이 결과는 정확한 경계가 제공되었을 때 어느 후보를 기존 T4/T5 특징이 확인했는지 보여주는 진단이며, 기존 영상 추론 경로의 적중 개선을 나타내지 않는다. ## 학습용·평가용 라벨 내보내기

Silverstone 1,200장, Spa 1,200장, Magione 1,887장에 차량 좌표의 좌우 단면과 네 카메라의 영상 투영을 내보냈다. 바로 옆에 비유효 표면이 확인된 좌우 쌍은 각각 19,435·12,453·31,420개다. 원본 프레임 키·메시 해시와 배열을 검증했고, Silverstone 우회전 13장의 전방 좌표는 별도 진단 결과와 일치했다. 화면 안 투영 여부와 인접 표면 확인 여부를 따로 담았다. 투영이 화면 안에 있어도 물체로 가려져 있을 수 있다. 앞쪽 2–34m 단면이므로 후방 화면의 대응점은 없었다. 라벨 내보내기 단계에서는 새 가중치 학습과 추론 입력 연결을 하지 않았다. 이후 이 라벨로 학습한 모델을 학습에서 제외한 Silverstone 영상으로 평가했다.
