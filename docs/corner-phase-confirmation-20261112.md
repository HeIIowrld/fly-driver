# 현재 코너 상태와 다음 코너 경보 · 2026-11-12

기존 경계·시간 판독이 선택한 후보를 고정한 상태에서, 차가 이미 코너 내부에 있는지 따로 추정했다. 모델은 가까운 단면의 폭·기울기·굽음, 현재 차체 속도·요율 및 연속한 직전 세 프레임의 변화를 사용한다. 미래 프레임이나 지도·절대 위치는 입력하지 않는다. 실제 상태는 개발 네 서킷의 기존 채점 라벨을 사용해 직선·거리 범위 밖, 접근, 코너 내부로 학습했다. 이 출력은 경보를 검토하는 데 사용했다. 사용자에게 제공하는 상태는 직선·좌·우·보류 네 가지다. [입력 및 상태 모델](../runs/vision-corner-phase-confirmation-20261112-01/phase_features.py) · [개발 학습 결과](../runs/vision-corner-phase-confirmation-20261112-01/training.json)

네 개발 서킷을 하나씩 빼고 얻은 점수에서 기존 동시 적중의 90% 이상을 경계·시간 조건과 T4/T5 확인 조건에 각각 남기는 기준을 두었다. 가장 엄격한 공통 코너 내부 확률 상한은 0.96864였다. 교차검증에서 이 기준으로 T4/T5 조건의 방향·거리 동시 적중은 10→9건, 코너 내부 경보는 123→83건이었다. 판독 문턱과 후보는 유지하고 코너 내부 확률이 높은 경보만 보류했다. 두 확인 조건에는 같은 상태 추정값을 적용했다. Silverstone과 Vallelunga Extended는 모델 학습과 문턱 선택에서 제외했다.

Vallelunga 650번에서 실제 시작 **8.33m**에 **우 8.97m**를 예고한 경보를 유지했다. 상태 모델의 코너 내부 확률은 0.340이었다. 실제 우회전 접근인 686번에서 채택됐던 좌 6m는 코너 내부 확률 0.985로 보류했다. 기존 경계 경보를 함께 보존한 Vallelunga의 결합 조건에서도 방향·거리 동시 적중 6장과 안정 예고 2곳이 유지됐고 코너 내부 경보는 87→77건이었다. 기존 제안과의 거리·방향 동일성, 학습에서 두 서킷을 제외한 기록, 시간 순서를 두 영상 2,400프레임에서 검증했다. ## Silverstone에서 남은 한계

Silverstone 접근 24장 중 4장을 접근으로, 19장을 코너 내부로 분류했다. 실제 코너 내부 266장 중 243장은 맞혔다. Vallelunga 접근은 61장 중 20장을 맞혔고, 코너 내부는 426장 중 356장을 맞혔다. 차체가 이미 돌고 있다는 감각만으로는 앞에 새 시작점이 있는지를 충분히 읽기 어려웠다. Silverstone 620번의 우 16m 후보는 상태 모델에서 접근 확률 0.404와 내부 확률 0.337을 받았다. 이 후보가 보류된 직접 원인은 T4/T5 확인 점수 0.651이 기존 문턱 0.849보다 낮았기 때문이다.

코너 내부 확률을 후보 점수에 곱해 낮추는 조건은 Vallelunga에서 코너 내부 경보를 더 줄였지만 우회전 적중도 잃었다. 별도 비교에서 상태 특징을 확인기에 직접 학습하고 개발 자료에서 직선·범위 밖과 코너 내부 경보 한도를 각각 맞췄다. Vallelunga T4/T5 순위 조건은 좌회전 동시 적중 3장, 코너 내부 경보 5건이었고 우회전 적중은 없었다. Silverstone에서는 두 변경 모두 새 동시 적중을 얻지 못했다. 고정 판독기에 적용하지 않았다. 다음 비교는 현재 요율의 방향과 후보 앞뒤 경계의 굽음 변화를 후보마다 대조한다. 몸이 돌고 있는 구간에서도 같은 방향의 회전이 계속되는지, 앞에서 새 굽음이 시작되는지를 구분해 Silverstone의 확인 순서가 개선되는지 검사한다.
