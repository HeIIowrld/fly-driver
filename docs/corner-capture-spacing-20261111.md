# 코너 경계 판독의 캡처 간격 대조 · 2026-11-11

Laguna Seca 기존 원본에서 같은 코너의 연속 프레임 사이 실제 남은 거리는 중앙값 4.25–4.53m 줄었다. Magione에서는 0.40–0.51m였다. 이 차이 중 캡처 간격의 영향을 확인하기 위해 Magione 원본에서 경계 입력만 매 2번째와 매 3번째 프레임으로 줄였다. 각 시작 위상을 모두 시험하고, 같은 평가 프레임에 원래의 경계 이력을 쓴 결과와 짝지어 비교했다. 원본 시계와 차량 몸 감각은 보존했고, 겹눈 유무 점수와 순서형 거리는 기존 출력을 재사용했다. 영상 전체 모델의 프레임레이트 실험은 아니다.

0.24초 이력을 쓴 결과다. 매 2번째에서는 오경보 14개가 두 위상에서 그대로였다. 이력 창을 0.36·0.48초로 늘리는 대조도 원래 이력을 일관되게 개선하지 못했다. 매 3번째에서는 약 195ms가 고정 연속 조건의 180ms를 넘겨 이력이 초기화됐고, 해당 접근 프레임에서 시간 경계를 산출하지 못했다. 이 결과는 시간 간격을 늘리는 실험이며, Laguna처럼 같은 시간에 차량이 더 멀리 이동하는 조건과는 차이가 있다.

## 이동량이 큰 경우 현재 경계 사용

Monza의 학습 제외 접근 14개에서 직전 캡처 이후 로컬 전방 이동량 중앙값은 4.47m였다. 시간 누적 굽음에는 좌·우 후보가 8개 있었지만, 각 캡처의 경계 모양 전체가 굽음에 동의해야 하는 조건에서는 후보가 없었다.

직전 캡처부터 2m 이상 이동한 경우 현재 영상의 경계로 판독하는 개발 대조를 실행했다. Monza에서 방향이 맞는 현재 후보 2개가 나왔지만 이동 확인을 통과한 건 없었다. 기존에 놓친 접근 중 방향 후보와 고정 겹눈 관문을 함께 충족한 프레임도 없었다. 항상 현재 경계를 쓰면 Magione 직선·범위 밖 오경보가 28→65개, Imola는 2→9개였다. 2m 이상에서만 바꾸면 세 자료의 최종 적중·오경보가 그대로였다. 조건을 채택하지 않았으며, 고정한 Zandvoort 촬영·평가에는 변경을 적용하지 않았다.
