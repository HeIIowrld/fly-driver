# 국소 곡률로 읽은 코너 시작 · 2026-11-12

Silverstone 1967과 Spa의 전후좌우 저장 영상 각 1,200묶음을 재생했다. 두 서킷을 제외한 다섯 서킷에서 학습한 경계 패치 체크포인트와 기존 0.55 패치 문턱을 재사용했다. 원래 좌우 경계로 적합 가능한 프레임은 원래 판독을 사용했다. 보류한 프레임에서는 영상 대비 또는 학습 확률로 결측 경계를 보완하고, 12m 창에서 양쪽 경계의 곡률 부호를 대조했다. 연속 두 거리에서 곡률이 같은 부호이고 절댓값이 0.002m⁻¹ 이상일 때 첫 위치를 후보로 삼았다. 카메라나 차량 속도가 유효하지 않은 프레임에서는 이 추가 경보를 만들지 않았다.
