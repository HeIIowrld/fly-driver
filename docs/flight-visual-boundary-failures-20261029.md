# 조향이 나오지 않는 현재 이유와 시각 경계 실험

2026-10-29, Asia/Seoul. 사용자 질문: “조향은 왜 안하는거야”.

현재 학생 모델을 차량 제어에 연결하지 않았다. 마지막 읽기 전용 CSP 상태 확인은
`paused=true`, `ai_controlled=false`, `expert_probe_active=false`, `camera_active=false`,
속도 0.009475km/h, generation `4525688ULL:0.0012764`였다.
따라서 지금 화면에서 조향하지 않는 직접 이유는 제어 주체가 실행되지 않는 것이다.
실제 조향·페달 인터페이스의 과거 응답 확인과, 학습 모델의 운전 능력은 구분한다.

학생을 연결하지 않은 이유는 시각 일반화 실패다. 학습 구간 오차는 감소하지만,
알려진 개발 구간의 앞길 방향 예측이 단순 TRAIN 평균/0방향 기준보다 나쁘다.
아래 실험은 모두 오프라인 시각 보조 경계 학습이며 실제 조향·가감속 정책 학습이나 주행 성공이 아니다.

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.**
일반 운전 모델로 이 대전제를 대체하지 않는다.

후보 선택은 개발 성적을 보고 바꾸지 않았다. 마지막200회 checkpoint와 모든 개입 결과를 보존했다.
원래 개발 자료를 반복 확인했으므로 독립 최종 평가로 부르지 않는다.

전방 창 비교는 원본 TRAIN 영상에서 정한 고정 영역 `[x=0..1, y=.40...67]`의
실제 뉴런 반응을 4×4로 읽는 공학적 주의 영역이다. 생물학적 중심와나 도로 분할로 부르지 않는다.
광학·원본 픽셀·뉴런 동역학은 그대로이며, 전방만 읽는 조건도 나머지 카메라의 원래 신경 상태를 삭제하지 않는다.
기준 전체 시점 특징을 모든 원본 이력에서2e-6 이내로 재현했다.
채널 정규화는 t1537의 TRAIN 통계를 그대로 사용하고, pooling 후 정규화도 TRAIN만 사용했다.
