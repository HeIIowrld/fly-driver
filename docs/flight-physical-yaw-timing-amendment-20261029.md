2026-10-29. 원래 고정 계획 `configs/flight-physical-yaw-perturbation-v1-20261029.json`과
기존 실행 원자료는 변경하지 않는다.

첫 완료 full/+ 시험(t1162/trial-00)의 원본 감사 t1163에서, 7관측 동안 적용한 조향 교란의
host 요청 간 지속시간이324.37ms였음을 확인했다. 관측 간격 변동 때문에 명목280ms와 다르다.
이 시점에 zero_yaw의 완료된 교란 시험은0개다. t1162/trial-01은 정차 prefix17관측에서
GPU 영상 복사 오류로 중단돼 교란을 적용하지 않았다.

서로 다른 길이의 교란을 회전 억제 차이로 해석하지 않도록, **쌍의 실제 host 요청 지속시간
차이가10ms 이내여야 유효 비교**라는 조건을 추가한다. 기존 위치·속도·baseline yaw·클리핑·
원본 이력·반복 조건과 IAE 개선 기준도 유지한다. 응답값에 맞춰 유효성 기준을 완화하지 않는다.

이 조건은 원래 계획의 일부였다고 소급 주장하지 않는다. 첫 full 시험의 시간 측정 뒤,
첫 완료 zero_yaw 교란 응답을 보기 전에 추가한 엄격한 입력 일치 조건이다.
추가 기준과 각 쌍의 실제 시간 차이는 블록 감사 manifest와 result에 남긴다.
host 요청 시각과 엔진의 정확한 물리 적용 시각도 구분한다.
