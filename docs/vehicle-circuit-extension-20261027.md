# 온도·하중과 전진·정지 경로를 포함한 파리 회로 후보

2026-10-27 KST. **기존 조향 부분망을6,557뉴런·644,512연결의 구조 후보로 확장했다.**
원본 MaleCNS 연결을 추출한 결과이며, 새 회로의 감각 어댑터나 조향·가속·브레이크를 학습한
운전 모델은 아니다. 최종 목표인 겹눈·몸 감각 기반 AC 무개입1랩은 아직 미완료다.

## 뉴런을 고른 근거와 제한

| 역할 후보 | 정확한 선택 | 선택 수 | 해석 |
|---|---|---:|---|
| 온도 입력 | Traced·thermosensory의 TRN_VP2/VP3a/VP3b | 14 | 온도 수용기 경계 후보. 타이어4개와의 대응·개별 튜닝은 공학적 모델로 별도 선언 |
| 하중 입력 | Traced·campaniform sensilla·ProLN/MesoLN/MetaLN | 12 | 다리 신경 진입 경계 후보. 앞·중간·뒤 다리와4바퀴의 대응은 미확정 |
| 조향 출력 | DNa02 | 2 | 기존 조향 후보 유지 |
| 전진 출력 | DNg100, DNg97 | 4 | BDN2/oDN1 대응을 확인한 전진 후보. 자동차 가속 페달과의 상동성을 주장하지 않음 |
| 정지 출력 | AN19A018 중 somaNeuromere T1/T2 | 4 | 불완전한 BRK 관련 후보이며 실험의6개 BRK와 일대일 대응 미확인 |
| walk-OFF 내부 후보 | DNg60 | 2 | Bluebell/BB 대응. 브레이크 페달과 동일한 기능으로 취급하지 않음 |

MaleCNS Cell Type Explorer는 [DNg100=BDN2](https://reiserlab.github.io/celltype-explorer-drosophila-male-cns/types/DNg100_R.html),
[DNg97=oDN1](https://reiserlab.github.io/celltype-explorer-drosophila-male-cns/types/DNg97_R.html),
[DNg60=Bluebell](https://reiserlab.github.io/celltype-explorer-drosophila-male-cns/types/DNg60_R.html)의
대응을 제공한다. [AN19A018](https://reiserlab.github.io/celltype-explorer-drosophila-male-cns/types/AN19A018_R.html)은
BRK 별칭을 포함하지만12개 세포로 범위가 넓다. 현재 주석에서 T1/T2 네 개만 별도 후보로
선택했으며, 복부 세포까지 모두 실험 검증된 브레이크 뉴런으로 해석하지 않는다.

[Sapkal 등의 실험](https://www.nature.com/articles/s41586-024-07854-7)은 걷기 촉진 회로를
억제하는 walk-OFF와 다리 저항을 높이는 brake를 구분한다. BDN2/oDN1은 전진 관련
후보지만, 이 논문이 타이어의 마찰 한계 판단이나 차량 브레이크 제어를 입증한 것은 아니다.
최종 차량 조작으로의 변환은 별도 학습과 폐루프 시험이 필요하다.

[열 감각 연구](https://www.nature.com/articles/s41467-023-42864-5)는 절대 온도와 온도 변화율을
서로 다른 경로에서 처리할 수 있음을 보여준다. 지난 단계의 수준·증가·감소 인코딩은
이런 구분을 시험할 공학적 입력이며 생리학적 응답 곡선을 그대로 복제한 것이 아니다.
공식 주석의 thermosensory25개를 전부 쓰지 않고 위 세 가지 정확한 type의14개를 골랐다.

campaniform 수용기는 기계적 변형에 반응하므로 N 단위 휠 하중을 그대로 뉴런 발화율로
해석할 수 없다. 초파리 뒷다리의 특정 수용기장을 다룬 [2025년 기계 모델 연구](https://doi.org/10.1098/rsif.2024.0559)도
정상 전진 보행의 지면 반력만으로 그 수용기장이 활성화된다는 가정을 지지하지 않았다.
이번 하중 포트는 차량을 가상 신체로 사용하는 기능 가설이다.

## 추출 방법

원본 Traced incoming CSR의 방향은 row=post, column=pre다. 원본 그래프와 주석,
기존2,626뉴런 그래프의 SHA256을 검증했다. 온도14개·다리 하중12개·기존 PFL36개를
시작점으로, 조향2개·전진4개·정지4개를 끝점으로 지정했다.

각 시작/끝 조합에서 **최대4홉 안의 최단 경로를 모두** 포함했다. 동률 경로 중 하나만
고르지 않았으며, 선언한10,000노드 예산을 넘으면 자르지 않고 실패하도록 했다.
경로 합집합4,072개 노드와 기존 부분망 등을 합친 뒤 선택된 노드 사이의 모든 원본 연결을
복원했다. 기존92,740개 연결의 방향·연결량이 그대로 남았는지도 전부 대조했다.

이는 구조적 추출 규칙이다. 가장 짧은 경로가 실제로 그 행동을 주도한다는 가정은 하지 않는다.
644,512연결 중235,488개는1시냅스 쌍이며 약한 연결·미검토 중계 뉴런이 많다.
필요한 회로를 모두 포함했다거나 기능·동역학이 보존됐다는 증거는 아니다.

| 시작 집단 | 조향2개 | 전진4개 | 정지 후보4개 |
|---|---:|---:|---:|
| 온도14개 | 28/28쌍, 2–3홉 | 56/56쌍, 2–3홉 | 56/56쌍, 2–3홉 |
| 다리 하중12개 | 24/24쌍, 2–3홉 | 48/48쌍, 2–3홉 | 48/48쌍, 2–3홉 |
| PFL36개 | 72/72쌍, 1–2홉 | 144/144쌍, 1–2홉 | 144/144쌍, 2–3홉 |

새 입력은26개이고 전체 입력은1,661개다. 원래 시각·chordotonal·haltere 입력은 보존했다.
PFL은 경로 탐색의 시작점으로 썼으며 **새 외부 입력으로 바꾸지 않았다.**
10개 출력 후보를 선언했지만 세 가지 차량 조작을 산출하는 readout은 아직 없다.

원본 전체 incoming 연결량을 그래프 노드 순서의 별도 NPY로 저장했다. 잘린 입력을 남은
연결에 재분배하면 안 된다. 보존한 incoming 비율은 집단 합계 기준 온도96.68%,
다리 하중23.47%, PFL31.22%, 조향67.35%, 전진76.34%, 정지 후보73.07%다.
누락 입력의 효과를 검증하기 전에는 완전한 신경회로 재현으로 부르지 않는다.

## 검증과 산출물

- 경로의 방향·동률 경로 보존·더 긴 우회로 제외·단절·예산 초과를 검사했다.
- 관련22검사와 전체 소스 정적 검사가 통과했다.
- 성공 실행216파일을 수집해 SHA256을 대조했다. 처음 실행은 새 입력을 임시 internal 역할과
  충돌한 것으로 처리하는 코드 오류로 실패했다. 기존 부분망 역할에 대해서만 충돌을 검사하게
  수정했고, 실패한 실행209파일도 수집·보존했다. 신경 선택·홉 예산은 바꾸지 않았다.

설정은 `configs/vehicle-circuit-extension.json`, 실행 코드는
`scripts/audit_vehicle_circuit.py`, 원본 실행 증거는
`runs/vehicle-circuit-20261027-t23b/runs/vehicle-candidate/`다.
실패 원본은 `runs/vehicle-circuit-failed-20261027-t23/`에 있다.

재사용 자료는 `assets/external/malecns-vehicle-candidate-20261027/`에 등록했다.
`vehicle-candidate.npz`, `annotations.json`, `ports.json`, `full-incoming-counts.npy`와
메타데이터의 해시를 복사 전후 대조했다. 전체 경계28MB는 실행 폴더에 보존하고 자산에는
집단별 `boundary-summary.json`을 두었다. 그래프 SHA256은
`5560833a16f198ebc4c051bf8cfbcffa1d96ac6046ff681f40864ef342bf5ff8`다.

다음은 이 후보의 전달물질·부호 검토, 명시적4바퀴→감각 포트 변환, 겹눈 입력 보존,
조향·가속·제동 readout과 오프라인 증류다. 공개 표본에는 동기 영상이 없으므로
추가 자료 확보도 필요하다. 기존 고정 속도 조향 checkpoint를 새 그래프의 운전 모델로
전용하거나 실제 AC에서 주행했다고 표시하지 않는다.
