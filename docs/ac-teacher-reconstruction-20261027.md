## 같은 입력 차원이어도 버전을 맞춰야 한다

현재 검토한 코드 `ef0fa502bdd257fc2affad9361c02b3dbdfe1632`와 달리
2024-10-08 코드 `a90db0a8b164164e11412857b396bf6874462976`는 측방 속도를
20이 아닌 10으로 정규화한다. 조향 상대 요청의 크기·범위도 다르다. 후자의
`legacy_20241008` 설정이 공개 표본의 조작 변환을 정확히 재구성했다.
현재 설정으로 임의 대체하면 조향·가속·제동 출력은 각각 최대 약 0.061·0.135·0.166 변했다.
정확한 학습 실행 manifest는 확보하지 못했으므로 이 일치만으로 학습 commit을 확정하지 않는다.

소스와 수치 참조는 `assets/external/acgym-teacher-recipe-20261027/source.json`,
관측·조작 설정은 `configs/ac-sac-replay.json`에 고정했다.
checkpoint SHA256은 `3f30cbb1b88ea221bf686c28b74d531ababe843da2e9529dc89a8a47aa157e84`다.
공개 pickle은 unrestricted load 없이 제한된 숫자 자료 판독기로 읽었다.

## 영상과 온도·하중 자료의 차이

확인한 표본에는 97개 필드와 네 바퀴 코어 온도·하중이 있다. 영상 또는 인코딩된 영상
후보는 없었다. 이 결과를 공개 전체 데이터셋의 영상 부재로 확대하지 않는다.
현재 표본만으로 겹눈 기반 증류를 시작하면 필요한 시각 관측이 빠진다.
동기 영상이 있는 기존 자료를 찾거나 짧은 교사 주행에서 영상과 센서를 함께 기록해야 한다.

## 학생용 온도·하중 인코더

`ScalarOrganSpec`을 `BodyOrganEncoder`에 명시적으로 추가했다. 센서 계약의 온도는 K,
하중은 N, 순서는 FL/FR/RL/RR이다. 각 채널에 7개 Gaussian 수준 반응과 증가·감소 반응을
만들어 온도 36개·하중 36개, 총 72개 특징을 추가한다. 이는 **차량 감각의 공학적
population code**이며 실제 파리 온도수용기나 하중 수용기의 생리를 측정한 결과는 아니다.

`configs/vehicle-scalar-organs.json`의 범위·폭·변화율은 인코딩 제안이다.
해당 범위를 최적 타이어 온도나 안전 하중으로 해석하지 않는다. 0 N은 유효한 접지 소실
표본일 수 있으므로 결측으로 바꾸지 않는다. 결측·stale·무효 채널은 값 0과 유효성 false를
함께 전달하며, 최초·결측 뒤 복귀·episode reset에서 미분값을 만들어내지 않는다.
동일 시각 재수집은 이전 변화율을 유지하고 값이 바뀌면 거부한다.

기존 인코더에는 새 감각을 자동 추가하지 않는다. `scalar_organs`를 명시한 설정만 확장하며,
정책의 특징 수와 교정 SHA256을 함께 검사해 같은 차원에서 다른 튜닝이 섞이는 것도 차단한다.
현재 MuJoCo bridge가 온도를 만들지 않으면 그 특징은 결측으로 남는다.

별도 합성 회로 시험은 온도·하중이 서로 다른 입력 포트로 들어가 순환 연결을 거쳐 출력에
영향을 주고 학습 gradient가 도달함을 검사한다. **이 합성 포트는 MaleCNS 뉴런 ID가 아니다.**
현재 실제 부분망에는 온도·하중 포트 선정과 전진·제동 경로 검토가 남아 있다.
기존 chordotonal/haltere 포트에 새 특징을 무분별하게 섞거나 출력을 직접 우회하지 않는다.

새 감각 경로의 Windows 관련 검사48개, WSL의 MuJoCo 설정 연동을 포함한 검사49개가
통과했다. 전체 소스 정적 검사도 통과했고 `runs/scalar-organs-20261027/`의201파일을
SHA256으로 대조했다. 이는 감각 변환·설정·합성 회로 경로 검증이며 운전 학습 결과가 아니다.
