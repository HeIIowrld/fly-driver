# 회전 감각 추가 모델과 30km/h 목표 시험

기록일: 2026-10-28, KST. 원본 AC, BMW Z4 GT3, Monza.

최고 속도는 33.647km/h까지 증가했지만 경로 유지 시험은 실패했다. 140회 모델 요청 후 약 29.016m 이동한 지점에서 reference-gap/lateral-clearance 제한으로 중단했다. 30m 목표와 서킷 완주는 달성하지 못했다. 속도 상한 추가 인상이나 후보 승격의 근거로 쓰지 않는다.

## 구현과 학습

- `localAngularVel[1]`을 양·음 회전 감각 두 채널(기관 슬롯 126/127)로 부호 분리하고 tanh로 변환했다. 나머지 미지원 슬롯 128–131은 결측 상태를 유지한다. 절대 방향·위치·트랙 진행률은 actor에 넣지 않는다.
- 축 선택은 t292의 native 회전값과 방향 변화율 비교에 근거한다. 독립 SI 단위 검증이나 실제 파리 생리 검증은 아니다. haltere에 대응시킨 공학적 감각 입력이다.
- t299의 실제 teacher 400개 표본을 원시 native prefix에서 재구성했다(t301). 기존 기관 0–125와 시각·행동·시각 유효성·시간 배열은 그대로임을 확인했다.
- 기존 t240에서 새 회전 입력 열을 0으로 초기화했다(t304). 이후 haltere_L/R 기관 연결부만 6 epoch, 150 optimizer update로 학습했다(t305). 회로·다른 감각 연결부·출력부는 변경하지 않았다.
- 체크포인트 SHA256: `dd5d5e6cab21f9b668f3def9cc4ab6e98af30ba3e2dd627664490d0813d46806`.

## 별도 개발 자료 평가

t303의 75개 표본은 학습 자료와 원시 기록·센서 표본·영상 파일이 겹치지 않는다. 기존 설계 판단에 사용한 개발 자료이므로 최종 독립 시험이라고 부르지 않는다.

| 조건 | 조향 RMSE | 가속 RMSE | 제동 RMSE |
|---|---:|---:|---:|
| 회전 입력 사용 | 0.09570 | 0.09525 | 0.03454 |
| 회전 입력 결측 | 0.10457 | 0.06224 | 0.04174 |

회전 감각이 출력에 영향을 주지만 가속 오차는 악화했다. 회전 입력을 가린 결과는 기존 모델 평가와 일치한다. t306은 변경된 텐서가 선언한 두 기관 연결부뿐임을 확인했다. 6,557개 노드·644,512개 연결의 그래프는 그대로이며 전체 파리 뇌를 검증했다는 의미는 아니다.

## 실제 엔진 검증

1. t308: 백그라운드 읽기 전용 추론 100회, 네 영상 모두 유효. 처리 시간 p50/p95/p99는 28.600/35.150/36.735ms였다. 40ms 마감 보장을 의미하지 않는다.
2. t309: CSP API로 재시작·시작 후 정차 상태 조향 보정과 1단 연결. 화면 조작 0회.
3. t310: 30km/h 목표, 40km/h 안전 상한, 30m 목표, 최대 300회 프로필로 주행. 140회 후 경로/여유폭 제한으로 중단. 최고 33.647km/h, 최대 기록 변위 29.016m. foreground 이벤트 0회.
4. t311: 원시 영상·기관 값으로 모델 출력을 재생한 최대 오차는 세 출력 모두 0. 정지 후 가속 0·제동 유지와 vJoy 해제를 확인했다. SDK 응답 시점 오차는 허용 범위를 통과하지 못했으므로 정확한 액추에이터 적용 시각을 검증했다고 말하지 않는다.
5. t312: API 일시정지 완료. 후보는 승격하지 않고 기본 live 입력 선언으로 복구했다.

## 다음 단계

30km/h 부근에서 가속 초과와 경로 여유폭을 함께 학습할 회복 자료가 필요하다. 출발점 한 구간의 400개 표본만으로 속도 유지와 조향을 일반화하기 어렵다. 학생이 실제로 벗어나는 상태에 teacher 목표를 추가하고, 일치하는 제어 주기에서 재학습한 뒤 반복 주행을 비교한다. 반복 경로 유지와 속도 조절을 확인한 다음 속도·구간 길이를 늘린다.

검증: 관련 단위 테스트 15개 통과, 변경 대상 Ruff 검사 통과. 실제 주행 실패를 학습 오차 개선으로 덮지 않는다. 전체 프로젝트 목표는 미완료다.
