# 실제 파라볼리카 구간 수집과 파리 학생 추가 학습

2026-10-28. 기존50개 출발 표본에 부족했던 반대 방향 조향과 코너 시각을 확보했다.
자료는 실제 AC BMW Z4 GT3 / Monza, 전면 영상과 native 기관 값이다. 미러·물리적 시야
보정·노출 동기는 여전히 미검증이며, 교사 코너 주행을 학생의 코너 주행으로 세지 않는다.

## 수집 방식과 실제 궤적

순수 공개 SAC 실행은60/90km/h 초기 시험 상한에 도달해 짧게 중단됐었다. 이번에는 별도
`collection_speed_kmh=70` 교육 조건을 선언했다. 가속 상한은 `(70-speed_kmh)/8`을0–1로
제한한 값, 추가 제동 하한은 `(speed_kmh-70)/15`를0–0.4로 제한한 값이다. 추가 제동이
있으면 가속은0으로 둔다. 교사의 원래 제동이 더 크면 유지하고 조향은 변경하지 않는다.
원래 SAC 절대 요청과 제한 후 요청, 제한 작동 여부를 모두 기록한다. 다음 상대 요청은
실제로 실행한 제한 후 요청에서 누적한다. 미실행 요청을 계속 누적하는 windup은 방지한다.

한 번의 예산을500결정·명목20초로 확장하되 속도 중단90km/h, gap3m, tyres-out 기준,
영상 freshness, 같은 세션 보정·프로필·창·장치·builtin AI guard와 종료 제동은 유지했다.
속도 목표와 중단 상한 간 여유는10km/h 이상 필요하다. 기존 무제한 공개 SAC의 전체 랩
성능을 재현한 실험은 아니다. 교사 루프·governor의 steering 보존·강한 제동 보존·실행
요청 누적·오류 중단 검사12개를 통과했다.

처음에는 현재 위치를 마지막 코너 이후 직선이라고 설명했으나, 이후 CSV 지도와 실제
위치·heading을 대조해 잘못된 해석을 정정했다. 성공 구간은 파라볼리카 코너를 포함한다.
reference 최근접 arc와 게임 spline 거리 차이는 이 구간에서 약4m로, 수백m의 위치
불일치는 관측되지 않았다. 이는 모든 트랙에서의 arc 정합 보정을 증명하지 않는다.

## actor 자료와 학습

`runs/ac-native-parabolica-teacher-20261028-t85/`에500표본을 봉인했다. 전면 유효500,
미러 유효0이고 actor에는 세계 위치·진행률·지도 ray·곡률이 없다. 라벨은 제한 후 실행한
canonical 절대 요청이며, 장치 조향0.6배 변환 전 값이다. `action_provider`에 SAC와
collection governor를 명시했고 원래 공개 모델의 성능이라고 하지 않는다. 원본 실행의
`training_admissible=false`를 보정된 데이터라고 덮어쓰지 않았으며 실험적 host-paired
오프라인 자료로만 분류했다.

`runs/ac-native-two-segment-teacher-20261028-t86/`은 원래50개와 새500개의 정확한 복사
합집합이다. merge 도구에 고정되어 있던 MuJoCo/페달 라벨 없음 설명을 실제 입력
계약·supervision 수에 맞게 수정했다. 원본 manifest와 NPZ 해시를 유지하고 각 출처를
기록했다. merge만으로 원본의 native 실험 여부를 독립 검증했다고 주장하지 않는다.

`configs/ac-native-parabolica-finetune.json`은 이전 로그 배율 학생에서 시작해6epoch를
학습한다. 신경 연결과 회로 파라미터는 고정하며 visual/organs/readout만 조정한다.
새 입력 광도 통계는 학습550개에서만 계산하고, gain은 상속해 추가 RMS 재설정을 하지

분리/출처 변조 검사5개를 통과했다. 학습 및 평가의 최종 결과는 실행 결과 파일을 따른다.

가속 오차는 커졌다. 개발75개 라벨은 원래 SAC 요청이고 새 학습500개에는70km/h

이 이유로 기존 개발 라벨을 바꾸거나 늘어난 오차를 통과로 처리하지 않았다. 전체 성능이
개선됐다고 단정하지 않는다. 제동 오차도0 기준선0.1115보다 조금 크다.
