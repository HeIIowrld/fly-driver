# 측면 카메라의 오른쪽 경계와 Monza 전이 · 2026-11-12

## Silverstone 오른쪽 경계 누락

4–20m 우회전 접근 13장에서 물리 노면 메시의 전환 지점이 카메라에 투영된 오른쪽 경계는 195점이었다. 원본 영상에서 시작하는 고정 판독은 185점을 추정했다. 빠진 10점은 모두 오른쪽 카메라에만 투영됐고 차량 앞 4–12m에 있었다. 고정 카메라 보정으로 계산한 좌표와 메시 투영의 차이는 평균 절댓값으로 가로 0.15px, 세로 0.98px였다. 10점 모두 기준 위치의 ±1m 범위에 영상 대비가 있었다. 투영 지점의 가림 여부는 메시 라벨에서 따로 판정하지 않았다. [프레임별 투영과 대비](../runs/vision-corner-outward-camera-20261112-01/right-camera-audit.json) · [오른쪽 원본 영상 대조](../runs/vision-corner-outward-camera-20261112-01/right-eye-missing.png)

세 조건에서 현재 영상의 유효한 경계값을 그대로 두고 빠진 값만 측면 카메라에서 채웠다. 영상 대비 조건은 같은 쪽 카메라에서 대비가 이어지고 현재 경계의 4m 이내 이웃과 횡좌표가 2m 이내일 때 사용했다. 학습 조건은 Magione과 Spa의 물리 경계로 바깥쪽 카메라의 색 대비와 경계 위치를 학습했고, 같은 이웃 제약을 쓰는 조건도 채점했다. Silverstone과 Vallelunga 영상은 학습에 포함하지 않았다. 학습 문턱은 두 개발 서킷의 제외 교차 평가를 합쳐 평균 횡오차 1.25m 안에서 정했다. 서킷별 오차는 Magione 0.84m, Spa 1.99m로 편차가 있었다. 대비 조건에서 새로 채운 10점 중 9점은 물리 경계보다 도로 안쪽이었다. 전체 Silverstone 영상에서 해당 조건은 오른쪽 메시 표본 709점을 추가했고, 새 관측으로 시간 복원 결과가 바뀌면서 이전에 복원했던 20점은 빠졌다. 추가 오른쪽 점의 평균 횡오차는 1.74m였다. [경계 오차 검증](../runs/vision-corner-outward-camera-20261112-01/side-verification.json)

Silverstone 우 동시 적중은 모든 조건에서 같은 807·808번 두 장이었다. 대비 조건의 같은 후보에 T4/T5를 추가하면 직선·범위 밖 경보는 16→15건, 내부 경보는 1→2건이었다. Vallelunga 대비 조건에서는 우 동시 적중이 3→6장, 직선·범위 밖 경보는 15→11건, 내부 경보는 5→11건이었다. 이전 Vallelunga T4/T5 조건과 비교하면 우 적중 5→6장, 직선·범위 밖 경보 5→11건, 내부 경보 10→11건이다. 추가 경계의 안쪽 편향과 경보 변화가 남아 기존 고정 판독기에는 적용하지 않았다. ## Monza 두 랩의 고정 판독 평가

현재 판독기의 학습에서 제외한 Monza의 기존 두 랩 3,152프레임을 원본부터 처리했다. 보존된 접근 라벨 989장 중 4–20m는 좌 24장과 우 42장이었다. 경계 기반과 T4/T5 결합은 같은 후보를 사용했다. 동시 적중은 방향과 시작 거리 ±5m를 함께 맞힌 프레임이다.

| Monza | 좌 동시 적중 | 우 동시 적중 | 범위 밖 경보 |
| --- | ---: | ---: | ---: |
| 경계 기반 | 0/24 | 3/42 | 8/923 |
| 경계와 T4/T5 결합 | 0/24 | 4/42 | 25/923 |

T4/T5가 추가로 맞힌 950번은 실제 우 14m에 우 11.74m를 확정했다. 범위 밖 경보를 2건 줄였고 19건을 추가했다. 추가된 19건 중 7건은 실제 코너가 20m 밖에 있었고, 12건은 기존 라벨 거리 범위 안에 다음 시작점이 없었다. 기존 라벨이 코너 내부를 제외하므로 이 평가에서는 내부 경보와 물리 경계 오차를 채점하지 않았다. 두 랩은 이전 연구에서 이미 사용한 녹화다.
