# 재구성 겹눈 광학축의 관측·주행 연결

기록: **2026-10-27, Asia/Seoul**. 차량을 가상 신체로 삼고 차량 움직임을 기관 입력으로 되먹임한다는 사용자 목표에 맞춘 부품 검증이다. 실제 Assetto Corsa 주행이나 전체 초파리 신경계의 재현 결과는 아니다.

## 연결한 부분

저자 μCT 자료에서 가져온 좌857·우852 광학축을 `MuJoCoSensoryBridge`에 연결했다. 원본·가공·라이선스·해시는 [자료 등록부](../configs/eyemap-t4-source.json)에 있다. 머리→차체 회전은 명시한 단위 회전이며 카메라의 yaw/pitch를 축에 다시 적용하지 않는다. 현재 카메라와 같은 두 가상 눈 원점을 사용하고 수용각의 Gaussian sigma는 **측정치가 아닌 1도 가정**이다.

현재 카메라에 덮이는 방향만 유효하다. 좌460/857, 우446/852가 관측되며 나머지는 무효·0으로 남긴다. packing은 좌우 최대 길이857에 맞추므로 우측 끝5개는 무효 padding이다. 실제 눈의 시야를 다 관측하거나 각 소안의 공간적 원점까지 재현한 모델은 아니다.

입력 배열·방향 지도가 달라져 기존 합성 격자의 가중치를 재사용하지 않았다. [새 설정](../configs/sensory-anatomical-eye-pilot.json)으로 관측과 시각 readout을 다시 만들고 회로 checkpoint를 별도로 저장했다. 합성 격자 고정 모델의 이전30/30 결과는 [이전 기록](routed-repeat-eye-import-20261027.md)으로 유지한다.

## 비교 조건과 정지 자세 진단

기존과 동일한300개 자세에서150개 훈련·150개 미관찰 위치 시험을 사용했다. 훈련 자료로만 정규화하고 ridge strength0.1을 고정했다. 기존 합성 격자 자료와 정답 label·몸 감각 입력이 모두 정확히 같다. actor는 영상과 허용된 몸 감각만 받으며 label은 오프라인 readout fitting 및 평가에 분리한다.

| 입력 | 횡오차 RMSE(m) | 방향 RMSE(rad) | 교사 조향 의도 RMSE |
|---|---:|---:|---:|
| 재구성 축의 시각 | 0.056990 | 0.018522 | 0.053156 |
| 몸 감각만 | 0.748435 | 0.126145 | 0.844983 |
| 시각+몸 | 0.056865 | 0.018511 | 0.053124 |

이 시험은 정지한 자세의 정보량을 확인한다. 생물학적 계산이나 연속 주행 성공을 증명하지 않는다. 시각 모델은 RGB 선형 readout이며 개별 광수용 뉴런과 MaleCNS 뉴런의 대응은0개다.

## 주행 결과

고정1.5m/s·평탄한 개발 도로의 조향 시험이다. 가속·제동 과제와 AC 서킷 랩은 포함하지 않는다. 같은 개발4조건에서 다음 결과를 얻었다.

| 모델·조건 | 완료 | 조건별 횡오차 RMS의 평균(m) |
|---|---:|---:|
| 새 겹눈의 시각 ridge 직접 조향 대조군 | 4/4 | 0.074816 |
| 새 겹눈→927뉴런 부분 회로+몸 피드백 | 4/4 | 0.136934 |
| 같은 회로 checkpoint, 영상 제거 | 0/4 | 1.352197 |
| 같은 회로 checkpoint, 측정 연결 절단 | 0/4 | 1.352575 |

회로 절단에서는 retinal signal이 남아 있어도 두 출력 뉴런과 조향이 정확히0이다. 완주한4조건은 새 학습 시드 반복이나 미관찰 코스 시험이 아니다. 이전 합성 격자 회로의 같은 개발4조건 평균0.094716m보다 오차가 커졌으므로 해부학적 축 도입을 성능 개선으로 주장하지 않는다. 시각 readout을 다시 fitting한 비교이며 눈 구조만의 인과 효과도 확정하지 않는다.

## 검증과 남은 관문

전체 WSL CPU 테스트 **137개 통과(26.72초)**, 정적 검사 통과. 새 통합 검증은 머리 좌표 보존, 뒤쪽 광선 무효화, 비대칭 눈 padding, 해시가 다른 checkpoint 거절, 불규칙 축을 합성 retinotopic grid로 처리하지 못하도록 한 계약을 검사한다.

시각 readout은 여전히 조향 의도를 추정해 잘린 PFL 경계에 넣는 공학적 어댑터다. 927뉴런의 측정 연결 구조를 거친다는 사실이 상류 시각엽·CX 계산의 재현을 뜻하지 않는다. 기관 선호도·회로 부호·시간 상수도 검증된 생리학적 모델이 아니다.

다음 순서는 [연구 계획](research-plan.md)의 관문을 유지한다.

1. 시각엽·CX 입력/출력 유형과 실제 연결 경계를 검토하고 현재 조향 의도 readout을 대체한다. 방향·운동 자극과 연결 절단/재배선 대조를 수행한다.
2. 실제 AC 설치 PC/경로가 확인되면 영상·계측·조작 응답을 동기 기록한다. 현재 설치 점검에서는 엔진을 발견하지 못했고 게임 연결은 미구현이다.
3. 기관별 지연·부호·유효 대역을 검증하고 속도·제동 출력을 추가한다. 이후 AC 구간→무개입1랩→새 학습 시드 반복으로 진행한다.

이 단계에서 A1/A2/A3/A4 또는 최종 목표를 완료로 바꾸지 않는다.
