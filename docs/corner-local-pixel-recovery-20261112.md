# 도로 폭 후보 주변에서 영상 전환점 찾기 · 2026-11-12

이웃 단면의 폭과 반대쪽 관측으로 제안한 누락 경계의 ±0.75m를 0.25m 간격으로 탐색했다. 위치별 안쪽·바깥쪽 명도와 중앙 기울기를 전방과 해당 측면 카메라에서 측정했다. 띠 전체가 같은 화면에 들어올 때만 사용했다. 명도 차가 큰 위치를 고르는 방식과, 명도 차와 중앙 기울기가 함께 큰 위치를 고르는 방식을 비교했다. 원래 관측과 기존 복구점은 보존했다. [탐색 코드](../runs/vision-corner-local-pixel-recovery-20261112-01/local_transition.py)

Imola·Laguna Seca·Zandvoort·Mugello를 하나씩 제외하고 기존 경계 선택기를 학습했다. 추가 경계점의 횡오차 1.25m를 기준으로 정확한 복구와 부정확한 복구를 셌다. 부정확한 복구에 두 배 비용을 주면 개발 영상에서는 새 점을 추가하지 않는 조건이 선택됐다. 정확한 복구와 부정확한 복구에 같은 비중을 주는 별도 비교에서는 중앙 기울기 문턱 80이 선택됐고, 개발에서 추가한 12점 중 7점이 정확했다. 두 비교의 문턱은 시험 영상의 채점에 앞서 개발 기록에서 정했다. [두 배 비용 설정](../runs/vision-corner-local-pixel-recovery-20261112-01/training.json) · [같은 비용 설정](../runs/vision-corner-local-pixel-recovery-20261112-01/equal-cost/training.json)

같은 비용의 설정으로 Silverstone 우회전 접근에서 오른쪽 누락 10점 중 1점을 추가했다. 620번의 전방 10m에서 우측 화면이 지지한 경계의 횡오차는 0.43m였다. 1049번의 전방 10m에서는 폭 후보에서 횡좌표를 0.25m 옮기면 오차가 0.34→0.09m로 줄었다. 이 위치의 점수는 29.56으로 동결 문턱 아래여서 채택하지 않았다. 두 점 모두 우측 화면을 사용했다. Silverstone 전체에서는 18점을 추가했고, 물리 라벨과 겹친 오른쪽 3점은 모두 1.25m 이내였다. 나머지 추가점의 정확도는 라벨이 없어 확인하지 못했다.
