## 새 공간 구간의 실제 시험

`t527`은 기존 정차 위치를 보존하고 API 재개·조향 계측·1단 확인을 완료했다. 게임 세션 재시작은 없었으나 새 actor 실행은 신경 상태를 명시적으로 초기화한다. 따라서 앞선 t523과 연속 신경 상태의 완주로 취급하지 않는다.

`t529`는 같은 t499 모델로816개 요청을 실행했다. 새 시작점에서 마지막 피드백까지 변위192.26868m, 최고 속도28.13644km/h였다. 게임 진행률은0.9015255에서0.9385194로 증가했으며 SDK 트랙 길이 기준213.03544m의 구간 진행이다. 좌표 변위와 게임 경로 진행을 구분한다.

마지막 피드백에서 바퀴 이탈1개로 course_240m의0개 기준을 위반해 중단했다. 당시 속도24.72845km/h, 기준선 간격6.24723m, 도로 여유 폭1.30409m였다. 전체 시험의 최소 여유 폭은1.10814m였다. camera 오류는 없었으며852그룹·379,094,368바이트의 원본을 보존하고 해시를 확인했다. 이 시험은 후속240m 목표에 도달하지 못했다.

`t530` API 일시 정지와 `t531` 정확 재생을 완료했다.816개 출력 모두 원본 픽셀·몸 감각 재생의 최대 차이0이었다. 위치/경로가 actor에 들어가지 않았고 교사 명령도 사용하지 않았다. 정차·vJoy 해제·전면 UI 조작0을 확인했다. 현재 차량은 바퀴가 코스 밖으로 나간 종료 위치에 있으므로 다음 주행은 시작 위치에서 재시작한다.

## 읽기 전용 API 권한 확인

전체 코스의 실행된 전문가 자료 수집 가능성을 확인하려고 Lua 상태 서비스에 두 getter만 추가했다: `car.isAIControlled`, `physics.allowed()`. false와 조회 불가(nil)를 구분하고 조회 오류가 lifecycle 서비스를 막지 않도록 처리했다. 실제 Lua 실행과 lifecycle 검사13개 및 Ruff가 통과했다. 자동운전 setter가 호출되지 않음도 검사했다.

`t540`에서 신선한 pause/brake hold, camera idle, vJoy FREE, 원본 offline engine과 설치/소스 해시 일치를 확인했다. 최초 배치 검증은 CRLF/LF 차이 때문에 설치 전에 중단됐다. 줄바꿈을 정규화한 코드 내용의 허용 변경만 비교하도록 수정한 뒤, `t541`에서 기존 설치 파일을 백업하고 atomic 교체했다.13개 시험을 통과한 getter 외의 의미 변경은 허용하지 않았다. 카메라 상한·광학·조향·페달·AI 제어 코드는 바꾸지 않았다.

- 이전 Lua SHA256: `f69be0c42ead204d949a4587118020f7977b14d2879d08e062951b32a175ac0e`.
- 새 Lua SHA256: `4859bb0424f76fba3fe0a6f78a08b8ee271263eefcf3cb28a4bfcd31bc8c5b6e`.
- 같은 엔진에서 app live reload 확인. generation은 `5836050ULL:0.0005521`에서 `5836050ULL:0.0008884`로 변경됐다.
- `t542`의 실제 읽기 전용 상태: **ai_controlled=false, physics_api_allowed=true**.
- paused=true, 가속0, 브레이크1, 카메라 비활성, lifecycle 오류 없음, 전면 창 아님.
- 이번 배치의 lifecycle 요청·조작 메시지·전면 UI 조작은0이며 트랙/차량 물리 파일도 바꾸지 않았다.

전역 물리 API 허용은 실제로 확인됐지만 자동운전 활성화·속도 제한 setter의 작동이나 안전한 종료는 아직 검증하지 않았다. 향후 기본 AI를 전문가 자료 수집에 사용하려면 별도 유한 lease/종료 감시, 속도 제한 및 브레이크 응답을 검증하고, AI 자료와 student의 독립 유효 랩을 명확히 구분해야 한다. 설치된 SDK 설명상 자동운전 활성화는 랩을 무효화한다. 이 조회 결과를 student 완주나 전문가 수집 구현 완료로 취급하지 않는다.
