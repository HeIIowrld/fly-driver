## 서킷 제외 결과

평가 서킷은 학습과 문턱 선택에서 제외했다. 문턱 선택 자료의 예측도 그 서킷을 학습에서 빼고 만들었다. Spa는 모든 학습·문턱 선택에서 제외했다. 개발 서킷에서 기존 좌·우·결합과 안정 예고 수를 유지하고, 직선·범위 밖 오경보 한도 안에서 좌 안정 예고를 우선했다. 여섯 서킷에서 세 방식 모두 경보를 추가하지 않는 조건이 선택됐다. 거리 변화와 미출력 수는 기존 고정 판독과 같았다.
