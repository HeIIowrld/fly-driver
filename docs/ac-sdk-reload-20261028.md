## 조작·종료 상태

`runs/ac-sdk-reload-session-20261028-t50/`의 제한된 neutral hold가 로딩 중 가속0·제동1을
요청했다. 총2088개 요청 뒤 `stop` 파일로 명시적으로 종료했고, 마지막 neutral 요청 후
장치 소유를 해제했다. 스크립트는 이 명시적 중단을 종료코드1과 `Explicit stop file received`로
기록한다. 예상하지 못한 크래시로 해석하지 않는다. `begin-probe`는 만들지 않았으며
이 실행에서 정차 축 probe나 SAC 주행을 시작하지 않았다.

현재 준비 화면에서 사용자 창 활동이 감지돼 추가 전면 조작을 중단했다. 마지막 백그라운드
센서는 조향0·가속0·제동1, 속도 약0.001km/h였다. 창을 주기적으로 활성화하지 않는다.

## 새 세션의 준비 메뉴 확인

요청 ±0.6에도 SDK/native 조향이 모두0이었다. 가속 요청은0·제동1이었으며 최대 속도는

확인했다. 루틴이 `completed`라는 것은 기록 종료를 뜻하며 조향 보정 성공을 뜻하지 않는다.

정확한 AC 창 원본 이미지 `runs/ac-driving-readiness-image-20261028-t51b/preview.png`에서
차량 준비 메뉴가 계속 떠 있는 것을 확인했다. 화면 일부가 바깥으로 나가 왼쪽 Drive 아이콘이

이를 관리자 권한 차이로 단정하지 않는다. 실패한 조작을 성공으로 기록하지 않는다.

추가 키 입력을 멈추고 게임 엔진을 런처 뒤로 두었다. 사용자가 직접 Drive(왼쪽 빨간 핸들)
버튼으로 조종석 화면까지 진입할 수 있는지 요청했다. 가속이나 수동 운전을 요청하지 않았다.
