# 학습 경계 후보의 확인기를 다시 학습 · 2026-11-12

Magione·Spa에서 이미 고정한 형상 모델로 Imola·Laguna Seca·Zandvoort·Mugello의 저장 영상 4,200프레임을 재생했다. 경계 모델이 이 네 서킷을 학습한 이력은 없다. 실제 판독과 같은 34m 단면을 만들고 기존 국소 곡률에서 후보 하나를 꺼냈다. 두 확인 모델이 함께 사용할 수 있는 후보 2,565개 중 기존 공통 채점에서 방향과 거리 ±5m를 모두 맞힌 후보는 49개였다. 나머지에는 코너 내부·직선·범위 밖·방향 오판·거리 오판을 포함했다. 지도는 기존 채점 라벨을 구성하는 데 쓰였고 확인 모델의 입력은 아니다. [학습 데이터와 확인기 고정 기록](../runs/vision-corner-shape-confirmation-20261112-01/training.json)

경계 확인 모델은 같은 후보 주변의 좌우 굽음, 폭, 적합 오차와 직전 후보를 사용했다. 결합 모델은 여기에 같은 프레임의 고정 FlyVis T4/T5 움직임 특징을 12개 주성분으로 추가했다. 두 모델의 공통 후보는 T4/T5 특징까지 검증된 프레임에서만 비교했다. 네 서킷을 하나씩 빼고 얻은 점수로 문턱을 정했다. 직선·거리 범위 밖 1,660프레임 중 오경보 83건 이하라는 상한을 두었다. 교차검증에서 방향·거리 동시 적중은 두 모델 모두 9장이었고, 오경보는 경계 48장, 결합 70장이었다. 문턱을 각각 0.788과 0.816으로 고정한 뒤 Silverstone과 Vallelunga Extended를 재생했다. 두 평가 서킷은 경계·확인 모델의 학습과 문턱 선택에서 제외됐다. 두 영상 모두 이전 개발 과정에서 분석한 적이 있다.

## 고정 문턱으로 2,400프레임 재생

| --- | ---: | ---: | ---: | ---: | ---: |
| Silverstone | 4/13 | 0 | 0 | 4→5 | 2→0 |
| Vallelunga Extended | 9/38 | 0 | 0 | 3→8 | 20→15 |

표의 경보는 새 후보만 채점한 결과다. Silverstone은 528개, Vallelunga는 650개 후보에서 두 점수를 모두 얻었다. Silverstone 접근에서는 두 모델 모두 새 후보를 채택하지 않았다. Vallelunga 361번은 실제 우회전 시작이 15.54m인데 두 모델 모두 우 6m를 채택했다. 726번의 실제 좌회전에는 결합 모델만 우 19m를 채택했다. 따라서 코너 내부 경보는 줄었지만 새 우회전의 방향·거리를 함께 맞힌 사례는 없었다. [Silverstone 프레임별 결과](../runs/vision-corner-shape-confirmation-20261112-01/silverstone-frames.jsonl) · [Vallelunga 프레임별 결과](../runs/vision-corner-shape-confirmation-20261112-01/vallelunga-frames.jsonl)

기존 경계 경보를 양쪽에 똑같이 보존한 경우에도 우 방향 적중은 경계와 결합이 Silverstone 1/13, Vallelunga 2/38로 같았다. 거부한 후보는 판독 보류로 기록했다. 구간을 계산할 수 있는 경계가 충분하고 범위 안 후보가 없으면 직선으로 출력했다. 두 영상에서 같은 후보, 네 판독 상태, 프레임 키 및 모델·입력 해시를 확인했다. [두 재생의 검증 기록](../runs/vision-corner-shape-confirmation-20261112-01/verification.json)

## 어떤 후보를 높게 평가했나

Silverstone 620번의 맞는 우 16m 후보에 붙은 점수는 경계 0.216, 결합 0.132였다. 이 점수 이상인 직선·범위 밖 후보가 각각 250장과 278장이었다. 문턱을 낮추기 전에 이 후보를 다른 후보보다 높게 평가할 근거가 필요하다.

두 평가 영상에서 문턱의 순서를 사후 진단했다. 오경보 수를 직선·범위 밖 프레임의 5% 이하로 같은 수준에 맞추면 Silverstone의 우회전 동시 적중 최대는 두 모델 모두 1장이었고, Vallelunga는 모두 0장이었다. Vallelunga에서 10%까지 허용하면 우회전 동시 적중 최대는 경계 2장, 결합 4장이었다. Silverstone의 같은 진단은 1장씩이었다. 이 진단의 문턱은 실제 판독에 적용하지 않았다. [오경보 한도별 순위 검증](../runs/vision-corner-shape-confirmation-20261112-01/verification.json)

새 확인기는 고정 판독기에 채택하지 않았다. 네 학습 서킷에서 동시 적중 후보가 49개였고 Laguna Seca는 교차검증에서 두 모델 모두 동시 적중이 없었다. 다음 학습에서는 후보 하나만 남기기 전에 대안 후보와 시간적으로 일관된 접근을 같이 기록해, 올바른 후보와 같은 구간의 오판을 직접 비교할 수 있게 한다.
