# 여러 도로 경계 경로의 코너 시작 일치 · 2026-11-11

여섯 서킷의 저장 영상 7,287묶음에서 학습한 경계 패치 점수를 다시 계산했다. 각 평가 서킷을 학습에서 제외했고, Spa는 모든 학습에서 제외했다. 동일한 후보 격자에서 경계 연속성의 가중치 0.25·0.45·0.60·0.85·1.10을 적용해 다섯 경로를 얻었다. 0.60의 모든 시작점 제안이 이전 실행과 일치함을 검증했다. 이 경로들은 같은 영상 점수와 후보를 공유한다. 같은 방향의 시작 거리가 3m 범위 안에 든 경로가 세 개 이상이면 시작 거리와 점수의 중앙값을 사용했다. 별도로 세 경로 이상에서 같은 위치의 경계가 일치한 단면만 남긴 뒤 시작점을 계산했다. 새 경보의 주 비교 문턱은 이전 학습 경계 실험과 같은 0.04였다. 지도와 절대 위치는 학습 라벨 및 채점에만 사용했다.
