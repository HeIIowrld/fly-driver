# 카메라 운동 반응의 차량 기준 해석 — 2026-10-29

[대전제](PROJECT_CHARTER.md)의 여러 시각 입력을 비행 감각운동 구조로 합치는 단계다.
고정한 flyvis T4/T5 반응에서 차량 기준 회전/상대 병진의 단서를 읽는 기능 어댑터를 구현했다.
실측 HS/VS 뉴런의 연결이나 생체 회로를 재현했다고 주장하지 않으며, 아직 비행 운동망에 연결하지 않았다.

## 구현과 정보 경계

`src/flybrain_drive/visual_self_motion.py`는 네 시점의 망막별 T4/T5 반응을 받는다.
저자 방향표대로 a/b의 좌우 상대 반응, c/d의 상하 상대 반응을 읽고,
각 카메라의 차량 기준 ray와 투영 Jacobian에서 회전3축·병진3축의 시각 흐름 패턴을 계산한다.
이 패턴과 신경 반응을 합쳐6개 시각 특징을 만든다. 네 시점의 기여는 이 차량 기준 패턴에서 합쳐진다.

이어42계수의 affine ridge 변환으로6개 좌표를 보정한다. **저자 시각 회로의 가중치는 고정**했고
이 작은 출력 변환만 CPU의 폐형식 계산으로 학습했다. 신경 반응 생성은 GPU에서 수행했다.
T4d 세포 이름·극성이나 원본 연결을 결과에 맞춰 바꾸지 않았다.

출력의 회전 좌표는 합성 자극의 rad/s에, 병진은 속도/합성 구면 반지름에 맞춘 값이다.
실제 게임의 거리·깊이를 모르는 상태에서 병진 출력이 차량 m/s라는 주장은 하지 않는다.
모든 출력은 우선 시각 운동의 기능적 단서다. 실측 몸 각속도·가속도와 구분한다.
지도·레이싱 라인·게임 world pose·교사 조작을 입력이나 보정 정답으로 쓰지 않았다.

## 알려진 3차원 자극

반지름20m의 고정된 절차적 무늬 구면 안에서 카메라를 움직였다.
카메라별 위치는 기존 CSP renderer 진단에서 추출한 서로 다른 위치다. 깊이를 모른 채
영상을 공통 원점의 파노라마로 붙이지 않았다. 자극의 위치는 생성기/정답에만 쓰고
출력 변환기의 입력은 신경 반응6특징뿐이다.

각 텍스처에 정지1+회전3축 양/음6+병진3축 양/음6=13조건을 사용했다.
조건마다41영상 표본,25Hz,최초0.4초 정지 후1.2초 운동이며 내부 신경 적분은5ms다.
서로 다른 자극 조건은 독립 에피소드이며, 각 에피소드 안의 시간 이력은 유지했다.
단일축·일정한 속도와 구면 장면의 시험이다. 혼합 운동·다양한 깊이·AC 도로를 검증한 것은 아니다.

## 실패와 수정, 새 시험의 분리

`t1031` 최초 보정은 정지한 무늬의 잔여 반응이 추정 회전값에 섞였다.
시험12운동의 부호는12/12였으나 주된 축은8/12로 사전 기준10/12에 미달했다.
정지 오차도0.574였고 **보정 통과=false**로 보존했다. 이때 시험을 본 뒤 개발 자료로 전환했다.

개발 분석에서 각 조건의 움직이기 전 정지 반응을 빼면 축 구분이 개선됐다.
이 분석 자체를 새 일반화 증거로 취급하지 않았다.
`t1032`는 정지 prefix의8:11표본 평균을 기준값으로 빼는 정책과
새 학습 텍스처863041/863042, 새 시험 텍스처863043/863044를 실행 전에 선언했다.
학습 각속도0.35rad/s/병진비0.20s^-1, 시험0.23rad/s/0.13s^-1로 속도도 달랐다.
총52조건 중26조건으로 보정하고, 나머지26조건(정지2+운동24)으로 평가했다.

| 시험 텍스처 | 운동 부호 | 주된 축 | 정규화 RMSE | 정지 오차 |
|---|---:|---:|---:|---:|
|863043|12/12|12/12|0.1794|0.1034|
|863044|12/12|11/12|0.2491|0.1197|
|전체|24/24|23/24|0.2171|최대0.1197|

두 시험 텍스처 각각이 사전 기준(부호100%,주된 축10/12이상,RMSE0.75이하,정지 오차0.35이하)을
통과했다. 한 실패는863044의 위쪽 병진+0.13s^-1를 왼쪽 병진으로 더 강하게 읽은 경우다.
실패를 제거하지 않았다. 시험이 작고 장면이 제한적이므로 포괄적 자기 움직임 인식의 증거로 확대하지 않는다.

## 독립 감사와 사용 조건

`t1033`은 저장된 시간별 특징에서 정지 기준/특징을 다시 계산하고,
**학습 조건만**으로 normalization과 ridge를 재구성했다. 정규방정식과 다른 augmented least-squares
계산의 계수 차이는최대8.67e-17이었다. 학습/시험 텍스처 집합도 겹치지 않았다.
시각 특징을 전부 제거한 고정 변환기의 RMSE는0.3982로, 정상0.2171보다 나빴다.
이는 이 작은 변환기의 시각 입력 의존성 검사이며 전체 비행 신경 경로 제거 시험이 아니다.

`CalibratedVisualSelfMotion`은 통과하지 못한 보정·해시 변경·다른 카메라 투영·정지 기준 미준비를 거부한다.
`StationaryMotionReference`는 신선한 native 몸 센서에서 속도/바퀴 회전/각속도가 정지 범위일 때만
새 capture와 native packet을 모은다. 최소11개 고유 표본과0.4초가 필요하며 마지막3개 특징을 평균한다.
반복 capture로 기준을 채우거나, 단지 원하는 속도가0이라는 이유로 정지를 가정할 수 없다.
새 에피소드에서는 명시적으로 기준을 reset해야 한다.

관련9검사와 Ruff가 통과했다. 기하 패턴을 유한 차분으로 대조하고,
비정상 신경 값·미통과 보정·미준비 기준을 거부하는지도 확인했다.
이는 실제 게임의 정지 기준 수집/시각 각속도 정확도를 검증한 결과는 아니다.
