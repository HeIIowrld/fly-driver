## 수집기와 원본 검증

`scripts/record_ac_engine_ai_probe.py`에명시적 `--shared-transport --image-format bmp` 경로를 추가했다. 카메라 목표 간격40ms,최대1200그룹/53초/1GiB를 유지한다. 네 시점·망막/기관 보정·실제 원본 시각을 바꾸지 않는다. 상태 내용과수정 시각은 같은 열린 파일의 json.load/fstat으로 읽는다. 임시 파일 교체의 재시도만 허용하며 같은 제어 요청을 다시 보내지 않는다.

원본 감사는 기존 RGB/native 재생에 원래 source clock bounds 재구성,메타데이터 해시,원본 렌더 시각,공유 texture/copy/ACK검사를 추가했다. 관련177개 검사와Ruff가통과했다. 네 기록은 원본감각배열 전체의 최대오차0을 확인했다. 학생/교사 actor에포즈나지도입력을추가하지않았다.

## GPU 배치 설정 정정

최초t912는기존source806에서같은자료/seed863005/16epoch/길이128/시각·기관·readout 학습을시작했다. 그러나 `episodes_per_batch:6`의기존구현은길이가같은에피소드만묶어많은작은배치가순차실행됐다. 이는예상한6개길이혼합배치가아니었고epoch약49~50초였다.

소유PID53356과명령행을확인한뒤6epoch에서중단했다. `resource-stop.json`과status stopped결과를남겼고checkpoint는없다. 중단기록·입력·기존모델은보존했다. 다른프로세스는중단하지않았다.

기존지원기능인 `episodes_per_batch:null`로12개를한번에계산하는t913 GPU순전파/역전파측정은유효1409관측당중앙1.013초,초당1391.07관측,최대텐서3012523008bytes였다. 모든파라미터/기울기는RX9070XT의cuda:0,기울기는유한했다. optimizer업데이트0이고전체epoch측정은아니다. 종료뒤어댑터전용메모리는약5.57GB였다.

패딩은배치계산에만쓰고inactive mask로끝난에피소드의수치상태를유지한다. 새관측을데이터에넣거나신경상태를중간리셋하지않는다. 새t915는같은초기체크포인트·자료·seed·손실·16epoch예산에서배치정책만기존null로바꾼별도실행이다. 부동소수점집계순서가달라질수있으므로중단실행과수치동일모델이라고주장하지않는다.

설정은 `configs/ac-shared-engine-ai-fullbatch-training.json`,고정런타임t914,실행은 `runs/ac-shared-fullbatch-training-20261029-t915`다. 연결그래프와감각보정은고정하고학습뒤다시대조한다. 실제게임수집과GPU학습은순차로실행한다. 모델승격은별도주행시험후판정한다.

## GPU 배치 변경 결과

새 t915는 16에포크를 완료했다. 에포크 중앙값은 11.683초, 중단한 t912의 6에포크 중앙값은 49.502초로, 동일 자료의 에포크 처리 시간이 4.24배 빨라졌다. 16에포크 계산 시간 합은 187.69초다. 초기화·입출력 시간은 이 합에서 제외한다.

학습 텐서 최대 할당은 4.766GiB (5117851136bytes)였다. 이는 전체 어댑터 메모리나 GPU 가동률이 아니다. 파라미터와 기울기는 모두 cuda:0의 AMD RX 9070 XT에 있었다. 연결그래프·감각보정은 기존 모델과 정확히 같고 변경된 가중치는 adapter/readout에 한정됐다. 체크포인트 및 자료 해시도 일치했다.

학습 자료에서 조향 RMSE는 0.13303→0.12126, 가속 RMSE는 0.06734→0.06842였다. 가속해제 가중 RMSE는 0.02708→0.02058로 줄었다. 일반 가속 오차는 증가했으므로 모든 출력이 개선됐다고 해석하지 않는다. 제동 양성 자료가 없고 실제 주행 검증 전이므로 모델을 승격하지 않았다. 상세 기록은 t915의 result.json, checkpoint-integrity.json, resource-comparison.json이다. 새 공유 자료의 원래 에피소드 재생 비교(t916)도 완료했다. 이는 학습 적합도 검사이며 독립 주행 시험이 아니다.
