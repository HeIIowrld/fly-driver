# 학습한 영상 패치로 Silverstone 오른쪽 경계 보완 · 2026-11-12

기존 지도 투영 패치의 학습 방식을 재사용했다. Imola, Laguna Seca, Zandvoort, Magione, Mugello의 학습 패치 해시를 확인했고 Silverstone 1967과 Spa는 제외했다. 패치 모델은 각 후보의 안쪽에서 바깥쪽까지 다섯 지점의 Lab 색을 읽고 경계 확률을 낸다. 지도와 절대 위치는 과거 학습 라벨과 이번 횡오차 평가에 사용했다. 추론에는 영상과 고정 카메라 배치를 넣었다. 모델 체크포인트를 저장하고 패치 문턱 0.55와 경보 확인 문턱 0.25를 기록했다. Silverstone과 Spa의 영상은 앞선 개발 진단에 이미 사용했다. [기존 학습](corner-learned-edge-20261111.md) · [학습과 재생 코드](../runs/vision-corner-learned-silverstone-20261112-01/replay_learned.py) · [모델과 입력 해시](../runs/vision-corner-learned-silverstone-20261112-01/frozen.json)

기존 판독이 보류한 프레임만 보완했다. 비교 대상은 독립 영상 대비 보완, 학습 확률로 좌우 경계 전체를 연결한 보완, 관측된 경계는 보존하고 비어 있는 쪽의 후보를 학습 확률로 고른 보완이다. 마지막 방식은 반대쪽 경계가 보이는 단면에서 폭 3–20m에 들어오는 후보를 대상으로 한다. 이 영역에서 학습 확률과 영상 대비를 모두 요구하는 조건도 같은 체크포인트로 재생했다. T4/T5 비교에서는 같은 경계 후보의 굽음 방향을 경계 모델과 경계에 세 프레임 T4/T5를 더한 모델이 같은 문턱으로 확인했다. 경보의 거리와 방향은 두 모델 모두 같은 경계 후보에서 가져왔다. [영상 대비도 요구한 조건](../runs/vision-corner-learned-silverstone-20261112-01/contrast_supported.py)

앞선 진단의 지도 경계 적합을 다시 대조했다. 코너 ID 0의 621~623번에서 지도 경계를 빠짐없이 주면 같은 적합기가 각각 16m, 12m, 11m 우회전을 제안했고, 실제 시작은 각각 14.40m, 10.17m, 6.02m였다. 620번에서는 지도 경계 전체로도 이 적합기가 경보를 내지 않았다. 지도 경계 결과는 이 구간에서 시각 경계 추정과 시작점 적합의 한계를 구분하는 진단이다. Silverstone 우 접근 13장에 걸쳐 오른쪽 경계 횡오차를 계산할 수 있는 단면은 기존 48개, 독립 영상 대비 112개, 학습 경계 전체 연결 59개, 학습 확률로 후보를 선택한 조건 88개였다. 각 방식이 출력한 전체 지점에서 지도 오른쪽 경계 대비 평균 절대 오차는 각각 1.82m, 2.24m, 1.65m, 1.83m였다. 방식마다 평가에 들어간 지점이 달라 이 수치만으로 동일 지점의 오차 개선량을 계산할 수 없다. 학습 확률로 보완한 620~623번에서 양쪽 경계가 보이는 단면은 6·8·9·5개였으며 네 프레임 모두 우회전 경보를 내지 않았다. [Silverstone 프레임별 기록](../runs/vision-corner-learned-silverstone-20261112-01/ks_silverstone1967-frames.jsonl) · [전체 채점](../runs/vision-corner-learned-silverstone-20261112-01/result.json)

같은 경계 후보를 비교했을 때 Spa 325번에서 T4/T5 입력이 우회전 경보 한 건을 추가했다. 예측 17m와 실제 9.69m의 차이가 7.31m였다. 범위 밖 경보도 한 건 늘었다. Silverstone에서는 공통 지표가 같았고, 625번 코너 내부에서 결합 모델만 8m 우회전 경보를 냈다. [Spa 프레임별 기록](../runs/vision-corner-learned-silverstone-20261112-01/spa-frames.jsonl)

학습 확률과 영상 대비를 모두 요구하자 Silverstone 우회전 접근의 오른쪽 경계는 86개 단면에서 관측됐다. 해당 지점의 횡오차 평균은 1.81m였다. 좌 5·우 0·동시 적중 4·오경보 3·안정 예고 2였고, T4/T5 입력 유무에서 이 집계가 같았다. Spa에서는 T4/T5가 같은 325번 우회전 방향 한 건을 추가했고 양쪽 모두 동시 적중 0·오경보 3·안정 예고 0이었다. [두 근거를 요구한 전체 재생](../runs/vision-corner-learned-silverstone-20261112-01/contrast-supported/result.json)

대표 접근 620~623번의 학습 확률 보완 경계는 기존 시작점 적합의 단면 연속성 조건을 통과하지 못했다. 경계의 국소 곡률을 따로 읽으면 621번에서 우회전 18m가 나왔고 실제 거리는 14.40m였다. 622·623번에는 같은 방식으로 우회전 경보가 없었다. 대비 보완의 622번에서는 단면 조건을 통과했으나 직선·일정 곡률보다 잘 맞는 굽음 시작점이 없었다. 시작점의 적합 개선 문턱만 내려서는 그 제안이 생기지 않는다. 국소 곡률은 이 다섯 프레임에서만 조사했고 채택 설정은 바꾸지 않았다. [적합 단계별 진단](../runs/vision-corner-learned-silverstone-20261112-01/fit-diagnostic.json)

경계 보완은 관측 단면을 늘렸으나 Silverstone에서 거리까지 맞힌 우회전이나 안정 예고를 늘리지 못했다. 다음 평가에서는 누락을 포함한 단면 연속성과 국소 곡률을 함께 점검하고, 설정 고정 후 새 서킷에서 평가한다.
