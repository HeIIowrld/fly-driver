# 상대 전진량과 영상으로 코너 거리 갱신 · 2026-11-11

여섯 서킷의 저장 영상 7,287묶음에서 같은 방향으로 연속 경보가 나온 경우를 비교했다. 직전 추정 거리에서 차량의 상대 전진량을 빼고 새 영상 거리와 합쳤다. 25·50·75% 혼합, 이동을 보정한 최근 세 관측의 중앙값, 새 관측에 따른 수정량을 2m 또는 4m로 제한하는 방식을 비교했다. 프레임·세션 세대가 끊기거나 진행량이 없거나, 이전 시작점을 지나쳤거나, 새 거리와 8m 넘게 차이 나면 영상에서 새로 시작했다. 방향·경보 유무·미출력은 각 비교의 입력 그대로 유지했다. 거리 갱신은 기존 고정 판독과, 정렬한 굽음·경계 시작점이 같은 방향일 때 경보를 추가한 사후 판독에 각각 적용했다. 방향·거리 동시 적중과 안정 예고 수를 유지하고, 공통 연속 쌍에서 오차와 거리 역행이 늘지 않는 조건 중 오차를 가장 줄인 방식을 다른 서킷으로 옮겼다. 평가할 서킷과 Spa는 선택 자료에서 제외했다.

## Spa 사후 비교

| 판독 | 좌·우·결합 적중 | 직선·범위 밖 오경보 | 안정 예고 코너 | 공통 6쌍 거리 변화 오차 |
| --- | ---: | ---: | ---: | ---: |
| 기존 고정 판독 | 2·15·10 | 80 | 3/24 | 5.01m |
| 같은 방향의 시각 근거를 결합 | 3·15·11 | 82 | 3/24 | 5.01m |
| 시각 결합 + 상대 이동과 새 영상 거리 50%씩 | 3·15·13 | 82 | 4/24 | 3.89m |
| 시각 결합 + 이동한 거리에서 새 영상 쪽으로 최대 2m 수정 | 3·15·13 | 82 | 4/24 | 3.79m |

새로 안정 예고가 나온 곳은 우회전 코너 17이며 최초 예고는 실제 시작 6.69m 전이었다. 50% 혼합에서 맞는 방향 경보의 절대 거리 오차도 시각 결합만 했을 때의 4.38m에서 3.96m로 줄었다. 공통 6쌍에서 접근 중 거리 역행은 한 건으로 같았다. 기존 독립 평가 기준의 거리 변화 항목은 통과했지만 안정 예고 항목은 미달이었다. [전체 비교와 최초 안정 예고 거리](../runs/vision-corner-motion-anchored-distance-20261111-01/result.json)

## 다른 서킷에서 고른 조건

Spa에서 좋았던 설정을 다른 서킷에 그대로 적용하면, 50% 혼합은 Magione의 결합 적중을 71→69건, Zandvoort는 8→7건으로 줄였다. Zandvoort의 일부 접근에서는 이미 짧았던 영상 거리까지 더 줄였다. 두 연속 영상 거리 모두 10m 이상일 때만 갱신하는 추가 비교를 했다. 이 조건의 2m 수정은 Zandvoort에서 결합 8건을 유지하며 공통 거리 변화 오차를 2.75→2.09m로 줄였지만, Imola에서는 3.08→3.19m로 증가하고 거리 역행도 1→3건이 됐다.

서킷을 빼고 고른 방식은 Spa·Magione·Laguna Seca·Mugello에서 영상 거리 그대로였다. Zandvoort에서는 공통 거리 변화 오차가 줄고 결합 적중을 한 건 잃었으며, Imola에서는 거리 변화 오차와 역행이 늘었다. 시각 결합으로 Spa의 좌회전을 한 건 더 잡고 거리 갱신으로 안정 예고를 한 곳 더 얻은 조합은 사후 결과다. 공통 설정으로 검증하지 못해 고정 판독을 유지했다.
