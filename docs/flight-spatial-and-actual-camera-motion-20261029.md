# 공간 요약과 실제 게임 장면의 회전 반응 — 2026-10-29

초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.

## 현재 판단

실제 게임 장면에서 알려진 순수 카메라 좌/우 회전4조건을 고정한 저자 시각 회로가 올바른 부호로 읽었다.
첫 영상만 유지하는 대조에서는 그 좌/우 구분이 사라졌다. **시각 운동 반응의 제한된 실제 장면 근거**다.
주행 중 차체 회전 추정이나 앞 도로를 보고 조향하는 기능은 통과하지 못했다.
기존 v2 후보·전체 운동정보 제거 실패는 그대로 유지하며 게임에 올리지 않는다.

## 정차한 실제 AC 장면에서 알려진 카메라 회전

실제 도로의 운동 시각 반응 자체를 분리하려고
`configs/ac-paused-scene-rotation-probe-20261029.json`을 실행 전에 고정했다.
차량·물리·조향·페달·게임 창은 건드리지 않고, 물리가 paused인 동안 센서 카메라의 방향만 회전했다.
각 카메라 중심은 고정이며 실제 차량 yaw 실험이 아니다.

- 조건: `full_scene`와 `track_only` 각각0/+0.2/−0.2rad/s,총6조건.
- 각61개 실제 프레임,요청25Hz,정지 prefix0.6초·회전1.2초·뒤 정지. 최대 회전각0.24rad.
- `track_only`는 진단 renderer의 track root만 그린다. 모든 차가 제외되므로 actor 관측 변경으로 쓰지 않는다.
- 매 프레임 실제 view matrix/요청 자세/독립 원점/실제 clock을 보존했다.
- `aid_probe_only=true`·`actor_admissible=false`이며 정상 actor admission이 모든 프레임을 거부함을 확인했다.

관련 Lua/기하159검사와 Ruff를 통과했다. t1375는 같은 엔진28428에서 앱만 실제 재로딩했다.
