# 먼 도로 경계의 픽셀 추적과 투영 민감도 · 2026-11-12

Silverstone 620–623번에서 전방 24–34m에 놓인 경계 후보를 원본 320×180 영상에 다시 표시했다. 같은 프레임의 지도 경계는 실제 렌더 카메라 정보로 따로 투영했다. 지도 투영과 절대 위치는 원인 진단에만 사용했다. 픽셀을 다시 추출한 뒤 네 프레임의 모든 34m 판독 제안을 이전 결과와 대조해 일치했다. ## 620번에서는 어느 선을 읽었나

620번의 26–34m 왼쪽 다섯 단면은 노면 대비 검출에서 나왔고, 오른쪽 다섯 단면은 영상 기울기로 보완했다. 화면에 보이는 왼쪽 잔디 전환과 오른쪽 어두운 띠를 기준으로 하면 각 단면의 픽셀 최단거리 중앙값은 왼쪽 1.45px, 오른쪽 0.73px였다. 620번의 먼 후보는 두 표면 전환에 가까웠다. 오른쪽 어두운 띠가 실제 주행 가능 영역의 공식 경계인지는 이 표시로 확정할 수 없다. [원본 영상의 표면 전환과 거리](../runs/vision-corner-far-pixel-trace-20261112-01/visible-transitions.json)

각 지도 경계의 횡위치를 고정한 상태에서 기존 평면 투영과 실제 카메라의 지도 투영을 비교했다. 620번 26–34m의 좌우 세로 오차 중앙값은 오른쪽 2.81px, 왼쪽 3.83px였고, 가로 오차 중앙값의 절댓값은 각각 0.21px, 0.16px였다. 이 배치에서는 작은 세로 오차로 샘플이 다른 거리의 표면 전환을 읽을 수 있다. 이 차이는 노면 높이, 차체 자세, 카메라 보정을 구분한 값이 아니다.

가로와 세로를 모두 바꾼 결과는 네 프레임에서 세로만 바꾼 결과와 같았다. 세로 위치가 620·622번 방향 반전에 관여했지만, 620번의 시작 거리와 621·623번 방향은 보정 후에도 맞지 않았다. [가로·세로를 분리한 진단](../runs/vision-corner-far-pixel-trace-20261112-01/projection-counterfactual.json)

## 지도 없이 새 후보의 민감도 검사

전방 카메라의 먼 단면 투영을 위아래로 2px씩 움직였다. 두 경우 모두 기존 후보와 같은 방향을 내고 시작 거리 차이가 3m 이내인 새 후보만 받아들였다. 경계 모델과 T4/T5 결합 모델에 같은 조건을 적용했다. 기존 경보는 그대로 보존했다. Silverstone·Spa와 다섯 개발 서킷의 기존 8,487묶음을 평가했고, 다섯 서킷은 평가 서킷을 학습에서 뺀 기존 체크포인트를 사용했다.
