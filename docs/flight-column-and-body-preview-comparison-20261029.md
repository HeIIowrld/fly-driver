# 원본 밝기·뉴런 공간 읽기·몸 감각 비교

2026-10-29, Asia/Seoul. 이전 목표 턴은 **진전**이다. 전방 영역 비교를 실제 실행하고,
전체 개발 실패와 학생 미연결 상태를 확인해 다음 비교 조건을 바꿨다.
이번에도 실제 주행 성공이나 조향 정책 완성을 주장하지 않는다.

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.**

## 새 근거와 결론

두 비교의 사전 선언 후보 모두 알려진 개발 기준을 통과하지 못했다.
학습 오차는 감소하지만 개발 오차와 시각/몸 특징 제거 효과가 일관되지 않는다.
저자 시각 뉴런 내부 가중치·비행 운동 그래프는 그대로이며 학생 제어와 게임 조작은0이다.

원본8이력과 새 코너 TRAIN2의 역할·모든 관측·시간·표적 마스크를 보존했다.
TRAIN8/개발2이며, 실패 episode05와 미수집 개발 자료는 사용하지 않았다.
평가 자료는 열지 않았다. 같은 개발 자료를 반복 보고 있으므로 독립 평가로 부르지 않는다.
미래 위치/카메라 방향은 앞길 표적 생성용이며 actor 입력이 아니다.

## t1543: 721개 위치의 학습 가능한 공간 읽기

같은14채널 구조에서 `intensity_fixed`, `intensity_learned`, `neural_fixed`,
`neural_learned`를 각각 마지막200회까지 GPU 학습했다. 후보는 미리 `neural_learned`로 고정했다.

- intensity는 저자 뉴런 처리 전의 **원본 영상에서 표본화한 밝기721개**와 상수0채널13개다.
  고해상도 RGB/CNN 비교군을 이미 구현했다고 해석하지 않는다.
- neural은 실제 L1/L2/Mi1/Tm3/Tm1/Tm9와 T4/T5의14채널 반응이다.
- 기존4×4 Gaussian 공간 가중치를 고정하거나 같은 초기값에서16×721 읽기 가중치를 학습한다.
  학습 가능한 부분은 공학적 readout이며 해부학적 연결이나 저자 뉴런 자체를 수정하지 않는다.
- 채널 정규화는 기존 TRAIN 통계, pooled 정규화는 초기 공간 읽기의 TRAIN 통계만 사용했다.
  전 이력 gradient를 chunk로 누적하고 epoch마다 한 번 갱신한다. 단위 검사에서 전체 배치 기울기와 일치했다.
- 고정 조건의 공간 가중치 변화0, 학습 조건은 intensity .0659920/neural .0385790으로 실제 변화했다.

마지막 TRAIN 표준화 손실은 각각 .0234274/.00302866/.00814856/.00226328이었다.
그러나 전체 개발 bearing(rad) 결과는 다음과 같다. 각 셀은5/10/20m 순서다.

| 조건 | 개발02 | 개발07 |
|---|---|---|
| intensity 고정 | .013883/.029448/.041739 | .020157/.030377/.041714 |
| intensity 학습 | .030377/.044696/.082223 | .017217/.023988/.035886 |
| neural 고정 | .015904/.025947/.050040 | .018367/.023846/.042496 |
| neural 학습 후보 | .019629/.027374/.045794 | .010777/.018914/.045036 |
| TRAIN 표적 평균 | .004840/.004988/.008038 | .012595/.015860/.021817 |

neural 후보의 개발07 5m 개선은 있지만 두 이력·세 거리 전체를 통과한 것은 아니다.
밝기 비교군도 실패하므로 뉴런 회로만이 실패 원인이라고 확정할 수 없다.
동시에 이 작은 readout 실패를 근거로 원본 영상에 정보가 없다고 주장하지 않는다.
각 조건 전체6표적·전체/초기3초 이후·특징 평균 대체 예측을 모두 보존했다.

## t1544: 새60km/h 코너의 몸 감각21

`replay_virtual_body.py`에 명시적 `--navigation-contract`와 `--legacy-reference` 경로를 추가했다.
기존 기본16 경로는 그대로다. 두 옵션을 함께 요구하며,
완료된 원본16 결과/배열 SHA와 전체 이력의 값·마스크·시각·최초 수신 시각·packet ID를 대조한다.

새 코너739/740관측에서 기존16이 정확히 같고, 속도m/s와 네 바퀴 회전rad/s만 더해21로 확장했다.
새 구간은21개 중 roll/pitch 각속도와 선형 가속도3개가 계속 무효다.
유효 yaw 각속도·차체 기울기·하중비·온도·속도·바퀴 회전을 사용한다.
검증되지 않은 축/중력 처리를 추측해 가속도를 채우지 않았다.
기존0..30 목표 계약이나 체크포인트를60으로 재해석하지 않는다. 이번 경계에는 목표 입력 자체가 없다.

## t1545: 시각·몸·결합 비교

`vision_only`, `body_only`, `vision_body`를 동일 구조·초기 가중치·TRAIN 통계와
고정 마지막200회로 GPU 학습했다. 사전 후보는 `vision_body`다.
시각은 실제14채널의 기존896 특징, 몸은21값+21유효성이다.
몸 평균/표준편차는 TRAIN의 **유효한 값만** 사용한다.
한 번도 유효하지 않은 채널은 평균0/scale1로 두고 무효 값을0, 마스크false로 유지한다.

결합 후보 TRAIN 손실은1.027991→.00667811로 감소했다.
전체 개발 bearing RMSE와 TRAIN 평균 기준은 다음과 같다.

| 이력 | 결합 후보5/10/20m | TRAIN 평균5/10/20m |
|---|---|---|
| 개발02 | .016842/.024451/.053041 | .004840/.004988/.008038 |
| 개발07 | .038131/.038090/.017850 | .012595/.015860/.021817 |

개발07 20m 개선만으로 승격하지 않는다. 시각 전체를 제거하면 개발07 5/10m가 개선되고,
몸 전체를 제거하면 개발02 전체 거리가 개선되는 등 일관된 결합 기여가 아니다.
이 제거는 정규화된 특징과 몸 마스크를0으로 바꾸는 대조이며 실제 뉴런 손상 시험이 아니다.
실제 조향·가감속과 고정 운동 회로 전달은 아직 수행하지 않았다.
