# 누락된 도로 경계에서 관측 후보 선택 · 2026-11-12

현재 영상에서 도로 경계 한쪽이 빠진 단면을 대상으로 같은 프레임의 앞뒤 단면 보간과 이전 최대 네 프레임에서 옮긴 관측을 각각 후보로 유지했다. 후보별 위치, 같은 쪽과 반대쪽의 이웃 관측, 다른 후보와의 일치, 이전 관측 순서로 각 후보가 물리 경계의 1.25m 이내일 점수를 학습했다. 이미 관측된 좌표는 유지했다. 채택 결과는 과거 관측에 다시 넣지 않았다. [선택과 재생 코드](../runs/vision-corner-boundary-candidate-selection-20261112-01/select_boundary.py)

Imola·Laguna Seca·Zandvoort·Mugello를 하나씩 제외해 평가했다. 서킷과 대상 단면별로 학습 표본의 비중을 맞췄다. 개발 평가에서 정확한 채택에 +1, 허용 오차 밖 채택에 −2, 보류에 0을 주고 서킷별 평균을 합산해 문턱 0.75를 고정했다. 개발 서킷별 채택과 정확한 위치는 Imola 153/198, Laguna Seca 5/5, Zandvoort 150/239, Mugello 130/151이었다. ## Silverstone에서 남은 누락

물리 라벨로 확인된 오른쪽 누락 10점은 고정 문턱에서 모두 보류했다. 문턱 적용 전 선택된 좌표는 6점이 실제 위치 1.25m 이내였고 평균 횡오차는 1.41m였다. 보간과 최근 프레임을 순서대로 고르면 3점과 2.12m, 다른 후보와 가장 많이 일치하는 좌표를 고르면 2점과 2.69m였다. 이전에 후보들을 하나의 좌표로 회귀한 방식은 1점만 1.25m 이내였다. 선택이 정확했던 여섯 점의 점수는 0.30–0.66이었다. 같은 13장에 있던 왼쪽 누락 13점 중 2점은 복원됐고 평균 횡오차는 0.50m였다. 물리 라벨은 노면 전환을 영상에 투영한 결과로 가림을 별도로 판정하지 않았다. [누락 좌표와 점수](../runs/vision-corner-boundary-candidate-selection-20261112-01/result.json)

Silverstone 우회전 접근에서 방향과 거리 ±5m가 맞는 후보를 포함한 프레임은 7→8장이었다. 488번의 선택은 좌 6.88m에서 우 14m로 바뀌었고 두 확인기는 모두 경보를 보류했다. 621번은 우 13m에서 우 14m로 바뀌었고 두 확인기 모두 보류했다. 출처 해시, 미래 프레임을 제거했을 때의 동일 선택, 기존 관측 보존, 같은 후보 사용, 직선·보류의 거리 미출력과 회전의 4–20m 거리 범위를 검증했다. ## 같은 영상과 경계 후보에서 T4/T5 비교

| 시험 영상 | 수정 후 경계 → 경계와 T4/T5 우회전 적중 | 직선·범위 밖 경보 | 코너 내부 경보 |
| --- | ---: | ---: | ---: |
| Silverstone 1967 | 2→2 / 13 | 13→10 | 7→9 |
| Vallelunga Extended | 2→5 / 38 | 7→7 | 6→10 |
| Monza | 3→3 / 42 | 11→27 | — |

Silverstone에서는 T4/T5가 경계 방식의 직선 경보 3건과 범위 밖 경보 1건을 없애고 직선 경보 1건을 추가했다. Vallelunga에서는 방향·거리 동시 적중을 4건 추가하고 1건을 놓쳤으며, 순증한 3건은 우회전이었다. Monza는 코너 내부 라벨을 제외한 989장에서 비교했다. 수정 전 T4/T5 우 적중은 Silverstone 2/13, Vallelunga 5/38, Monza 4/42였다. 수정안은 Silverstone 오른쪽 누락을 줄이지 못했고 Monza 적중이 감소해 고정 판독기에 적용하지 않았다.
