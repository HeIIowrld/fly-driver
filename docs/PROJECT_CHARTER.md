# 프로젝트 대전제

사용자 확정: **2026-10-29, Asia/Seoul**. 이 문서는 진행 로그가 아니라 이후 작업의
기준이다. 새 대화나 컨텍스트 정리 후에도 유지하며, 사용자가 변경할 때만 고친다.

## 사용자 재확인 목표 (2026-10-31)

**파리운전시키기 — 실제 flybrain 폴더와 기존 변경을 유지하며, 초파리 겹눈·운동 시각 및 비행 유래 균형·운동 회로를 차량 몸에 연결하고 몸 감각 되먹임·시각 선행 예측·가감속·변속·셋업 적응을 학습 및 실제 검증하여 빠른 유효 완주, 레이싱 라인과 랩타임 최적화까지 진행한다.**

전후좌우 시각을 함께 처리하며 실제 검증된 상대풍을 몸 감각과 함께 다룬다. 정답 라인·지도·절대 위치는 교사/평가 경계에 두고 운전 판단에는 영상과 허용된 몸 감각만 사용한다. 실측 구조와 기능 근사·공학 어댑터를 구분하고, 부품 반응뿐 아니라 폐루프 운전 기여를 검증한다.

## 차종 일반화 사용자 재확인 (2026-11-02)

사용자는 교사 모델의 차종이 달라도 괜찮으며, 차량 차이를 감각·조작 단위와 동특성으로
해석해 범용 모델을 개발하는 것이 목표라고 재확인했다. 다른 차종이라는 이유만으로
공개 교사 후보를 제외하지 않는다. 먼저 그 교사가 학습된 차량과 조건에서 재현하고,
차체 크기·조향/기어/타이어·관성/하중 특성과 감각 결측을 명시해 공통 표현·학습한
어댑터 및 차종 밖 평가로 연결한다. 다른 차종의 절대 랩타임을 곧바로 같은 순위로
비교하거나, 한 차에서의 성공을 범용성 입증으로 쓰지는 않는다. 최종 학생은 여전히
초파리의 겹눈·운동 시각과 비행 유래 균형·운동·감각 되먹임의 통합 구조를 사용한다.

## 컨텍스트 인계 시 반드시 남길 문장

> 초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
> 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과
> 빠른 레이싱 라인/랩타임을 학습한다.

사용자의 표현으로는 **“차체 기울어짐을 몸 기울어짐으로 넣는”** 방향이다.
여러 시점의 시각 입력을 방향·시간·운동 정보로 처리하고 몸 감각과 함께 써서,
운동 명령과 실제 차량 반응이 이어지는 감각운동 고리를 만든다.
이 문단은 확정된 목표이며, 현재 구현이나 검증이 끝났다는 뜻이 아니다.

## 바람 감각 추가 사용자 요구 (2026-10-30)

시각과 차체 기울기·회전 등의 몸 감각뿐 아니라 바람을 포함한 감각을 함께 바탕으로 판단하고 조작하는 모델을 개발한다. 상대 바람의 출처·단위·차체 좌표 방향·시각 정합과 결측을 검증해야 한다. 차 속도를 바람으로 바꾸어 부르거나 실제 센서가 없는데 값을 만들어 넣지 않는다. 이는 기존 겹눈/운동 시각·비행 유래 회로·가감속·빠른 유효랩 목표에 추가된 요구다.

## 사용자가 말한 운전의 범위

조향만 출력하는 것으로 끝내지 않는다. 가속·감속·코너 진입과 탈출·하중 이동을
함께 학습하고, 유효한 레이싱 라인을 따라 더 빠른 랩을 찾는다. 레코드 라인은
교사와 비교 기준으로 쓸 수 있지만, 차량·타이어·셋업 조건이 달라져도 항상 같은
선이 가장 빠르다고 가정하지 않는다. 차체 기울기를 몸 기울기로 받는다는 발상은
영상 인식 뒤에 붙이는 장식이 아니라, 운동 결과가 다시 제어를 바꾸는 되먹임이다.

다음 요약은 위 필수 인계 문장과 함께 **비행 기준**, **영상+몸 감각으로 판단**,
**조향과 가감속 모두**, **유효 완주 이후 레이싱 라인/랩타임 최적화**,
**생물학적 근거와 차량 대응 가설의 구분**을 유지한다.

## 통합 회로의 의미 (2026-11-01 사용자 재확인)

목표는 전후좌우 겹눈·운동 시각, 비행 유래 균형/운동 회로와 자동차 몸 감각이 연속적으로 상호작용하는 **하나의 통합 감각운동 시스템**이다. 구 30km/h 경로와 물리 단위 고속 경로는 현재의 실험 구현과 중간 검증이며, 서로 독립된 최종 운전자나 별도 운동 뇌로 유지하지 않는다. 기존 측정 연결과 실험 가중치는 보존하되 시각·몸 감각·비행 회로·차량 조작의 단일 연속 상태 경로를 구성하고, 공학적 변환/예측기와 생물학 근거를 구별해 인과 및 폐루프를 검증한다. 하나로 구성한다는 사실과 생리적 타당성·실제 완주가 입증됐다는 주장은 다르다.

## 무엇을 만들고 있는가

**초파리의 시각 인식·감각·몸 제어 구조를 자동차라는 가상 몸에 연결하고,
그 구조로 조향·가속·감속과 빠른 레이싱 라인/랩타임을 학습해 Assetto Corsa
서킷을 자율 주행하게 한다.**

사용자가 선택한 기준은 보행보다 **비행의 날개 조종·균형·시각 안정화**다.
초파리의 몸을 자동차로 바꾸어 감각과 운동의 닫힌 고리를 만들려는 것이며,
차를 잘 모는 일반 신경망을 하나 더 만드는 것이 목적은 아니다.

## 감각과 몸의 대응

| 자동차에서 얻는 것 | 가상 몸에서의 의미 |
|---|---|
| 전·좌·우·후방 영상, 움직이는 시야 | 겹눈 방향 입력과 운동 시각, 주변 경로의 시각 증거 |
| 차체 기울기·각속도 | 몸의 자세·회전·균형; 정적 기울기와 동적 회전은 구분 |
| 가속·감속·관성과 하중 이동 | 운동 명령으로 몸이 실제 어떻게 반응하는지 |
| 타이어 슬립·온도·접지·셋업 변화 | 차량이라는 가상 몸의 상태와 힘을 낼 여유 |
| 조향·가속·제동 | 감각을 바탕으로 내린 운동 의도를 차량에 적용한 결과 |

이 대응은 필요한 공학적 설계다. 바퀴를 실제 날개나 감각 수용기와 일대일로
동일시하거나, 자동차 브레이크가 초파리에 그대로 있다고 주장하지 않는다.
전체 초파리의 공력·근육을 먼저 완전히 시뮬레이션하는 것을 선행 조건으로
추가하지 않는다. 어느 구조를 도입하고 어느 부분을 축약했는지 검증한다.

## 성공에 필요한 두 축

1. **기전:** 겹눈/운동 시각과 비행 유래 운동·균형·감각 피드백 구조가 동작하고,
   해당 경로의 반응·제거·교란 시험으로 실제 기여를 확인한다.
2. **운전:** 그 구조를 쓰는 학생이 영상과 몸 감각으로 조향·가감속을 수행하고,
   서킷 유효 완주·반복 안정성과 조건별 레이싱 라인/랩타임 개선을 검증한다.

시냅스 연결망을 통과시켰다는 사실, 짧은 구간 성공, 일반 운전 모델의 완주,
교사가 대신 운전한 거리 중 어느 하나도 두 축을 함께 충족한 결과가 아니다.
발견한 최선의 유효 랩과 수학적으로 전역 최적인 경로의 증명도 구분한다.

## 지킬 정보 경계

- actor의 경로 판단은 영상에서 출발하고 허용된 몸 감각을 함께 쓴다.
- 정답 레이싱 라인·지도·world pose·진행률·미래 곡률·교사 명령은
  교사/보상/critic/평가에만 사용한다. HUD나 주행선으로 우회하지 않는다.
- 몸 자세와 회전은 단위·축·부호·시각을 명시한다. 절대 world heading을
  몸 감각이라는 이름으로 actor에 넣지 않는다.
- 실제 측정 연결/주석, 생리학적 결과, 기능 근사, 차량 대응, 학습한 변환을 구분한다.
  생체 전체나 전체 뇌 재현을 주장하지 않는다.
- 회로 상태는 원래 에피소드 안에서 유지한다. 공백을 삭제하거나 시간을
  다시 매기거나 중간 상태를 초기화해 검증을 통과시키지 않는다.
