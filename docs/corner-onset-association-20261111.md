# 연속 예고 기회와 같은 코너의 거리 연결 · 2026-11-11

방향 연속 적중은 거리 ±5m까지 요구하는 안정 예고의 선행 조건이다. 기존 고정 판독과 방향이 같은 두 시각 근거를 결합한 사후 판독은 이 표의 연속 방향 적중 수가 동일했다.

Spa에서 추가 적중한 좌 코너 18의 974번은 시작 5.78m 전이었다. 직전 973번은 이전 코너 안이었고, 직후 975번은 같은 좌 코너 시작 1.14m 전이었다. 4–20m 조건을 만족한 프레임은 한 개였다. 반면 좌 코너 26은 1180·1181번에서 15.22m와 7.16m로 연속 채점이 가능했지만 두 판독 모두 직선을 냈다. 좌 8곳에서 연속 채점이 가능했고, 이 중 7곳에서는 두 프레임 연속 방향 적중을 얻지 못했다. ## 같은 시작점인지 확인한 거리 갱신

연속 경보의 방향이 같아도 같은 코너인지 판단하기 위해 두 영상 거리, 차량의 상대 전진량, 유무 점수와 도로 경계에서 찾은 시작점을 입력으로 사용했다. 지도상 물리 코너 ID와 실제 거리는 학습용 라벨과 채점에만 사용했다. 각 평가 서킷을 학습과 문턱 선택에서 제외했고, 문턱 선택 자료의 예측도 해당 서킷을 빼고 만들었다. Spa는 항상 학습·문턱 선택에서 제외했다. 추정한 이전 시작이 지났거나 거리 차이가 8m보다 크면 새 영상으로 초기화했다. 조건을 통과한 경우에만 상대 이동으로 예측한 거리를 새 관측 쪽으로 최대 2m 수정했다. 합성 입력에서 방향 변경, 세대 단절, 미출력, 정답 변경과 무관한 입력을 확인했다. [실행 코드](../runs/vision-corner-onset-association-20261111-01/association.py) · [검사와 기록](../runs/vision-corner-onset-association-20261111-01/checks.log) · [실행 기록](../runs/vision-corner-onset-association-20261111-01/receipt.json)

Spa의 같은 방향 연속 경보 175쌍 중 같은 실제 코너에 접근 중이라는 학습 정의를 만족한 쌍은 12개였다. 거리·이동·유무 점수 모델의 평균 정밀도는 0.087, 경계 시작점도 넣은 모델은 0.074였고 양성 비율은 0.069였다. 개발 서킷에서 고른 두 모델의 문턱 0.60에서 Spa의 공통 6쌍 거리 변화 오차는 5.01→5.40m였고 안정 예고는 3곳이었다. 시각 근거를 결합한 사후 판독에 적용해도 좌·우·결합은 3·15·11건, 직선·범위 밖 오경보는 82건으로 같았고 거리 오차는 5.40m였다.

Imola에서 경계 시작점을 제외한 모델은 기존 좌·우 적중을 유지하며 결합을 15→16건, 공통 거리 변화 오차를 3.08→2.62m로 개선했다. Zandvoort에서는 결합이 8→7건, 거리 변화 오차가 2.75→3.04m로 나빠졌다. 공통 거리 갱신으로 채택하지 않았다. [문턱별 채점](../runs/vision-corner-onset-association-20261111-01/result.json)

다음 검증은 연속 영상이 있는데도 직선으로 분류된 실제 좌 접근에 집중한다. 짧은 코너 사이 구간의 신규 촬영에서는 더 촘촘한 캡처가 가능한지 실측하고, 실제로 연속 채점 표본을 확보한 경우를 따로 기록한다.
