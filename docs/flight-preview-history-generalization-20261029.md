# 앞길 시각 학습: 이력 단위 검증과 v4 경로 범위

2026-10-29, Asia/Seoul. [대전제](PROJECT_CHARTER.md)를 유지한다.
**학습한 이력에는 맞출 수 있지만, 빼둔 이력으로 일반화하지 못했다.**
이는 신경 회로로 운전에 성공했다는 결과가 아니다. 이번 모델은 표현 능력을 분해하는
공학적 비교군이며 파리 운동 회로를 통과하는 실제 actor가 아니다.

## 실제 GPU 학습과 검증 경계

- 원래 TRAIN 6개 이력 중 하나를 통째로 빼고 5개만 학습하는 검증을 6회 실시했다.
  개발/평가 배열은 열지 않았다. 기존 개발 결과를 아는 상태의 탐색적 내부 검증이다.
- 기존 576차원 → 64 tanh → 6 출력 모델과 전면 8×8 위치별 공유 9→8 tanh,
  이어서 512→64 tanh→6 출력 모델을 각각 학습했다.
  새 고위 시각 표현의 공학적 비교이며 측정된 고위 뇌 연결망이라는 주장은 없다.
- 출력은 원래 5/10/20m 방향·chord 곡률 표적이다. 원래 마스크와 시각을 유지했다.
  입력은 시각뿐이며 좌표·미래 궤적·교사 조작·시각 clock은 넣지 않았다.
- 각 회차의 학습 이력 5개만으로 입력/표적 평균과 표준편차를 구했다.
  입력 표준편차 하한 1e-5, 입력 ±5, 표적 표준편차 하한은 방향 0.005rad/곡률 0.0001m⁻¹이다.
  표적은 clipping하지 않았다. 유효 표적에 대한 표준화 MSE를 출력 6개에 동등하게 적용했다.
- RX9070XT에서 두 구조 × 6회 × 고정 200 epoch = **2,400회 업데이트**를 완료했다.
  AdamW lr 0.001/weight decay 0.01, seed 863449+회차를 사전 고정했다.
  마지막 checkpoint만 사용하며 검증 기반 조기 종료나 epoch 선택은 없다.
- feedforward 비교군이므로 신경 재귀 상태가 없다. 원래 파리 회로의 가중치/상태를 바꾸지 않았다.

## 결과

방향 RMSE(rad). 각 회차의 표본 수를 반영한 제곱오차 합으로 집계했다.
학습 오차는 여러 회차에 같은 이력이 포함되므로 독립 표본의 평가치가 아니다.

| 표현 | 범위 | 5m | 10m | 20m |
|---|---|---:|---:|---:|
| 기존 576·비선형 | 학습 이력 | 0.00362 | 0.00447 | 0.00634 |
| 기존 576·비선형 | 빼둔 이력 | 0.08412 | 0.11348 | 0.16417 |
| 전면 8×8·공유 변환 | 학습 이력 | 0.00498 | 0.00616 | 0.00952 |
| 전면 8×8·공유 변환 | 빼둔 이력 | 0.09935 | 0.13848 | 0.20504 |
| 각 회차 학습 표적 평균 | 빼둔 이력 | 0.07276 | 0.09595 | 0.13005 |

평균 첫 손실 → 마지막 업데이트 직전 손실은 기존 표현 1.06750→0.00328,
전면 8×8 표현 1.02519→0.00622였다. 저장한 최종 예측은 마지막 업데이트 뒤의 값이다.
표준화 손실 감소와 실제 방향 RMSE를 구분한다.

두 구조 모두 전체 집계의 모든 거리에서 평균 기준보다 나빴다. 3초 이후 집계도 같은 결론이다.
개별 회차의 일부 거리는 평균을 이겼지만 보편적인 성공은 아니다.
코너 구간 05를 뺐을 때는 두 구조 모두 세 거리에서 평균보다 나빴다.

따라서 현재 업데이트가 아예 불가능하다는 설명은 맞지 않는다. 다만 학습 오차가 작다는 사실은
시각으로 일반적인 도로 구조를 배웠다는 증거가 아니다. 구간을 기억하는 과적합과
표현/자료 분포의 문제를 우선 다뤄야 하며, epoch만 늘리는 해결은 근거가 없다.

## v4 완전 이력 재사용과 경로 범위

원래 역할이 봉인된 v4 TRAIN 5/개발 1의 6개 완전 이력, 4,432개 관측을
기존 GPU 시각/몸 계약의 별도 캐시로 만들었다(t1451). 원래 실패한 수집 전체를 성공으로
바꾸지 않았으며, 실패·부분 이력과 평가 이력은 넣지 않았다. 몸 입력은 이 캐시에서 기존 16개다.
몸21로 이행하거나 새 actor를 배치한 것은 아니다.

같은 앞길 표적 생성/고정 선형 probe도 완료했다(t1452). 카메라 기하 거부는 0이다.
개발 방향 오차는 5/10/20m에서 0.010414/0.018747/0.028452rad였다.
20m만 TRAIN 평균 0.029914보다 작지만, 0방향 기준 0.009669보다 나빴다.
개발의 모든 표적은 여전히 ±5도 이내이며, 실제 제동 정답도 0이다.

별도 t1453 감사는 원래 telemetry의 AI 주행·바퀴 이탈 0·속도 1km/h 초과 표본을
수평 XZ 평면에서 비교했다. v4 각 TRAIN 이력의 **모든 해당 표본이 기존 TRAIN 경로 표본에서
0.283m 이내**였고, v4 개발 표본도 모두 기존 개발 표본에서 0.250m 이내였다.
이는 경로 표본의 기하 범위 결과이며 픽셀 중복·동일 정답·통계적 독립성의 증명은 아니다.
하지만 v4를 새로운 도로 구간의 다양성으로 세어 일반화 개선을 주장할 수는 없다.

## 다음 실제 학습 자료 방향

1. 같은 경로의 재촬영과 새로운 경로/조작 조건을 구분한다. v2/v4를 합쳐도 새로운 코너 범위가
   늘었다고 세지 않는다. 개발/평가 역할을 학습으로 바꾸지 않는다.
2. 현재 수집의 시작 위치/구간 선택을 확인하고, 아직 덜 본 좌/우 코너·연속 코너를 포함하는
   경로를 수집 전에 정한다. 서로 겹치는 경로 묶음은 역할 사이로 나누지 않는다.
3. 여러 목표 속도와 실제 주행 제동을 포함한다. 종료 복구 제동을 정답으로 사용하지 않는다.
4. 새 표현 학습은 시각적 방향/곡률의 구간 일반화로 검증한 뒤, 비행 유래 조향·가감속 명령과
   운동 회로로 연결한다. 빠른 몸 피드백, 기울기·하중·타이어/셋업, 학생 완주와
   빠른 라인/랩타임의 최종 목표는 유지한다.
