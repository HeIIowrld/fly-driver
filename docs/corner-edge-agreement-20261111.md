# 경계별 코너 시작과 상대 이동 확인 · 2026-11-11

여섯 서킷의 저장 영상 7,287묶음에서 양쪽 경계를 독립적으로 맞췄다. 각 경계에서 직선과 이미 휘어진 곡선을 대조해 4–18m의 가장 가능성 높은 시작점 하나를 골랐다. 두 시작의 방향이 같고 거리가 3m 이내면 평균을 사용했다. 연속 영상 조건은 직전의 시작 거리를 몸 상대 전진량만큼 빼고 현재 시작점과 3m 이내에서 일치할 때만 제안했다. 프레임이나 세션 세대가 끊기면 직전 값을 사용하지 않았다. 영상과 상대 이동만으로 예측했고 서킷 기하와 절대 위치는 채점에 사용했다. ## 경보와 거리 채점

Spa 사후 문턱 0.04에서 같은 프레임의 양쪽 경계만 확인하면 좌 적중은 2→3건이었다. 우 적중 15건, 방향·거리 동시 적중 10건, 직선·범위 밖 오경보 80건, 최초 안정 예고 3곳과 공통 연속 6쌍의 거리 변화 오차 5.01m는 같았다. 문턱을 적용하기 전 Spa에서 실제 20m보다 먼 접근의 제안은 함께 맞춘 경계 8건에서 경계별 일치 0건으로 줄었지만, 방향이 맞은 실제 좌 접근도 2→1건으로 줄었다. 여섯 서킷에서 직전 영상까지 일치한 제안은 좌 접근 한 건, 직선 한 건, 4m보다 가까운 한 건이었다. 우 접근은 없었다. 평가 서킷을 제외해 문턱을 고른 세 조건은 경계 두 개로 새 경보 추가, 직전 영상까지 확인해 추가, 직전 영상까지 확인한 거리로 기존 경보의 거리만 변경이다. 마지막 조건은 같은 연속 쌍에서 거리 변화 오차와 거리 역행이 늘지 않고 적중 및 안정 예고 수가 유지되는 문턱만 허용했다. 여섯 서킷 모두 세 조건에서 적용하지 않는 설정이 선택됐다. Spa는 이미 본 자료로, 문턱 선택에는 한 번도 넣지 않았다. [합성 반전·이동·세대 단절 검사](../runs/vision-corner-edge-agreement-20261111-01/checks.log)
