# 이전 영상의 좌우 경계로 현재 단면 복원 · 2026-11-12

현재 영상에서 경계가 빠진 곳에 이전 최대 네 프레임·0.45초의 관측을 옮겼다. 차량의 국소 속도와 요율로 차량 좌표를 갱신했다. 프레임 번호·세대·시각의 연속성이 끊기면 기억을 비웠다. 이전 경계 두 쌍이 1m 이내에서 일치하거나 이전 관측 한 쌍을 현재 관측이 앞뒤에서 지지할 때 사용했다. 현재와 겹치는 경계가 1.25m 넘게 다르면 해당 과거 관측을 제외했다. 현재 보이는 경계는 보존했고, 과거 자료의 범위 밖으로 외삽하거나 복원 결과를 다시 기억에 넣지 않았다. 기존 후보를 보존하면서 복원된 경계에서 나온 새 후보를 추가했다. [경계 복원 코드](../runs/vision-corner-aligned-sections-20261112-01/aligned_sections.py)

Imola·Laguna Seca·Zandvoort·Mugello에서 기존과 같은 오경보 상한으로 재학습·교차 평가했다. Silverstone 1967과 Vallelunga Extended는 이 과정에서 제외했다. 기존 확인기와 문턱을 그대로 사용하는 조건 및 확장된 후보로 다시 학습한 조건을 같은 1,200장씩 평가했다. 지도·절대 위치·메시 라벨은 채점에 사용했다. 원래 경계만 쓴 대조군의 결과가 이전 실행과 프레임별로 일치했다. 초기 실행은 후보 목록을 합칠 때 방향 정수가 실수로 바뀌어 채점이 틀어졌다. 후보 자료형을 보존하도록 수정한 뒤 전체를 다시 실행했고 모든 선택의 방향이 정수인지 확인했다. ## Silverstone에서 복원된 경계와 후보

전체 1,200장 중 103장에서 경계 쌍 161개를 복원했다. 우회전 접근 13장 중 5장에서 경계 쌍 9개가 늘었다. 그중 807번의 12m·14m 단면이 복원되며 기존에 후보가 없던 실제 우 16.76m 시작에 우 15m와 우 13m가 생겼다. 고정 확인기는 우 15m를, 재학습 확인기는 우 13m를 확정했다. 808번에서도 실제 우 9.03m에 우 14m 경보를 냈다. 두 적중은 같은 코너 접근의 연속 프레임이다. 808번의 거리 오차 4.97m는 허용치 5m에 가깝다. 고정 확인기에서는 488번의 기존 좌 후보 대신 우 경보가 나왔으나 우 6m로, 실제 18.04m보다 12.04m 가까웠다.

별도 물리 노면 메시로 채점했을 때, 우회전 접근 중 화면에 투영되고 표면 전환이 확인된 오른쪽 경계의 관측은 185/195점으로 같았다. 왼쪽은 190→195/203점이었으며 추가 5점의 평균 횡오차는 2.05m였다. 모든 프레임의 같은 기준으로는 오른쪽 116점과 왼쪽 101점을 새로 복원했고 평균 횡오차는 각각 1.77m와 2.53m였다. 투영 라벨에는 가림 여부를 따로 판단하지 않은 점도 포함된다. Silverstone의 재학습 조건에서 T4/T5는 직선 경보 5건을 없애고 범위 밖 경보 1건과 코너 내부 경보 2건을 더했다. 두 우회전 적중은 양쪽 확인기에 공통이었다. Vallelunga의 재학습 조건에서는 T4/T5가 우 동시 적중을 2→4장으로 늘렸고 내부 경보를 8→13장으로 늘렸다. 기존 경계 경보와 함께 출력한 Silverstone 비교에서 재학습 T4/T5의 전체 동시 적중은 5→7건, 직선·범위 밖은 77→76건, 내부는 20→23건이었다. 두 오경보 수를 이전 T4/T5 설정 이하로 동시에 제한하는 사후 진단에서 Silverstone의 고정 확인기는 우 적중 2장을 유지했다. Vallelunga에서는 같은 조건의 전체 적중이 기존 6장에 비해 1장이었다. 이 상한은 평가 결과에서 가져왔으므로 고정 운영 문턱으로 쓰지 않았다. 두 서킷의 기존 녹화에 대한 결과이며 실시간 판독기에 적용하지 않았다. 다음에는 새 후보가 기존 후보와 경쟁하는 경우와 기존 후보가 없을 때만 복원 후보를 확인하는 경우를 개발 서킷에서 대조한다.
