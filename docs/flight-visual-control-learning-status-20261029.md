2026-10-29, Asia/Seoul. 사용자 질문: “시각에서 조향, 가감속으로 이어지는 학습이 잘 안 되는 것 같은데 맞나?”

**맞다. 현재 시각→조향·가감속 학습이 성공했다는 근거가 없다.**
자동차를 초파리의 가상 몸으로 삼는 [대전제](PROJECT_CHARTER.md)는 유지하되,
수집·재생·회로 반응 검증을 운전 학습 성과로 대체하지 않는다.

현재 게임 차량의 이동은 engine-AI 교사 자료 수집이다. 초파리 모델은 오프라인 재생/검증 단계다.
학습 자료 오차의 감소나 신경 회로 실행 자체를 학생 운전 성공으로 보고하지 않는다.
최근 작업은 계측·자료 확보 안정화에 비중이 컸다. 자료 수만 늘리면 조향 일반화가 해결된다는 근거는 없다.

## 다음 모델 작업의 우선순위

1. 영상에서 도로 경계·앞길의 곡률·차량 기준 목표 방향을 읽을 수 있는지 먼저 검증한다.
   지도·world pose·정답 라인은 교사/평가용으로만 두며 actor 입력은 영상과 허용된 몸 감각이다.
2. 그 시각 표현을 비행 유래 하행 명령과 몸 회로에 연결하고,
   시각/몸 입력 제거 비교로 실제 조향·속도 제어 기여를 확인한다.
   현재 cache의 기능적 자기회전6채널이 zero/invalid인 연결 누락도 별도 해결한다.
3. 실제 가속·감속·제동이 포함된 자료와 명시적 속도 목표를 사용한다.
   cleanup full brake를 코너 제동 정답으로 바꾸지 않는다. 기존30km/h 주행의 제동0을 명시한다.
4. 원래 개발 역할과 실패를 유지한다. 결과가 좋아 보이도록 정답 시각 이동·구간 제거·평가 재사용을 하지 않는다.
   가속·제동·차체 기울기/하중·타이어/셋업·유효 완주·레이싱 라인·랩타임을 목표에서 빼지 않는다.

이 항목은 계획이며, 새 상위 시각/감각 융합이나 공동 제어 학습이 이미 구현됐다는 뜻이 아니다.
실측 연결·저자 학습 가중치·기능 근사·차량 대응·새 학습 경계를 구분한다.
