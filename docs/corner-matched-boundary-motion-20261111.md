# 실제 좌회전과 오경보의 연속 경계 비교 · 2026-11-11

Spa에서 비슷한 거리로 제안된 실제 좌회전 410번, 직선 797번, 범위 밖 1176번과 각각의 직전 전방 영상을 비교했다. 파란 십자는 원래 색 대비 경계, 녹색 십자는 후보를 연결한 경계, 노란 원은 실제 카메라 행렬로 투영한 AI 경계다. 지도 경계는 진단에만 썼다. 가까운 경계점은 다른 카메라에서도 얻으므로 표시 위치는 전방 카메라가 직접 고른 픽셀과 다를 수 있다. 연속 횡차이는 직전 프레임의 경계를 상대 전진량과 요율로 현재 좌표에 옮긴 뒤, 제안한 시작점 앞뒤 6m에서 공통으로 관측한 경계점의 평균 절대 차이다. 앞뒤 카메라 캡처 시각 간격은 저장된 수신 시각으로 근사했다. 양쪽 경계를 모두 비교할 수 있는 단면이 두 곳 미만이면 이 수치를 내지 않았다. 797번에서는 도로 안쪽으로 들어간 원래 경계점이 있었고, 연결 경계가 포장 가장자리 부근을 더 잘 따라도 10m 코너 제안은 나왔다. 실제 좌회전 410번의 연결 경계 차이는 두 오경보보다 컸다. ## 여섯 서킷에서 연속 경계만으로 구분 가능한지 확인

기존 다중 후보 재생에서 이동 확인 점수 0.45 이상이며, 기존 고정 판독에서 추가 경보를 낼 수 있던 사례를 비교했다. 같은 방향의 실제 접근과 직선·범위 밖 후보를 사용했다. 이 표는 경보 전체를 재채점한 결과가 아니다.

| 서킷 | 실제 방향 적중 후보 | 직선·범위 밖 후보 | 연결 경계 횡차이의 ROC AUC |
| --- | ---: | ---: | ---: |
| Magione | 18 | 248 | 0.584 |
| Laguna Seca | 11 | 59 | 0.541 |
| Zandvoort | 11 | 24 | 0.470 |
| Mugello | 14 | 90 | 0.461 |
| Imola | 17 | 141 | 0.477 |
| Spa | 5 | 77 | 0.509 |

AUC는 연속 횡차이가 작을수록 실제 접근에 더 높은 순위를 줬을 때의 값이다. 관측 부족으로 횡차이를 낼 수 없는 일부 후보는 이 계산에서 제외했다. Spa에서 방향과 제안 거리 ±2m까지 맞춰 실제 후보와 오경보를 비교하면, 실제 후보의 연결 경계 차이가 더 작았던 비율은 78쌍에서 47.4%였다. 한 프레임이 여러 짝에 포함될 수 있다. 연속 위치가 맞아도 가까운 코너 시작이 있다는 근거는 부족했다.
