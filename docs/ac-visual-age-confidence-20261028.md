## 학습 데이터만 사용하는 초기 보정

`calibrate_visual_age_decay`는 각 시점의 유효한 원본 학습 영상 나이 평균 ā_v를 구한다. 시간 상수를 τ_old에서 τ_new로 바꿀 때 각 시점의 입력 가중치를 다음과 같이 보정한다.

`W_new,v = W_old,v × exp(ā_v × (1/τ_new − 1/τ_old))`

따라서 영상 나이가 ā_v일 때 해당 시각 포트의 선형 drive는 유지된다. 영상 나이가 달라지면 의도적으로 반응이 달라지며, 전체 신경 궤적이나 모든 행동이 같다는 뜻은 아니다. 원본 영상 나이·마스크·RGB·대비도는 변경하거나 새로 만들지 않는다. 각 시점에 유효한 학습 표본이 없거나 stale 영상을 유효로 표시한 경우 보정 전에 거부한다.

실험용 `visual_age_confidence: {"scale_seconds": 0.3}`를 학습 설정에 넣을 수 있다. 시간 상수는 하드 신선도 이상, 최대1초로 제한한다. 고정 원본 정책 보존 항과 학습 가능한 시각 입력이 있어야 한다. 트레이너는 **기존 원본 정책의 보존 타깃을 먼저 계산한 뒤** 새 신뢰도와 입력 가중치 보정을 적용한다. 이를 반대로 하여 바뀐 정책을 원본 정책으로 잘못 고정하지 않는다. 설정·시점별 표본 수·평균 나이·보정 계수는 `visual-age-calibration.json`에 저장하고 새 시간 상수는 체크포인트 생성자에 포함한다.

보존 타깃 계산 전 pedal mode, organ validity, photometry, gain parameterization, 기존 confidence 설정이 원본 생성자와 다른 경우도 거부한다. 기본 연산의 뜻이 달라진 정책을 원본 정책이라고 부르지 않기 위한 검사다. 기존 t414 기반 실제 학습 설정들은 이 조건을 만족한다.
