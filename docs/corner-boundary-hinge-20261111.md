# 양쪽 도로 경계에서 코너 시작점 찾기 · 2026-11-11

Magione, Laguna Seca, Zandvoort, Mugello, Imola, Spa의 전·후·좌·우 저장 영상 7,287묶음에서 차량 좌표계의 양쪽 도로 경계를 다시 추출했다. 가까운 단면은 여러 카메라를, 먼 단면은 전방 카메라를 사용했다. 현재 프레임과 이전 관측을 상대 전진량·요율로 정렬한 결과를 각각 비교했다. 지도와 절대 위치는 저장된 정답과 비교할 때 사용했다. 4–18m의 후보마다 양쪽 경계가 같은 거리에서 직선에서 곡선으로 바뀌는 모양을 맞췄다. 전체 직선 또는 처음부터 휘어진 곡선보다 잘 맞고 양쪽 경계의 곡률 부호가 일치할 때만 제안했다. 유효 단면이 여섯 개 미만이거나 가까운 경계가 비거나 4m를 넘는 단면 공백이 있으면 판정을 보류했다. 저장 영상의 목표 채점 범위는 4–20m로 유지했다. 이 구현은 경계가 보이는 길이 때문에 19–20m를 직접 제안할 수 없다. 합성 자료로 좌우 반전, 4·9·14·18m 시작, 직선 및 이미 휜 도로, 관측 공백과 미출력 보존을 검증했다.
