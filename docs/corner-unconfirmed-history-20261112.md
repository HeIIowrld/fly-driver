# 회전 경보 전 후보의 시간 연속성 · 2026-11-12

원래 관측으로 회전 경보가 나오지 않은 프레임의 복구 후보를 대상으로, 직전 두 프레임의 관측·복구 후보를 검토했다. 앞선 후보가 같은 방향이고 차량 이동 후에도 앞에 남아 있으면, 국소 속도와 요율로 계산한 전방 이동량을 후보 시작 거리에서 뺐다. 현재 후보의 시작 거리와 남은 거리의 차이를 계산했다. 세대·프레임·시간 간격이 끊기거나 차체 입력이 유효하지 않으면 이력 사용을 멈췄다. 확인 결과를 후보 이력으로 되먹이지 않았다. [재생 코드](../runs/vision-corner-unconfirmed-history-20261112-01/confirm_history.py)

기존 확인 점수만 쓰는 조건, 직전 후보와 3m 이내인 조건, 두 프레임 모두 4m 이내인 조건, 현재 확인 점수에 두 거리 일치도를 가중합한 조건을 비교했다. 가중합에서 현재 점수·직전 일치도·두 번째 일치도의 비중은 70%·20%·10%이며 일치도는 거리 차가 커질수록 감소한다. 이전에 보류한 후보도 연속성 검사에 사용했다. 경계 기반과 T4/T5는 후보와 이력을 공유했다. [문턱과 개발 검증](../runs/vision-corner-unconfirmed-history-20261112-01/training.json)

Imola·Laguna Seca·Zandvoort·Mugello에서 해당 서킷을 제외하고 학습한 경계 선택기로 복구했다. 기존 코너 선택기와 확인기는 동결본을 사용했다. 개발 후보는 1,091개였고 방향·거리 동시 적중 후보는 23개였다. 두 판독 모두 기존 보완 실험의 추가 오류 상한을 적용했다. 네 조건 모두 상한 안에서 추가 적중을 얻지 못해 새 경보는 내지 않는 설정을 골랐다. 시험 영상 라벨은 설정 확정 후 사용했다.

621번은 직전 3m 조건을 통과했다. 두 프레임 연속 조건은 통과하지 못했다. 488번은 앞선 후보 이력으로 현재의 우회전 후보를 지지할 수 없었다. 두 장 모두 영상 경계 복구 뒤 후보의 방향과 거리가 맞았다. [Silverstone 후보 이력](../runs/vision-corner-unconfirmed-history-20261112-01/ks_silverstone1967-evidence.jsonl)

동결 설정으로 재생한 Silverstone의 같은 후보 비교에서 경계와 T4/T5 우회전 적중은 모두 2/13이었다. T4/T5를 추가하면 직선·범위 밖 경보 14→10건, 코너 내부 경보 5→7건이었다. Vallelunga 우 적중은 3→5/38, Monza는 3→4/42였다. Monza 범위 밖 경보는 8→25건이었다. 경보 보존, 동일 후보, 미래 프레임을 제거한 재생, 세대 변경 시 과거 증거 차단을 확인했다. 이 조건을 고정 판독기에 적용하지 않았다. 첫 적중을 포함할 때의 추가 오경보도 따로 확인했다. 직전 3m 조건은 개발 후보를 1,091개에서 242개로 줄였고, 그 안에 맞는 후보가 4개 남았다. T4/T5에서 그중 점수가 가장 높은 적중을 경보하려면 이미 직선·범위 밖 28건과 내부 39건도 함께 채택해야 했다. 기존 점수만 사용했을 때의 첫 T4/T5 적중에서는 각각 10건과 8건이었다. 두 프레임 모두 4m 이내인 조건은 후보 80개를 남겼고 그중 동시 적중은 없었다. 따라서 거리 연속성만으로는 실제 코너 시작과 반복해서 나타나는 잘못된 후보를 구별하기 어려웠다.
