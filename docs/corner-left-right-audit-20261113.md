## 보류된 좌회전만 다시 확인

이미 동결돼 있던 오류 유형 분류 확인기와 문턱을 사용했다. 원래 관측 경계에서 선택한 좌회전 후보를 가져와, 현재 판독에서 두 방식 모두 회전 경보가 없고 코너 내부 차단을 통과하는 프레임만 다시 확인했다. 기존 회전 경보와 거리는 모두 보존했다. 원래 관측 경계를 사용한 조건과 복구 경계를 사용한 조건을 둘 다 재생했다. 후보 출처와 좌회전 전용 사용은 이 저장 영상의 실패를 본 뒤 정한 탐색 조건이다. 가중치와 문턱에서 제외한 서킷이라도 이번 라우팅의 새 독립 평가는 아니다. ## 다음 목표와 합격 기준 제안

한 설정으로 여러 서킷의 4–20m 접근에서 좌우 방향과 시작 거리를 함께 맞힌다. Silverstone 1967과 Vallelunga Extended를 필수 재현 평가로 두고, Monza는 기존 비교로 유지한다. 세 영상에서 좌회전 방향·거리 적중을 올리고, 기존 우회전 적중을 각 서킷에서 유지하거나 높인다. 직선·범위 밖과 코너 내부 오경보는 개발 영상에서 사전 고정한 한도 안에 둔다. 보류와 미출력을 포함하고, 프레임 적중에 더해 서로 다른 연속 코너 접근 구간에서의 적중과 방향별 거리 오차를 보고한다. 최종 설정을 고른 뒤 학습·튜닝에 사용하지 않은 별도 서킷 저장 영상으로 재검증한다.
