# 실제 AC 네 시점 영상 → flyvis 연속 시각 회로 — 2026-10-29

[프로젝트 대전제](PROJECT_CHARTER.md)에 따른 M1 입력 연결이다.
기록된 실제 영상이 저자 시각 회로를 거쳐 망막 위치별 T4/T5 반응을 내는 경로를 구현했다.
새 비행 운동망이나 차량 actor와 합친 운전 모델은 아직 아니다.

## 카메라 방향과 망막 입력

`src/flybrain_drive/flyvis_camera.py`는 저자 R1 입력의 실제 u/v 순서721개를 확인한다.
전·좌·우·후방 카메라마다 이 순서를 유지한 영상 격자와 수용 범위9점 가중 평균을 만들고,
반환된 CSP 투영 계수·등록된 차량 기준 forward/right/up에서 각 입력의 body ray를 계산한다.
중앙 입력은 각각 전방(+X),왼쪽(+Y),오른쪽(-Y),후방(-X)을 향한다.
화면 오른쪽이 v증가, 화면 아래쪽이 u+v/2증가인 저자 영상 순서를 유지했다.

이는 카메라마다 정규화 영상에 맞춘 **공학적 공간 변환**이다. 수평·수직 각도 간격은 카메라마다
달라지며, 저자 자극장의5.8° 간격이나 실제 초파리 광학축을 그대로 재현한 것이 아니다.
전방 카메라와 측후방 카메라의 서로 다른 시야각도 보존한다. 수용 범위 전체가 실제 원본 픽셀
안에 있는지 확인하며, 바깥 영역을 회색/검정으로 채우지 않는다.
입력은 LDR RGB의 가중 밝기이며 선형 광자량이나 생물학적 색각을 검증한 변환이 아니다.

네 카메라는 서로 다른 위치에서 촬영한다. 독립된 시점 ID·망막 방향·회로 상태를 유지하며
깊이를 모른 채 공통 중심의 파노라마나 실제 양안 겹눈으로 합치지 않는다.
향후 비행 회로에 합칠 때 이 방향·시점·원자료 경계를 유지해야 한다.

## 원래 시간과 신경 상태

`t1029`에서 원본 t1002의 **학생805+대기2+교사736=1543관측 전체**를 처리했다.
원본 파일/RGB/카메라 ZIP 해시를 검사했고, 몸 관측 v1(t1028)의 packet·decision 시각과 일치시켰다.
각 카메라는 저자 네트워크의 독립 batch 원소로 실행했다. 가중치는 공유하지만 신경 상태는 분리된다.
한 카메라당45,669모형 노드/1,513,231연결이며, 실제 MaleCNS 개별 뉴런 ID와 직결한 것은 아니다.

- 시작 때 저자 방식으로1초 회색 steady state를 한 번 만든다. 첫 실제 장면에 대한 초기 과도 반응은 남아 있다.
- 원래 decision 간격을5ms이하 내부 적분과 나머지 시간으로 정확히 보존한다.
- 새 장면이 들어오기 전 구간은 **직전까지 알려진 입력**을 유지한다. 현재/미래 장면을 과거 구간에 넣지 않는다.
- 내부13,466적분 tick은 새 측정 영상13,466장이 아니다. 원본 capture가 같았던113결정도 같은 망막 입력을 유지했다.
- 카메라 갱신이 없어도 시간 상태는 계속 적분하며, 학생/교사 인계에서 초기화하지 않는다.
- 카메라 세대 변경·ID역행·누락·150ms초과 exposure 하한 age는 실패 조건이다. 다른 시점이나 정답 정보로 대체하지 않는다.

동기화한 시각은 원래 호스트 decision 시각이다. 엔진 시뮬레이션 노출 시각의 일치나 네 카메라의
동시 노출을 주장하지 않는다. 실제 actor가 사용할 때의 추론 지연·처리량도 별도 검증이 필요하다.

## 결과와 수치 검증

원본 경과62.4674초를 재생 구간58.8860초에 처리했다. 이 시간은 steady state·프레임 처리·
신경 계산·결과 저장을 포함하며, 앞선 원본 해시 검사·모델 로딩을 포함한 전체 명령 시간은 아니다.
최대 GPU tensor 사용량5,515,289,088bytes, 가중치 변경·최적화·차량/UI 조작은0회다.

저장한 반응은 중앙65세포형과 **4시점 × 8개T4/T5유형 × 721망막 위치**의 전체 시간 이력이다.
모두 유한값이며, 원본1,543시각과 인계 단계를 유지했다. 이는 도로/커브 인식을 이미 정확히
학습했다는 뜻이 아니다. 아직 비행 하행망에 합친 항법/운동 출력이나 랩타임 향상은 검증하지 않았다.

`t1030`에서 저장된 몸 시각/단계 일치와 반복 capture의 같은 망막 입력을 재확인했다.
실제 네 시점 입력으로 저자 회로8tick을 한 번에 계산한 결과와3+5tick으로 나누되 상태를
전달한 결과의 최대 오차는7.15e-7이었다. 독립 카메라 batch 순서를 바꾼 대조도7.15e-7이었다.
상태를 버리고 초기 상태로 바꾼 반례는 최대0.5023만큼 달랐다. 같은 상태가 이어진다는 수치 검사다.
이8tick 검사를 전체 주행의 정확성이나 생리 기능 검증으로 확대하지 않는다.

투영/방향/시간 분할 검사3개와 Ruff가 통과했다. 원래 공개 모델의 T4d 대비 불일치는 그대로이며,
새 카메라 공간 변환에 대한 방향/속도 선택성·회전/병진 반응 검증은 남아 있다.
