# 주행선 OFF 새 기록과 경로 추종 진단

기록일: 2026-10-29, Asia/Seoul. [대전제](PROJECT_CHARTER.md)는 유지한다.

후속 회로 범위/균형 학습/알려진 기록 재평가는 [최신 조향 진단](flight-steering-capacity-and-balanced-learning-20261029.md)을 따른다.
초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다.
차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.

**새 입력 자료의 주행선 OFF는 확인했다. 고정 후보의 시각 경로 추종은 여전히 검증하지 못했다.**
이 기록을 재학습에 넣지 않고 기존 마지막 체크포인트 그대로 평가했다.
이전 t1107의 개발 합동 검증 실패도 유지한다. 실제 학생 제어·완주·생리 기능을 입증한 실험이 아니다.

## 다음 작업과 실행 상태

1. 평균 손실과 시각 제거만으로 후보를 승격하지 않는다. 좌우 표적과 중립 구간, 조향0/정적 장면
   대조를 함께 보고 HS/VS 경계와 추가 명령 경로의 학습 실패를 진단한다.
2. 시작 직후의 반응과 실제 주행 중의 판단을 분리해 검증한다. 예열이 필요하면 다음 수집에서
   정차 brake hold 상태의 실제 영상·물리 packet prefix부터 명시적으로 기록한다.
   기존 기록에 가짜 prefix를 덧붙이거나 처음3초를 삭제해 채택하지 않는다.
3. 실제 좌우 커브를 지속해서 보는 자료와 양성 제동을 확보한다. 이번 기록은 평가 역할로 유지한다.
   제동 없는 교사만 반복해 가감속 학습이 끝났다고 하지 않는다.
4. 몸 미등록 축/가속도·타이어/접지/셋업·실제 plant 안정화와 기전의 인과적 기여를 검증한 뒤,
   검증된 구조로 학생 단독 완주·반복·레이싱 라인/랩타임 개선을 검증한다.
