# 원래 판독 경보 복구와 방향·거리 결합 · 2026-11-11

원래 판독에서만 경보가 울린 프레임을 Magione·Laguna Seca·Zandvoort 전체에서 찾았다. 새 판독이 이미 경보를 낸 프레임에는 기존 상대 색도 경계의 방향 교체와 새 거리 부품을 적용했다. 새 판독이 경보를 내지 않은 프레임에서만 원래 경보의 복구를 시험했다. 복구 여부를 반사 방향 점수, 공동 방향·거리 점수, 영상 경계의 방향으로 각각 확인했다.

Laguna Seca에서 복구 대상 20개 중 3개는 원래 판독이 방향을 맞힌 접근이었다. 원래 경보를 복구하면서 새 거리값을 절반 섞으면 좌 방향 4개를 회복하고도 결합 적중이 3개였다. 원래 경보의 거리값을 함께 복구하자 결합 적중도 4개였다. 영상과 몸 감각에서 계산한 값만 사용했으며 지도는 개발 정답과 채점에만 사용했다.
