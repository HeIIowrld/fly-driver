# 같은 몸의 영상 개입 재검사와 실제 조향값 손실 — 2026-11-03

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.** 비행 기준, 가감속·변속·차종/타이어/셋업·검증된 상대풍·빠른 라인/랩 목표와 actor의 지도/world pose/교사 조작 배제를 유지한다.

## 무엇을 확인했는가

사용자의 질문은 같은 몸 상태에서도 영상에 따라 코너 진입 전 조향이 달라지는지, 그리고 지금 결과가 반복 코너 암기에 해당하는지다. [앞선 개입](steering-precorners-20261103.md)은 같은 시작 회로 상태와 이후 몸·과거 몸을 고정한 영상 특징 교환에서 4구간 중 3구간의 예상 방향 반응, 공간 경계 제거 시 진입 전 오차 2.22% 증가를 보였다. 익숙한 영상 장면의 기억과도 양립하는 결과다.

**현재 수치는 학생이 실제로 서킷을 타고 낸 성적이 아니라 교사 기록에서 조작을 예측한 오프라인 결과다.** actor에 코너 목록/지도/절대 위치를 주지는 않았으나 반복된 Monza의 몸 반응과 장면으로 코너를 구분할 가능성이 남아 있다. 차체 기울기·회전·속도와 이력에는 이미 진행 중인 조작/운동의 단서가 있다. 시각 제거의 작은 영향은 새 도로를 보고 선행 판단한다는 증거가 부족하다는 뜻이지, 시각이 원래 불필요하다는 뜻이 아니다. 미학습 트랙이나 자세·도로 상대 위치까지 맞춘 곡률 대조는 아직 없다.
