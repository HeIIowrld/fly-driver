# 국소 곡률 판독의 서킷별 제외 평가 · 2026-11-12

Imola, Laguna Seca, Zandvoort, Magione, Mugello의 기존 영상 6,087묶음으로 전체 판독기를 다시 검증했다. 한 서킷씩 평가 대상으로 두고 나머지 네 곳으로 경계 패치, 경계 확인, 경계와 T4/T5를 결합한 확인 모델을 각각 학습했다. 평가 서킷의 영상을 세 모델의 적합에 사용하지 않았다. 평가 서킷의 지도와 주행 좌표는 채점에 쓰였다. 이 다섯 영상은 앞선 개발 실험에 사용한 자료다. Silverstone에서 연속 경보를 얻은 국소 곡률 판독을 사용했다. 패치 문턱 0.55, 곡률 문턱 0.002m⁻¹, 경보 확인 문턱 0.25와 한 프레임 거리 갱신 조건을 적용했다. 같은 경계 후보에서 확인 모델의 T4/T5 입력 유무만 바꿨다. 방향·거리 동시 적중은 실제 접근이 4–20m이고 방향이 맞으며 거리 오차가 ±5m 이내인 경우다. 안정 예고는 같은 코너 접근에서 연속 두 프레임이 동시 적중한 경우다. 오경보는 공통 기준의 직선·범위 밖 경보를 뜻한다.

물리 코너 수는 한 서킷에서 같은 코너를 여러 번 접근해도 한 곳으로 셌다. 주행 기록별로 따로 세면 결합 조건의 안정 예고는 13건이며 Magione의 한 코너가 두 주행 기록에 포함된다. 안정 예고한 우회전 물리 코너는 다섯 서킷 합계 1→5곳이었다. 국소 곡률 보류 복구를 적용하기 전의 기준선은 좌 6·우 13·동시 적중 5·오경보 59·안정 예고 1곳이었다. [검증한 물리 코너 ID](../runs/vision-corner-local-heldout-20261112-01/verified-summary.json)

짝지은 프레임에서 T4/T5 입력을 추가하면 보류에서 동시 적중으로 바뀐 경우가 42건, 동시 적중에서 보류로 바뀐 경우가 4건이었다. 직선·범위 밖 오경보는 126건이 사라지고 158건이 새로 나왔다. 코너 안 경보는 48건이 사라지고 375건이 새로 나왔다. 이 수치는 공통 오경보 합계와 별도로 집계했다. Magione에서는 동시 적중 증가와 오경보 감소가 함께 관측됐고, Zandvoort에서는 좌우 방향 적중이 각각 한 건씩 줄었다.
