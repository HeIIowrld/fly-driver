# 현재와 과거 관측을 결합한 도로 경계 추정 · 2026-11-12

Silverstone 우회전에서 오른쪽 경계의 누락과 잘못 놓인 위치를 따로 다뤘다. 같은 쪽의 현재 관측, 앞뒤 단면으로 보간한 위치, 이전 최대 네 프레임·0.45초의 경계를 입력했다. 이전 영상 경계는 차량의 국소 속도와 요율로 옮겼고, 양쪽이 동시에 보인 단면을 요구하지 않았다. 시간이나 세션 연속성이 끊기면 이력을 비웠다. 반대쪽 경계는 위치를 추정할 때의 입력으로만 썼다. 같은 쪽의 현재·보간·과거 좌표가 모두 비어 있으면 결과를 비웠다. 관측 범위 밖으로 과거 경계를 외삽하지 않았고 추정 결과는 이력에 다시 넣지 않았다. [학습과 재생 코드](../runs/vision-corner-supervised-boundary-fusion-20261112-01/fit_fusion.py)

개발 서킷 Imola·Laguna Seca·Zandvoort·Mugello의 투영 가능한 노면 전환 좌표로 경계 위치를 학습했다. 이미 관측한 점은 새 추정의 오차가 0.15m 이상 작아질 가능성을, 빈 점은 새 추정 오차가 1.25m 이내일 가능성을 점수로 학습했다. 서킷을 통째로 뺀 평가에서 새 점의 횡오차와 기존 점의 평균 오차 변화를 기준으로 문턱 0.8을 고정했다. Laguna Seca는 유효 경계 라벨이 395점으로 다른 개발 서킷보다 적었다. 시험 녹화에 쓰인 물리 좌표는 채점에만 사용했고, 투영 표본에는 가림을 별도로 판정하지 않은 점이 있다. [동결 설정과 서킷 제외 채점](../runs/vision-corner-supervised-boundary-fusion-20261112-01/training.json)

Silverstone의 우회전 접근 13장에서는 오른쪽 경계 195점 중 원래 관측된 185점의 평균 횡오차가 1.78→1.72m였다. 수정된 네 점은 4.86→2.40m였다. 누락된 오른쪽 10점과 왼쪽 13점은 그대로 비어 있었다. 세 시험 영상에서 추가된 경계는 각각 한 점이었다. [경계 좌표와 결과](../runs/vision-corner-supervised-boundary-fusion-20261112-01/result.json)

동시 적중은 4–20m 접근에서 방향과 시작 거리 ±5m를 함께 맞힌 프레임이다. 화살표는 기존 경계에서 새 경계로 바꿨을 때의 변화다. Monza는 기존 라벨 989장으로 채점했고 코너 내부 라벨은 없다. 새 경계는 두 판독에 공통으로 적용했고, 각 판독의 확인기와 문턱은 기존 설정을 썼다. 경계 위치는 일부 개선됐지만 Silverstone 우회전에서 누락이 줄지 않았고, 경보 지표도 일관되게 개선되지 않았다. 이 변경은 고정 판독기에 적용하지 않았다.


Silverstone에서 방향과 거리가 맞는 우회전 후보가 있던 프레임은 7→9장이었고, 최종 비교 후보로 선택된 프레임은 6→7장이었다. 488번에서 선택은 좌 6.88m에서 우 14m로 바뀌었다. 실제 시작은 우 18.04m였고 경계 확인은 통과했지만 T4/T5 확인은 보류했다. 전체 Silverstone 비교에서 T4/T5는 경계 방식의 직선 경보 6건과 범위 밖 경보 1건을 없앴고 직선 경보 1건을 추가했다. 코너 내부 경보는 2건을 없애고 3건을 추가했다.

누락된 오른쪽 10점에는 모두 보간 또는 과거 관측이 있었다. 후보 좌표 중 하나 이상이 실제 위치 1.25m 이내인 점은 8개였다. 학습한 좌표가 1.25m 이내였던 점은 하나였고 확인 점수 0.46으로 보류됐다. 따라서 복구의 다음 비교 대상은 여러 좌표를 한 번에 회귀하는 대신 원래 관측 후보를 유지하고, 후보별 위치 오차와 신뢰도를 학습해 고르는 방식이다. 같은 후보 비교, 이전 기준 재현, 입력 해시, 미래 프레임 제외와 세션 경계의 이력 초기화를 확인했다.
