## 교사와 계측 근거

공개 SAC는 앞선 정차 재출발에서 gap3m 기준으로 중단됐다. 그 제한을 넓혀 SAC를 계속
실행하지 않았다. 별도 `geometric_recovery` 모드를 추가하고 실제 복귀 범위를 선언했다.
학생 actor, 체크포인트, recurrent graph와 입력 배열은 이번 작업에서 바꾸지 않았다.

`runs/ac-geometric-teacher-motion-fit-20261028-t92/`는 앞서 실제 파라볼리카를 주행한
t83 기록에서 native yaw 변화와 SDK 평면 이동거리, native 적용 조향의 관계를 추정했다.
±5표본 구간에서 거리2m 초과, canonical 조향 절댓값0.07 초과인181개를 사용했다.
조향 단위는 기존 별도 정차 보정 결과로 device 축과 맞췄다. 중앙 curvature/canonical
steering은−0.09879357,25/75분위는−0.10643/−0.09368이었다. 사용 표본 속도 범위는
17.17–68.84km/h다. 이 값은 교사용 근사 관계이며 roadwheel radians, 차량 전체 동역학,
노출 동기 또는 파리 신경 생리 검증이 아니다.

교사는 hash로 고정한 Monza reference line에서 최근접 선분과 전방 지점을 찾는다.
lookahead는 `8 + 0.6 * speed_m_s` m이고, 목표 곡률은 `2*cross/target_distance²`다.
위 근사 배율로 canonical 조향을 구해±0.35로 제한한다. 목표 속도는 최대20km/h에서
기준선 거리·목표 방향 오차가 커질수록 낮춘다. 최대 가속0.25, 최대 제동0.5이며 시간에
따른 임의 stop/restart 라벨은 만들지 않는다. 위치·yaw·지도는 교사에만 사용한다.

복귀 모드는 초기 gap6.5m 이하, lateral ray 여유1m 이상, 정차·전진 기어를 요구한다.
최초 허용 gap은 `max(3, initial_gap+1.5)` m이며 최대8m다. gap이 줄 때마다 허용 범위도
줄어 최종3m로 돌아온다. speed hard stop30km/h, 같은 세션 조향 보정, profiles/DLL 해시,
장치·창 identity, builtin AI 비활성, source freshness, stop 파일, 종료 제동·해제를 유지한다.
이는 새 복귀 과제의 명시적 한도이며 기존 SAC의3m 한도를 바꾼 것이 아니다.

## 남은 문제와 자료 사용 범위

이번에는 양·음 조향과 저속 복귀 자료를 확보했으나, 속도 목표가 복귀하며 점차 높아져
주행 중 제동 요청은0이었다. 강한 감속 자료를 확보했다고 하지 않는다. 종료 제동은 별도
정리 요청이며 학생이 선택한 제동 라벨이 아니다.

원래50개, 파라볼리카500개, 새 복귀500개로 실제 기록 자료는1050개지만 새 복귀 자료는
아직 학생에 학습시키지 않았다. SAC/70km/h curriculum과 최대20km/h 복귀 교사는 서로
다른 과제다. 속도 목표가 다른 라벨을 구분 없이 섞으면 같은 actor 상태에서 상충하는
페달 목표가 생길 수 있다. 다음은 일관된 교사 속도·경로 계약으로 실제 상태를 재평가하고,
필요한 경우 미실행 교사 라벨임을 명시해 수집 실행 요청과 분리하는 것이다. 실제 코너
접근·감속 자료와 학생의 지속 주행 검증도 필요하다.

학생은 여전히 t87 체크포인트이며 최근 실제 제어는 t90의12요청·속도 제한 중단이다.
새 복귀 교사의76m 결과를 학생의76m 주행으로 세지 않는다. 다중 시각 입력과 몸 감각,
셋업·타이어 판단, 자율 서킷 완주·랩 최적화 목표는 유지한다.
