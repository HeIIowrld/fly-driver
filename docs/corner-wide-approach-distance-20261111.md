# 20m 밖 접근을 포함한 코너 시작 거리 학습 · 2026-11-11

같은 운동 시각과 몸 감각으로 시작 거리를 추정하되, 학습 범위를 4–20m, 4–32m, 4–48m로 바꿨다. 먼 표본과 먼 구간에서 시작한 연속 쌍의 총 가중치는 각 개발 서킷에서 가까운 표본의 0.4배로 뒀다. 같은 코너에 접근하는 연속 두 영상의 거리 차이도 학습했다. 지도와 코너 ID는 학습·채점에만 사용했다. 평가에서는 기존 경보의 거리만 보정했다. 범위를 늘리면 먼 코너를 가까운 거리로 읽는 빈도가 줄었으나 가까운 접근의 절대 오차가 커졌다. Spa 612번은 실제 15.72m에 대해 20m 학습에서 4.70m, 32m 학습에서 10.09m였다. 절대 오차는 줄었고 여전히 ±5m를 넘었다. [프레임별 거리](../runs/vision-corner-wide-approach-distance-20261111-01/rows.jsonl)

Spa 사후 비교에서 48m까지 학습한 값을 기존 경보에 절반 섞으면 공통 연속 6쌍의 거리 변화 오차가 5.01→4.56m였다. 사전 기준 4.70m를 통과했지만 좌 2/22, 우 15/49, 결합 10/71, 안정 예고 3/24곳은 같았다. 오경보도 80/605건이었다. [전체 채점](../runs/vision-corner-wide-approach-distance-20261111-01/result.json)

여섯 서킷 전체 7,287개를 채점했다. 평가 서킷과 Spa는 학습과 보정 비율 선택에서 제외했고, 비율을 고르는 개발 예측도 각 서킷을 학습에서 제외해 만들었다. 18개 비교 중 하나에서 비율이 선택됐다. Magione에서 32m 조건을 25% 적용했을 때 결합 적중은 71→74건, 공통 거리 변화 오차는 0.293→0.290m였고, 예고 거리가 늘어난 쌍은 16→19개였다. 다른 서킷으로 넘어가도 거리·경보 기준이 개선되는 공통 설정은 확보되지 않았다.
