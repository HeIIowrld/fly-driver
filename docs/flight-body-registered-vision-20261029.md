# 다중 시점·몸 자세 정렬과 파리 시각망 학습 경로

기록: 2026-10-29 실험 t1645–t1654. 기존 TRAIN3/개발1, 총 2,956관측을 재사용했다. 게임의 현재 실행 상태를 새로 확인한 기록은 아니다.

## 대전제

초파리 겹눈·운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어를 몸 감각으로 되먹임하고 조향·가감속, 빠른 레이싱 라인과 랩타임을 학습한다. 일반 운전망으로 대체하지 않는다.

## 실제 진전

- 기하 예측의 몸 입력을 pitch/roll/yaw/속도로 명시했다. 원본 21개 값과 유효성은 보존하며, 타이어·하중은 접지·제동·속도 제어 경로에 계속 필요하다. t1646에서 세 조건 각 200회, 총 600회 보조 학습을 수행했다.
- 네 시점의 실제 저자 시각망 반응을 몸 자세와 카메라 장착 위치로 공간 정렬했다. 가상 수평면 투영이며 실제 노면 깊이·가림을 측정했다는 뜻은 아니다. 스칼라 여섯 종류만 합치고 방향성 T4/T5 반응은 카메라별로 유지했다.
- t1650에서 세 표현을 동일 141,558개 파라미터·초기값으로 각 200회 비교했다. 개발 표준화 MSE는 기존 영상 격자 1.142742에서 자세 정렬 0.252290으로 약 78% 감소했다. 시각 특징을 평균으로 대체하면 0.527860으로 악화했다. 전방·양옆·후방 각각의 반응을 없애도 악화했다. 이 결과는 알려진 개발 자료의 구성 요소 진단이다.
- 그러나 5/10/20m 방향 예측 중 5m와 10m는 기준 미달이다. 전체 사전 통과 기준은 실패다. t1652의 동일 703개 유효 관측에서 20m 곡률 RMSE는 모델 0.005579, 현재 yaw/속도의 물리 근사 0.002440이다. 코너 진입 12관측에서도 선행 예측 우위를 입증하지 못했다. 현재 회전을 읽는 것과 앞으로 꺾을 길을 읽는 것은 구분해야 한다.
- t1654에서 실제 저자 시각망 내부까지 역전파되는 것을 하드웨어로 검사했다. 기존 동결 재생과 뉴런 반응 차 3.58e-7, 정렬 특징 차 2.98e-7이다. 원래 학습 가능했던 734개 중 674개에 유한한 비영 미분이 생겼다. 고정 2,959개와 모든 가중치 값은 변경하지 않았다. GPU 텐서 최대 약 5.52GB였다. 두 관측 간격의 미분 경로 검사이며 실제 시각망 학습은 아니다. 앞선 t1653 환경 설정 실패도 보존했다.

이번 추가 보조 학습은 1,200회이며 t1637 이후 합계 2,200회다. 파리 내부 파라미터 optimizer 업데이트 0, 운동 그래프 업데이트 0, 학생 배포 0, 학생 유효 랩 0이다. 이 실험들은 종료됐으며 현재 학습 중이라고 표현하지 않는다.
