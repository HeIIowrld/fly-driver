속도/제동 진단에서 다시 **시각→조향 명령→비행 유래 운동 회로** 학습으로 작업을 옮겼다.
후속 t1473 조향 명령 학습/개발 평가는 종료0이며 개발 미통과다. [최종 결과](flight-steering-terminal-and-speed60-pilot-20261029.md)를 따른다. 성공·학생 주행·레이싱 성능을 주장하지 않는다.

## t1471: TRAIN 영상의 반사 입력을 실제 저자 시각 회로에 재생

등록된 721개 겹눈 UV에서 수평 반사의 대응이 오차 0인 전단사·involution임을 확인했다.
전면/후면은 수평 반사, 좌/우 카메라는 서로 교환한 뒤 수평 반사한다.
실제 RGB를 새로 촬영한 것이 아니라 원래 등록된 retinal 입력을 변환한 공학적 증강이다.
원래 카메라/실제 경로/신경망이 생리적으로 좌우 대칭이라는 주장은 하지 않는다.

T4/T5 이름이나 채널을 임의로 바꾸지 않았다. 반사 retinal 입력을 원래 저자 시각 신경망에 다시 넣어
운동 시각 반응을 재계산했다. 원래 TRAIN 6개 이력만 사용했고 개발/평가 원시 배열은 열지 않았다.
각 이력마다 원래 1초 grey 초기 상태, 실제 관측 시각과 이전 입력 hold를 유지했다.
중간 신경 상태 reset/시각 재배열/공백 보정은 없다.

첫 TRAIN 이력 전체의 원본 신경 반응/scene 재현 최대 오차는 **0**이었다.
저자 가중치는 바꾸지 않았다. 반사한 이력을 다시 반사하면 원본 retinal 배열과 정확히 같았다.
별도 반사 검사 3개와 Ruff를 통과했다. 원래 T4d 등 생리 기능 실패를 해결된 것으로 바꾸지 않는다.
추가 물리 관측은 0개이며, 6개 반사 이력을 새 실차/게임 구간으로 세지 않는다.

## t1472: 조향과 앞길 방향의 사전학습 — 개발 실패

실제 원래/반사 T4/T5·retinal 반응의 576차원 요약을 입력으로 사용했다.
공유 patch 9→8, latent 512→64 뒤의 4개 훈련 출력으로 조향 및 5/10/20m 앞길 방향을 학습했다.
이 출력은 사전학습 표적이며 직접 액추에이터 정책이 아니다.

- 원래 TRAIN 6/개발 2 역할을 유지했다. 원래 조작/시각/마스크는 바꾸지 않았다.
- 반사 TRAIN의 조향/방향 표적만 부호를 바꾸며 원래 이력과 별도 파생 자료로 구분했다.
- 원본만 쓴 조건과 반사를 더한 조건을 seed 863472, AdamW lr0.001/weight decay0.01,
  고정 200epoch씩 비교했다. TRAIN만으로 입력/표적 정규화와 fitting을 했다.
- 손실은 절반의 좌/우/중립 동등 조향 MSE와 절반의 세 거리 방향 MSE다.
  개발 결과로 epoch/조건을 선택하지 않았다. 두 조건 모두 마지막 checkpoint를 보고했다.

|---|---:|---:|---:|
| 원본만 | 0.055968 | 0.101012 | 0.016991 |

반사를 더한 조건은 두 개발 구간에서 오히려 나빴다. 3초 후 조향 오차도 개선되지 않았다.
앞길 방향의 일부 거리만 기존 대비 줄어든 것을 성공으로 해석하지 않는다.
원본 valid 조향 표적은 3,497개이며, 반사를 더한 학습의 좌/우/중립 수는 2,006/2,006/2,982다.
좌우 수를 균형 있게 만든 것만으로 구간 일반화 문제가 해결되지 않았다.

## t1473: 실제 파리 운동 회로의 조향 명령 학습 — 아래는 실행 중 당시 기록

사전에 정한 반사 조건을 사용해 후속 명령 경계 실험을 진행한다. 개발에서 더 좋은 조건을 골라
성공을 주장하는 절차가 아니다. 시각 조건의 실패와 운동 회로 연결의 결과를 따로 보존한다.

- 사전학습 patch/latent 가중치를 새 경계에 복사했다. latent의 속도/목표 추가 입력 가중치는 0이다.
  사전학습 출력층을 액추에이터로 연결하지 않는다. 새 조향 출력층은 초기 0이다.
- 출력층의 4개 DNa04/05 current 조절만 학습한다. 시각 encoder, 운동 그래프의
  9,728뉴런/1,311,145연결, 몸/운동 readout과 power 경로는 고정한다.
  조향 전류가 공통 운동 출력에 간접 영향을 줄 가능성은 남으므로 forward 오차도 평가한다.
- 원래 TRAIN 이력 6개를 전체 시간 순서대로 사용한다. 파생 반사 몸 상태를 임의 생성하지 않는다.
  원래 신경 상태/이전 held drive를 유지하고 64관측마다 미분만 detach한다.
- 원래의 좌/우/중립 동등 bounded logistic 조향 손실, lr0.01, 고정 24epoch다.
  TRAIN 손실에 대한 guarded Adam을 사용하며 개발 자료는 마지막 보고에만 쓴다.
  각 업데이트에서 고정 파라미터 불변과 몸 경계 보호를 검사한다.
- 초기 전체 TRAIN drive가 원래 모델과 정확히 같음을 검사했다. 학습 기울기는 조향 명령층에서
  실제 운동 회로를 통과한다. 직접 액추에이터 잔차/새 일반 운전 정책으로 우회하지 않는다.

당시 소유한 실제 프로세스 PID **40084**, 도구 session **31336**이다.
로컬 출력 `C:/Users/jeff4/AppData/Local/flybrain/runtime-runs/20261029-t1473-pretrained-real-flight-steering`.
마지막 확인에서 3/24epoch가 승인됐고 손실은 0.658804→0.655661이었다.
이 값은 당시 진행 상태이며 다음 작업에서는 원본 progress/PID/도구 핸들을 다시 확인한다.
관측 timeout만으로 새 학습을 제출하거나 기존 프로세스를 종료하지 않는다.

학습 후 같은 스크립트가 개발 두 이력의 intact/새 명령 제거/시각 TRAIN평균 치환을 평가한다.
전체와 3초 후의 조향/forward 오차를 모두 저장한다. `training-result.json`은 학습만의 완료이며
`result.json`과 도구 종료까지 확인해야 평가 완료로 판단한다. 아직 학생 제어에는 적용하지 않았다.

별도 amd-smi 질의는 응답하지 않아, 실제 명령/부모 PID를 확인한 소유 metric 프로세스만 종료했다.
학습 PID와 다른 llama-server/작업 프로세스는 건드리지 않았다.
