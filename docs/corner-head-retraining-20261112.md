# 코너 유무와 방향 재학습 비교 · 2026-11-12

같은 T4/T5 영상 특징에서 유무 판독만 재학습, 방향 판독만 재학습, 둘 다 재학습, 유무와 좌우 조건부 방향을 따로 학습하는 네 조건을 비교했다. 모든 조건에 같은 기존 거리 추정기를 사용했다. 표의 기준은 같은 거리 추정기를 쓰는 기존 유무·방향 판독 재생이다. 고정 Silverstone 독립 평가의 경계 복구·거리 후처리를 포함한 결과는 별도 기록에 있다. 학습 시 서킷별 전체 가중치를 맞췄다. 양성은 좌·우와 물리 코너별로, 음성은 직선·범위 밖·코너 내부별로 균형을 맞췄다. 개발 서킷 하나를 제외할 때 남은 서킷에서도 각 서킷을 학습에서 뺀 예측으로 문턱을 고르는 중첩 비교를 했다. Spa와 Silverstone은 가중치 학습과 문턱 선택에서 전부 제외했다. 채점은 7개 서킷의 8,487프레임에서 수행했다. 두 서킷은 고정 결과를 이미 읽은 뒤의 사후 진단이다. Silverstone에서 유무·좌우 조건부 방향의 문턱을 0.35로 내리면 우 6, 결합 5, 안정 예고 2곳을 얻었지만 오경보가 77건이었고 좌 적중은 0이었다. 이 사후 수치로 문턱을 채택하지 않았다. 고정 비교군과 공유하는 연속 방향 적중 쌍은 0이었다.

방향만 바꾼 Zandvoort는 좌 0→2, 우 6→7, 결합 1→4, 오경보 49→23, 안정 예고 0→1곳이었다. 같은 방식에서 Magione의 좌는 9→0, 우는 62→8로 줄었다. 유무를 새로 학습한 세 조건은 중첩 비교에서 오경보와 기존 적중·안정 예고 제한을 지키며 개선한 문턱이 없었다. 사용 모델에는 반영하지 않았다. [개별 접근 프레임](../runs/vision-corner-head-ablation-20261112-01/approach-rows.jsonl)
