# 기관별 되먹임 연결과 큰 곡선 시험

기록: **2026-10-27, Asia/Seoul**. [직전 시각 회로](local-temporal-20261027.md)에 조향 위치·차체 yaw 회전의 되먹임을 연결했다. 같은 checkpoint가 기본4조건과 곡선 진폭4m·6m의8조건, 총 **12/12를 완료**했다. 시각 전용·기관 제거 대조군도 완료율을 유지했으므로 기관이 완주에 필수라고 주장하지 않는다. 실제 AC 주행과 속도·제동 관문은 남아 있다.

## 구현과 교정

2,626뉴런·92,740연결, 원본 Traced incoming 분모, 시각 특징·시간 상수·readout 이득을 유지했다. 시각 입력은 여전히1,009개 MeTu의 국소12광선×RGB다. 시각 가중치를 다시 학습하지 않았으며 위치 피드백 보상에 맞춰 기존 공간 패턴의 이득만 **1.2배**로 정했다.

- **위치 경로:** chordotonal 주석의425개 입력 포트에 Gaussian 조향 위치 집단을 넣는다. 차량 Ackermann 관계로 위치 집단→정규화 조향 변환을 교정했으며 RMS 오차는0.000149873이다. 위치 되먹임 이득은0.2다.
- **회전 경로:** haltere 주석의201개 입력 포트에 부호를 나눈 yaw 각속도 신호를 넣는다. rotation scale5에서 rad/s로 복원하고 되먹임 이득0.1을 적용한다.
- 선호도는200틱 단위 자극의 구조 민감도로 정한 **공학적 가설**이다. 교사 경로·주행 label을 사용하지 않았고, 뉴런별 측정 감각 선호도를 확보한 것은 아니다. 감각은 해당 input 포트로만 들어가며 PFL·내부·출력 뉴런에 직접 주입하거나 motor residual로 우회하지 않는다.

`organ_feedback.py`는 위치 decoder가 회전 채널을 읽는 것을 거절하고, 이미 교정된 기관 가중치를 다시 교정해 이득을 중복 적용하지 못하게 한다. 단위 자극에서 양의 조향 위치와 양의 yaw가 음의 조향 되먹임을 만들고, 회전 부호 반전 시 반응도 반전함을 검사했다. 감각 무효화 시 해당 외부 drive는0이다.

선언 포트626개 중 비영 가중치가 생긴 포트는 **601개(위치407·회전194)**다. 나머지는 선택 부분망에서 출력에 대한 구조 민감도가0이다. 실제 교사 관측128개를 입력했을 때 비영 몸 감각 drive가 발생하며, 차이는 기관 input 포트에만 존재함을 확인했다. 최대 절댓값은1.97e-8이며 내부 단위에 대한 값이다. 작은 drive가 큰 readout 이득을 거치므로 이 값만으로 기능적 영향의 크기를 판단하지 않는다.

이번 되먹임에서 사용하는 것은 **조향 위치와 yaw**다. 서스펜션·방향 운동·진동·하중·roll/pitch 채널은 이 교정의 기능 입력으로 사용하지 않는다. 기관 인코더와 주석 경로의 기능적 근사이며 실제 기관 기계 구조나 생리학적 회로의 재현을 뜻하지 않는다.

## 기본4조건

전진 의도는 기존 공통 제어기의1.5m/s 목표에 고정하고 actor는 조향만 결정한다. 실제 속도의 완전한 일정성이나 자율 가속·제동 결과는 아니다. 매 제어 틱의 상태를 유지하며 교사·정답 경로는 actor에 제공하지 않았다.

## 다음 관문

이제 우선순위는 **AC의 영상·계측·조작 bridge와 단위·좌표·시각 계약**이다. 마지막 설치 점검에서 등록된 Steam 경로의 엔진을 발견하지 못했으므로 실제 런타임 검증에는 설치된 PC·경로가 필요하다. 그동안 연결 프로토콜과 기록 재생 경로를 준비할 수 있다. 정답 도로 정보는 계속 교사·평가에 분리한다.
