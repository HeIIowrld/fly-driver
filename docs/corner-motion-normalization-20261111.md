# 이동 거리로 정규화한 겹눈 반응 · 2026-11-11

세 개발 서킷의 기존 영상과 카메라 메타데이터에서 연속 프레임 사이 로컬 전방 이동을 다시 읽었다. 4–20m 접근에서 이동량 중앙값은 Magione 0.41m, Laguna Seca 4.40m, Zandvoort 4.09m였다. 전체 접근 264개는 두 간격 모두 움직임을 확인할 수 있었다. 일반 프레임에서 두 이동 구간이 있는 특징은 각각 1,873/1,887, 998/1,000, 998/1,000개였다.

같은 공동 판독층에 최신 T4/T5 반응만, 최신 반응과 앞선 두 프레임 간 차이, 최신 반응과 그 차이를 로컬 이동량으로 나눈 값을 넣었다. 분모가 너무 작은 경우 0.25m를 적용했다. 이 변환은 비선형 T4/T5 반응 전체를 속도로 나누지 않는다. 특징 가용성과 학습 데이터 조건을 세 방식에 공통 적용하고, 매번 평가 서킷 전체를 학습에서 제외했다.
