## Hotlap 시작 경로 확인

고정해 보관한 [공개 프로젝트 설치 문서](https://github.com/dasGringuen/assetto_corsa_gym/blob/ef0fa502bdd257fc2affad9361c02b3dbdfe1632/INSTALL.md)의
SHA-256을 source registry와 대조했다. 문서의 시작 경로는 **Challenge > Hotlap**이다.
공유메모리의 고정된 선언에서 AC_HOTLAP은3이다. 이를 `configs/ac-session-bootstrap.json`에
다음 시작 검증 항목으로 기록했다. race.ini의 TYPE 값을 추정해 쓰거나 현재 세션을 바꾸지 않았다.

같은 문서는 자동차 reset에 CSP가 필요하다고 안내한다. 현재 별도 CSP 설치를 수행하거나
요청하지 않았다. 처음의 제한된 주행 구간은 자동 reset 없이 검증할 수 있다. 공개 문서의
권장 보조장치 설정을 정확한 체크포인트 학습 manifest로 취급하지 않는다.

기어 버튼 연결·작은 창 설정을 적용할 재실행 시점에 대한 응답은 아직 대기 중이다.
