# 거리별 도로 굽음에서 코너 시작 찾기 · 2026-11-11

여섯 서킷의 영상 7,287묶음에서 4–20m를 2m 간격으로 나눴다. 후보 앞뒤의 도로 경계에서 접선 변화, 부호 있는 굽음, 도로 폭, 직선·이미 휜 곡선 대비 시작점 모형의 적합도를 읽었다. 단면이 끊기거나 앞뒤 관측이 부족한 후보는 사용하지 않았다. 실제 시작까지 ±2m 이내이며 방향도 맞는 후보를 양성으로 학습했다. 지도와 절대 위치는 학습 라벨과 채점에만 사용했다.
