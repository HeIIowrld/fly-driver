# 먼 거리 추정으로 너무 이른 예고 확인 · 2026-11-11

가까운 거리 모델과 기존 경보는 유지했다. 48m까지 학습한 모델을 추가해 요율 반전으로 생긴 새 경보 후보가 20m, 24m, 28m보다 먼지 확인했다. 20m를 넘고 두 모델의 거리 차도 6m를 넘을 때만 보류하는 조건도 시험했다. 평가할 서킷과 Spa를 두 모델의 학습 및 문턱 선택에서 제외했고, 문턱 선택용 개발 예측에서도 해당 서킷을 제외했다. Spa에서 먼 거리 확인 전 새 경보 후보는 58개였고, 48m 모델이 20m보다 멀다고 추정한 두 프레임은 모두 실제 코너 내부였다. 앞선 사후 비교에서 너무 이르게 예고한 611번은 실제 시작 20.48m 전에 48m 모델도 9.95m로 읽었다. 이 프레임은 요율 조건에서 이미 걸러졌다. 48m 학습이 전체 먼 접근의 거리에는 도움이 됐지만, 요율 조건을 통과한 오경보를 추가로 줄이지 못했다. [후보별 출력](../runs/vision-corner-far-distance-veto-20261111-01/rows.jsonl)

Spa 사후 점수 0.10에서 좌 4/22, 우 17/49, 결합 12/71, 오경보 80/605, 안정 예고 4/24곳이었다. 같은 점수에서 Imola 오경보 48건과 Zandvoort 오경보 67건도 그대로였다. 전체 7,287개를 채점한 30개 제외 비교 중 다섯 개에서 문턱이 선택됐으나, 모두 Magione 평가 지표가 기존과 같았다.
