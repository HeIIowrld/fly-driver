# FlyBrain

**초파리의 겹눈/운동 시각과 비행 유래 균형·운동 회로를 자동차라는 가상 몸에 연결한다. 차체 기울기·회전·하중·타이어 상태를 몸 감각으로 되먹임하며 조향·가감속과 빠른 레이싱 라인/랩타임을 학습한다.**

목표는 Assetto Corsa에서 서로 다른 트랙·차종·타이어/셋업에 적응하는 하나의 감각운동 회로다. 전후좌우 영상과 몸 감각으로 판단하며 지도·절대 위치는 교사·보상·평가에만 사용한다. 변속과 셋업 적응도 연구 범위에 포함한다.

## 현재 상태

2026-11-02 실험 기준:

- **교사:** BMW Z4 GT3 / Monza 유효 랩 1:52.314–1:52.515.
- **학생:** 적격 시연으로 오프라인 모방 학습 완료. 실제 자율 완주·다른 트랙/차종 일반화는 미검증.
- **다음:** 시각 병목 진단 → 공간·미래 예측 강화 → 다중 트랙 학습 → 학생 완주 → 차량 적응·랩타임 개선.

카메라·몸 감각은 bounded 정합 기준을 통과했으나 정확한 GPU 노출 시각과 물리 tick 동기는 미검증이다. 상세 수치와 한계는 [학습 보고서](docs/teacher-synchronized-learning-20261102.md)를 참고한다.
