# FlyBrain — 초파리의 감각·몸 제어 구조로 자동차 운전

**자동차를 초파리의 가상 몸으로 삼아, 초파리의 시각 인식과 비행 유래 감각·균형·운동 제어
구조를 도입하고, 그 구조로 조향·가속·감속·빠른 레이싱 라인과 랩타임을 학습한다.**
최종 검증 무대는 원본 Assetto Corsa 서킷의 학생 단독 주행이다.

일반 운전 모델의 성능이나 실측 연결망을 단순히 통과시킨 결과로 이 목표를 대체하지 않는다.
전체 초파리 공력 시뮬레이터를 먼저 완성하는 것을 선행 조건으로 추가하지 않는다.
실측 구조·생리 근거·기능 근사·차량 대응·학습한 변환을 구분한다.

## 몸과 감각의 연결

`네 시점 영상·차량 움직임 → 겹눈/운동 시각과 가상 몸 감각 → 비행 유래 균형·운동 회로 →
조향·가감속 의도 → 차량 조작 → 다시 감각으로 되먹임`

차체 기울기·회전은 몸 자세/회전으로, 하중·접지·타이어 상태는 몸 반응과 제어 여유로 대응한다.
정답 레이싱 라인·지도·world pose는 교사/보상/평가용이다. actor는 영상과 허용된 몸 감각으로 판단한다.
몸 자세/각속도와 절대 world heading을 구분한다.
